# AICoin K 线复刻规格

> 只讲 K 线图表本身：画什么、多大、什么形状、怎么响应手势。
> 与看盘无关的东西（社区、资讯、下单、预警、画线工具、账户）一律不收。

## 0. 怎么用这份文档

### 0.1 证据等级

每条结论后面的标注就是它的可信度，**冲突时按这个顺序**：

| 标注 | 含义 |
| --- | --- |
| `【实测】` | 在用户本人 iPhone 的 AICoin 专业版上量出来的。最高优先级 |
| `【已穷举验证】` | 反编译源码里穷举搜索过，确认是这个值 / 确认不存在 |
| `【源码】` | 反编译源码里读到的常量，附 `文件:行号` |
| `【推断】` | 从源码结构或资源推出来的，没有直接证据 |
| `【未找到】` | 找过了，没找到，别当结论用 |

真机实测 ＞ Mac 客户端 ＞ 反编译。反编译只用来拿实测看不出来的常量（上下限、公式系数、
高度分配），不能拿它代替实测。

## 1. 屏幕结构

### 1.1 竖屏整页（`res/layout/ui_kline_frg_ticker_kline.xml`）

从上到下：

| 区 | 高 | 说明 |
| --- | --- | --- |
| 顶部周期/工具条 | 34dp | 周期胶囊 + 右端齿轮（K线设置）。竖横屏共用布局 |
| 十字线信息条 | 34dp | **可选**，见下 |
| 图表本体 | 余下空间 | 主图 + N 个副图，内部按公式分高 |
| 底部指标栏 | 25dp | 副图指标的切换入口 |

十字线信息条不是浮动 tooltip，是**占位的一条**。但它只是三种模式之一——
「K线设置 → K线数据显示」有 `K线内 / 顶部 / 跟随K线` 三选一，`顶部` 才是这条。
`K线内` 画在图表区左上角，`跟随K线` 是跟手气泡。三种都要能切。

### 1.2 主图 / 副图的高度分配 `【源码】`

设副图个数为 k（k ≥ 0），图表区总高 H：

```
主图高 = 3H / (k + 3)
每个副图高 = H / (k + 3)
```

| k | 主图 | 每个副图 |
| --- | --- | --- |
| 0 | 100% | — |
| 1 | 75% | 25% |
| 2 | 60% | 20% |
| 3 | 50% | 16.7% |

**这是硬比例，不是可拖拽的分隔条。** 用户能调的只有「K线设置 → 竖屏高度」那根 SeekBar，
它调的是整个图表区 H，不是主副比例。

### 1.3 每个 pane 的内边距 `【源码】`

| pane | top | bottom |
| --- | --- | --- |
| 主图 | 40sp | 8sp |
| 副图 | 16sp | 8sp |

**这是固定像素留白，不是按价格区间比例外扩的。** AICoin 的价格轴**没有 ±5% 比例留白**
`【已穷举验证】`——`AbstractC2759w0.java` 里找不到任何 `range * 0.05` / `* 1.05`。
可观察的后果：留白量不随价格波动幅度变化，缩放时顶部永远是那 40sp 的像素条。

### 1.4 右侧价格轴宽度 `【源码】` `AbstractC2759w0.java:642`

```
起始宽 = 56dp
按最长价格文本增长，步长 8dp
上限 = 容器宽 / 3
图表绘制宽 = 总宽 − 价格轴宽
```

价格轴是**独占的一列**，K 线不画到它下面。

## 2. 坐标系与缩放

### 2.1 列宽（节距）`【源码】` `Rj/y1.java:290`

```
节距 itemWidth = scale × 12.0f     ← 裸像素，不是 dp
scale ∈ [0.4, 10.0]                ← 硬夹取，Wj/a.java:234
```

于是节距 ∈ [4.8 px, 120 px]。在 3x 屏上折合 [1.6 pt, 40 pt]，
一屏（约 390 pt 宽）能放 **约 10 ~ 244 根**。

> **`2000 根` 是达不到的。** 任务书里写的一屏 2000 根在 AICoin 上不存在，
> 它的下限就是 scale 0.4。按实际情况来，把实测值如实写进验收证据。

`scale` 是**全局单例** `C2760w1`，**跨周期保持**——切 1m → 1h 再切回来，缩放级别不变。

### 2.2 横向缩放 `【源码】`

- **不用系统 `ScaleGestureDetector`**，是把 AOSP 的实现逐字拷到 `Wj/b.java`。
- **quick-scale（双击后上下拖）被关掉**，framework 长按也被关掉。
- **缩放锚点 = 双指质心 focusX**。连续，无档位，无阻尼，无橡皮筋。
- 如果已经贴在最右（最新 K 线），缩放时**保持贴右**。

### 2.3 右侧留白与可滚范围 `【源码】` `C2765z.java:319,962`

- 可见区右边默认留 **30dp** 空白（最新一根不贴着价格轴）。
- 数据尾部追加 **400 根 NaN 占位**，所以能往右空滚 400 根的距离。
- 边界是**硬停，没有橡皮筋**（`forceFinished(true)`）。

### 2.4 平移与惯性 `【源码】` `Rj/C2746s.java:99`

```java
new OverScroller(context)                          // 默认摩擦 0.015，未调用 setFriction
viewConfiguration.getScaledMinimumFlingVelocity()  // fling 阈值，约 50 px/s
viewConfiguration.getScaledTouchSlop()             // 拖动判定阈值
```

**以下几种模式在抬手时一律不 fling** `【源码】` `C2746s.java:155`：
十字线、画线手柄、Y 轴缩放、价格窗口平移。只有普通横向平移才有惯性。

## 3. 价格轴

### 3.1 三种坐标模式

「K线设置 → 坐标」三选一：**对数 / 线性 / %**。
（`ui_kline_menu_log_chart` / `ui_kline_menu_normal_chart` / `ui_kline_menu_percent_chart`）

`【实测】` 默认档位下网格线是**等比且等像素**的 —— 实测三组相邻网格价格的比值恒定，
而像素间距也恒定 ⇒ **价格轴是对数刻度**。

### 3.2 刻度步长阶梯 `【实测】`

在 ln 空间里取「好看的步长」，实测到的三档：

| 主图 ln 跨度 | AICoin 取的 ln 步长 |
| --- | --- |
| ≈ 0.175 | **0.025** |
| ≈ 0.594 | **0.100** |
| （更密时） | **0.010** |

三档全部落在 **1 / 2 / 2.5 / 5 / 10 × 10^k** 的 nice-number 阶梯上。
**看盘现有的 `Ticks.niceStep` 正是这个阶梯，且是在变换后空间里取的——这块本来就对。**

**标签密度**：用上面两组实测反推，
`want` 必须落在使步长恰好是 0.025 / 0.100 的区间里 ⇒ **每标签占 30 ~ 39 pt**。
看盘现在的 `Chart.priceLabelPx = 46` 偏稀，应收到 **36 pt** 左右。`【实测反推】`

手动 Y 缩放状态下，横向网格线/价格标签数量 **×1.8** `【源码】` `AbstractC2759w0.java:555`：

```java
return ng.i.f(jg.c.c((double) i10 * d10 * (this.f19586s != 1.0d ? 1.8d : 1.0d)), 1);
```

### 3.3 自动范围：**包含指标线** `【源码】` `AbstractC2759w0.java:323`

min/max 先取自主指标集合 `.m`（MA / BOLL 等，**必取**）与辅助集合 `.a`，
**然后**才叠加可见蜡烛的 high/low。

有一个性能退化分支 `【源码】` `:354`：默认设置下**列宽 < 5 px 时不再扫描蜡烛高低点**，
价格范围退化成只看指标线。极度缩小时价格轴"看起来收窄"是刻意的，不是 bug。

### 3.4 上下缩放（Y 轴缩放）

**触发区域 = 右侧价格轴条**，不是主图区，也不是双指竖向捏合
（缩放检测器的 span 是各向同性的 hypot，捏不出纯竖向）。

判据：起点命中价格轴矩形 && `|dy| ≥ touchSlop` && `|dy| ≥ |dx|`。

公式 `【源码】` `Wj/a.java:318`：

```
yScale = yScale₀ × 2^( −(y − y₀) / max(axisHeight/4, 1) )
```

即**向上拖过价格轴高度的 1/4 就翻一倍**，很灵敏。

`【实测】` 在镜像窗口里向下拖 90 px（价格轴高约 208 px）：
公式预测 `2^(-90/52) = 0.301`，实测倍率 **0.310**。在读数误差内 ⇒ **公式实测确认**。

| 约束 | 值 | 来源 |
| --- | --- | --- |
| yScale 夹取 | **[0.03, 16.0]** | `【源码】` |
| 回吸 | `\|s − 1\| ≤ 0.02` 直接吸回 1 | `【源码】` `AbstractC2759w0.java:432` |
| 横向平移时 | **手动档保持**，不自动回到自动定标 | `【源码】` |

### 3.5 恢复自动定标的两条路

1. **双击价格轴**（不是双击主图）`【源码】` `Wj/a.java:88`
2. **点「A」按钮**

`【实测】` 「A」按钮是**圆角矩形弱徽章**，位在**价格轴列内**、「⏮」圆钮**上方**，
**只在手动档（yScale ≠ 1）出现**。

> ⚠️ 订正：早期文档说 A 贴在主图底边——错的；后来又说 A 不存在——也是错的。
> **两个按钮都存在，在价格轴列里上下叠放**：上面是圆角矩形灰底「A」，
> 下面是半透明灰圆的「⏮」（回到最新）。

**双击主图区（非价格轴）不做任何缩放** `【源码】`，只走一个宿主回调。

### 3.6 价格窗口平移

只有在 `yScale ≠ 1`（手动档）之后，在主图区里竖向拖动才变成**价格窗口平移**
`【源码】` `Wj/c.java`。自动档下竖向拖动不做事（或交还父容器滚动）。

### 3.7 范围切换动画 `【源码】` `Rj/C2764y0.java:36`

```java
setDuration(250L);
setInterpolator(new DecelerateInterpolator());
```

动画的 key 是**可见区间的首/尾时间戳**。滚动/缩放过程中区间一直在变，动画被 `end()`
立即收尾 ⇒ **实际观感是：平移时价格轴瞬时跟随，停下后的那一次范围变化才有 250ms 缓动**。

## 4. 蜡烛本体 `【源码】` `Rj/C2723k.java`

### 4.1 几何：实体占节距 2/3，影线固定 2 裸像素

```java
float fU = y1VarM.u();              // 节距
float fJ = y1VarM.J();              // scrollX mod 节距，亚像素相位
float f20 = (fU / 6) - fJ;          // 实体左边  = w/6
float f21 = (fU / 2) - fJ;          // 影线 x    = w/2（正中）
float f22 = ((fU * 2) / 3) + f20;   // 实体右边  = 5w/6
```

| 量 | 表达式 | 节距 12px 时 |
| --- | --- | --- |
| 实体宽 | **2w/3** | 8px |
| 左右缝 | w/6 各一侧 | 2px + 2px |
| 影线 x | w/2（正中） | 6px |
| **影线宽** | **写死 `strokeWidth 2.0f`，不随缩放变** | 2px |

影线宽不随缩放变这一条要照抄：放到最大（节距 120px）实体 80px 宽而影线仍是细线；
缩到最小（节距 4.8px）实体 3.2px、影线 2px，两者几乎一样粗。

### 4.2 涨的实体右边 −1，跌的不减

```java
// 涨：close > open
if (bottom - top >= 2.0f) canvas.drawRect(f23, top, f22 - 1, bottom, 涨笔);
else                      canvas.drawLine(f23, y, f22, y, 影线笔);
// 跌：
if (bottom - top >= 1.0f) canvas.drawRect(f23, top, f22, bottom, 跌笔);
else                      canvas.drawLine(f23, y, f22, y, 影线笔);
// 十字星：close == open → strokeWidth 2.0f 画一条横线
```

两个要点：

- **「留 1 像素缝」只做在涨的实体上**，跌的画满 `[w/6, 5w/6]`。密集时跌柱看着比涨柱宽 1px。
  这是实现的不对称，不是设计。抄不抄可以自己定，但别以为两边都做了。
- **实体高度不足退化成线，且涨跌阈值不同**：涨 `≥ 2.0f` 才画矩形，跌 `≥ 1.0f` 就画。

### 4.3 涨跌判定 = 收 vs 开

`close > open` 为涨，`close < open` 为跌，`close == open` 为十字星。
**不是**和前一根收盘价比。

### 4.4 空心 / 实心是设置项

「K线设置 → K线阳线：空心 / 实心」，默认**实心**。
空心时涨的实体改成 `STROKE` + 2px 描边；另有一个开关会把实体描边收到 1px。

### 4.5 落笔对齐：没有 +0.5，没有 density 取整，没开抗锯齿 `【已穷举验证】`

全链路直接用浮点坐标落笔。亚像素相位靠 `J() = scrollX mod 节距` 保留，
所以平移时蜡烛边缘会有亚像素抖动——这是它的真实观感。

## 6. 十字线

- 竖线**永远吸附到列中心**（不跟手连续移动）`【源码】`
- 横线**自由跟手**，停在抬手的位置
- 抬手后**十字线不消失，没有定时器**；再单击一次才收起
- 十字线**跨周期保持**
- 「K线设置 → 十字线：收盘价 / 选中价」决定横线吸到哪
- 「十字线添加距实时价标签」开关：标签内容 = `(十字线价格 / 实时价格) − 1`
