## 2. 价格轴是对数刻度（已实测确认）

网格线标签相邻**比值恒定**，不是差值恒定：

| 状态 | 标签 | 相邻比值 | ln 步长 |
|---|---|---|---|
| 原生截图 s02 | 79221.3 / 78433.0 / 77652.6 / 76879.9 / 76115.0 | 1.01005 | **0.010** |
| 手动缩放态 t00 | 80821.6 / 78826.1 / 76879.9 / 74981.7 / 73130.4 / 71324.8 / 69563.8 | 1.02532 | **0.025** |
| 缩放更开 t01 | 89321.7 / 80821.6 / 73130.4 / 66171.2 / 59874.1 | 1.10517 | **0.100** |

线性假设可排除：t00 的差值是 1995.5 / 1946.2 / 1898.2 / 1851.3 / 1805.6 / 1761.0，单调递减。

**网格线步长在 ln 空间取「好数」阶梯 1 / 2.5 / 5 / 10**（实测到 0.010、0.025、0.100 三档）。
像素间距实测等距（t00 ≈ 28.2 px / 0.025 ln ⇒ ≈1128 px per 1.0 ln；t01 ≈ 35 px / 0.100 ln ⇒ ≈350 px per 1.0 ln）。

## 3. 价格轴纵向缩放（上下缩放）

- **手势：在价格轴条带上单指上下拖动。** 镜像坐标 x≈295..320 为价格轴列。
- 向下拖 = **缩小**（价格区间变大、K线被压扁）。实测 (302,300)→(302,390)，90px 下拖，
  刻度从 1128 px/ln 变到 350 px/ln，缩放因子 ≈ **0.310**。
- 拟合：若锚点取绘图区顶边 y≈259，则 factor = (y0-yTop)/(y1-yTop) = 41/131 = 0.313，与实测 0.310 吻合。
  → **推断纵向缩放是「以绘图区顶边为锚的距离比」模型**，待再取一组数据验证。
- **状态会持久保留**：切到 App 切换器再切回来，手动缩放态还在。
