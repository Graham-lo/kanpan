# 用户真机图表复核 · 2026-09-14

本轮直接操作 iPhone 镜像。参数以用户当前手机为准。截图与哈希见 manifest.json；镜像画面带系统窗口缩放，不能当原生像素或精确 pt 测量。原生历史证据另见 ../s02-native.png。

| 核验 | 证据 | 结果 |
|---|---|---|
| A 自动定标 | 01、02 | A 消失，价格范围重新贴合；历史时间范围保留。 |
| 单击十字线 | 06 | 单击显示，松开保留，再单击关闭。当前是选中价；X 对齐 K 线，Y 取点击价格。 |
| MA | 04、05 | 生效 10/30/120/256；MA5、MA90 关闭。线型弹窗有色板、透明度及四档线宽。 |
| MACD | 07–11 | 10/30/9，DIF/DEA/MACD 三项启用，透明度 100、第一档线宽。一次误触 DEA 已恢复并复核，未点保存。 |
| 成交量均线 | 12 | 5/10/30/60/120 全开。 |
| 右下圆形按钮 | 13、14 | 展开/收起「主力/大额/筹码」侧栏，主绘图区随之变窄/恢复。不是回到最新。该业务侧栏不在本项目实现范围内。 |
| K 线设置 | 15–20 | 对数、靠右、实心、选中价、最小线状、开盘8点；网格/倒计时/指标区域自适应关闭。 |
| Y 轴翻转 | 18、21、22 | 设置开关表示“允许点击坐标区翻转”，并非当前倒置状态。轻点主图右轴翻转，再点恢复。副图翻转开关关闭。 |
| 周期切换 | 23、24 | 1h→4h→1h；外框保持，返回时间窗发生变化，不能声称保持绝对历史时间。 |
| 页面滚动 | 25 | 滚动会收起上方大行情头，显露 VOL/OI/MACD 三副图；不是 Y 轴缩放。 |
| 横竖屏 | 26、27 | 横屏顶部紧凑周期行，主图+VOL 可见；退出后返回竖屏，时间窗变化。不能声称所有副图始终适配到一屏。 |

## 未完成实测

当前镜像 API 不提供可控的两指触点序列。单指 drag 未得到可重复的 Y 轴缩放测量，因此不以它推导 iOS 缩放曲线。安卓公式只作为待校准的实现依据。惯性衰减、边界手感、所有画线工具、其它指标的全部操作未完成真机逐项覆盖。

查看过程中曾恢复 Y 自动定标、切换周期、进出横屏并测试翻转；原先手动价格范围与历史视野没有精确恢复。所有读到的持久图表参数以 USER-CHART-PROFILE.json 为准，没有执行恢复默认操作。
