## 约定

- 原型做完要覆盖全部状态，并部署到主 VPS 的 `/var/www/kanpan/ui/` 让用户在浏览器里看。
- 配色只在青苔 / 陶土两套里做；字号与元素尺寸克制；K 线与指标底座不是设计对象。
- 旧原型 `src/` 的 `chart.js` 与 `KanpanCore` 的函数名基本对应（`BarSeries`、`clamp`、`layout`、`candleWidths`、`niceStep`、`flingAt`），核对指标数学时仍可拿它当参照。
