# TradingView 付费功能整理（2026-09-29，给网页版选功能用）

按 2026 年 TradingView 官网与几家对照站整理（来源见文末）。四档：Essential $14.95 / Plus $34.95 /
Premium $69.95 / Ultimate（更贵，主要是配额再翻倍）。整理的目的不是照抄套餐，而是回答一个问题：
**它们收钱的功能里，哪些是交易员真的天天用、Hkline 网页版值得做的。** 判断按看盘的既定规矩：
不接 AI、不做量化判定、只做实用的、少让用户设置。

## 一、按值得做的程度排

### 第一档：网页版应该做（TradingView 里是 Premium / Plus 才有，我们数据都在手里）

| 功能 | TV 哪档才有 | 它解决什么 | Hkline 网页版怎么做 |
|---|---|---|---|
| **成交量分布（Volume Profile）** | Plus 起，固定区间 / 可视区间 / 逐根 三种 | 看「哪个价位成交最厚」，比水平线画支撑压力靠谱 | 主图右侧叠一层横向柱，POC（最厚价位）与价值区高亮。数据是我们自己的 K 线聚合，不用额外接口 |
| **多条件提醒** | Plus 起（最多 5 个条件） | 「价格到 X 且 资金费率 > Y」这种组合 | 提醒对话框里加「同时满足」第二条件；响一次就删，不做重复提醒 |
| **提醒配额** | 20 / 100 / 400 / 1000 条 | 免费版 20 条根本不够看几十个币 | 我们没必要设上限；网页版提醒面板已经是按品种分组的总表 |
| **多图布局** | 每页 2 / 4 / 8 / 16 张图 | 一屏盯几个品种或同一品种多周期 | 原型已有 1 / 2 / 4；2K 屏再加 6 与 8（3×2、4×2），联动光标与联动品种做成开关 |
| **图上指标数量** | 5 / 10 / 25 / 50 个 | 免费版 5 个指标一下就满 | 网页版副图放宽到四个（这一版已改），主图叠加不限 |
| **K 线倒计时 + 结算倒计时** | 部分要 Plus | 当前 K 线还剩多久收、离下次资金费还剩多久 | 价格轴标签下已有 K 线倒计时；侧栏详情里有结算倒计时 |
| **二级 K 线（秒级）** | Premium | 剥头皮时看 1 秒 / 5 秒 / 15 秒 | 币安永续 WS 有 aggTrade，可以自己聚成 1s / 5s / 15s；只给这三档，不做自定义秒数 |
| **交易回放（Bar Replay）** | 免费版只给日线以上，日内要付费 | 把行情倒回某一天从头看一遍 | 已并入「复盘」页；按用户定的规矩不做逐根步进，只拖进度与关键点跳转 |
| **历史数据深度** | 日内历史 180 天 / 365 天 / 全部；每图 10K / 20K / 40K 根 | 免费版 1 分钟只能回看几周 | 服务端已经在存 K 线，网页版按需拉即可；这是我们天然的优势，不用省 |

### 第二档：值得做，但要按看盘的规矩改一下形态

| 功能 | TV 哪档才有 | 备注 |
|---|---|---|
| **Volume Footprint（逐格成交明细）** | Premium | 每根 K 线里每个价位的主动买 / 卖量。和「主力订单流」是一家人（都是聚合真实成交），但信息密度极高，只在 1 分钟以下周期、图放大后才展示，默认关 |
| **TPO / 市场轮廓（Market Profile）** | Premium | 按时间段字母堆出来的价值区。和 Volume Profile 二选一即可，交易员更常用 Volume Profile；先不做 TPO |
| **成交量蜡烛（Volume Candles）** | Premium | 蜡烛宽度随成交量变。看着新鲜、用得少，按「不做华而不实」的规矩不做 |
| **自定义周期** | Plus 起 | 比如 7 分、45 分。我们周期条已经有「更多」弹层，加一个输入框就行，成本低 |
| **自定义公式 / 价差图** | Plus 起 | 输入 `BTCUSDT/ETHUSDT` 画比值。对做配对与强弱的人很实用；数据是两条 K 线相除，实现简单 |
| **图表数据导出 CSV** | Plus 起 | 把当前图的 K 线与指标值导出。网页版顺手做，一个按钮 |
| **保存布局数量** | 5 / 10 / 无限 | 我们的布局跟账号同步，不设上限 |
| **盘后 / 盘前（Extended hours）** | Plus 起 | 只对传统股票有意义；币安美股永续是 24 小时的，不需要 |

### 第三档：明确不做

| 功能 | 原因 |
|---|---|
| **自动形态识别（Auto Chart Patterns）** | Premium。它是「判定」不是「展示」——头肩顶、三角形这种由算法框出来，与「图表只展示聚合数据、不做量化判定」的规矩冲突 |
| **AI 类（Pine 生成、策略 AI 优化）** | 不接 AI |
| **策略回测 / Pine 编辑器** | 看盘不做量化 |
| **无广告、多端登录数** | 不是功能 |
| **Renko / Kagi / 砖形图 日内版** | 用得少，手机端也没做 |

## 二、指标：TradingView 上真正被高频用的（免费和付费都算）

TV 内置指标本身是免费的，付费买的是「一张图上能叠几个」。下面是社区使用率最高、Hkline 还没有的：

| 指标 | 用途 | 建议 |
|---|---|---|
| **VWAP（成交量加权均价）** | 日内基准线，机构最常用的一条 | 做，主图叠加，带上下一 / 二倍标准差带；锚定 VWAP（从某根 K 线开始算）作为画线工具的一种 |
| **Volume Profile** | 见上表 | 做 |
| **ATR（真实波幅）** | 定止损距离 | 做，副图，一条线 |
| **OBV / CVD（累计成交量差）** | 看主动买卖谁占上风 | CVD 更贴合加密圈，用 aggTrade 主动买卖聚合；副图一条线 |
| **超级趋势（Supertrend）** | ATR 通道翻转的趋势线 | 做，主图叠加，参数只给周期与倍数 |
| **一目均衡表（Ichimoku）** | 云层支撑压力 | 做，主图；这是亚洲市场用得多的 |
| **StochRSI、CCI、威廉指标** | 摆荡类 | 便宜，一起补上 |
| **持仓量 / 资金费率历史** | 币圈特有，TV 上只能靠第三方脚本 | 我们服务端就有，副图直接画；这是 TV 做不到的差异点 |
| **多空比 / 大户持仓比 / 主动买卖比** | 币安 fapi 公开数据 | 侧栏详情这一版已展示当前值；副图画历史曲线是下一步 |

## 三、这一版原型已经落地的

- 副图默认从约 200 px 压到 136 px（画布高的 11%，夹在 96–136），主图拿剩下的全部；四个副图也只占 736 px 里的 544 px。
- 副图上限从三个放到四个（网页版副图矮了、屏幕高）。
- 侧栏详情从四格扩成十二格：持仓量、持仓 24h 变化、24h 成交额、资金费率、下次结算、24h 笔数、多空人数比、大户持仓比、主动买卖比、标记价、指数价、基差；上面加一条 24h 最低—最高的区间条，圆点标当前价落在哪。
- 三套皮肤（青苔 · 冷，出厂；陶土 · 暖；经典 · 白）各浅深，与手机端同名同色，在「我的 › 外观」与原型控制台里切。
