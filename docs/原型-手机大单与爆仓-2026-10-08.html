01主线：图上大单签 → 点一下 → 整页「大单与爆仓」

没有新 tab、没有新顶级页。大单与爆仓长在行情页上：图上每根 K 线最多一枚签，点签（或从分析面板）拉出弹层，一开就是整页、每张卡都摆出来，不分半屏 / 上拉两步（2026-10-08 用户试用后定）。

02十字线联动 · 周期粗细 · 分析面板入口

按住图读十字线时弹层跟着那一根走（「本根」变成「12:30」）；反过来在弹层「逐根」条上点一根，图上十字线也跳过去。1 分钟图签很密时只剩点与三角，金额签只给最顶那档；1 日图签很少、每枚都带金额。

03全部状态：首次加载 · 服务端没跟踪的品种 · 断网重连 · 现货没有爆仓 · 今日没爆仓 · 数据停了

每个状态都有自己的样子，不弹窗、不讲解。拿不到服务端历史时本机照样算（只是窗口短），不把功能整个关掉。

04三套皮肤 × 深浅

弹层用全 app 共用的琉璃料（青苔冷绿光斑、陶土暖纸纹、经典白底无光斑，深色不画光斑）；涨跌一律绿涨红跌。

05为什么这样设计（给交易员的价值，按优先级）

  1. 一眼知道「此刻谁在打」。 弹层第一块是本根 K 线的买卖对撞条：买从左、卖从右，交汇点就是净方向，交汇点上一颗「净买 +1.2M」药丸。条永远铺满宽度（按买卖占比分），所以不管金额大小，哪边占上风一瞥就有；绝对金额写在两端。电脑网页版用的是按 √ 金额定长度的条，手机上没那个宽度，改成占比条 + 两端数字更快读。
  2. 图上不再「下一根就没了」。 签按根生成，数据来自分钟桶 + 服务端三天历史，刷新 / 后台回来 / 换周期都还在。每根最多一枚、只画主导方向、三档（点 / 三角 / 三角 + 金额签），档位按近 300 根的相对分位定，所以山寨币和 BTC 看起来密度一样。
  3. 爆仓只回答一句话：「1 小时多单 / 空单爆仓额、今日最大单笔在哪个价」。一条多单爆仓 / 空单爆仓对撞条 + 一行「今日最大单笔」，下面另有 24 小时时间轴。不做热力、排行、推送。
  4. 价位要看「钱堆在哪」而不是逐笔。 整页「价位」是现价上下 ±5 档的竖梯：左边买单堆、右边卖单堆、梯子末端挂着现有的挂单墙药丸。手机竖屏天然适合梯子，这是电脑版横条没有的。
  5. 少点：签 → 整页是一下；分析面板 → 「大单与爆仓」也是一下；改门槛沿用现有的编辑页（右上「门槛」药丸）。没有任何新设置项，开关只有一个「图上大单签」（出厂开）。

08交互细节清单（施工项）

  • 签的命中区 44 × 44 pt（签本身 6–16 pt），两枚签命中区重叠时取离手指近的那根。
  • 点签反馈：触感 .selection；签放大到 1.3 倍 120 ms 再回；弹层 280 ms 弹簧（damping 0.86）升起；「每根」条滚到那根并高亮 1.2 s。
  • 实时一根的签：新大单落进来时签外圈扩散一道 8 pt 光环（600 ms，ease-out），减少动效时改为 150 ms 的透明度闪一下。
  • 对撞条动画：交汇点位置变化 240 ms ease-in-out；金额数字滚动 200 ms；净药丸换色不动画。
  • 十字线联动：按住图时弹层标题从「本根」变「12:30」，数值随手指实时换，不节流；抬手 3 s 后回到本根（渐变 300 ms）。
  • 逐根条：横向可滚，默认停在最右；点一根 → 图上十字线跳到那根 + 触感 .light；最右那根顶部有一粒呼吸点表示未收线。
  • 弹层档位：只有一档，整页 780 pt（屏幕矮时让出顶上安全区），盖住底栏、压暗背后；内容可滚，滚到顶继续下拉过 110 pt 就关，不够就弹回。
  • 默认值：图上大单签 出厂开；弹层一开就是整页；门槛沿用现有默认（现货 750K / U 本位永续 2.5M …，按品种）。
  • 撤销 / 误触：弹层没有破坏性操作；门槛编辑页沿用现有「恢复默认」。
  • 可达性：字 ≥ 11 pt；签颜色之外还有形状（点 / 三角 / 带字签）区分档位；减少动效时全部动画关闭；VoiceOver 朗读「买方大单 1.2M，12:30 这根」。
  • 横屏画线台：签照画，不开弹层（横屏保留给画线）。

10数据口径（三端一致，直接复用网页版验证过的）

  • 大单：三家（币安 / OKX / Coinbase 现货）逐笔合并，≥ 门槛 ÷ 50 计入分钟桶，按根汇总买 / 卖金额与笔数。历史走 GET /v1/market/orderflow/flow（3 天），实时走已有的成交流；服务端没跟踪的品种只用本机从打开起的桶。
  • 签档位：近 300 根的 P85 / P95 / max(P99, 3 × P95)，绝对地板 门槛 ÷ 5。一根一枚，落主导方向。
  • 价位梯：1 分钟大单行 × 1 分钟 K 线 (高 + 低 + 收) ÷ 3 落进步长桶，最新一桶用实时覆盖；墙来自现有挂单墙。
  • 爆仓：GET /v1/market/orderflow/liq?base=&from=&to=（币安 + OKX，分钟聚合，3 天），30 s 一取；多单爆仓用跌色、空单爆仓用涨色。现货品种不请求。
  • 停更判定：实时流 20 s 没有新成交且不在休市 → 数字变 ink3、写「数据停于 hh:mm」，不弹提示；恢复后无感回到正常。

12施工说明（定板后派 Opus 子代理，iOS 与手机网页各一条）

  1. iOS · 图层：KanpanChart/OrderFlowGroup.swift 旁新建 BigTradeSigns（纯函数：根 → 档位 / 方向 / 位置，含翻侧与退档），ChartRenderer+OrderFlow 画签；数据从 KanpanData/OrderFlow/OrderFlowFeed 加分钟桶（照网页 tradeFlow.ts 的 Cell），历史接 /flow。签的命中走现有图层手势，回调宿主开弹层。
  2. iOS · 弹层：Kanpan/Kanpan/OrderFlow/BigTradeSheet.swift（一档整页，PanelHost 琉璃底 + PanelCard），四张卡各一个 View，数据模型一个 BigTradeSummary（本根 / 近 1 小时 / 今日 / 每根 / 价位 / 爆仓）；爆仓源 LiquidationFeed（30 s 轮询 /liq）。十字线联动走现有 CrosshairBand 的读数回调。分析面板「主力订单流」分组加「图上大单签」开关（Prefs.bigTradeSigns，出厂开，跟账号同步）与「大单与爆仓」行。
  3. 手机网页版：照 iOS 复刻（Web/src/m/），分钟桶与档位算法直接复用桌面版 bigTags.ts / tradeFlow.ts 的纯函数，只换画法与弹层。
  4. 测试：档位 / 翻侧 / 退档的纯函数测试（照 Web/tests/orderflow-bigtags.test.ts 搬）；弹层三档状态快照；十字线联动 UI 测试；画线交叉（签与画线文字 0 相交）；1 分钟 × 500 根性能（整帧 p95 不比现在多 1 ms）。
  5. 验收：模拟器 iPhone 16 Pro / 17 Pro Max 三皮肤深浅 + 上面全部状态截图进 docs/acceptance/；真机在手边才装。
