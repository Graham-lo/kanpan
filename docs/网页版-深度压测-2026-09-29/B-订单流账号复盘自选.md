# 网页版深度压测 · B 路（订单流 / 账号与同步 / 复盘 / 自选 / 板块 / 我的）· 2026-09-29

主账号 `webstress_b0929`；一次性账号 `webstress_b0929_1`（走查用）与 `webstress_b0929_<n>`（regress 注销断言每轮自建），测完都已注销。
本机 `vite --port 5182` + playwright-core 驱动本机 Chrome（2560×1440，无头）。没有改服务端、没有开模拟器。

## 做了什么

1. **自动化**：`regress.mjs flow account review watch sectors` 先跑一轮找红，逐条从根因修，再在 rebase 到最新 main 之后整轮复跑。
2. **订单流走查**：BTC / ETH / WIF / NVDA / XAU 各开订单流，看梯子、成交流、大单、24h 两块、悬停卡、右键拖偏后行情跳动会不会把图拽回、双击回中；八块小部件全开；侧栏拉到 320 / 360 / 400 宽量详情卡截断。
3. **200 次随机切品种**：记 WS 开关数、订阅残留、内存、控制台报错；随后量了每次切换打出去的请求（10 次切换 149 个请求）。
4. **账号走查**（一次性账号）：注册、同名再注册、密码错、用户不存在、以「手机」身份并存登录、设备页列表与「下线」、改密码（错 / 对）、旧密码失效、注销（错密码 / 两步确认）、注销后服务端登录被拒；另由 regress 覆盖：令牌续期、access 过期直接进复盘、退登保留本机、退登期间画线再登录上云、另一台电脑顶掉不死循环。
5. **两个标签页**：同一浏览器开两页，一页切深色、另一页切周期，再开第三页看盘上留下的是什么。
6. **限流模拟**：用 playwright 拦截把 fapi 全部回 429（不去真打币安额度），看冷却期内还发不发请求、界面说什么、放开后能不能自己恢复。
7. **深色逐页**：板块、复盘、我的在陶土深色下截图并量低对比文字。

## Bug 与修复（同一提交，提交号见文末）

1. **复盘找相似「后来怎么走」永远停在「载入后计算」**（产品 bug，regress 抓到）
   根因：`pages/review.ts` renderDetail 在「这一段已经在放就直接返回」之前，先用 `null` 重写了页脚；列表一刷新或再点同一行，载入后算好的那格被冲掉，而且因为不会重新载入，再也回不来。
   修：正在放的这段当场用已拉到的 K 线补算 `afterMove(plan)`。复跑 regress review 段通过。

2. **订单流侧栏八块全开时成交流只剩 5 行**（可用性 bug）
   根因：`orderflow/sidebar.ts` 收缩顺序把成交流排得太靠前、各块没有像样的下限。
   修：收缩次序改为 提醒 → 大单 → 盘口 → 24h 两块 → 成交 → 自选，下限成交 ≥ 8 行、自选 ≥ 5 行、盘口 ≥ 4 档；实在放不下（小屏）侧栏可纵向滚动兜底。2560×1440 下实测 1384/1384 无滚动、成交 8 行、自选 7 行、大单 3 行。vitest + regress 断言。

3. **窄侧栏品种详情数字被截断**（指派项）
   复现：侧栏 320 宽时 12 格截 9–10 格，360 宽截 3–5 格，400 宽不截。
   修：侧栏 < 400 px 时详情改两列、高度 +48（`partsFor(width)` 给布局表，`fitStack` 按实际宽度取，`.detail.two` 两列栅格）。320 / 360 深浅色实测 0 截断。截图 `B-订单流-窄侧栏320-详情两列-深色.png`、regress 截图 `网页版-2026-09-29/订单流-详情-窄侧栏两列.png`。

4. **快速切品种撞币安 429，而且撞了还接着打**（产品 bug，有封 IP 风险）
   复现：200 次切换的后段 19 条 429；终态图上「取不到 ZECUSDT 的 K 线（429）」、自选写「连不上币安合约接口」、梯子空（`B-200次切换-修复前429终态.png`）。
   根因：每次切换约 33 合约权重（depth 1000 = 20、klines 1500 = 10、另有 OI 等）+ 现货深度 5000 档 250 现货权重；超过约 72 次 / 分钟就超 2400。更要命的是 429 之后没有任何退让：深度快照每 3 秒重拉、每次切换照打 K 线与详情——这正是币安升级成 418 封 IP 的形状，而这台电脑和用户手机常是同一出口，封了连 iOS 端也取不到行情。
   修：新增 `market/limit.ts` 限流闸，任一主机回 429 / 418 即按主机冷却（有 Retry-After 按它，读不到 429 记 60 秒、418 记 5 分钟；fapi / dapi / 现货 / OKX 各算各的）。冷却中 `j()` 与 `getJSON` 本地直接失败、不发请求；深度快照等冷却完再拉；品种表与 K 线空态改说「币安限流了…冷却后自动重试 / 重取」并到点自动重取，不再误报「连不上币安合约接口」。vitest `rate-limit.test.ts`（冷却期内 20 次请求 fetch 只被调 1 次）。模拟 429 截图 `B-限流-冷却中.png` / `B-限流-自动恢复.png`。

5. **取 K 线失败后重取回来，图只露出最老的几根**（产品 bug，修 4 时发现）
   根因：`chart/chart.ts` setData 判「同品种同周期 = 刷新」就沿用视口；失败时先 `setData([])` 把视口定在空数据的下标上，重取回来的 1500 根被当成刷新，只露出几十天前的那几根，价格轴也停在那时的价位（BTC 显示 64k，现价 83k）。点「重试」一样会中。
   修：上一份为空时按新品种摆视口。vitest `chart-setdata.test.ts`。

6. **同一浏览器两个标签页互相覆盖本机状态**（产品 bug，会丢画线 / 自选 / 提醒）
   复现：标签 1 切深色，标签 2 切 4 时，新开标签 3 → 主题回到浅色。
   根因：没有任何跨标签处理，每页内存里一份 st，谁 save 谁把整份写进同一个 localStorage 键；后台那页一存（同步拉到东西、提醒响了、切个周期）就把另一页刚改的整份盖回旧的。
   修：`app/store.ts` 每次写盘顺带记「写的这页最近一次被人动（按键 / 按下指针）的时刻」；别的页写了而它比我更近被人动过 → 我这份旧了、不再写盘，人回到这页（焦点、可见、或直接点按）时整页重载；我更近被人动过（对方是后台拿旧内存自动存的）→ 立刻写回。不依赖 `document.hasFocus()`（并排窗口、无头浏览器里不可靠，第一版就栽在这上面）。修后同一复现：三页都看到深色 + 4 时。vitest `tab-guard.test.ts`。

7. **网页没有「注销账号」**（功能缺口）
   iOS `AccountFeature` 有注销（DELETE `/v1/auth/account`），网页「我的 · 账号」没有入口。补上：填当前密码、点两下确认（第一下按钮变「再点一次，确认注销」，5 秒内再点才删），删完回到未登录、本机数据留着。走查 + regress 断言（每轮自建一次性账号注册 → 注销 → 服务端登录被拒）。

8. **regress 脚本自身两处错**：订单流拖图用左键（自动模式下左键只横移，应右键纵移）；复盘「空账号」在刚补传一条观点后按 0 条断言。已改，并新增「右键拖偏 5 秒后行情跳动不把图拽回中间价」断言。

## 没修的与原因

- **板块页有几个板块没有走势线**（比特币生态、基础设施、粉丝代币、DeFi 其他）：时间盒内没查，推测是服务端历史覆盖不足；不影响涨跌与排序。「成员不到三家沉底」的排序是 iOS 定下的规矩，不是 bug。
- **切换时的请求量本身没减**：限流闸解决的是「撞了还打」与误报，没有把每次切换的 33 权重降下来。正常人切品种远到不了 72 次 / 分钟，只有脚本或按住方向键连切才会撞；若要再压，可以把详情五个接口、OI、关键价位、深度快照延到品种停稳约 0.5 秒再取——这会改变首屏节奏，留给主窗口定。
- 服务端：本路没有发现需要改服务端的问题；`/v1/market/orderflow/flow` 线上 404 是已知项，相关空态不算 bug。

## 假设

- 两个标签页以「最近被人动过的那页」为准、旧页切回时整页重载——重载约 1–2 秒，换来不丢数据；没有做「热合并不重载」，那要把全部页面的重渲染接上，风险大。
- 429 冷却按主机算、读不到 Retry-After 时 60 秒（币安 CORS 不暴露该头，实际多半走 60 秒兜底）。
- 注销的两步确认沿用网页里其它危险操作的做法（按钮二次确认），没有弹框。

## 终轮（rebase 到最新 main 之后）

54 项，失败 11 项，**都不是新代码的回归，是同一出口 IP 被币安限流了**。跑这一轮时，A 路的 soak 压测、A 路整套 regress 和 C 路都在本机上并行打币安。日志里有 429，后段还有 **418**（封 IP）：

- 订单流 / 账号 / 板块三段的「控制台无报错」挂了，原因是 429 / 418 资源错误。
- 账号段「改自选 15 秒内上云」、两条续期后推送、「退出登录留本机」挂了，原因是品种表被 429 挡住，自选与画线建不出来。
- review 段是「记一笔」弹窗等不到，原因是没有 K 线。
- watch 段 400 宽六列、跑完两条挂了，原因同上，是品种表空。
- 板块走势线 15 秒内没出来，原因是 418。

同样这几段，在限流之前各自跑过都是绿的：

- flow 段修后复跑全绿。
- review + account 复跑 48 / 48。
- watch 与 sectors 第一轮全绿。

跑完后单次探测币安已恢复（fapi 返回 200，used-weight 55）。机器上当时还有 3 个别路的 node 压测进程在跑，我没有再跑第五轮去叠加请求。

**给主窗口的风险提示：** 几路压测同时直连币安，会把本机出口 IP 打到 418。用户手机和这台电脑常常共用出口，这时 iOS 端也会取不到行情。

- 本提交的限流闸只能让「本页在撞了之后不再打」。
- 它管不住别的 worktree 里还跑着旧代码的 dev server，也管不住多个浏览器上下文各自首轮并发打出去的请求。
- 建议以后同一时刻最多一路跑直连币安的回归，或者改走网关线路。
