- **一个全局选择，管所有价格提醒**，不按条设置。四档：「默认」（系统声）+ 三段自备短音「清脆」「电子」「玻璃」。不做振动开关、不做重复响铃、不做每条提醒单独选。
- **入口只有一个**：「提醒」总表页（`Kanpan/Kanpan/Alerts/AlertListPage.swift`，从 `Panels/SettingsPanel.swift:81` 进）顶部加一行「提醒铃声 · <当前>」→ 推一页四行单选（勾选在右）；点一行立刻试听一遍（`AVAudioPlayer`，`.ambient` 类别，静音键拨下就不响）并选中。中文标签，不加解释文案。
- **随人走**：`Prefs` 新增 synced 字段 `alertSound`（`"default" | "crisp" | "electronic" | "glass"`），按 `Kanpan/Kanpan/Settings/Model/PrefsFieldPlan.swift:56-71` 登记；服务端 `Backend/kanpan-api/src/sync.rs:50 SETTINGS_FIELDS` 同步加。
- **两边都要响对**：
  - 客户端本地摆出来那一下：`Kanpan/Kanpan/Alerts/AlertNotifications.swift:107` 的 `content.sound = .default` 改成按 `alertSound` 取 `UNNotificationSound(named:)`。
  - 服务端推送：`Backend/kanpan-api/src/apns.rs:111` 写死 `"sound":"default"`。`push_alert`（`apns.rs:109`）加 sound 参数，`alerts.rs` 触发时从该用户同步下来的 settings 里读 `alertSound`（读不到 → `default`），映射成文件名。部署 kanpan-api（备份 → rsync → `cargo build --release` → `ops/install.py` → `systemctl restart` → 只读验证），报告里贴一条真实推送的 payload。

- **音频文件**：仓库里没有任何声音资源。用脚本合成（`Tools/make-alert-sounds.py`：正弦/包络合成 → wav → `afconvert -f caff -d ima4`），每段 0.6～1.5 秒、响度归一、≤30s 上限内、文件名 `alert-crisp.caf` / `alert-electronic.caf` / `alert-glass.caf`，放进 app target 的资源；脚本进仓库让它可重建。三段要听得出区别、不刺耳。
