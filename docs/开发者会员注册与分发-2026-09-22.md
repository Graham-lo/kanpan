# 开发者会员注册与分发（2026-09-22）

**前提：不上架 App Store。** 目标是注册 Apple Developer Program 会员，然后把包发到
自己和几位朋友的 iPhone 上。下面每一条都对照过当前工作树的事实（bundle id、
Info.plist、本机证书），不是通用教程。

## 1. 注册会员（个人，¥688/年）

1. 在 iPhone 上装 **Apple Developer** app，用当前给工程签名的那个 Apple ID
   （`eth2022df@gmail.com`，现在挂在免费个人团队 `27Y32PT2HZ` 下）。
2. 该 Apple ID 必须已开双重认证。
3. 在 app 里选 **Individual**，填英文姓名与地址（要和证件一致），做证件 + 人脸识别。
4. 同意 Apple Developer Program License Agreement，用支付宝 / 微信支付 ¥688。
5. 一般 24–48 小时通过，多数不到 24 小时。

注意：

- 全程在同一台设备上完成，人脸识别找光线好的地方。
- 年费是**自动续费的订阅**，断缴 = 证书与 profile 失效、TestFlight 停。
- 个人 vs 公司：公司要邓白氏编码（D-U-N-S，免费但要几天到两周）加法人授权。
  只有 organization 身份才能做「虚拟货币存储 / 钱包」类 app；Hkline 不存币、
  不撮合，个人身份足够。
- 不上架就不牵扯 ICP 备案、App 名称查重、发布区域这些事。

## 2. 会员立刻带来的三件事

1. **真机 profile 从 7 天变 1 年。** 免费个人团队签出来的包 7 天就失效，
   现在 `make install-release` 装上去的包能用一整年。
2. **能建 APNs Auth Key（.p8）。** 这解掉了「没有 APNs 密钥、推送只能做成可插拔」
   那个长期约束：`Backend/kanpan-api` 才能真发远程推送，
   `Kanpan/Kanpan/Alerts/PushRegistration.swift` 那条链路才算通到底。
3. **能用 TestFlight。** 朋友自己点一下就装上，不用连电脑、不用收 UDID。

## 3. 不上架的情况下，怎么发给朋友

| 方式 | 人数 | 要不要 Apple 审核 | 代价 |
| --- | --- | --- | --- |
| **TestFlight 内部测试（推荐）** | 100 | **完全不用** | 构建 90 天过期，到期重传一个 |
| Ad Hoc | 每类设备 100 台 / 年 | 不用 | 要逐台收 UDID，装起来麻烦，换设备要重签 |
| TestFlight 外部测试 | 10000 | 首版要过 Beta App Review（2026 年普遍 2–7 天） | 3 个朋友没必要，且会碰上 3.1.5 加密货币那套审查 |

**走内部测试。** 个人（Individual）会员也能在 App Store Connect 的
「用户与访问 / Users and Access」里添加用户——个人账号添加的用户只拿到
App Store Connect 权限，不算进开发者团队，但足以当内部测试员。流程：

1. 在 App Store Connect 建一条 app 记录（只要 bundle id 和名字，
   不填截图、不填隐私标签、不提交审核）。
2. 把朋友的 Apple ID 邮箱加进「用户与访问」，角色给 Developer 或更低。
3. 建一个内部测试组，把他们拉进去。
4. 上传构建 → 他们的 TestFlight app 里直接出现，点一下就装。

构建 90 天过期，所以大约每三个月传一版新的；反正版本本来也在动。

   走 Ad Hoc 用 Ad Hoc 类型），在 `Makefile` 里补一条 archive / export-ipa /
   上传 TestFlight 的通路。
