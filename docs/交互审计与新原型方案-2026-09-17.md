## 一、诊断：现版 15 处硌手的地方

按用户一天里碰到的先后排序。每条给出现象、代码位置、为什么在中国用户语境下成问题。

| # | 现象 | 位置 | 为什么是问题 |
|---|---|---|---|
| 1 | 冷启动落在「自选整页盖层」上，第一帧不是上次看的那张图 | `Kanpan/Kanpan/Main/MainScreen.swift:164-185` | 国内用户绝大多数是「拿出手机瞄一眼 BTC 就收起来」的碎片式看盘，启动第一屏应该就是上次那张 K 线。自选页是「换品种」的地方，不是「看盘」的地方。 |

| 3 | 账号页有三个呈现点，条件互斥靠布尔拼 | `MainScreen.swift:253`、`:267`、`Panels/SettingsPanel.swift:86` | 「账号」在中国用户心智里是「我」，应该是一个固定入口，而不是从设置里、从复盘里、从主屏里都能冒出来的 sheet。 |
| 4 | 底栏四格「复盘｜指标｜自选｜设置」，两个是页、两个是面板，视觉上同级 | `Kanpan/Kanpan/Main/BottomBar.swift:21-35` | 指标和设置是「调图 / 调 app」的低频动作，与「自选 / 复盘」这两个高频目的地并列，用户要靠记忆区分点下去会发生什么。 |

| 11 | 设置面板里混着「API 域名」输入框、「清缓存」、「恢复默认」 | `Panels/SettingsPanel.swift:105-137`、`:152-167`、`:80-83` | 这是后台字段。≤10 个朋友在用，没人需要改域名；「恢复默认」一点即重置无确认。 |

| 13 | 复盘用 segmented「待办 / 记录 / 战绩」三 tab，历史用「上一页 / 下一页」翻页 | `KanpanReview/Sources/ReviewUI/ReviewBook.swift:11-13`、`:31-37` | 手机上翻页按钮是网页思维；「待办」是个工程词，用户想看的是「哪几笔还没判对错」。 |
| 14 | 复盘和记一笔按钮 `.tint(.orange)` 硬编码，不跟皮肤 | `ReviewBook.swift:56`、`ReviewCaptureCard.swift:65` | 换皮肤后这两块永远橙色，破坏整体。 |

## 二、交互逻辑：在 GPT 文档之上再走一步

GPT 文档（§3）把信息架构收成四处：盘面 / 自选层 / 复盘 / 调图，底栏「自选｜复盘｜记｜调图」。这个方向对，但有四处我认为可以更好，新原型按下面做：

### 2.1 「我」收进左上头像，底栏只留目的地与动作

GPT 文档把设置藏在「调图」的偏好 tab 里，账号又另开入口。新原型把**外观、盯盘、账号、诊断**全部收进左上角头像「我」这一页，底栏 Dock 只剩 **自选 · 复盘 · 记 · 图表** 四格：前两个是「去哪儿」，「记」是强调色渐变方钮（唯一的动作，永远在拇指落点），「图表」是调图面板。用户学一次就知道：左上是我，底下是走。

### 2.2 周期条「全部 ⌄」原地展开，不开 sheet

6 个常用周期（按停留时长学习）+「全部 ⌄」+「画线」。点「全部」在周期条下方原地展开 7×2 网格，K 线区顺势下压 100pt，选完自动收回。没有第二层 sheet，也没有「更多 · 2h」这种带状态的按钮文案。

### 2.3 自选是一张有导航栏的整页，不是盖层

自选 = 顶部「‹ 返回盘面」+ 标题 + 搜索 + 加号 + 更多，chips 一行「全部 · 加密 · 美股 · 主力（自建）」，右端一条 72pt 涨跌比例条「6 · 4」代替「涨 2 跌 0」文字。行高 62pt：徽章 + 名称 / 市场标签 / 额·幅一行小字 + 迷你走势 + 价格 / 涨跌幅胶囊。点行 = 换品种回盘面；**长按 = 菜单**（置顶 / 移到分组 / 到价提醒 / 记一笔 / 删除）；删除立即生效 + 底部「已删除 · 撤销」5 秒。左滑只保留一个动作「删除」，右滑不设。搜索直接在本页顶部展开键盘，不再跳独立搜索页。

### 2.4 复盘 = 摘要卡 + chips + 记录卡，没有 tab 也没有翻页

顶部摘要卡：命中率大字 + 「多 72% / 空 61%」+ 三色比例条（对 / 错 / 待判定）+ 「连对 4 笔」。chips：全部 · 待判定 3 · 已判定 · 品种。记录卡：品种 + 周期 + 方向标签，原话最多两行，底部判定标 + 「看图 ›」。「待判定」的卡片直接在卡上「判对 / 判错」。历史无限下滑，不翻页。战绩是摘要卡点进去的一整页。

### 2.5 颜色语义硬规则

- 选中态与主动作按钮 = 强调色渐变 `accBg` + `onAcc` 文字（陶土 CE6A3E→E5975C / 青苔 2E7D6B→55A891）。周期、chips、分段控件、Dock 方钮、「记下」都是这一条，全 app 只有这一种「亮」。
- 强调色 `acc` 单色用于：Dock 当前项文字、开关 ON、提醒角标、已收藏星星、链接式动作。
- 墨色（ink1）实底只给 toast 一处。
- 涨 / 跌是一对可互换 token（`--cUp / --cDn`），红涨绿跌只翻这一对。
- 危险色固定，不随涨跌翻。

这样用户看到强调色渐变就知道「现在在这 / 这个能按」，看到涨跌色只会想到行情，两者永远不撞。

### 2.6 反馈层统一为一个 toast，带撤销

所有「刚做了什么」都走同一条底部 toast（Dock 上方 12pt，5 秒），可撤销的带「撤销」字按钮：删自选、删记录、移分组、恢复默认、清缓存。确认框全部取消，只留「退出登录」一个保留确认。

### 2.7 冷启动第一帧是上次那张图

120 ms 内先画上次的品种、价格（灰）与本机 K 线快照，价格右侧一行 11pt「上次 07:41」；第一帧实时到就替换，小字消失。没有 spinner，没有骨架屏。自选页只在用户按 Dock 时出现。

## 六、落地顺序建议

1. **Dock + 头像「我」+ 周期条**（MainScreen / BottomBar / IntervalBar / TopBar）：一次把入口换完，功能表（第三节）全部走通。

## 七、功能分层与导航（施工规则，与原型第 0B 节一致）

原则只有一条：一天点几十次的东西 1 步到，一个月点一次的东西可以躲到第 3 步，但每条路都写在这里。

### 7.1 功能分层（按频次排）

| 功能 | 频次 | 从首页几步 | 放哪 | 为什么 |
|---|---|---|---|---|
| 看最新价 / 涨跌幅 / 高低额 | 每天 30–60 次 | 0 步 | 盘面头部 | 冷启动落点就是它；正常态没有状态词 |
| 切常用周期 | 每天 20 次以上 | 1 点 | 周期条 6 格（按停留时长学习） | 一天点最多的动作，永远在条上、无动效 |
| 切非常用周期 / 钉住周期 | 每周几次 | 2 点 | 「全部 ⌄」原地展开 7×2 | 不开 sheet，选完自动收回 |
| 换到最近看过的品种 | 每天 10–20 次 | 2 点 | 品种胶囊 ⌄ → 弹层 3 行 | 快捷切换，不是自选页 |
| 换品种（分类 / 搜索 / 排序） | 每天 5–10 次 | 1 点进页 + 1 点选 | Dock「自选」整页 | 分类 chips 一行可见，搜索在本页展开 |
| 加 / 取消自选 | 每天 0–3 次 | 1 点 | 头部 ★ | 实心 = 强调色；不重排列表 |
| 画线 | 每天 0–2 次 | 1 点 | 周期条右端「画线」→ 横屏 | 横屏只做这一件事，完成自动转回 |
| 记一笔 | 每天 0–3 次 | 1 点 | Dock 中央方钮 | 拇指落点；卡片覆盖不压图；草稿自动留存 |

### 7.3 体验细节（12 条）

- **手势**：长按 = 菜单（自选行 / 记录卡 / 周期格钉住）；左滑只有「删除」一个动作；屏幕左缘右滑 = 返回；无下拉刷新（行情是实时流）；图表内手势由 AICoin 底座负责。
- **默认值**：新装机落 BTC / USDT 1h；记一笔默认 把握 70% · 图在先 · 不提醒；自选为空时列成交额前 20；排序默认成交额；深浅跟随系统。
- **键盘**：搜索 / 登录进页即聚焦；搜索与用户名强制英文键盘；到价输入数字键盘并预填当前价；键盘上方不放自定义工具条；点空白处收键盘。
- **撤销 / 确认**：删自选、删记录、移分组、恢复默认、清缓存 → 立即执行 + toast「已… · 撤销」5 秒；确认框只留退出登录；toast 全 app 一层，Dock 上方 12pt。
- **状态文案**：不说「成功」「实时」「已连接」；只说时间（已同步 · 14:02）和异常（重连中 / 3 条还没上传 / 上次 07:41）；异常消失即文案消失，不弹恢复提示。
- **尺寸与热区**：热区一律 ≥ 44×44（周期 chip 视觉 30 高、热区补到 44）；自选行 62、设置行 50、复盘卡自适应；Dock 60 高、离底 26；页边 16、组间 14、4pt 基准。
- **触感**：selection：周期 / 星标 / 分段 / 钉住；success：记下 / 判定 / 登录；warning：删除 / 恢复默认 / 退出；其余无。
- **动效**：换品种 / 换周期 / 排序 0 帧；价格变化 120–180ms 底纹；sheet 0.28s spring 覆盖升起；周期展开 0.2s / 收 0.18s；整页 push 用系统转场；Reduce Motion 下全部退化为淡入。
- **深色与护眼**：跟随系统；自动护眼开：环境亮度 < 0.32 入深色、> 0.45 回浅色、90 秒冷却；两套皮肤各有深浅四组 token。
- **Dynamic Type**：正文 / 列表随系统到 xxL；最新价 26、涨跌 15、周期 chip、Dock 文字锁定，避免头部换行。
- **横竖屏**：竖屏锁定；只有「画线」进横屏；横屏隐藏 Dock、周期条与所有指标。
- **空态 / 错态**：空自选 = 成交额前 20 + 一句话；搜不到 = 一句话 + 「换个写法」「去分类里翻」；复盘空 = 一句话 + 「记第一笔」；未登录复盘 = 一句话 + 「登录」；全部不用插图、不用大图标。
