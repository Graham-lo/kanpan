# AICoin 图表复刻：现行规格与证据边界

更新：2026-09-22。本文只描述现行实现及取证边界；工作安排仅在 [唯一交接书](待办交接-Codex-2026-09-22.md)，产品排除项仅在 [不做清单](不做清单.md)。

## 产品与布局

- 原生 SwiftUI + UIKit / CoreGraphics，最低 iOS 26.0，兼容 iPhone 15 及更新机型和 iPad；当前任务全部在模拟器验证。
- 图表只有 AICoin 一套造型；图外三套皮肤为青苔·冷、陶土·暖、经典，各有浅 / 深色。经典浅色画布为纯白 `#FFFFFF`，图内结构线 `#F2F4F7`，周期条结构线 `#EAEAEA`。浅色蜡烛沿用已测 AICoin 色值，颜色设置不改变坐标与手势。
- 底栏固定「画线 · 图表 · 自选 · 板块分类 · 设置」。横屏用于画线，完成回到竖屏。画布上没有浮动控件，面板选完收起。
- 头部为左侧价格与涨跌小字两行、右侧两列三行统计，只有一种布局。价格 22pt，涨跌小字 13pt，统计标签 12pt / 值 13pt；头部字号封顶 `.large`，实测六格高53pt。详细证据见 [P0 及返工报告](acceptance/待办交接-2026-09-22/P0.md)。
- 所有价格位数来自 `SymbolInfo.priceDecimals`：有效报价步长优先，缺步长才用下单字段精度，极小价格保留不归零规则。成交量、比值与百分比按各自单位格式化。
- 常用周期六档等宽，出厂5分钟 / 30分钟 / 1小时 / 4小时 / 1日 / 1周，全部14档从1分钟到1年，行尾「更多」钉住或取消；列表不横向滚动。
- 主图与副图在一个视口内，副图同时最多三个。出厂主图均线10 / 30 / 120 / 256，副图成交量、持仓量、平滑异同均线；画线工作台隐藏指标。当前画法是蜡烛和平均K线。

## 坐标、视野与手势

- `ChartState`、`ViewWindow`、`Layout` 共管节距、时间窗、实时跟随、手动定标、主副图高度与十字线。主题切换不重置看盘位置。
- 冷启动先用正确品种 / 周期的快照，再补网络；在历史视野时新数据不夺走位置。切周期保住根宽和右侧锚点。
- 双指中点是缩放焦点。捏合转单指后保留手势来源，松手不被当成轻点；单指拖动、惯性、十字线与画线由共同状态机处理。
- 只在越过已加载边界时有轻微阻尼，位移不超过 `min(32pt, plotW×10%)`，有限320毫秒单调归位；减少动效时直接归位。
- 价格轴支持手动缩放，双击翻轴受主 / 副轴权限控制。价格轴列按本屏最宽标签加两侧各4pt定宽，等宽数字量宽避免逐口报价抖动。
- 副图下边界拖动调高，长按副图后拖动可换序，高度按指标身份保存；图例自适应与整屏高度分配是两件事。
- 十字线按K线中心定位；中心附近拖动移线，其它图区拖动回到平移。图外提供上一根 / 下一根、按此价画线、看细节；看细节切下一档小周期，返回大周期保留原视野。
- 41把画线工具共用坐标、几何、命中和锚点；拖动时冻结两轴，撤销栈按品种保存。图表并不因画线端点自动扩大价格范围。

## 数据与订阅

- 最新价走共享 `QuoteBook` 的真实成交版本；周期历史、标记价不得覆盖最新成交。24小时统计用独立时钟，较晚返回的旧统计不回退报价。
- 品种目录包含交易中的普通和美股等永续合约，目录状态在行情、自选和搜索一致显示。自选分类为现有固定分类，收藏与人工归属持久化。
- 设置中行情线路由用户手选：直连只用币安，网关只用两台VPS的现有OKX服务，不混源。自动切换与额外多交易所功能不做，见 [不做清单](不做清单.md)。
- 持仓量历史最细5分钟，1分钟 / 3分钟按阶梯对齐，周 / 月 / 年按日历聚合取末值；已有数据先画，增量补历史。网关持仓量副图不做，见不做清单。
- 行情与可见自选 / 搜索订阅复用连接，后台释放、前台恢复；列表迷你走势默认关闭，展开详情才按需取对应历史。

原版Y轴连续曲线、精确字体 / 节距、深色蜡烛色校准属于交接书第3节外部条件，不在当前执行范围。现有实现及独立验收见 [底座验收目录](acceptance/AICoin-base/) 与 [画线验收目录](acceptance/drawing-v2/)。没有“全部交互已穷举”或“全量一比一验收”的结论。
