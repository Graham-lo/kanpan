# 画线 v2 与均线颜色

日期：2026-09-15。实际项目：`/Users/mdd/zhk/kanpan`。

## 交付范围

- 原生图表共 10 种工具：趋势线、水平线、射线、水平射线、直线、垂直线、矩形、平行通道、斐波那契回撤、价时测量。
- 线条/区域/斐波那契/测量分类；常用工具收藏；独立弱磁吸；连续画线。
- 选中后的样式、锁定/解锁、复制、单根删除；管理列表按对象选择、隐藏、滑动删除；全部隐藏/显示与确认后清空当前品种。
- 撤销/重做始终位于画线栏。未完成对象先撤回上一个点；完成对象的创建、拖动、样式、锁定、隐藏、复制、删除与清空均可撤销。历史栈为当前图表会话内最多 50 步；已保存的对象与偏好可跨进程恢复。
- 样式支持显式 sRGB 颜色、线宽、实/虚/点线、区域填充；时间/价格可精确编辑，回撤比例可编辑。锁定对象可选择和删除，不能拖动。
- MA、EMA 各输出槽位独立颜色。取消/滑动关闭编辑页不提交；保存同步曲线与图例，恢复默认仅清除该指标的颜色覆盖，不改变周期和输出开关。

## 数据与交互约定

### 如何删除一根画错的线

进入「画线」，点击对象，底部出现「样式 / 锁定 / 复制 / 删除」，点「删除」只移除当前对象。重叠或隐藏对象可通过「管理」列表选中，也可在列表中滑动删除。误删后立即点「撤销」；「重做」可重新执行删除。批量清空是独立的确认操作。删除结果写入存档，重启不会复活；撤销历史仅保留在当前图表会话中。

### 绘制与调整

1. `Drawing.points` 保存毫秒时间戳和价格；旧 `a/b` 档通过解码迁移。对象几何、预览、选中、命中共用 `DrawGeometry`。水平射线向右延伸；普通射线由起点经过终点延伸；通道通过三个锚点构成平行三线；矩形采用两个对角锚点。
2. 斐波那契回撤 0 为波段终点、1 为波段起点，比例按真实价格计算后投影，切对数轴不会改价格。通道以当前屏幕变换构造平行线。价时测量显示真实价差、相对起点涨跌幅、时间差。
3. 图表与画线共用时间/价格转换、主图范围与倒置状态；只在主图接收画线落点和选择。画线不再撑大自动 Y 范围；远处标注可以保留在视野外。
4. 弱磁吸比较屏幕距离（10pt），不再无条件跳到 OHLC；空数据、远离蜡烛及右侧未来空白保持自由坐标。整线移动不磁吸，对数轴按像素移动保持形状。
5. 手势取消回滚；没有移动的点按不占撤销步。双指开始时撤销未提交拖动、保留完成的锚点，将两个触点交回图表缩放；缩放期间不落点。
6. 拖动每帧只更新覆盖层预览；开始/结束各更新一次静态层，抬手提交一次模型和存档。放大辅助缓存单次手势开始时的图表图像，避免每帧重绘整图；图片在下一次手势更新，不是实时行情替代品。
7. 常用/选中操作条保持同一高度，避免完成画线时图区再跳一次。竖屏底栏、横屏可滚动侧栏均保留撤销和删除入口。管理面板外点击只关闭面板，不触发十字线。

## 持久化与升级保护

- 正式画线文件位置保持 `Application Support/kanpan/draws.json`，归档版本 2。按当前行情源使用的品种键隔离、跨周期共享；没有新增多交易所聚合。未来接入多个市场源时应先升级该键的身份模型。
- 原子写入；首次替换既有文件前保留一个 `.backup`；损坏/未知工具/未来版本读取失败时保留原文件，并拒绝用空档覆盖。
- 画线类型、锚点、颜色、线宽、虚实、填充、比例、锁定、隐藏、工具收藏、磁吸、连续模式和每种工具的默认样式落盘。默认样式不保存已删除对象的锚点。
- 每品种仍最多 50 个对象；创建/复制满额拒绝新增并提示，正常操作不挤掉旧对象。
- 均线颜色随现有 Prefs 存档保存，按指标与输出槽位独立覆盖；旧存档缺少字段时沿用主题颜色。未变更原偏好版本与默认值，避免重置用户现有配置。
- UI 测试启用独立 UUID 存储配置；跨进程测试使用真实 UserDefaults 和 JSON 文件，不写正式自选/画线存档。单元测试合成数据只用于算法断言；UI 使用真实网络行情。
