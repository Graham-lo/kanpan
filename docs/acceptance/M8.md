## 红项与根因（逐条复现过再修）

提交 `0217844`（用例）与本阶段 P4.5 那一次提交（产品代码）：

- **十字线移线、拖副图换序、调高度、一屏三副图（ChartFoundation 四条）**：价格刻度列按最宽刻度文字
  贴着算宽，行情一跳宽度差 1 pt（实测绘图宽 356→355、根宽不变、右缘不变），左缘就差四分之一根。
  这不是平移；用例改成比右缘、根宽、图高，把刻度列 1–2 pt 的伸缩折进左缘容差。
- **数据模式（testDataModesClearHeaderAndSelection）**：十字线开着时周期条让位给操作行，
  「图表」钮点不到；用例先在图上收起十字线再开面板，并断言让位本身。
- **盘口梯 / 外部指标 / 价格精度（含板块行）/ 画线换工具 / 换口径**：品种内部 id 已是完整 key
  （`binance/usd_m/…`），用例跟上 `testInstrumentKey`。
- **复盘契约对账**：服务端 P3.8 起按字符数数品种名长度（`chars().count()`），对账正则只认 `.len()`，
  两种写法都认；客户端 `String.count` 本来就是字符数，口径一致。
- **DynamicType AX3 / 新上线「新」标记**：同上，品种 id 换成完整 key 后用例还在找旧 id（`dec3ab6`）。
- **ChartLayoutPersistence 冷启动落在自选页（已登录）**：rerun1 在 `:234` 等元素超时红了一次，
  rerun2 同一条路径复跑通过，此后没再复现；没找到产品侧原因，记为一次性，不当作已修。
  顺带给有账号的四个类（ShareFlow / Compare / AccountMarket / ChartLayoutPersistence）加了
  tearDown 兜底删号（`TestAccounts.delete`），中途红了也不在线上留测试账号。
- **自选重启保留（A5.8，FavoritesSurviveRestart）**：测试档里不给 `KANPAN_ACCOUNT_API_URL` 时 app
  不建账号桥，自选只落在内存仓，重开必丢——测的不是用户那条落盘路径。用例补上接口地址后通过。
- **跨设备并发收敛（P4.5，新用例）**：产品 bug——已登录的设备每次冷启动都把自己全部非默认设置以
  当下时间重记一遍，最后冷启动的那台盖掉别人更晚的改动。详见 `待办交接-2026-09-22/P4.md` 4.5。

## 按设计跳过的 8 条

- `ChartFoundationUITests` 的 5 条手动工具（`testInstallRequestedFavoritesInUserStore`、
  `testUserSession*` 四条）：只在显式给 `KANPAN_INSTALL_USER_FAVORITES` / 用户会话开关时跑，
  会写用户正式存档，矩阵里不跑。
- `IPadLayoutUITests` 两条、`IPadReviewBookSignedInUITests` 一条：只在 iPad 上跑，iPhone 上跳过。
