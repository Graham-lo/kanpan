# 画线：每一族记住上次选的画法（2026-09-23）

用户原话：「画线工具我选择了趋势线，然后我把样式改成了两端延伸保存，然后重画还是线段，这里有问题，另外云端也是需要记住的」。

## 做了什么

- **记住画法**：`DrawingPreferences.variants`（`KanpanCore/Sources/KanpanCore/Drawing/DrawStore.swift`），键是面板那一格（`trend` / `hline` / `vline`，由 `Drawing.Kind.paletteHead` 认族），值是这一族上次在样式表里选的那一种。样式表保存时由 `DrawingController.update` 记（只记同一族、真的换了的）；面板点那一格，落笔与拖动预览都换成记住的那种（`DrawingPreferences.newDrawing` / `kind(for:variants:)`，`ChartView+Drawing.swift`）。换回「线段」也是一次选择，照记。
- **样式照旧规矩**：新线样式取 `styles[记住的那种] ?? styles[面板那一格]`，两份互不覆盖。
- **云端记住**：`variants` 随 `drawingPreferences:tools` 同步，扁平成 `variants/trend` 等子键（`PersonalSyncCodec.nested` 与最大模板已补）；服务端 `DRAWING_PREFERENCE_FIELDS` 加 `variants`，值规则 `variants/<KINDS>` 只收已知画法（`Backend/kanpan-api/src/sync.rs`、`sync_validation.rs`）。老存档 / 云端缺这个键照常读；认不出的画法丢掉那一条，不整份抛。
- **样式表「画法」一排改成直接摆开的按钮**（`DrawingKindSwapRow`，`Kanpan/Kanpan/Drawing/DrawingBar.swift`）。原来是 `Picker` 弹出菜单：样式表起手 0.4 屏高时这一行贴着面板下沿，菜单往上弹，「向右延伸」落到面板外、压在调暗的图表上，XCTest 判「点不到」，既有用例 `testDrawingToolsAndPersistentStyles` 因此在本分支稳定红。一族最多四种、字短，摊成一排放得下（大字号时标题在上、按钮在下），也省掉「先点开菜单」那一下。选中态与「粗细」那排同一支笔。
- 面板那一格仍叫「趋势线」，没有新入口、没有解释文案。一键「按此价画线」（`addHorizontalLine`）不跟记忆走，仍是整条水平线——锚在最后一根 K 线上的水平射线几乎看不见。

## 验收

- 用户那个现象已消失：UI 用例 `ChartFoundationUITests.testDrawingSwapIsRememberedForTheNextLine`（模拟器 iPhone 16 Pro / iOS 26.5）——先画一条趋势线（`trend`），样式表里点「两端延伸」保存（`extended`），再从面板点「趋势线」画第二条，两条都是 `extended`；杀掉重开再画第三条，仍是 `extended`。截图：
  - `样式表里画法一排选中两端延伸.png`
  - `换成两端延伸后再画仍是两端延伸.png`（第二条线横贯整张图）
  - `重开后仍记得两端延伸.png`
- 单测：Core `DrawingVariantTests` 5 条 + 画线相关共 51 条；AccountCodec `DrawingVariantSyncTests` 3 条（共 17 条）；Rust `cargo test --lib` 159 条（含新增 `the_remembered_drawing_method_is_stored`、`the_remembered_drawing_method_travels_with_the_account`）；`make sync-contract` 契约无变化。
- UI 用例（同一模拟器，单条跑、超时 15 分钟）：`testDrawingSwapIsRememberedForTheNextLine` 通过（88.8 s）；既有 `testDrawingToolsAndPersistentStyles` 通过（133.3 s），「向右延伸」一步走新的按钮排，截图 `老用例-换成射线并锁定.png`。
- 既有用例在 origin/main 6b845f7 上单独跑了三次：1 次过、2 次红在「画法」菜单那一步（「向右延伸」不在可点区域 / Activation point invalid）——菜单这一步本来就是时好时坏，不是本次改动引入的。
- 排查插曲：中途连续几次红在转屏那一步（设备转了、界面不转），换一条与本改动无关的 `ChartRotationRoundTripUITests` 也一样红；重启模拟器后两条都绿，判为模拟器转屏状态卡死，不是 app 的问题。

## 补：画法名字统一（2026-09-23 验收意见）

- 样式表按钮写「两端延伸」，选中条和提醒确认条却叫「直线」。现在名字只存一份在 `Drawing.Kind.title`：ray「向右延伸」、extended「两端延伸」、hray「向右延伸」、crossLine「十字线」；样式表那排除面板那一格外直接取它（水平一族原按钮「向右」单拿不成词，一并改成「向右延伸」）。kind 的 raw 值与同步字段不动。
- 提醒确认条「要在这条两端延伸线上提醒你吗？」（「…延伸」后补「线」字）；提醒列表遇到老提醒 title 里的「直线 / 射线 / 水平射线」显示为新叫法，存的 title 不改。选中条的线名窄机放不下四个字时先缩到 0.75 再截断。
- 验证：Core `DrawingKindNameTests` 3 条 + 画线/提醒共 100 条、Alerts 包 40 条通过；UI `testDrawingSwapIsRememberedForTheNextLine` 新增选中条与提醒条断言后通过（98.2 s）。截图 `画法名字统一-选中条与提醒条.png`。
