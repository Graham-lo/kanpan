# 手机订单流点击与大单页排版验收

日期：2026-10-09（Asia/Shanghai）。iOS / 手机网页；电脑本轮无界面改动。

## 结果与根因

- 聚合金额签会为避让 K 线、盘口或画线文字而移位，原命中只检查挂单细线。现在按最终金额签矩形映射回整组挂单，点签即显示聚合墙详情。金额签与气泡热区重叠时，屏上金额签优先；点气泡露出的部分仍进入大单页。
- 点气泡会程序定位十字线，原来又被当成手动挂单悬停，因而同时出现挂单卡与大单页。现在定位携带临时 bigTrade 来源，清除挂单选择并抑制这次定位的挂单悬停；实时数据刷新不把卡重新弹出。手动移动十字线后正常检查挂单。
- 大单页整页复用现有 TypeScale / CSS 字体令牌：页标题与本根金额 17 semibold，卡片标题 / 动作 13 semibold，最大单笔金额 15 medium，辅助文字 / 次级数字 12，图轴 / 紧凑挂单墙 11。去掉局部 bold、负字距与 20 / 22 / 14 等独立字号；数字等宽、iOS Dynamic Type 保留。
