2026-09-14。基于 Claude 已有看盘工程增量修改，未重建项目。初始脏工作区保存在 `pre-existing.diff`，没有回退其它工作。原始任务书与 prototype 仅作历史参考，未修改。

## 本次结果

- AICoin 默认 + 原有 11 种视觉风格；所有风格共用实体 2/3 占比、影线宽、节距、坐标轴、主副图、价格范围和手势。风格类型中删除尺寸/留白字段，几何函数不再接收无用的风格参数。
- 删除旧 PriceAnchor 永久区间、旧价格 shift 模型、soft 边界与回弹、325ms 指数惯性、风格切换重新定宽、旧偏好版本迁移；不保留旧算法开关或转发包装。
- 横向硬边界含半根偏移；最新列右缘预留30pt；历史区焦点缩放，左右端按边界状态锚定；逐次有效缩放事件更新基准。
- Y 使用倍率及 centerFraction；倍率0.03–16、接近1吸附；自动Y复位保留历史X与倒置状态。自动Y下纵拖不再偷偷修改价格区间。
- 惯性采用 AICoin 所调用 OverScroller 的 AOSP SPLINE 参考阶段，触边停；平台阈值与物理换算仍列为待当前iPhone定标，绝不将Android屏幕density等同于iPhone屏幕scale。
- 冷启动采用手机已确认设置：对数、MA10/30/120/256、VOL5/10/30/60/120、MACD10/30/9、VOL/OI/MACD副图、无网格、无倒计时、选中价格十字线。
- 修复同数K线替换与末根更新不刷新指标、启动周期竞态、快照追赶到实时、风格切换/SwiftUI更新覆盖视野等问题；OI接入既有真实数据源。
- 补右轴测宽、指标图例换行、副图刻度、共用时间列的主副图十字线、高低点标注。极值引线是根据手机截图的保守布局，尚非逐像素定稿。
- 按用户22:43新要求，上方行情、周期栏、图表、底栏/安全区统一使用靛色图表背景；浅色#F4F6FD、深色#161A3F。

## 仍需校准

本次不是“所有AICoin图表操作已完整读完”的声明。当前iPhone精确节距、字体/线宽/色值、自动Y动画、惯性平台参数、纵向父页面滚动/横屏溢出排布、全指标/画线工具及极值避让细节仍需继续实测。

主图/副图目前采用共用加权分区；它保证所有风格一致，但尚未复制手机关闭自适应后的全部外层滚动体验。对数Y状态在变换空间运算，是工程选择；Android父类价格域手动运算不可冒充iOS证据。
