# 机型兼容验收

2026-09-15 已接手并停止原兼容任务，其遗留 Pro13 点击穿透和搜索入口问题已修复。用户范围为 iPhone15及更新型号、iPad；不把模拟器型号覆盖写成旧版iOS覆盖。

## 基础功能包最终兼容矩阵（已完成）

手机断开后完成原基础包 `310e8c1` 的 **13 台 × 16 项 = 208 项**模拟器回归：iPhone 15、16 Pro、16 Plus、17、17 Pro、17e、17 Pro Max、Air，以及五台 iPad。均为 iOS 26.5(23F77)，最多同时 2 台。汇总见 `release-final-summary.json`；17 Pro 使用 `run-release-17-complete.py`，17e 初次因控制并行设备数量而取消，保留原始记录，`run-release-17e-retry.py` 的独立重跑16项全过。

用户随后新增护眼配色、报价/K线/指标完整性审查、全部收藏快捷切换和市场板块。这些新增代码的结果单独记录在 `../../eye-colors/`，不能用上述旧二进制的208项替代。详见 [新功能与数据审查](../../护眼配色与数据完整性.md)。

范围包含12种风格共用几何、横屏/全屏、缩放、十字中心移线/其它位置拖图、完整副图排序、一屏四副图与手调高度、自选分类与跳转、无需编辑的行排序、右滑删除、搜索中心单击输入/取消、最新端回位/历史停留/重进贴右，以及主功能入口。该矩阵隔离测试偏好和自选种子，行情仍使用真实网络；用例不以网络时延或服务容量为断言，这些结果另见已完成的真机与公网网关证据。

首轮`release`在Pro13上16/16通过，16Plus上15/16通过。失败截图显示BTC从首行移到第二行，排序确已触发，但快速手势未投放到最后一行之后。随后测试冻结窗口坐标，以1秒长按、慢拖至末行下方并停留0.5秒释放，仍断言BTC位于SOL之后，没有修改应用排序代码或放宽断言。初次失败、截图及修正说明保留在`release-first-failure.json`。

`release-v2-source-sha256.json`和`release-v2-binary-sha256.json`记录最终测试包：相对首轮，仅XCUITest源码/测试二进制改变，App二进制完全一致。示例截图附件沿用早期“真机双指缩放”名称时，仅为旧附件标题，**本矩阵均为模拟器结果**。
