# 10-05 新功能回归压测（iOS，2026-10-05 ~ 10-06）

范围是 10-05 一批新功能：
- 美元指数（DXY）当作普通品种：能搜、能加自选、能开图、能建提醒
- 对比＋，最多三只
- 顶栏铃铛打开的「提醒」页，分「列表 | 日志」
- 画线条按使用频率排：竖屏 4 格、横屏 5 格
- 横屏画线台默认画主图指标，带「眼睛」开关和「主图˅」就地切换
- 横屏根宽与竖屏分开记，价格轴倍率按横竖屏各记一份
- 捏合手感

压测用例在 `Kanpan/KanpanUITests/StressRegression1005UITests.swift`，原始数据（所有轮次，包括修前）在 `ui-数据.txt`。

## 2. 修了什么（都从根因改）

| 提交 | 现象 | 根因 |
|---|---|---|
| `5c0c7691` | 每次启动后第一次进画线，主线程卡 200–570 ms | 画线工具记号与长按小卡的迷你 K 线是逐个 SwiftUI 子视图拼出来的，第一次布局很贵。两处都改成单个 `Shape` 一次描路径。修后探针 3 轮 × 多次都是 0 卡顿，走查三全程 0 卡顿 |
| `9c1026c1` | 顶栏「＋」打开的对比搜索页里，每一行的价格和涨跌一直显示「—」 | 报价簿只给 `visible \|\| chartSymbol \|\| named` 的品种拉报价，`MainScreen.listVisible` 只算了自选页和顶栏搜索，漏了对比搜索页（`showComparePicker`） |
| `64a8ff07` | 自选没有分类时，右上的放大镜和「…」两颗圆片跑到屏幕正中（截图 `16Pro-修前-空自选圆片挤到正中.png`） | 分类条为空时占位是 `EmptyView()`，不占宽度，HStack 就把右侧圆片推到中间。改成 `Color.clear` 撑满左侧 |
| `0ff179b7` | 16 Pro 全量 UI 里挂的三条 | ① AICoinBase：横屏根宽改成单独一份后，旧断言还拿竖屏的值比，改成比 `landStored`。② ReleaseBackdoor：全新安装播下默认自选后会从图表跳到自选页，用例抢在跳转之前点，改成 30 s 内循环回到图表。③ Walkthrough 自选：种子自选不带分类，分类要等品种表到了才生成，改成等「加密」胶囊出现。另外压测用例补了两条回归断言：「…」圆片要贴右沿、对比搜索里 DOGE 要有价格 |
| `465a8499` | 17 Pro Max 全量 UI 里 Walkthrough 自选挂：八只种子自选全被归进「贵金属」一格，「加密」「美股」不见了 | 品种目录还没到时，有一只被交易所拒掉（`onSymbolRejected`），`SymbolPickerModel.markDelisted` 拿「空目录 + 这一只的占位行」写成了目录。`classifyUnassigned` 见目录非空就开始分类，其余品种在这份假目录里都查不到类型；`FavoriteCategory.knows` 只认得 XAU 这种 ISO 贵金属代号，于是全落到贵金属。改成目录为空时什么都不写（和 actor 版 `SymbolCatalog.markDelisted` 同一条规矩），单测 `rejectionBeforeCatalogDoesNotFakeACatalog` |
| `d342e30f` | `make hotpath-test`（Release）整包编不过 | `e1f16b45` 的压测用例在嵌套函数里把 `app.openFavorites()` 直接塞进 `XCTAssertTrue` 的 autoclosure；Debug 能过，Release 按区域隔离报「sending 'self' risks causing data races」。先落局部量再断言 |
| `e1f16b45` | — | 新增 10-05 回归压测 UI 用例：DXY、对比三只、提醒列表/日志、画线条排序与横屏画线台、捏合、杀进程重启 |

## 3. 以交易员身份走一遍（16 Pro 截图 `16Pro-走查NN-*`）

- **走查一（冷启动 → 自选 → 搜「美元」→ 美元指数图 → 各周期 → 指标）**：DXY 能搜到、能开图、能切 1m–1w；BOLL 和 MACD 能叠。全程最坏一次卡顿 146–231 ms，没有超过 250 ms 的。
- **走查二（美元指数叠 BTC、ETH → 对比满三只 → 删到只剩 BTC → 提醒页）**：第四只加不进去，提示已满；提醒表从空到一条正常；日志页未登录时展示的是登录提示。最坏 150–219 ms。
- **走查三（竖屏画线条 → 画趋势线 → 全部工具里挑一把冷门工具 → 横屏画线台 → 眼睛 → 主图侧栏换布林带 → 捏合 → 回竖屏）**：
  - 冷门工具 anchoredVWAP 顶掉第四格，竖屏条变成 `trend, hline, fibonacci, anchoredVWAP`；横屏 5 格是 `trend, anchoredVWAP, hline, fibonacci, channel`。
  - 横屏捏合：根宽 4 → 9.33 → 4.67，竖向捏价格轴 1 → 3.05。`landStored` 记成 4.67，竖屏的 `stored` 仍是 4.0，两份互不干扰。
  - 修完 `5c0c7691` 后全程 0 卡顿。
- **走查四（BTC 头部六格、订单流、成交量 → 切美元指数）**：BTC 估值格 0.47%、额 15.10B，订单流有大单。切到 DXY 后订单流和成交量都不画（指数没有盘口和成交量，符合预期）。
- **走查六（杀进程重启）**：竖屏条、横屏条、横屏根宽 8.27、竖屏根宽 4.0、对比列表，重启后全都还在。
- **皮肤**：三套皮肤 × 深浅色，美元指数页和提醒表各一张（`16Pro-皮肤-*`），没有看到对比度或错位问题。

### 走查里看到、但不算 bug 的

- **DXY 周末有一段空档**：图表是时间轴，休市时段照实留空。网页版 §40 也是同一个做法（48baee2f 按 cells 收口）。如果想把休市段压缩掉，那是一个新的设计议题，这一轮没有改。
- **对比搜索里 NEIROETHUSDT 显示「—」**：这只币状态是 SETTLING，按下架处理，「—」是 B-06 的设计。
- 横屏和画线时对比线暂时收起，回到竖屏会恢复（截图 `16Pro-对比三只-横屏暂退.png`）。
- 画线条的排序在下一次进画线时才重排，画到一半不会跳格。
- 全新安装时会先播下默认自选，然后从图表跳到自选页一次；分类胶囊要等品种表到了才出现（冷启动后几秒）。
- 测试模式下自选只放在内存里，这是测试种子的约定。
