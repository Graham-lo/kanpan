## A0.4 —— CLT 环境下的 `make core-test`

`KanpanCore` 是纯 Swift 包，不 import UIKit，所以不需要 Xcode GUI。命令：

```bash
DEVELOPER_DIR=/Library/Developer/CommandLineTools make core-test
```

输出（完整日志见 `M1.md`）：

```
✔ Test run with 150 tests in 18 suites passed after 0.825 seconds.
```

`Makefile` 里 `core-test` 会自动探测 CLT 的 swift-testing 目录并补上 framework 搜索路径和两条 rpath——CLT 不把 swift-testing 放在默认路径里，不补就是 `dyld: Library not loaded`。装了完整 Xcode 之后这组参数无害，所以不分两套。
