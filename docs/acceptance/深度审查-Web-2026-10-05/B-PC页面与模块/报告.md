# 深度审查 Web · B 线：PC 网页页面与模块（2026-10-05）

范围是 PC 网页版里图表引擎以外的部分：`Web/src/app/`、`main.ts`、`pages/{sectors,review,me}.ts`，以及 `watch/`、`alerts/`、`notes/`、`trades/`、`review/`、`sectors/`、`ui/`、`util/` 几个目录，加上 `styles/app.css`、`index.html`、`public/diag.html`。

做法分三步：
1. 先只读审一遍，记下现象、根因和严重度。
2. 每一条用 vitest 复现。复现用例先在修前的提交上跑，确认是红的。
3. 从根因修掉，配上回归用例，逐条小步提交到 main。

修复表的根因一列写的是「文件:函数」，行号是修后的位置。

## 复核后不算 bug 的项

- **B7：价格提醒「首帧就已满足」时的处理。** 和 iOS、服务端第 3 条规则一致：以武装时的价格定方向，首帧已在阈值另一侧的不当场响。
- **同一价位多条提醒。** 一次穿越全部触发，各自只响一次，响完删掉，符合「只响一次」的定稿。
- **跳空。** 判定用这一段的 [lo, hi] 区间，跳空穿过也能捕到。
- **板块排序稳定性。** `boardOrder` 同值时按固定次序排，不抖。
- **「跑赢大盘」的口径。** 和 iOS 的聚合方式一致。
- **复盘 KPI 除零。** `roundStats` 对 0 回合、0 亏损都有保护。
- **复盘回放与图表互跳。** player 的 load token 已能防旧请求回写。
- **笔记创建的幂等。** 服务端按客户端 id 去重，重传不会重复。
- **URL 里认不出的 `s` 代号。** 图表启动时回落到默认品种（chart.ts:1145），不白屏。
- **行情线路的默认说明文字。** 按要求只记在本机这台设备上，文案不动。
- **退出登录不清本机数据。** 这是设计如此（「这台电脑上的数据都留着」），再登录同一账号时双向合并。
- **快捷键与输入焦点。**
  - 复盘页的空格会忽略输入框、按钮和下拉框。
  - 自选的方向键只作用在它自己的表格里。
  - 板块页的键盘事件只作用在表格行上。
- **canvas 与 CSS 主题同步。** `applyTheme` 会触发 `onTheme` 钩子，图表和复盘画布都跟着重画。
- **`index.html` 预绘脚本。** 默认皮肤（青苔、浅色）和 hydrate 的默认值一致，首帧不闪。
- **`public/diag.html`。** 是诊断页，不在用户路径上，审过没有问题。
- **复制链接时代号没做 `encodeURIComponent`（pages/chart.ts:494，A 线文件）。** 浏览器会自动编码，B9 修过之后 query.ts 能正确解码，结果正确。
