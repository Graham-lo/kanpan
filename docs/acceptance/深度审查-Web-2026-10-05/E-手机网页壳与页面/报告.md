## 不是 bug（附理由）

- **A-14 toast**：iOS 是同一套「一条覆盖上一条」的语义，网页照抄，没有丢消息。
- **A-5 板块行跳转**：板块行点进品种走的就是 `openSymbol`，来路和扫图名单都正确。
- **头部六格、收盘倒计时**：头部是用户定的两列六格（仓/额、市值/费率、结算/估值）。行情页已按 2026-10-03 的决定不再显示收盘倒计时；「结算」格是资金费率倒计时，保留。
- **周期条与「更多」**：周期条行尾固定三件，「更多」是带遮罩的弹层，都符合定稿。
- **左上品种名**：不是按钮，符合「品种名不是选择器」的定稿。
- **A-4① 占位语**：「点这里写字」的行为与 iOS 一致。
- **A-8 涨跌幅**：只有一个 `pct` 来源，头部、列表、胶囊读的是同一个数。
- **alertForm**：品种不可编辑、没有 ±%、Webhook 只填地址、只列未触发的提醒，符合「创建提醒」页的规矩。
- **搜索框**：自动聚焦与 ASCII 键盘符合约定。`inputmode="latin"` 在桌面 Chrome 上无法验证，要真机看。
- **更新已删除的画线**：updateDrawing 本来就找不到这条线，是空操作，不会把线复活。
- **非模态 sheet**：当前代码里没有使用。
- **A-9 至 A-12**：行情、同步、账号属于 C 线范围，交给 C 线。
- **自选页**：没有轮询，行情推送到来时就地改字；只有品种表、皮肤或回前台时才整页重建。所以没有板块页那种「按着被换掉」的问题。
- **主力订单流详情卡（`pages/chart/orderFlowCard.ts:82`）**：30 秒重画一次，但卡片外层是 `pointer-events:none`，没有可点的东西，不会吞点按。
