## 二、Coinbase BTC-USD 端到端

用例 `Kanpan/KanpanUITests/CoinbaseVenueUITests.swift` 三条：回后台那条 cb7、cb8 都过；两条线路那条 cb7 红在自选分类胶囊
已选中时点不动（用例改为已选中就不点），cb8 红在「网关下 Coinbase 推送没连到 kanpan-api 透传口」——这是真毛病，
见下第 1 处；修完后 cb9（18:25–18:28）两条线路与画线提醒都过。

| 项 | 用例里怎么验 | 证据 |
| --- | --- | --- |
| 1m / 1h / 1w | 搜索进图后逐档切，≥ 20 根、价 > 1000；1w 由日线聚（44 根） | [阶段4](阶段4.md) 截图表 |
| 切线路 直连 ↔ 网关 | 切「网关」后 DEBUG 网络诊断里必须出现 `wss://kanpan.107-174-172-10.sslip.io/v1/market/stream?source=coinbase` 与 `GET /v1/market/raw/products/BTC-USD/candles?source=coinbase…→ 200`；最新价 45s 内在跳；切回直连仍在跳 | [阶段4](阶段4.md) 末节 |
| 断网重连 | 退后台 40s（系统挂起，推送连接失效），回前台图还在、最新价 45s 内重新跳。真拔网会把整台 Mac（含 Surge）一起断，所以用这条同样会让 socket 失效的路 | `testCoinbaseResumesAfterBackground` |
| 画一条线、设一条提醒 | 深链开 BTC-USD 1h → 竖屏画线 → 水平线 → 选中栏「跌到 84,993.74 会叫你」点一下 → 诊断 `drawingAlerted` 有这条 → 提醒总表写「BTC/USD · 水平线」 | [画线-选中栏](阶段5-模拟器/画线-选中栏.png)、[画线-已挂提醒](阶段5-模拟器/画线-已挂提醒.png)、[提醒总表](阶段5-模拟器/提醒总表.png) |
| 不露内部键 | 每一屏扫一遍，`coinbase/spot/…`、`binance/usd_m/…` 只允许出现在 DEBUG 诊断元素上 | 三条用例全部断言 |

验收里抓到并修掉两处：

1. **切到「网关」Coinbase 实际没换线**（`5909020`）：feed 身份只有「交易所|上游」，Coinbase 两条线路上游相同，
   键不变就不重起。键加上线路。单测先红（60s 超时）后绿（0.4s）。详见 [阶段4](阶段4.md)。
2. **Coinbase 的提醒写成「BTC」**（`8626d0a`）：提醒总表、通知标题、裸价格提醒、自选波动提醒都只取基础币，
   和币安 BTC 永续分不出来。加 `Alert.name(of:)`：代号带分隔的写 `BTC/USD`，币安照旧 `BTC`。服务端通知
   标题阶段 3 已经是 `BTC/USD`，两端现在一致。
