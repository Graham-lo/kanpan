# 多交易所 阶段 2：行情提供者抽象（行为零变化）

日期：2026-09-23。接手线程在短命工作树 `kanpan-wt-xchain-venue`（分支 `xchain-venue`，rebase 到
`origin/main` 后直接推 `main`，不留长命分支）完成。提交：`09a4067`。

## 改动

- `KanpanNetwork/Provider/`：`MarketProvider`（一家交易所的 REST + 推送 + 能力）、`ProviderCapabilities`
  （原生周期、哪些周期由上层聚、各能力位）、`ProviderEvent`、`UpstreamError`、`RouteResolver`
  （直连 / 网关两档 → 这家交易所自己的主机名）、`VenueRegistry`（交易所清单：显示名、搜索小字、
  自选分类名、提供者工厂）。
- 币安现有实现原样包成 `BinanceProvider`：接口、报文、主机名、重连节奏一处没改。
- 删掉 `MarketSource` 与 `MarketRoutePolicy.source`：线路只剩「直连 / 网关」两档，主机名由提供者自己决定；
  `Interval.api` / `Interval.source` 挪到能力位 `source(for:)`。
- `MarketFeed` / `RoutedMarketFeed` / `OISource` / `QuoteBook` / `SectorFeed` / 复盘桥改走提供者；
  新增 `MergedMarketStream`（多家推送合流）；`SymbolCatalog` 与 K 线缓存路径按交易所各一份。
- 守门：`Tools/check-venue-isolation.sh`——交易所专属代码（`Binance*` / `Coinbase*`）不许漏出各自目录，
  挂进 `make app-logic-test`。
- `kanpan-feed` 增加 `--venue` / `--route` / `--cache-root`（冷缓存测量用独立目录，不和别的窗口共用）。

## 假设与边界

- 「行为零变化」的判据：币安所有既有测试不改断言照过 + 冷启动首屏 / 首帧不倒退（下面的实测）。
- 能力位只描述「这家交易所有没有」，界面上缺数据的格子由阶段 4 统一写「—」，不在提供者里拼文案。
- 线路选择仍只记在本机（见记忆「行情线路只有直连 / 网关」），提供者层不引入自动切换。

## 速度：改前 / 改后冷启动（直连、网关）

`kanpan-feed` 冷缓存（每轮一个新的 `--cache-root`），测 BTCUSDT 1h：「首屏」= 第一批 K 线可画；
「WS 首帧」= 推送第一条有效帧。改前 = 阶段 1 的 `origin/main`，改后 = 阶段 2。改前、改后交替跑以抵消网络波动。
原始日志与脚本在 [`阶段2-速度/`](阶段2-速度/)，统计来自 [`stats.txt`](阶段2-速度/stats.txt)。

| 组 | 轮数 | 首屏中位（最小 / 最大） | WS 首帧中位（最小 / 最大） |
| --- | --- | --- | --- |
| 改前 · 直连 | 13 | 1570ms（447 / 4267） | 914ms（502 / 1456） |
| 改后 · 直连 | 13 | 1089ms（444 / 3243） | 1040ms（543 / 1616） |
| 改后 · 网关 | 3 | 744ms（605 / 751） | 1103ms（1077 / 1522） |
| Coinbase BTC-USD · 直连 | 3 | 781ms（754 / 801） | 1856ms（1798 / 2149） |
| Coinbase BTC-USD · 网关（阶段 3 部署后） | 3 | 894ms（708 / 1272） | 1214ms（1014 / 1504） |
| Coinbase BTC-USD · 直连（部署后复测） | 3 | 725ms（588 / 729） | 1785ms（1747 / 1827） |

结论：首屏中位改后更快（1570 → 1089ms），WS 首帧 914 → 1040ms 的差在两组区间大面积重叠
（改前最大 1456、改后最小 543），属网络噪声，结构上没有多一跳或多一次握手——币安提供者的连接与
订阅报文逐字节未变（`BinanceProvider` 只是原实现的包装）。Coinbase 的 WS 首帧直连约 1.8s、
网关约 1.2s（网关的 hub 在美国机器上连 Coinbase，离上游近；已有人订阅同一品种时直接复用那一路上游），首屏 0.7～0.9s。
