# 多交易所 阶段 4：Coinbase 品种的完整界面

日期：2026-09-23。提交：`d7410d8`（界面）、`5909020`（验收时抓到的网关换线毛病）；模拟器验收用例 `Kanpan/KanpanUITests/CoinbaseVenueUITests.swift`（随本报告提交）。

## 改动

- 自选：别家交易所的品种固定进它自己那一类（注册表显示名「Coinbase」），第一次加时在「美股」之后开这一类；
  分类名由宿主从 `VenueRegistry` 注入，自选包不认识任何交易所。代号带分隔的写成 `BTC/USD`，币安行一个像素不变。
- 显示：`InstrumentID.display`（`BTC-USD → BTC/USD`）用在画线切换、横屏标题、重温标题、拖动预览与无障碍标签；
  顶栏小签与搜索行小字按市场写「现货」/「永续」；品种页页头分开数永续与现货。
- 搜索：Coinbase 品种行名字右侧一个灰色小字「Coinbase」（注册表 `searchTag`，币安不标）。
- 顶栏六格：仓 / 费率 / 结算无数据写「—」；市值由 kanpan-api `/v1/market/meta` 认 `BASE-USD` 现货对、按 base 查
  总供应量；额 = 24h 基础币成交量 × 现价；振幅取 24h 高低。
- 副图：现货根本没有持仓量与衍生统计，外部指标副图直接不画、不报错；`prefs.subs` 不动，切回永续原样回来。
- 板块：板块页只收分类表所属那一家的品种，别家品种不进兜底桶。

## 假设与边界

- 用户看得见的文案只放显示代号（`BTC/USD`、`BTC-USD 现货`），内部键 `coinbase/spot/BTC-USD` 只出现在
  DEBUG 诊断（`chart.canvas`、`review.range`、`market.*`，正式包整块 `#if DEBUG` 掉）。用例每一屏都扫一遍。
- 真机不可用，验收全部在 iPhone 17 Pro Max 模拟器（iOS 26.5）上做；真实网络（直连 Coinbase、网关走线上 kanpan-api）。

## 验收抓到的毛病：Coinbase 切到「网关」其实没换线（已修，`5909020`）

头一轮（cb5）只看「网关下有图、价在跳」，全绿。第二轮给用例加了一条硬断言：网关下 DEBUG 网络诊断里
推送必须连到 `…sslip.io/v1/market/stream?source=coinbase`。这一条红了——诊断里全是直连
`api.coinbase.com/api/v3/brokerage/market/…` 的请求：设置里切到网关，Coinbase 这一只照旧直连。
所以上表里 cb5 那两张「网关-1h / 网关-1m」实际是直连出的图，已用修复后的重跑替换（见下）。

根因：`RoutedMarketFeed` 按「交易所|上游」认一份 feed，换线路时键没变就不重起。币安换线路时上游
恰好也换（币安 ↔ OKX 替身），一直没暴露；Coinbase 两条线路上游都是 coinbase，键一模一样，
直连那份 feed 原样留着。修法：键改成「交易所|上游|线路」，`activate` 时把线路和提供者一起记下。

单测 `RoutedFeedPolicyTests.coinbaseSwitchingRouteMovesToGateway`：假服务器两条线路都答正常 K 线
（答 500 会触发出错后的健康探测，探测顺手打到新线路上，把毛病盖住——第一版单测就是这样假绿的），
直连起步后切网关，必须出现 `gw.test/v1/market/raw/…`。改前 60 秒超时失败，改后 0.4 秒通过；
`make data-test` 208 条全绿。

修复后重跑（cb9，18:25–18:28，`exit 0`）：`testCoinbaseBTCUSDChartsLiveInBothRoutes` 通过，上表网关三张与
「切回直连」换成这一轮的截图。网关下 DEBUG 网络诊断里 Coinbase 那几行：

```
Coinbase WS 连上 #1 wss://kanpan.107-174-172-10.sslip.io/v1/market/stream?source=coinbase
GET /v1/market/raw/products/BTC-USD/candles?source=coinbase&granularity=ONE_MINUTE&… → 200 36564B
```

（切网关之前同一份诊断里是 `Coinbase WS 连上 #1 wss://advanced-trade-ws.coinbase.com`，切过去之后换到了透传口。）
