## 2. 与任务书不一致的地方（一律以原型为准）

1. **设置面板条目顺序按原型排。** 任务书 §10.6 的顺序是 涨跌配色 · 价格轴 · 十字线磁吸 · 本根倒计时 · 盯盘时不锁屏 · 启动快照 · 时区 · API 域名 · 清缓存 · 关于；原型 `renderSettings` 是 外观 · 涨跌配色 · 价格轴 · 时区 · 十字线磁吸 · 演示实时跳动。取原型顺序（外观打头、时区紧跟价格轴），任务书独有的几行接在后面。
2. **时区三档叫「本地 / UTC / 交易所」，不是「设备 / UTC+8 / UTC」。** A6.9 写的是后者，原型写的是前者，而且 `KanpanCore` 的 `TZChoice` 就是 `.local / .utc / .exchange`。取原型。
3. **参数上限 400，不是 500。** 原型步进器 `Math.max(1, Math.min(400, …))`；A6.5 说「> 500 拒绝」。区间取 1...400；`reject()` 仍然对 0 / 负数 / > 500 给出各自的拒绝理由，所以 A6.5 那三类输入一条不漏。
4. **周期面板是列表，不是 14 档网格。** §10.6 写「14 档网格」，原型是一列行。取列表。常用行的增删原型用长按，这里长按保留，另外补了一颗看得见的图钉按钮（纯长按没有视觉提示，手机上找不到）。
5. **存档键取任务书的 `kanpan.prefs.v1`，不是原型的 `kanpan.v3`。** 这一处反过来以任务书为准：A6.12 把键名写成了验收项，而原型那个键是 localStorage 的 web 细节，搬不过来。
6. **原型没有、按任务书补的：** 副图高度三档、副图拖动排序、参数数字行、API 域名、清缓存、本根倒计时、盯盘时不锁屏、启动快照、恢复默认。
7. **原型有、app 不做的：** 「演示实时跳动」（原型的假跳动开关，app 有真 WS）、周期面板脚注「原型只带了 6 档真实数据」。
8. **副图高度三档做成倍率，不是三个绝对值。** 原型的副图高度是风格表里的 `subH` 定死的。三档实现为 0.75 / 1.0 / 1.3 乘在风格给的基准上，再兜底 44 pt，这样换风格时三档仍然相对该风格成立。
9. **「外观」三档同时出现在风格面板和设置面板** —— 这不是分歧，原型的 `renderStyleSheet` 和 `renderSettings` 里都有，照搬。

## 3. 没做完的，以及为什么

1. **A6.2 的「逐像素相同」没做到字面意义。** app target 只链了 `KanpanCore`，没链 `KanpanChart`，所以 `StyleThumbnail` 是照原型 `styleThumb` 一行一行译过来的 SwiftUI `Canvas` 实现（THUMB 12 根数据、`step = max(3, min(W/6, spacing*2.2))`、网格四态、实心 / 空心 / 描边逻辑、影线调色、末价虚线都对齐了），不是与主图共用同一段代码。等主界面把 `KanpanChart` 链进来，把 `draw` 换成图表的绘制入口即可，调用点不用动。现有证据是并排出图 + 「11 款两两不同」的回归锁。
2. **A6.4 / A6.7 / A6.8 / A6.9 / A6.10 的图表侧那一半**要等你把面板挂到主界面、把 `Prefs` 订阅进 `KanpanChart` 和 `KanpanData` 之后才能整条走完。M6 交的是「存对、传对、面板上点得动」。
3. **A6.11 在 app 里现在显示「数据层未接入」。** `MarketCache` 用 `#if canImport(KanpanData)` 做了桥接，真实现 `DiskMarketCache` 已经写好并在 `swift test` 里跑通（那边链了 `KanpanData`）；app target 一旦链上 `KanpanData`，同一份代码就自动量出真实数字。
4. **`make app-test` 当前红的不是 M6 的锅。** 唯一的报错是 `Kanpan/Kanpan/Diagnostics/MeasurementText.swift:151`（M9 那位还在写）。把 `Diagnostics/` 摘掉后同样的 scheme `BUILD SUCCEEDED`，`Panels/` 和 `Settings/` 零警告零报错。
5. **`Kanpan/Settings` 这个旁挂包还没进 Makefile。** 我不能改 `Makefile`，需要你加一行，照 `symbols-test` 的样子：

```make
settings-test:
	cd Kanpan/Settings && swift test $(CORE_TEST_FLAGS)
```

   再把它挂进 `app-test` / `test`。
