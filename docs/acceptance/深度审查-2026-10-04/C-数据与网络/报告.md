## 二、判为非 bug 的项（及理由）

- **`markPrice` 解析出非有限值**（`KanpanNetwork/.../DTO.swift:412`）：唯一消费者 `Kanpan/Kanpan/Main/MarketModel.swift:504` 已用 `isFinite` 守住，不会上屏。
- **OrderFlowCatalog 命中缓存但簿为空**：空簿就是「这家没有这只」，命中照常返回、不额外重拉是对的。
- **`MergedMarketStream.reconcileOnce` 的直落分支**：最坏多发一次订阅请求，订阅集是幂等的，无副作用。
- **`OISource.fetchMetric` 固定 30 天截断会让 OKX 替身去借币安归档**：不可达。调用处 `MarketModel.swift:235` 以 `hasDerivativeMetrics` 守门，只有币安有，而币安本来就有归档。
- **`CompareFeed.stop()` 取消 `inboxPump` 会终结 AsyncStream，stop 后再 start 会丢 `post(main:)`**：不可达。`Kanpan/Kanpan/Compare/CompareModel.swift:56` 每次都新建一个 feed，从不复用。
- **OrderFlowSlot 的脱离式清扫会删 `orderflow/` 下非 json 文件，可能撞上前一个 feed 正在保存**：不会撞。`.atomic` 写的临时文件落在系统的 item-replacement 目录，不在 `orderflow/` 里。
- **`Zip.inflate` 按 zip 头里写的解压大小一次分配**：来源只有币安公开归档站（HTTPS，≈ 12 KB 一个 zip）和自家网关；头坏了会在 `firstEntry` 的截断校验或 `inflate` 失败上抛错，不会静默给出错数据。
- **`SymbolCatalog` 单飞刷新里沿用发起者的 `now`**：同一趟刷新的所有等候者拿同一份已验过、已采纳的表，正是 B-05 要的；`now` 差几毫秒不影响 24 小时 TTL。
- **`OIArchive.parseCSV` 不校验日期分隔符**：归档站格式固定；数字位逐位校验，非数字整行丢弃，不会产生错时间。
