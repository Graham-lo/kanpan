## 三、判定不是 bug 的项

| 项 | 理由 |
|---|---|
| 对数轴刻度落在非整数位（e^n 一类） | 与 AICoin 手机端对数轴取刻度方式一致；对数 / 线性是用户自选项，不改 |
| 分析面板里点 WR、OBV 没有副图 | 产品范围内没有这两个副图指标，开关不存在 |
| 搜不到 USDCUSDT | `KanpanNetwork/Sources/KanpanNetwork/Binance/RESTClient.swift:161` `parseExchangeInfo` 故意排除稳定币为底的永续 |
| 网关线路下部分数字与直连不同 | 网关线路由 OKX 替身顶数（`KanpanNetwork/Sources/KanpanNetwork/Binance/Route.swift:3-5`），两家盘口本就不同 |
| 退登后落在行情页 | 设计如此（退登回到图表首页），「我的」页账号格同步变回「登录 / 注册」 |
| 自选页点「+」进搜索，键盘自己弹起 | 那是整页级搜索页（从搜索入口进），按 2026-09-18 定的规则自动聚焦是对的；「不自动弹键盘」只管换品种浮层。键盘为 ASCII 英文键盘，符合规则 |
| 板块总页头部仍有「N 个板块 · N 个品种」 | 「只留跑赢大盘」的规则只管下钻页头部，总页不在此列 |
| 周线下持仓副图只有最近一段 | 币安 `openInterestHist` 只给约 30 天，交易所数据上限 |
| 早先判的「1000SHIB 涨跌空着——未复现」 | 已推翻：时序相关，按走查原路线复现后列为 G7 修掉 |
