## 2. 与任务书不一致的地方（一律以原型为准）

开工提示词里说「原型即规格，两者冲突以原型为准并在 PR 里说明」。实现时遇到七处：

1. **价格刻度密度 46，不是 44。** 原型 `drawPriceGrid` 是 `niceStep(z - a, max(2, Math.floor(pane.h / 46)))`，任务书 §5 正文写 44。取 46。
2. **时间刻度密度 74，不是 78。** 原型 `timeTicks` 是 `timeStep(span, plotW, 74)`。取 74。
3. **成交量单位是万 / 亿，不是 K/M/B。** 原型 `fmtVol`：< 100 两位小数、< 1 万整数、< 1 亿「x.xx万」、再上「x.xx亿」。A1.11 写的是 K/M/B。取万 / 亿——中文盘面看万亿更顺，而且黄金值 fixture 是从原型导的，改单位等于改 fixture。
4. **命中阈值是线身 9 pt、手柄 12 pt，不是 8 pt。** 原型 `hitDraw` 用 `< 9` 和 `< 12`。A1.12 写「距离 ≤ 8pt」。取 9 / 12。
5. **趋势线不外延。** 原型只有水平线横跨整个 plot 宽；趋势线就是两点之间的线段。A1.12 的「趋势线延伸」按原型理解为「水平线延伸到两端」。
6. **长按是 320 ms，不是 450 ms。** 原型 `pointerdown` 里 `setTimeout(…, 320)`，位移上限 6 px。任务书 §7 的手势表写 450 ms。取 320。
7. **周期表里有 `1y`、没有 `3d`。** 原型 `ALL_PERIODS` 是 14 档：1m 3m 5m 15m 30m 1h 2h 4h 6h 12h 1d 1w 1M 1y。我先前把 `Interval` 写成了带 `3d` 不带 `1y`，这次已改正，并补上 `Aggregator`（1y 由 1M 按自然年 UTC 聚出来，币安没有 `1y` 这个 interval）。

### 实现上比原型多做的两处

这两处不是风格差异，是原型里的真 bug，照搬会在 app 上出事，所以修了：

1. **画线 ID 不撞号。** 原型是 `'d' + Date.now()`，同一毫秒内连画两条就是同一个 id，之后选中和删除会连坐。Swift 侧保留同样的前缀，再补一个进程内自增尾号。
2. **空序列上更新末根不崩。** `IndicatorEngine.updateTail` 原来在 `count == 0` 时会算出 `start = 1` 去扫零长数组，直接越界崩。WS 事件比 REST 历史先到就会走到这条路。现在空序列直接放过。

### 一处实现选择

**视野存的是 `to` + `span`（Double 毫秒），不是 `from` / `to`。** 任务书 §4 建议时间戳用 Int64。时间戳在 1.79e12 毫秒这个量级上，存 `from`/`to` 再相减会吃掉七八位有效数字，A1.7 要求的 `barSpacing` 前后差 < 1e-9 根本够不着（实测差 1.3e-9）。改成存右缘 + 窗宽之后，窗宽是第一手数据、不是减出来的，A1.7 的 14×14×10 组全部通过。序列里的 `openTime` 仍然是 Int64，只有视野这一个结构用 Double。
