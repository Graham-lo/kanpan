规格见 `docs/待办交接-Codex-2026-09-22.md` §3.6。代码提交 `a4057e2`（服务端、Caddy 转发、客户端、测试同一提交）。

## 做了什么
- **服务端导出** `GET /v1/auth/me/export`（`Backend/kanpan-api/src/export.rs`）
  - 在同一个 RLS 事务里把这个人的东西打成一份 `hkline-export-1` JSON，顶层键为 `account / exportedAt / format / friends / review / shares / sync`。
  - `sync` 里是同步对象（自选 / 画线 / 提醒 / 设置），`review` 里是复盘记录、事件和存下的相似案例。
  - 凭据不导出：密码哈希、会话、推送令牌都不在里面。
  - 单文件，超过 20 MB 回 413，不会悄悄截断。限速一小时十次。
- **隐私政策 / 服务条款**：`/privacy`、`/terms` 两张静态页，正文编进二进制（`legal.rs`），文案照规格写。Caddy 的账号路由把这两个路径转给 kanpan-api。
- **忘记密码**：不做客户端。运维 CLI `kanpan-api reset-password <用户名>` 打印一次性密码，同时吊销全部会话、清登录锁。写进了 `ops/README.md`。
- **客户端**
  - 账号页「导出我的数据」：先落一份 `Hkline-我的数据-<日期>.json`，再弹系统分享面板。复用画线快照那一处 present，全 app 只有一个分享面板入口。
  - 设置面板底部有「关于」一行：显示版本号和构建号（`Hkline 1.0.0 (1)`），右边两条链接「隐私政策」「服务条款」。
