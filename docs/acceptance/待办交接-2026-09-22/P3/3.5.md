# P3.5 验收：分享「回给他」

规格见 `docs/待办交接-Codex-2026-09-22.md` §3.5。代码提交 `a3a34a9`。

## 做了什么
- **服务端**（`Backend/kanpan-api/src/share.rs`）
  - 发送体加可选的 `replyTo`（分享 id）。
  - 校验：必须是 22 位字母数字，而且那封分享必须是**对方发给我**的（`to_user = 我 AND from_user = 收件人`）。不满足就回 400 `invalid_reply_to`，不能借回信给不相干的人塞东西。
  - 入库带 `reply_to`，收件箱 JSON 带 `replyTo`。
- **客户端**
  - 预览别人发来的画线时，卡片上多一个「回给他」（`share.reply`）。点了之后回到自己的图上，这些线留在图上接着画。顶部有一条「回给 XX · 发送 / 取消」（`ShareReplyBar`）。
  - 发送走原来的 `/v1/shares`，带上 `replyTo`。收件人的收件箱卡片标题写「XX 回了你」。
  - 切品种、切账号时回信状态自动清掉。那封原分享已经不在时，提示「这封已经回不了了」。
