# P2.3 验收报告：QuoteBook 写盘任务认取消

规格：`docs/待办交接-Codex-2026-09-22.md` §P2 第 2.3 行。`persistTask` 体内加取消检查，写法和同文件其余后台任务一致；补单测，断言 cancel 之后不落盘。

## 改动
- `Kanpan/Kanpan/Main/QuoteBook.swift`
  - `persistQuotes`：写盘改成一条链。新任务先 `await` 上一笔、再写盘；上一笔先被 `cancel()`。
    这样做的原因：两个 detached 任务谁先跑没有保证，只加取消检查的话，旧的那笔若已开写，仍可能晚于新的那笔落盘。
  - 真正的写入收成 `nonisolated static func writeSnapshot`，开写前先 `guard !Task.isCancelled`。
  - `persistBaselines` 原本是一个没人持有的 `Task.detached`，现在同样交给 `baselineTask` 串起来，并加了同样的取消检查。
- `Kanpan/KanpanTests/Tests/KanpanMainTests/QuoteBookPersistTests.swift`（新增）
  - `cancelledWriteLeavesNoFile`：任务把自己撤掉后调 `writeSnapshot`，文件不存在。
  - `liveWriteLands`：没被撤的任务照常写盘，文件读得回来。

## 测试
- `cd Kanpan/KanpanTests && xcodebuild test -scheme KanpanMain -destination 'platform=iOS Simulator,id=<p2 模拟器>' -only-testing:KanpanMainTests/QuoteBookPersistTests`：2 条通过，见 `logs/main-test.log`。
- App 构建 `xcodebuild build -workspace Kanpan.xcworkspace -scheme Kanpan -destination 'generic/platform=iOS Simulator'`：`BUILD EXIT 0`，见 `logs/app-build.log`。
