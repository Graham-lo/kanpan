# P2.9 验收报告：触觉收拢到一个包装里，成功与警告两种通知震感

规格：`docs/待办交接-Codex-2026-09-22.md` §P2 第 2.9 行。要求：
- 记下、判定、登录震 success；
- 删除、恢复默认、退出震 warning；
- 所有触觉都收进现有的触觉包装。

## 做法
- 现有包装 `Haptics`（`KanpanChart/Sources/KanpanChart/ChartView+Gesture.swift`）改成 `public`，app 各处都从这里出。新增六个出口：

| 出口 | 震感 | 用在 |
|---|---|---|
| `tap()` | light | 点星、宿主上的轻点 |
| `press()` | medium | 选中品种、拖完排序 |
| `step()` | selection | 换一档（原来散在 MainScreen / ChartHost 的 `UISelectionFeedbackGenerator`） |
| `alarm()` | rigid | 前台提醒响（原来 AlertWatcher 自己 new 的） |
| `success()` | notification .success | 记下、判定、登录 |
| `warning()` | notification .warning | 删除、恢复默认、清缓存、退出 |

- app 里原来各处自己 new 的 `UIImpactFeedbackGenerator` / `UISelectionFeedbackGenerator` 全部换掉。`SymbolPickerView` 自带的 `haptic` / `HapticStyle` 小工具也删了。复查命令 `grep -rn "FeedbackGenerator" Kanpan/Kanpan` 结果为零。
- success 的三处：
  - **记下**：记下卡 `onSaved`（`MainScreen`）。
  - **判定**：`ReviewFeature.saveReflection(publish:)` 发布成功、`resolveGroup` 成功时，经新增的 `onFeedback(.done)` 通知宿主，宿主调用 `Haptics.success()`。复盘包不依赖 KanpanChart，所以用回调，不直接调用。
  - **登录**：`AccountFeature.accept` 登录或注册成功。
- warning 的各处：
  - 删自选：自选页、品种页、板块品种列表。
  - 删除当前分类。
  - 作废记录：`holdVoid` → `onFeedback(.removed)`。
  - 删画线、清空画线。
  - 删提醒、删好友。
  - 清搜索历史。
  - 指标「恢复默认颜色」、删周期。
  - 设置「恢复默认」、清缓存。
  - 「退出登录」、设备列表里的「退出」。
- 模拟器摸不到震动，所以包装里加了一行 DEBUG 日志（subsystem `kanpan.haptics`，内容为 `haptic <kind>`），用来证明「该震的时候确实调用了」。Release 包里不存在这行。
- 顺带修了一处 P2.7 的遗留问题（`Kanpan/Kanpan/Main/ToastCenter.swift`，单独一个提交）：
  - 提示窗在没有提示时藏起来（`isHidden`），有提示时才出现。
  - 状态栏和转向都转交主窗口决定。一扇常驻的透明全屏窗不应该替界面做这两件事。

  - 草稿保存不震；

  - 作废报一次 `.removed`。
- `xcodebuild build`（generic iOS Simulator）通过。
