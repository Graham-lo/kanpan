# P2.13 动态字体跟随：验收报告

- 日期：2026-09-23
- 实现与验收：p2dt 子代理（Claude Opus 5.5）
- 基点：origin/main 3c9462f
- 模拟器：克隆的 iPhone 17 Pro（iOS 26.5）
- AX3 的写法：启动参数用 `UICTContentSizeCategoryAccessibilityXL`，simctl 里是 `accessibility-extra-large`

## 做了什么

图表画布以外的字改为跟随系统「文字大小」，整个 app 最大只放到 `.xxxLarge`。
行情页头部（顶栏品种行、价格、六格、十字线读数行、提醒小确认）单独封顶在默认档 `.large`。

### 封顶的做法

| 位置 | 封顶 | 原因 |
|---|---|---|
| `KanpanApp.swift` 的 `MainScreen()` 根 | `...DynamicTypeSize.xxxLarge` | AX1–AX5 会把自选、板块这类密集列表撑爆。环境值会一路继承，面板和 sheet 都会吃到，截图已证实 |
| `MainScreenParts.swift` 的 `MainHeaderView` 整块头部 | `...DynamicTypeSize.large` | 头部高度不能变，六格要留在价格右边，不许换排版、不许缩字截字。这一档比 P0 D.13 原来只挂在价格行上的 `.xLarge` 更严，所以把旧的那条挪上来、罩住整块头部 |

### 字号怎么随系统放大

- `PanelTheme.swift` 新增 `ScaledFont`，记三样东西：设计字号、字重、字体设计。
  - 相对的文本样式按字号自动取最近的一档：11→caption2、12→caption、13→footnote、15→subheadline、17→body……也可以手动指定。
  - 配套的 `ScaledFontModifier` 用 `@ScaledMetric(relativeTo:)` 算出实际字号。
  - 再加一个重载 `View.font(_: ScaledFont)`。
- 这样 `PanelFont` 的 12 个常量改成 `ScaledFont` 以后，所有 `.font(PanelFont.x)` 调用点一个字都不用改。
- 零散的 `.font(.system(size: N, weight: w))` 按原参数机械换成 `.font(.scaled(N, w))`，调用点的结构不动。
- 默认档 `.large` 下 `@ScaledMetric` 返回的就是原字号，所以默认档渲染一个像素都没变。
- 两个皮肤衬线函数 `serif(_:)`（FavoritesView、SectorPage 各一个）返回值改成 `ScaledFont`，调用点也不变。

### 刻意不动的

- KanpanChart 画布和它的像素基线。
- 画布以外、但本质是画图产物的渲染器：ChartSnapshotRenderer、ShareCard、SectorBubbleRenderer。
- 图标与徽章：底栏 TabBar、CoinBadge，以及所有 `Image(systemName:)` 的字号。
- 周期条 IntervalBar，按既定尺寸保持不动。
- 横屏画线工作台的工具栏：LandscapeChrome、DrawingBar、DrawingToolPicker、DrawingSymbolSwitcher。它和周期条一样是工具条，保持既定尺寸。
- 十字线读数行本来就在头部封顶以内。
- 账号页和复盘本来就用语义字体，只是被根封顶一并管住。

```

```

  六格的 minX（202.7）落在价格 maxX（105.3）和涨跌行右边再加 7.5 之外，且在屏幕右缘以内。价格、六格、周期条的位置在两档之间 0 pt 差异。

## 判断与假设

1. 任务里给的 `accessibility-extra-extra-large` 在 simctl 中其实是 AX4。本次按「AX3」取 `accessibility-extra-large`，对应 `UICTContentSizeCategoryAccessibilityXL`。
2. 头部的 `.large` 封顶罩住整块头部，而不只是价格加六格；原因是顶栏品种行一旦放大就会把六格往下顶，同样违反「头部不增高」。
3. 大字号下的兜底只在 `dynamicTypeSize > .large` 时生效，默认档的布局代码路径和原来一样，因此不影响既有 UI 用例和截图基线。
4. 中文副文案在两行时按字断行，例如「跑/赢」「成交/额」，这是系统对中文的正常断行，不算截字。
