   - 判定为模拟器环境问题，与 P2 的改动无关，没有改这个用例。证据见 `P2/2.9/logs/`。
2. **2.15 选「网关」线路时不显示「新」。**
   - Python 网关的 `/market/v1/instruments` 从 OKX 转成币安格式时，没有带 `onboardDate`。
   - 按规矩，后端新功能写在 Rust 的 kanpan-api，不往 Python 网关里补。所以这件事留给多交易所 InstrumentID 阶段：那时解析 OKX 目录，顺手带上 `listTime`。
   - 出厂默认是直连，不受影响。
3. 2.2 的帧探针只在 DEBUG 下接入，Release 零调用，符合规格。
