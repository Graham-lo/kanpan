**第一次跑量出来的卡，九成是测量工具自己。** `sample` 采主线程：12425 笔里 11221 笔在 `__NSStringDrawingEngine`（断行 6332、栅格化 4854），app 自己的代码约 1%。源头是诊断浮层里的 `market.network`——一个 1 pt、0.01 透明的 `Text`，装着最多 8000 字的网络日志，每出一笔请求就追加一行，整段重新断行、塑形、栅格化。它只在 DEBUG + `KANPAN_CHART_DIAGNOSTICS=1` 下出现，正式包不受影响，但它让所有 UI 压测的数字作废。改成只挂 `.accessibilityLabel`（用例照旧读得到全文）后，同一风暴里主线程每 13.3k 笔样本中约 8500–10400 笔空闲，K 线绘制 640–890，`ChartHost.updateUIView` 约 400，文字绘制约 250。

## 5. 弱网 / 6. 长时间运行 / 7. 小组件与实时活动

只读审查（弱网断网 / 通宵运行 / 小组件与实时活动）＋ 计数型单测。

- **H1 断网后顶栏永远不变灰**（`MarketModel.swift` `priceFresh`）：`tickerStale` 只在换线路时置真，推送连接断了 `status` 变 offline 却没人读，顶栏价格、涨跌、六格照旧全彩，交易员拿几分钟前的价当现价。修：前台里连接不在 `.live` 起算，满 5 秒翻 `linkDown` 灰显，接上立刻复原；5 秒内闪断看不见，后台不计（bfc1c816）。自选行的灰显在 Symbols，转交。
- **M1 小组件快照每次偏好变动都整份重写**（`WidgetFeed.track`）：观察的是整只 `Prefs` / `SymbolPrefs`，换周期、捏合松手、扫图记最近看过都触发主线程编码 + 落盘 + 叫扩展重排时间线。修：比较 shape 串，真变了才写（fe0153ae）。
- **M2 走势给全部自选取数**：300 只自选每 15 分钟取 300 段 1h×24，closes 与账本只增不减。修：扩展把正在画的那只记进 App Group 的 `widget-sparklines.json`（两天过期），app 只取「在自选里且被画着」的几只，其余连账本一起放掉（fe0153ae）。
- **L4 小组件时间戳冒充「现在」**：没有 `timeMs` 的种子价每 30 秒被盖成 now，30 分钟淡化失效。修：先用 `QuoteBook` 记下的收到时刻，都不知道写 0（fe0153ae）。
- **L1 收件箱毒丸**：回执遇到 400 / 410 这类永久错误后 flush 每次都卡在它上面，收件箱再也刷不出新信。修：4xx 除 401 / 403 / 408 / 429 外视为回执已死丢掉（74ebbce7）。**L2** 「暂时连不上，请重试 · 重试」重复，去掉文案里的「请重试」（74ebbce7）。
- **M4 同类（本线目录里的那一半）**：重温取数失败直接摆 `error.localizedDescription`，弱网下是「请求超时。」、非本地化错误露类型名。修：`ReviewChartBridge.message(for:)`（85cc1e70）。账号 / 同步那一半转交。
- 长时间运行：QuoteBook 重连、退避、后台宽限拆连接、SectorFeed / SectorHistoryFeed 退避封顶、订单流本地日志 24 h / 5000 条、KanpanChart 各缓存都有界——看过没问题。通宵慢增长只剩 L3 余项（见第 9 节）。
- 生命周期审查另抓到三处本线的并修了：心跳在 `.inactive` 就停、倒计时一拉通知中心就闪没（c9388b56）；后台宽限期里换品种 / 换线路会把持仓量轮询和费率整表重新拉起（60618ebe）；停在板块页进后台「5 日」取数循环照跑（61d6c22a）。

## 9. 已看过不改

| 项 | 位置 | 为什么不改 |
|---|---|---|
| 300 条画线的敌意数据每帧约 20 ms | KanpanChart 绘制 | 用户手里每品种上限 50 条（≤ 9 ms）；300 条只能从同步 / 收件箱越过上限进来，掉到约 50 fps、不卡死。上限该在入口卡住，不在渲染里特判 |
| 面板开关剩下 23 次 100–275 ms | 系统 sheet 弹出 / 收起 | 采样里没有单独成块的 app 热点（主线程约 75% 空闲，XCUITest 无障碍快照 6.5%，K 线 2.5%，Debug 构建）；「更多」必须是弹层、指标 / 图表设置是面板，这是定稿形态 |
| 快切风暴剩下 23 次 101–142 ms | 换品种冷路径 | 400 次操作里零星 23 次、全在 142 ms 以内，K 线重画 + `ChartHost.updateUIView` 为主，Debug 构建；Release 会更低 |
| 通宵慢增长余项（L3 余下部分） | `MarketModel.lockedPrecision`、`OrderFlowFactsTable`、`MarketStats.metaCache` 等 | 上限是品种表（几百只），一夜几十 KB；小组件那两张表已随自选裁剪（fe0153ae） |
| L5 对比态每次推送分配一个时间数组 | `Compare/CompareModel.swift` `series()` | 十几 KB 的短命分配，对齐结果本身有缓存；没量到可见影响 |
| 生命周期 D：内存警告只清当前 feed 的 K 线缓存 | `MarketModel.swift:386` → KanpanData | 其余缓存都有界（`oiMemo` 24、QuoteBook 按 wanted 裁剪）；大头 feed 缓存与非当前线路 provider 在 KanpanData，转交 |
| 生命周期 E / F：`MemoryWarningRelay`、`registerResources(id:"feeds")` 按固定 id 覆盖 | `App/MemoryWarningRelay.swift:37`、`MainScreen.swift:1462/1467` | 只在 iPad 多窗口下成立，而工程没开 `UIApplicationSupportsMultipleScenes`；iPad 只要求「不破」 |
| 生命周期 G：WidgetFeed 表不修剪 | `Widget/WidgetFeed.swift` | 已随 fe0153ae 按「在自选里且被画着」裁剪 |
| `PrefsStore` 每次点按同步写 | Settings | 「手势一松立刻落盘」是用户定的规矩；且不在本线目录 |
| 板块页 body 里给列表层算 20 日中位数 | `Sector/SectorPage.swift` | 只算一个板块，开销小 |
| 冷启动直接进后台时闸位不对 | `AppLifecycle` | Info.plist 没有 UIBackgroundModes，路径不可达；将来加后台模式时要修 |
| `wireWidget` 等闭包无捕获列表形成引用环 | `MainScreen.swift:1619` 起 | 只影响根视图销毁（iPad 关窗），前后台压测里不触发 |
