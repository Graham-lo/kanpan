# 提醒铃声 · 阶段 2

日期：2026-09-22。阶段开始已 `git fetch && git rebase origin/main`，基线为阶段一 `20d057d`。

## 实现与假设

- 提醒总表只新增顶部「提醒铃声 · 当前值」一行，推入四行单选页。沿用 PanelSheet / PanelRow、字号、三套皮肤及右侧勾选，不重排原提醒列表，不增加第二个入口或解释文案。
- 点击即保存并试听，可在同页连续比较。按本功能交接书「推一页四行单选」保留该页，返回后总表同步显示选择；不另设确认按钮。
- 三段自备音使用 AVAudioPlayer，音频会话 `.ambient`，单次播放；再次点击、离页、应用离开前台均停止旧试听。前后台管理复用 AppLifecycle。
- iOS 没有公开的系统默认铃声文件 URL，不能把系统默认声交给 AVAudioPlayer。默认档用只带 `.default` sound 的本地通知试听，只使用已获通知权限，不在选择页另要权限；通知代理仅返回 `.sound`，不产生试听横幅。这是公开 API 限制下的实现差异。[Apple AudioServices 说明](https://developer.apple.com/documentation/audiotoolbox/audioservicesplayalertsound(_:))明确 iOS 不提供系统预设声 ID；未使用私有路径或硬编码系统声编号。
- AlertWatcher 在每次触发时读取当前账号偏好，本地通知使用对应 CAF；前台价格通知允许 sound、继续压制重复横幅。复盘到期通知源码与原有前台呈现保持原样，仍用系统声。
