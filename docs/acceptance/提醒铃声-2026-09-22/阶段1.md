# 提醒铃声 · 阶段 1

日期：2026-09-22。工作树 `kanpan-ringtone`，分支 `alert-sound`。

## 实现

- `Tools/make-alert-sounds.py` 合成三段原创短音，输出 app target 资源 `alert-crisp.caf` / `alert-electronic.caf` / `alert-glass.caf`。采样率 44100 Hz、单声道 IMA4 CAF；时长分别 0.85 / 1.05 / 1.40 秒，统一 −20 dBFS RMS，无削波。两次重建 SHA256 一致。
- `Prefs.alertSound` 为四值枚举（default / crisp / electronic / glass），默认系统声。缺字段、未知值、错误类型均只回退这一项；不改存档版本，不重置其它偏好。
- 字段归类为 synced，契约通过 `make sync-contract` 生成。服务端字段白名单与值规则同步加入；非法文件名、未知枚举与错误类型拒绝。
- 单测覆盖四档资源映射、编码往返、重新加载存储、同步上行与下行、旧客户端缺字段，以及服务端真实 merge 路径。
