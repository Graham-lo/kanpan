## 一、现状诊断

1. **底栏四格是四种东西。** 复盘、自选会整页跳走，指标、设置只抬起半屏面板，而只有面板那两格会亮成琥珀色——点之前无法预判屏幕会发生什么。
2. **同一份自选数据有三套行样式。** 顶栏弹层里是「BTC / USDT 永续 · 75920.40」，自选页是「首字母牌 + 额/振幅 + 红色填充胶囊」，品种页又是第三套；连数字格式都不一致，顶栏写 75,925.50，自选页写 75925.50。
3. **换品种要穿三层。** 顶栏品种名 → 半屏弹层 →「全部自选与分组」→ 全屏自选页，中间弹层先落下、页面再升起，有一段谁都不在的空窗。
4. **14 个周期只有 5 个在条上。** 第 6 个起要点「更多」开一张 14 行的长表；这张表在半屏高度只露得出 7 行，想往下滑它会先被抻成全屏，再滑才是滑。
5. **状态只有一颗灰点，还要长按 0.35 秒才肯说话。** 数据多久没动、在不在重连、有没有同步失败，平时一个字都看不到。
6. **三种强调色同时在跑。** 应用是琥珀，复盘是系统橙，设置的「开盘时间」和记一笔卡片的「收起 / 把握 / 找相似」是系统蓝；更糟的是面板里的开关打开时用的是「涨」色，用户一旦切成红涨绿跌，全 app 的开关会跟着变红。
7. **破坏性操作既没有确认也没有撤销。**「重置所有偏好设置」点一下就清空，「删除当前分类」点一下就没。
8. **平时不用动的东西占着最显眼的位置。** 设置里四张 130×90 的配色卡片横着滚，比下面所有开关加起来还大；再往下 `fapi.binance.com`、`fstream.binance.com` 直接摆在普通设置里。
9. **空状态照样把控件全渲染出来。** 自选为空时涨跌统计条和五个排序按钮原样在；品种页搜索框永远挂着一个「清空」；复盘空页底下还有一条没有来源的分割线。
10. **列表在手指底下自己动。** 在品种页点星标，那一行立刻跳到顶部的「自选」组，下面整列往上顶——连点两下必然星错品种（本次走查实测中招）。
11. **搜索框吃中文输入法。** 默认拼音键盘下敲 `eth`，字段里留下的是「儿童画」，列表回一句「没有这个品种」，没有下一步。

> 图表本体备注（不在本轮范围，仅记录）：记一笔卡片升起时主图与副图被压扁，MACD 收成一条缝——卡片应该覆盖而不是挤压。

## 二、设计原则

1. **三秒够用。** 首屏要在三秒内回答「我关心的那个东西现在怎么样」，其余一切都排在这之后。
2. **默认替用户定。** 能从上下文推出来的（周期、品种、排序、配色、线路）一律不问；把选择权留给真正因人而异的那几件事。
3. **一份数据一套样式。** 同一个品种在任何地方长得一样、数字格式一样、点下去反应一样。
4. **手指够得着的地方放高频。** 一天点几十次的控件必须在屏幕下半部；一个月点一次的可以躲进二级页。
5. **安静。** 动效、颜色、提示都压到几乎注意不到；只有价格剧烈变动、连接断了、东西没存上时才允许提高音量。
6. **不丢东西。** 任何入口合并都必须写清被合掉的功能从哪条新路走到；宁可多留一条路，不许悄悄消失。
7. **动效只解释「我从哪来」。** 换页、展开可以有；周期、品种、排序这种一天几十次的动作一帧都不许动。

## 三、信息架构

### 3.1 现状

```
盘面 MainScreen ──┬─ 顶栏品种名 → 半屏自选弹层 ─┬─ 搜索品种 → 全屏品种页
                  │                              └─ 全部自选与分组 → 全屏自选页
                  ├─ 周期条：5 个周期 │ 更多▾ │ 画线 │ 记 │ 图表
                  └─ 底栏：复盘(页) │ 指标(面板) │ 自选(页) │ 设置(面板)
                                                              └─ 登录 → 账号栈(5 页)
面板：周期 / 指标 / 图表 / 设置        页：自选 / 品种 / 复盘 / 账号
```
去处 4 个、面板 4 个、弹层 1 个，共 9 处，互相之间有 3 条重复路径。

### 3.2 提案

```
┌───────────────────────────────────────────────┐
│  盘面（唯一首屏，冷启动落点）                    │  ← 每天 30–60 次
│   顶栏：品种 ⌄ · 状态 · ★ ／ 价格 · 涨跌 · 高低额 │
│   周期条：6 个学来的周期 │ ⌄ ‖ 画线              │
│   图表（冻结区）                                 │
│   底栏：自选 │ 复盘 │ 记 │ 调图                  │
└───────────────────────────────────────────────┘
      │              │        │        │
      │              │        │        └─ 调图面板（半屏，三段）      每天 1–3 次
      │              │        │            ① 图表  ② 指标  ③ 偏好
      │              │        │                        └─ 账号 / 诊断
      │              │        └─ 记一笔卡片（原地升起，不跳页）      每天 0–3 次
      │              └─ 复盘页（整页 cover）                        每天 1 次
      │                  摘要条 + 一个列表（全部/待判定/已判定）
      │                      └─ 记录详情（push）→「在图上重温」→ 盘面
      └─ 自选层（从顶部下拉覆盖，图表留在下面）                     每天 10–20 次
          搜索框 + 分区 chips + 清单；搜索框一聚焦，原地变搜索结果
```

去处从 9 处降到 **4 处**：盘面、自选层、复盘、调图面板。

### 3.3 与现状的差异，以及被合掉的功能落在哪

| 被取消的 | 新路径 |
|---|---|
| 底栏「指标」格 | 调图面板 ② 指标段（内容一字不改） |
| 底栏「设置」格 | 调图面板 ③ 偏好段 |
| 周期条尾部「图表」 | 调图面板 ① 图表段 |
| 周期条尾部「记」 | 底栏「记」格（更靠拇指，且盘面/复盘都能按） |
| 周期条「更多 ▾」 | 周期条第 7 格「⌄」，原地下拉 14 格全表 |
| 周期面板的图钉 | 全表里长按任一格＝钉住/取消钉住，功能与上限（1–8）不变 |
| 半屏自选弹层 | 自选层（顶栏品种名 ⌄ 与底栏「自选」都下拉它，是同一层） |
| 弹层里的「全部自选与分组」中转行 | 取消中转，自选层本身就是完整的分类页 |
| 弹层里的「搜索品种」中转行 | 自选层顶部的搜索框，聚焦即搜 |
| 全屏品种页 | 并入自选层的搜索态；市场/板块筛选变成搜索框下的一行 chips |
| 自选页「‹ 行情」返回 | 向上推自选层，或点层下方露出的图表区 |
| 自选页的排序条（5 个控件） | 「⋯」菜单里的一项「按涨跌幅排（临时）」 |

| 复盘的 待办/记录/战绩 三段选择器 | 待办→列表 chips「待判定」；战绩→页顶摘要条，点开是完整战绩 |
| 设置里的 API 域名 / 推送域名 / 清缓存 | 偏好段最底一行「诊断」，二级页 |

## 四、场景剧本

### 场景 1 · 早上第一次打开
**他想要的：** 昨晚睡着以后，我那几个东西有没有出事。
**他会做的：** 解锁 → 点图标 → 看一眼 → 下拉看清单 → 关掉。全程 6 秒。
**app 应该：** 冷启动直接落在**上次那张图**上；120ms 内顶栏就有上次的品种名和上次收到的价格（灰一档，右上写「上次 07:41」）；250ms 内本地快照把 K 线画出来；第一帧实时价一到，价格切回实时色，状态字变「实时」，图表右端补齐——整个过程没有 spinner、没有白屏、没有骨架抖动。他下拉出自选层，10 行清单一次画完，跌得厉害的那两行左侧有一条 2pt 的竖色条。他松手，层缩回去，图还在原来的位置。

### 场景 2 · 排队时看 3 秒
**他想要的：** 就看一眼涨跌幅，别的都不要。
**他会做的：** 单手，拇指从底部上滑唤醒 → 点图标 → 眼睛扫左上角 → 锁屏。
**app 应该：** 最新价是屏幕上最大的字（28pt），涨跌幅紧跟在右边同色；高/低/额缩成下面一行 11pt 灰字，他的眼睛不会被它们绊住。**不要**因为他回来就弹 toast、不要播动画、不要把图表重新加载一遍。如果离开不到 30 秒，画面原封不动，只是数据补上；超过 30 秒，价格先变灰并写「离开了 5 分钟」，补完再恢复颜色。

### 场景 3 · 某个币突然暴动
**他想要的：** 是哪个、多大、我现在该不该打开看。
**他会做的：** 可能在别的 app 里，也可能手机在口袋里。
**app 应该：** 这是**唯一允许提高音量**的场合。自选里任一品种 5 分钟涨跌超过 1.5%，发一条安静通知：「SOL 5 分钟 +2.3% ｜ 213.40」。点通知直接落到那个品种的 5m 图（不是首页再点两下）。如果他此刻正开着 app：那一行的涨跌幅色块加 1pt 描边、行左侧出现 2pt 竖色条，**但这一行不上浮**——位置记忆比即时性重要，浮上去会让他下次找不到别的品种。

### 场景 4 · 晚上坐下来研究
**他想要的：** 把图看清楚、画两条线、把今天的判断记下来。
**他会做的：** 点「画线」进横屏 → 画 → 转回竖屏 → 点底栏「记」→ 写一句 → 记下。
**app 应该：** 点「画线」直接横屏，指标全部不画，只留原始 K 线和工具；画完点「完成」自动转回竖屏，画的线还在原位。回到竖屏点「记」，记一笔卡片从底部**覆盖**升起（0.2s），图表不被压扁，选中的区间在图上高亮并显示「49 根 · 9/14 13:00 – 9/16 14:00」。卡片里只有 4 件事：方向、一句话、把握、记下。填不填把握都能记。点「记下」——卡片落下，底部一条 toast「已记下 · 撤销」，1.8 秒后消失。

### 场景 5 · 刚装上，自选是空的
**他想要的：** 别让我先学一遍怎么用。
**他会做的：** 打开 → 看到一张图 → 想加自己的币。
**app 应该：** 不做引导页、不做权限说明。直接落在 BTCUSDT 的 1h 图上（替他定了），顶栏星标是空心的。他下拉自选层，看到的不是「暂无自选 ⭐」，而是**按成交额排好的前 20 个品种**，顶上一行 11pt 灰字「点星加进自选」。他点三个星——被点的那一行**留在原地**，只是星变实心、右侧多一个「已加入」的 0.8s 微光，列表不重排。加完往上推，图还在。

### 场景 6 · 地铁里没网，出站恢复
**他想要的：** 别骗我，也别把我画的线弄丢。
**他会做的：** 打开 → 发现数字不动 → 过几站再打开。
**app 应该：** 断网瞬间不弹任何东西。顶栏右上的状态字从「实时」变「重连中」（琥珀色，1.2 秒一次的缓慢呼吸），价格降为灰色并保留最后一次的值，图表**不清空**。他画的线、写到一半的记一笔草稿全部留在本机。恢复网络后：价格闪一次（120ms）、状态字回「实时」、静默补齐 K 线，**不弹 toast**。只有两种情况才出声：① 换了行情线路 → toast「已切到备用线路」；② 有记录没上传成功 → 顶栏状态位写「3 条待上传」，点一下手动重试。

## 五、逐页设计

### 5.1 盘面（首屏）

**目标：** 三秒内回答「现在多少、涨跌多少、数据新不新鲜」。

**信息层次**
- 一级：最新价、涨跌幅
- 二级：品种名、数据状态、图表
- 三级：24h 高/低/额/振幅、周期条、底栏

**布局主张**

```
 ┌ 16 ────────────────────────────────── 16 ┐
 │ BTCUSDT ⌄            ● 实时        ★     │  24pt  ← 行1
 │                                           │  6pt
 │ 75,942.00  -2.12%      高 77691.50        │  34pt ← 行2
 │                        低 74909.40        │
 │ 额 170.6亿 · 振幅 3.59%                    │  16pt ← 行3
 ├───────────────────────────────────────────┤  1pt hairline
 │  1m   5m  15m   1h   4h   1d   ⌄ ‖  画线  │  44pt
 ├───────────────────────────────────────────┤  1pt
 │                                           │
 │                 图 表                      │  ~610pt（冻结区）
 │                                           │
 ├───────────────────────────────────────────┤
 │   自选      复盘       记       调图        │  56pt + 安全区
 └───────────────────────────────────────────┘
```

- 页边距 **16pt**（现状 12pt，太紧，价格贴边）。
- 顶部区总高 **80pt**＝8(上) + 24 + 6 + 34 + 16 − 8(行间压缩)；现状 76pt，只多 4pt，但最新价从 18pt 长到 **28pt**（1.56×）。
- 最新价 **28pt semibold monospaced**，涨跌幅 **15pt semibold monospaced**，同色，基线对齐，之间 8pt。
- 高/低 **11pt monospaced**，标签 10.5pt ink3，右对齐，两行堆叠，占右侧 120pt。
- 额/振幅 **11pt** ink3 单行，永远显示（现状在 402pt 宽下被 `ViewThatFits` 整条丢掉，等于这台设备上永远看不见成交额）。
- 一屏可点目标 **16 个**，按重要性从上到下、从左到右：价格区（不可点，最大）→ 品种名 → 状态 → 星标 → 6 个周期 → ⌄ → 画线 → 图表 → 4 个底栏格。

**交互细节**
- 品种名整块（含 ⌄）是一个 44pt 高的热区，点击下拉自选层。
- 「永续」徽标只在加密永续上出现；美股品种不显示（现状会给美股也挂「永续」）。
- 星标点击：实心/空心即时互换，**无动画**，触感 `selection`，不弹 toast。
- 状态位是文字不是点，见 §5.7。

**动效**
- 品种切换、周期切换：**0ms**，图表内容直接换。
- 价格变化：数字背后 120ms 淡入 / 180ms 淡出的一层涨跌色 8% 底纹，仅限 28pt 的主价位。
- 自选层下拉：0.26s，见 §六。

**空 / 错 / 加载**
- 加载（冷启动）：不用 spinner。顶栏先出上次的品种名与上次的价格（灰），状态字「上次 07:41」；图表用本地快照。
- 空（首次安装、无快照）：直接给 BTCUSDT 1h，不给空页。
- 错（行情连不上）：图表保留最后一屏，状态字「离线 · 轻点重试」，可点。

**差异 / 被影响的旧功能**
- 周期条尾部的「记」和「图表」被取消 → 见 §3.3 表。
- `ViewThatFits` 的三级降级被取消 → 改为固定三行，成交额不再消失。

### 5.2 周期条

**目标：** 常看的 1 击、任意 14 个 2 击，且位置不许变来变去。

**布局主张**
- 固定 **7 格，不横滚**：6 个周期 + 1 个「⌄」。每格宽 **45pt**、高 **44pt**。
- 右端「画线」**52pt**，与周期区之间 1pt 竖线、左右各 11pt 内边距。合计 7×45 + 1 + 52 = 368 ≈ 370（370 = 402 − 16×2）。
- 选中态：文字转 **琥珀 + semibold**，底部 2pt 琥珀短线，宽度＝文字宽 + 8pt，居中（现状是 inset 10 的长下划线，在 45pt 格子里比例失衡）。
- 未选中：13pt medium，ink2。

**app 自己学常用周期（取代手动图钉）**
- 统计口径用**停留时长**而不是点击次数——点错了也算一次点击，但不会停留。近 14 天每个周期的累计停留秒数，取前 6。
- 排列顺序**永远按周期从小到大**，不按频次排——频次排会让格子天天换位置，肌肉记忆立刻失效。
- 每天只在凌晨更新一次，且**一次最多换 1 格**，避免「昨天还在这儿今天没了」。
- 图钉功能保留：在全表里长按任一格＝钉住（锁定进 6 格）／取消钉住，上限仍是 1–8。被钉住的格子不参与学习淘汰。

**「⌄」下拉全表**
- 点「⌄」，一张 14 格网格**原地从周期条下沿展开**（不是 sheet、不跳页），**4 列 × 4 行**，每格 88×52pt，覆盖图表上沿约 **220pt**，0.2s。
- 格内：上行中文名 13pt，下行原始代号 10pt ink3（`1m` `4h` `1w`）。当前周期琥珀描边。
- 选中即收起，图表在收起动画开始的同一帧就换好数据。
- 长按格子＝钉住，钉住的格子右上角一个 8pt 的琥珀小点（现状是一排 36×30 的图钉按钮，贴在 402pt 屏的最右边缘，单手够不着）。

**跨品种是否沿用**
- **沿用，全局只有一个当前周期。** 理由：他一天扫几十次，脑子里装的是「我在看 1h」；换个品种还要重新确认周期，是凭空多出来的一次确认。
- 例外只有一种：目标市场不支持当前周期时，自动降到最近的合法周期，并让那一格闪 0.3s 琥珀——**降级要被看见，但不值得弹窗**。

**手势**
- **不在图上做左右滑切周期。** 图上的左右滑是平移 K 线，属于冻结区，抢不得。
- **在周期条上左右滑** 可以在 6 格之间移动选择：安全（这条本来就是横的）、可发现（手指已经在上面）、不影响图。每跨一格给一次 `selection` 触感，**无动画**。

**动效 / 三态**
- 切换周期：0ms。展开全表：0.2s。收起：0.18s。
- 没有空态和错态（周期永远是这 14 个）；数据没加载完时格子照常可点，图表自己处理。

**被影响的旧功能**：「更多 · 2h」尾按钮、周期面板、面板里的图钉列表、面板底部「点图钉设为常用」的说明文字——全部落到「⌄ 全表」里，说明文字直接删掉（长按有触感反馈，不需要解释）。

### 5.3 自选层

**目标：** 一次下拉看完全部持仓关注，并在两击内换到任意一个品种。

**为什么是「层」不是「页」**
自选和行情不是两个地方，是**同一件事的两种密度**。所以它从顶部下拉覆盖，图表留在底下不卸载，回去时滚动位置、缩放、画的线全在——现状是整页替换，回来要重新定位。

**布局主张**

```
 ┌───────────────────────────────────────────┐
 │        ▁▁▁▁                                │  下拉把手 5pt
 │ 🔍 搜 BTC、ETH、SOL                        │  44pt
 │ 全部  加密  美股  ⋯          涨 3 · 跌 7   │  36pt
 ├───────────────────────────────────────────┤
 │▏B  BTC /USDT  永续      75,942.00  -2.12% │  56pt
 │   额 170.6亿 · 振幅 3.59%                  │
 ├───────────────────────────────────────────┤
 │▏S  SOL /USDT  永续         213.40  +2.31% │  56pt
 ...
```

- 行高 **56pt**（现状 64pt），左边距 16pt，首字母牌 **28×28 圆角 8**。
- 品种名 **15pt semibold**，`/USDT` 11pt ink3，「永续」9pt 徽标。
- 价格 **15pt monospaced**，与顶栏同一套千分位格式（现状两处不一致）。
- 涨跌幅 **13pt semibold monospaced**，**纯文字着色，不用填充胶囊**——一屏 10 个红色填充块太吵，违反「安静」。
- |Δ| ≥ 5% 时：涨跌幅加 1pt 同色描边 + 行首 2pt 竖色条。**行不上浮。**
- 分区 chips **36pt 高**（现状 58pt 的分类头），只在存在自建分组时才多出第 3 个以后的 chip；默认只有「全部 / 加密 / 美股」。

**三个「是不是真需求」的回答**
- **分组：** 需要，但只需要一刀——加密和美股的作息完全不同（一个 24 小时，一个有开收盘）。用户自建分组保留，但收进「⋯ → 编辑自选 → 移到分组」，不再占头部。
- **排序：** 不是真需求，是把选择推给用户。默认永远是**用户手排的顺序**——他自己加的十个币，顺序就是他的心智地图，天天重排等于每天换一次家具位置。只在「⋯」里留一个**临时**的「按涨跌幅排」，退出自选层即恢复。五个排序控件（品种/成交额/价格/⇄/涨跌幅）全部取消。
- **编辑：** 需要，但不需要独立模式。长按行 → 菜单：置顶 / 移到分组 / 设提醒 / 删除。批量删除留在「⋯ → 编辑自选」。

**展开行里放什么**（点右侧 ⌄ 展开，0.2s）
一张 64pt 高的 24h 迷你走势（无坐标轴、无指标）+ 一行「高 / 低 / 额 / 振幅」11pt + 两个 32pt 高的动作：「记一笔」「设提醒」。展开状态**跨会话记住**。

**交互细节**
- 点行的任何位置 = 换品种并收起层（**不是**展开）；展开只认右侧 44×44 的 ⌄ 热区。现状两个动作共用一行且没有视觉分界，必然误触。
- 换品种时，行的首字母牌 + 品种名做 0.28s 的位移过渡到顶栏位置——这是**唯一**需要动画的地方，它回答「这张图是哪来的」。
- 搜索框一聚焦，清单原地交叉淡入 0.15s 换成搜索结果；分区 chips 行换成「全部市场 / 全部板块」两个 chip（和分区 chips 同一种样式，不再用 `confirmationDialog`——现状搜索页和自选页是两套筛选心智）。
- **键盘强制 ASCII**（`asciiCapable`、关自动更正、关智能标点）。走查里默认拼音键盘把 `eth` 变成了「儿童画」。
- 首字母输入后 **≤ 80ms** 出结果：717 条全在内存，前缀优先 + 子串兜底，不走网络。
- 星标结果**不重排**：点星只改图标，加一次 0.8s 的「已加入」微光，行留在原地。现状点星后该行跳到顶部、整列上顶，连点必然点错。

**动效**：下拉 0.26s（clip from top）；收起 0.22s；行展开 0.2s；搜索态切换 0.15s 淡入。

**三态**
- 空（首次安装）：不显示「暂无自选 ⭐」。直接给**按成交额排的前 20 个**，顶上一行 11pt「点星加进自选」。统计条和排序条不渲染（现状会渲染）。
- 加载：清单一次画完；没拿到报价的行价格位显示上次的值 + 灰色，不留白、不骨架闪。
- 错：顶部一行 11pt 琥珀「行情连不上，正在换线路」，清单保留上次的数字。

**被影响的旧功能**：见 §3.3 表（半屏弹层、全部自选与分组、品种页、排序条、统计条、「‹ 行情」）。

### 5.4 调图面板（指标 + 图表 + 偏好三合一）

**目标：** 把「调这张图」和「调这个 app」收进一个地方，让底栏不再混着页和面板。

**布局主张**
- 半屏 sheet，detent `medium / large`，圆角 18，拖拽条。
- 顶部 44pt：三段分段控件 **图表 ｜ 指标 ｜ 偏好**（用 app 自己的分段样式，不用系统的）。左上角**不要**那个「‹」——走查里它长得像返回上一级，其实是关闭整张面板。改成右上角一个 28pt 的「完成」。
- 行高统一 **48pt**，左右 16pt，分组标题 11pt medium ink3，组间距 24pt。
- 开关 ON 用 **琥珀**，不再用「涨」色（现状用户切成红涨绿跌后全 app 开关变红）。

**三段内容**
- **图表**：现 `ChartPanel` 全部条目原样搬入（布局与读数、类型、K 线、显示）。
- **指标**：现 `IndicatorPanel` 原样搬入；「参数与颜色 / 参数与输出」从居中的一行文字改成行尾的 `chevron`，与其他可进入的行一致。
- **偏好**：只留 8 项——配色（见下）、涨跌配色、时区、开盘时间、十字线磁吸、盯盘时不锁屏、启动快照、自动护眼。最底两行：「账号」和「诊断」。

**偏好段的两处重排**
- 四张 130×90 的配色卡片改成**一行 4 格的 44pt 分段控件**（跟随系统 / 浅色 / 深色 / 护眼）。理由：这是一个月点一次的设置，现在它比所有开关加起来还大，而且要横滚才能看到第四个。
- API 域名、行情推送域名、智能行情线路、清缓存 → 全部移进「诊断」二级页。普通设置里不出现服务地址。

**破坏性操作**
- 「重置所有偏好设置」：点击后**立即生效** + 底部 toast「已重置 · 撤销」，5 秒可撤销。不弹确认框（确认框和撤销二选一，撤销更快）。
- 同规则适用于「删除当前分类」「删除自选」。

**动效**：面板升起 0.3s；段切换 0.15s 交叉淡入；开关 0ms。

**三态**：无空态；诊断页的探测结果用文字，不用转圈。

### 5.5 账号

**目标：** 让他相信「我的东西存住了」。

**布局主张**（取消系统 `List`，用 app 自己的卡片）
```
 ┌───────────────────────────────────────────┐
 │  (M)   mdd                                │  72pt   首字母牌 40pt / 用户名 17pt semibold
 │        已同步 · 14:02                      │         11pt ink3
 ├───────────────────────────────────────────┤
 │  同步                              ›       │  48pt
 │  设备（3 台）                       ›       │  48pt
 │  修改密码                           ›       │  48pt
 ├───────────────────────────────────────────┤
 │  退出登录                                  │  48pt
 │  注销账号                                  │  48pt  danger 色
```

**登录页**
- 标签和占位文字现在是同一句「用户名 / 用户名」，去掉标签，只留占位。
- 进页即聚焦用户名，键盘 ASCII，密码框 `.password`。
- 「注册」从右下角的小字改成登录按钮下方 **居中 15pt 琥珀文字**。
- 登录按钮 48pt 高、圆角 12、琥珀实心，`disabled` 直到两个字段都非空。

**同步状态怎么说才让人安心**

### 5.6 复盘

**目标：** 让「我判断得准不准」变成一眼能看见的事。

**三个 tab 的真实关系**：记录是全集，**待办是记录的一个筛选**，**战绩是记录的汇总**——它们不是并列的三样东西，所以不该是三段选择器。

**布局主张**
```
 ┌───────────────────────────────────────────┐
 │ ‹            复盘                    +     │  44pt
 ├───────────────────────────────────────────┤
 │  67%   近 30 笔                            │  56pt  ← 摘要条，点开＝完整战绩
 │  ████████████████░░░░░░░░▒▒▒▒              │  4pt   对 20 / 错 7 / 待判 3
 ├───────────────────────────────────────────┤
 │  全部   待判定 3   已判定                    │  36pt  chips
 ├───────────────────────────────────────────┤
 │  BTCUSDT · 1h                    对 ✓   图 │  64pt
 │  "站上 MA30 就追"                          │
 │  看多 · 图在先 · 9/14                       │
```
- 准确率 **28pt semibold**，「近 30 笔」11pt ink3，一条 4pt 高的三色横条按比例分段。不要饼图、不要表格——3 秒看不懂的统计等于没有。
- 记录行 64pt：品种+周期 13pt / 原话 15pt（2 行截断）/ 元信息 11pt；右侧「对 ✓ / 错 ✗ / 待」用 ink 色文字 + 涨跌色符号，和一个 44×44 的「图」按钮。
- 默认排序：待判定在前，其余按时间倒序。

**记录 ↔ 图表怎么往返**
- 记录行的「图」按钮 → 盘面切到该品种 + 该周期 + 该时间窗，并把当时的区间高亮（复用现有「在图上重温」）；系统返回手势回到列表**原来的滚动位置**。
- 反向：记一笔卡片顶部显示「这个品种已有 3 笔 ›」，点进去就是已经筛好的列表。

**配色**：`.tint(.orange)` 全部换成 app 的琥珀。圆形玻璃返回/加号按钮换成与其他页一致的「‹ 返回」文字返回 + 右上「+」。

**三态**
- 空：「还没有记录」+ 一个**真的按钮**「记一笔」（现状那行「记一笔」只是灰色副标题，点不动），并去掉底下那条无来源的分割线。
- 战绩未登录：不再是一条裸 List 行。一行 15pt「战绩要登录后才能算」+ 11pt「记录一直存在这台手机上，不会丢」+ 一个 44pt 琥珀「登录」按钮。
- 错：「记录同步失败 · 轻点重试」。

### 5.7 记一笔

**目标：** 看着图的时候，想记就记，不用找。

**入口**（现状是周期条最右端一个 13pt 的「记」字，402pt 屏最右侧，单手够不到）
- 主入口：**底栏第 3 格「记」**——拇指自然落点，盘面和复盘页都能按。
- 辅助入口：**长按底栏「复盘」格 0.4 秒**直接开卡片（跳过列表）。
- 自选层展开行里也有一个「记一笔」。
- **不在图上放浮动按钮**（冻结区约定）。

**布局主张**
- 卡片从底部**覆盖**升起（不挤压图表——走查里现状把 MACD 压成一条缝），高度 **280pt**，圆角 16，顶部拖拽条。
- 卡片升起的同时，图上高亮选中区间并显示「49 根 · 9/14 13:00 – 9/16 14:00」（这个现状做得好，保留）。
- 内容只有四件事，纵向 16pt 节奏：
  - 方向：3 格分段「看多 / 看空 / 只记录」44pt
  - 一句话：单行输入 48pt，占满宽
  - 把握 + 来源：两个 inline menu，13pt，同一行；**默认值直接给**（把握 70%、来源「图在先」），不再显示「未填写」
  - 底部：左「找相似」文字按钮，右「记下」琥珀实心胶囊 44pt
- 全部系统蓝/系统橙换成琥珀 + ink。

**交互细节**
- 一句话可以空——空着也能记（这是一次「我当时这么想」的快照，不是表单）。
- 「记下」后：卡片 0.2s 落下，toast「已记下 · 撤销」1.8s，`success` 触感。
- 中途退出：草稿自动留存，下次点「记」直接接上，卡片顶部 11pt 写「接着上次」。

## 六、运动语言

### 6.1 转场语法（只有 4 种，不许有第 5 种）

| 语法 | 用在哪 | 时长 / 曲线 |
|---|---|---|
| **cover**（整页自下而上） | 去另一个地方：复盘 | 0.32s · spring(response .34, damping .92) |
| **push**（横向） | 同一件事的更深一层：记录 → 记录详情、偏好 → 诊断 | 0.30s · 系统默认 |
| **sheet**（半屏抬起） | 对当前这张图的调节：调图面板、记一笔 | 0.30s / 0.20s |
| **drop**（从顶部下拉覆盖） | 同一件事的另一种密度：自选层 | 0.26s 落 / 0.22s 收 |
| **morph**（原地展开收起） | 周期全表、自选行展开、战绩摘要展开 | 0.20s · easeOut |

### 6.2 时长分级与理由

| 级 | 时长 | 用在哪 | 为什么 |
|---|---|---|---|
| 0 | **0ms** | 周期切换、品种切换、排序、开关、星标 | 一天几十次的动作，人对「我刚点的」期待是即时；任何动画都是在他和结果之间加一道门 |
| 1 | **100ms** | 状态色变化、选中态、按钮按下 | 100ms 以下人读成「响应」，以上才读成「动画」 |
| 2 | **200ms** | 局部展开 / 收起 | 够看清「是从这里长出来的」，又不至于要等 |
| 3 | **300ms** | 换页、面板抬起 | iOS 系统 push 的既有节奏，快了显得跳，慢了显得拖 |

### 6.3 必须有动画的地方（做上下文保全）
1. 自选行 → 顶栏品种名：首字母牌 + 名字位移 0.28s。回答「这张图是哪来的」。
2. 记一笔卡片升起 / 落下。回答「我在图上加了一层东西，图还在」。
3. 自选层下拉 / 收起。回答「清单是盖在图上面的，图没走」。
4. 记录 →「在图上重温」：高亮区间 0.25s 淡入。

### 6.4 必须没有动画的地方
周期切换、品种切换（图表内容）、排序切换、开关、星标、涨跌幅数字、分区 chips 切换、搜索结果刷新。

### 6.5 价格数字怎么变
- **不滚动、不翻牌、不弹跳。** 数字直接换。
- 变化时在数字背后铺一层涨跌色 **8% 透明度**的底纹，120ms 淡入、180ms 淡出。
- 只有顶栏那个 28pt 的主价位每次都闪；自选清单里一屏十行同时闪会变成灯光秀，所以清单里**只在 |Δ| ≥ 0.3% 时闪一次**。
- 闪光的颜色跟随涨跌配色设置（红涨绿跌时自动互换）。

### 6.6 Reduce Motion
- 所有 cover / push / drop / morph → 0.15s 交叉淡入，无位移。
- 位移型的上下文保全（自选行 → 顶栏）→ 改为目标位置 0.15s 淡入。
- **价格闪光保留**——它是信息，不是装饰。
- 重连中的呼吸点 → 改为静态琥珀点 + 文字。

## 七、视觉系统

### 7.1 字阶（6 级 + 1 个徽标级）

| 级 | 字号 / 字重 | 用在哪 |
|---|---|---|
| D | 28 semibold **mono** | 最新价、战绩准确率（全 app 每屏最多 1 个） |
| H1 | 20 semibold | 页面标题（复盘、诊断） |
| H2 | 17 semibold | 品种名、账号用户名、卡片标题 |
| B1 | 15 regular / semibold | 列表主文、输入框、按钮文字 |
| B2 | 13 medium | 周期格、分区 chips、次级按钮、记录元信息 |
| C | 11 regular | 单位、时间、状态、说明、分组标题 |
| Badge | 9–10 medium | 「永续」「待判定 3」 |

数字一律 monospaced（价格、涨跌幅、成交额、时间），文字一律系统字。

### 7.2 间距节奏
- 基准单位 **4pt**。允许值：4 / 8 / 12 / 16 / 24 / 32。
- 页面左右边距 **16pt**（现状 12pt）。
- 列表行高：56pt（自选）/ 48pt（设置、账号）/ 64pt（复盘记录）。
- 组间距 24pt，组内行间 0（靠 1pt 分隔线）。
- 最小点击热区 **44×44**，无例外。

### 7.3 圆角 / 描边 / 阴影
- 圆角：**8**（小控件、徽标、首字母牌）/ **12**（卡片、按钮、输入框）/ **16**（记一笔卡片）/ **18**（面板）/ **胶囊**（toast、主按钮）。
- 描边：只有 **1pt hairline** 一种，颜色 `line`。选中态描边同为 1pt，颜色 `accent`。
- 阴影：全 app 只有 **toast 和记一笔卡片**有阴影（y 2、blur 8、12% 黑）。其余一律靠 `raised` 底色分层。现状 toast 用 blur 12 / y 4，偏重。

### 7.4 色板与语义

| 语义 | 含义（只许用在这） | 浅色 | 深色 |
|---|---|---|---|
| `accent` 琥珀 | 当前选中、主操作按钮、**开关 ON** | `#B26A00` | `#FFB454` |
| `accentSoft` | 选中底纹、微光 | accent @ 10% | accent @ 14% |
| `up` | 只表示涨 | `#34B257` | `#3DC65C` |
| `down` | 只表示跌 | `#E64553` | `#F2555B` |
| `warn` | 重连中、有待上传 | `#F5A524` | `#F5A524` |
| `danger` | 破坏性操作（**固定红，不随涨跌配色翻转**） | `#D63A46` | `#F2555B` |
| `ink` | 主文字 | `#12163A` | `#EDEEF8` |
| `ink2` | 次文字 | `#565C85` | `#A6A9C0` |
| `ink3` | 单位、时间、说明 | `#8B90B2` | `#6D719A` |
| `app` / `raised` / `raised2` | 三层背景 | `#FFFFFF` / `#F7F8FC` / `#ECEFF9` | `#0F1230` / `#1C2154` / `#232858` |
| `line` | 唯一的分隔线与描边 | `#DCE0F0` | `#2A2E6E` |

**三条硬规则**
1. **开关 ON 用 `accent`，不用 `up`。** 现状用 `up` 色，用户一切红涨绿跌，全 app 的开关变红——这是语义泄漏。
2. **`danger` 不随涨跌配色翻转。** 用户选红涨绿跌时「跌」变绿，破坏性操作仍是红；两者不会撞色。
3. **系统蓝、系统橙一律不出现。** 现状：设置「开盘时间」是系统蓝，记一笔卡片的「收起 / 未填写 / 图在先 / 找相似」是系统蓝，「记下」和复盘全页是系统橙——三套强调色同屏。

**红涨绿跌支持**：`up` / `down` 是一对可互换的 token，所有引用它们的地方（价格、涨跌幅、K 线、统计条、闪光底纹、涨跌统计）只读 token 不读具体色值；**不读 token 的地方（开关、按钮、进度、danger）就不受影响**。

**浅色也要立住**：浅色不是深色反色。浅色下 `accent` 用 `#B26A00`（深琥珀）保证在白底上 4.5:1；深色下用 `#FFB454`（亮琥珀）。`ink3` 在两套里都做到 4.5:1 以上。两套都必须自测：价格、涨跌幅、周期选中态、状态字。

### 7.5 图标规则
- **默认全部用 SF Symbols**，weight `.regular`，尺寸跟随所在字阶（底栏 22pt、行内 15pt、徽标 11pt）。
- 只有三处保留自绘：① 底栏「自选 / 复盘」的 K 线图标（品牌识别）② 画线工具的 10 个几何图标（SF 里没有对应语义）③ 品种首字母牌。
- 一条铁规：**同一个界面里不出现两种线宽**。现状底栏的手绘 K 线（细）和 SF 的星/齿轮（粗）并排，一眼就能看出不是一套。
- 首字母牌取**基础币种的前 1 个字母**，不是前 2 个字符——走查里 `1000PEPE` 的牌子写着「10」，毫无意义；应写「P」。

### 7.6 Dynamic Type 降级
- 支持到 **XXL**。价格、涨跌幅用 `@ScaledMetric` 但**上限 1.3×**（再大会挤掉高/低/额那一行）。
- **周期条和底栏不随 Dynamic Type 变化**，固定字号。理由：它们是位置记忆型控件，一放大就换行或滚动，位置一变肌肉记忆就作废。
- 超过 XXL：自选行从「两行」降级为「一行（品种 + 涨跌幅）+ 展开看详情」；复盘记录行的原话从 2 行截断降为 1 行。
- 所有 44pt 热区不随字号缩小。
