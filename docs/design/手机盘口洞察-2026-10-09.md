# 手机盘口洞察

用户决定：2026-10-09。原生 iOS 与手机网页版采用同一内容顺序、文案含义和交互；电脑网页版沿用自己的摘要抽屉。

## 页面与入口

- 全屏纵向滚动，不横向分页。固定导航栏含返回、盘口洞察、品种与门槛入口，内容滚动时不改导航位置。
- 行情画布下方、底栏上方提供至少 44pt 的轻量入口，点击或从该区域向上滑至少 48pt、纵向位移超过横向 1.8 倍时进入。横向拖动不能退化为点击。手势只在画布外判定，不抢 K 线平移、价格轴缩放、头部扫图与系统 Home 手势。
- 原气泡点击与分析面板入口统一进入本页。点气泡时明确显示对应 K 线的时间，查看当前数据有明确入口；不同时展示挂单详情卡。
- 点可定位的价区或事件，返回行情图定位对应位置。返回保留品种、周期与原图表现场。

## 内容顺序

1. 当前状态与证据：以近 5 / 15 分钟大额主动成交、价格变化、可用爆仓信息描述已观察到的情况。
2. 关键价位：现价上下最近的有效挂单，显示方向、价格、距现价、当前剩余金额、持续时间与匹配成交。只用与主图交易所、产品和合约相符且当前簿仍 ready、快照不超过 30 秒的挂单。
3. 今日大额成交聚集区：只用真实大额成交按价位聚合，显示区间、买卖金额、近 15 分钟变化与观测起点。各本簿独立，不能把基差直接拼成同一价位。
4. 主动成交与价格反应：时间窗、主动买卖差、现货与合约参与结构；有连续覆盖才判断放量但价格未推进等候选现象。
5. 爆仓与后续反应：近 5 / 15 分钟已观测多空被平，结合最大爆仓分钟结束后的同所完整分钟行情。现货不显示其自身爆仓。
6. 近期重要变化：近 15 分钟已结束的挂单，最多四条，区分成交消耗、挂单减少退出或失联；失联不能视作撤单。保留清楚的来源与时刻。

## 信息边界

- 挂单金额是当前存量，成交额是时间窗口流量；不相加。强平成交可能同时在主动成交里，不与大单金额叠加成所谓总买卖压力。
- 主动买卖差不写作资金净流入，不据此识别交易员身份。OI 增加不能单独判为新多或新空；只有实际可用、同交易所、同时间粒度的数据才参与判断。
- 吸收、回补、去杠杆只写观察特征或候选，不展示未经验证的胜率、进出场指令或预测爆仓价。
- 币安强平数据有抽样；各家强平价格口径不同，Bybit 价格字段为破产价，不能统一画成精确成交价位。
- 今日以北京时间 0 点起算。新价位聚合从上线后收集，不从 K 线典型价、全天成交足迹倒推大单分布；未完整覆盖全天时显示“从 HH:mm 起”。缺数、未跟踪、暂停与零成交分开。
- 新聚合记录每分钟、每价桶、每本簿的大额成交，保留 3 天，使用交易所成交时刻与既有去重入口；不永久存逐笔。
- 今日聚集区取每本簿的局部成交密度峰，最多合并五个最粗价桶宽、每簿最多三个区间，不能把全天连续经过的价格串成一条“聚集区”。服务端最多返回十二个、手机显示成交额最高的三个；跨所现货与合约参与金额只表示已观测来源。

## UI 规范

- 沿用青苔、陶土、经典及浅深色材料，不新建色板。复用 TypeScale 与手机 `--t-*`，顶栏与关键金额最大 17 semibold，正文与辅助信息按已有字阶。
- 数字等宽，买卖与多空使用文字标识并辅以方向色，不只靠颜色传意。
- 点按目标至少 44pt / 44px；尊重安全区、动态字体、读屏与减少动效。
- 不堆工程字段和大段说明；每条洞察有简洁依据，详细证据按需展开。刷新不移动用户当前阅读位置，不抢焦点。
- 数据请求仅面板需要时开启，关闭、切品种与进入后台时取消；旧响应不能覆盖新币种。分钟与缓存数据不伪装为秒级状态。

## 数据接口

`GET /v1/market/orderflow/insights?base=BTC`。与现有订单流 API 使用相同线路、限流、短缓存与 gzip。

```json
{
  "base": "BTC",
  "generatedAtMs": 0,
  "dayStartMs": 0,
  "tracked": true,
  "coverageSinceMs": null,
  "lastTradeMs": null,
  "bigUsd": null,
  "windows": [{
    "minutes": 15,
    "sources": [{
      "venueID": "binance:usdtPerp:BTCUSDT",
      "exchange": "币安",
      "product": "usdtPerp",
      "buyUsd": 0,
      "sellUsd": 0
    }]
  }],
  "zones": [{
    "venueID": "binance:usdtPerp:BTCUSDT",
    "exchange": "币安",
    "product": "usdtPerp",
    "low": 0,
    "high": 0,
    "buyUsd": 0,
    "sellUsd": 0,
    "recentBuyUsd": 0,
    "recentSellUsd": 0,
    "firstMs": 0,
    "lastMs": 0
  }]
}
```

上面的数字是字段示意，不是有效行情。产品枚举沿用 `spot / usdtPerp / coinPerp / delivery`，本接口新成交聚合排除交割。价区是每个基础币的规范价格；千币合约展示时由客户端按当前图表缩放映射。

时间窗口结束点为 `floor((generatedAtMs - 3000) / 60000) * 60000`，等待三秒宽限后只读已结束分钟。5 / 15 / 60 分钟从该结束点往前算，价格反应使用相同区间的当前交易所一分钟 K 线；不以当前未收盘价代替窗口结束价。`coverageSinceMs` 是能证明的最新连续观测起点，不因为服务重启或请求成功就恢复全天覆盖。源缺席、写入丢失和无大额成交是不同状态。
