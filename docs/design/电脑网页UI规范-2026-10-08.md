# 电脑网页 UI 规范（2026-10-08 · 草案，原型确认后定版）

适用：电脑网页版 `Web/src`（不含手机网页 `Web/src/m`、不含 iOS）。
基调：**尺寸、密度、点按面积照 TradingView 实测；材料、颜色、图标是我们自己的一套。**
不直接套苹果 HIG（为触屏和 macOS 原生控件定的，桌面网页密度不对），也不套 Material / Fluent / Carbon（后台味重）。

对照原型：`/ui/web-visual-2026-10-08.html`（现在 / 提案 × 浅 / 深 × 三套皮肤）。

## 0. 现在为什么「割裂」（2026-10-08 线上诊断）

| 问题 | 现状 | 后果 |
|---|---|---|
| 三种底色撞在一起 | 缝 `--app` 是皮肤色（青苔浅 #CFDFD6）；面板 `--surface` 带皮肤色；K 线画布是 TradingView 中性白 / #0F0F0F | 图表像一块补丁贴在绿框里，深色下尤其明显 |
| 框架和内容不分 | 顶栏、工具条、左画线栏、右侧栏、图表、抽屉全是同一种圆角卡片，浮在同一条缝上 | 没有主次，左右两条栏像「虚」的，和图表抢同一层 |
| 图标太淡 | 静止时 `--text-2`，加上双调衬底只有 30% 透明 | 20 px 下糊成一团灰，左右栏尤其「虚幻」 |
| 色相太多 | 皮肤强调色（青苔绿）、通用 `--accent-2` 蓝、订单流按品类四色（青 / 紫 / 琥珀 / 粉，买卖只差 ±12° 色相）、抽屉交易所五色（黄 / 灰 / 蓝 / 橙 / 品红）、挂单墙紫、关键价位紫 / 青、提醒橙、涨跌红绿 | 同一屏七八个互不相干的色相，各自饱和度、明度都不一样 |
| 主功能没有层级 | 品种、周期、指标、对比、提醒、记一笔、热力全是同一种 `tb-btn` | 眼睛找不到起点 |

## 1. 材料：只有两层

**框架层（frame）**：顶栏、图表工具条、左画线栏、右侧栏，以及它们之间的缝。框架层是一整块连续的底，不是卡片，没有圆角、没有阴影。
**内容层（content）**：图表格子、底部抽屉、右侧面板。内容层是嵌在框架里的卡片，圆角 8，K 线画布与卡片同一个底色。

浮层（菜单、对话框、悬停卡）在内容层之上，用 `--overlay` + 阴影。

| 变量 | 意思 | 青苔浅 | 青苔深 | 经典浅 | 经典深 | 陶土浅 | 陶土深 |
|---|---|---|---|---|---|---|---|
| `--frame` | 框架层与缝 | #E4EAE6 | #090D0B | #E7EAEE | #0A0C10 | #ECE4DA | #0C0805 |
| `--surface` | 内容卡片 = K 线画布 | #F8FAF8 | #121815 | #F8F9FA | #14171D | #FBF8F4 | #18120C |
| `--surface-2` | 卡片里的次级底（输入框、表头） | #F0F4F1 | #182019 | #F0F2F4 | #1B1F27 | #F4EEE7 | #201811 |
| `--surface-3` | 悬停 | #E8EEEA | #1F2823 | #E8EBEF | #222732 | #EDE5DB | #291F16 |
| `--frame-hover` | 框架层上的悬停 | #D9E1DC | #151C18 | #DCE0E6 | #151920 | #E2D8CC | #17110B |
| `--line` | 卡片内分隔 | #E0E7E2 | #212B26 | #E2E5EA | #242A35 | #E9DFD3 | #2C2118 |
| `--text-1` | 主文字 / 关键数据 | #17201B | #E6ECE8 | #161A22 | #E4E7ED | #231A13 | #F2EAE1 |
| `--text-2` | 次要 | #4A5A52 | #A3B2AA | #4D5462 | #A2A8B4 | #67574A | #BFAB98 |
| `--text-3` | 辅助 / 轴 / 占位 | #5E6C65 | #84928B | #626876 | #868C98 | #75665A | #9A8B7D |

### 浅色不刺眼（用户 2026-10-08：「浅色模式下稍微有点刺眼」）

- **不用纯白大面积铺底**。内容卡片与 K 线画布是 97–98% 明度的柔白（上表 `--surface`）；纯白 #FFFFFF 只留给浮层（菜单、对话框、悬停卡），让浮层自然「浮」起来。
- **框架比内容暗一级**，而且低饱和：缝不再是 #CFDFD6 这种带色的亮绿，整屏读成一块安静的底。
- **主文字不用纯黑**：`--text-1` 是带一点皮肤色的深墨，对 `--surface` ≈ 15:1，足够清楚又不扎眼。
- **大面积彩色填充降饱和**：浅色下订单流带、热力、抽屉条形的填充透明度比深色低（见第 2 节），彩色只在边缘与文字上用足。

### 深色不发闷

- 内容卡片比框架亮一级（≈ 4% 明度），靠这一级分块，不靠亮缝。
- `--text-1` 不用纯白（≈ 14:1），长时间看不发晕；关键数字用字重而不是更亮的白来突出。
- 方向色文字在深色下提亮到 ≥ 5.5:1。

规则：
- **K 线画布底 = `--surface`**。图表和它所在的卡片是同一块材料，不再是另一种白 / 黑。网格、十字线、轴文字仍照 TradingView。
- 缝 = 框架色，4 px。缝和卡片的明度差：浅色 6–8%，深色 3–4%。深色不靠亮缝分块，靠卡片比框架亮一级。
- 顶栏不再刷强调色渐变，和框架同一个底，下面不加线（框架是一整块）。
- 卡片不加描边。只在深色、两张卡片紧挨时，用 `--card-edge` 1 px 描边分开。

## 2. 颜色：四类语义，外加一套分类色

整屏只允许四类颜色：

1. **中性**：皮肤的灰阶，即上表加上 `--text-1/2/3`。
2. **强调**：皮肤一色（青苔绿 / 经典蓝 / 陶土赤），用于选中、焦点、主按钮、挂单墙、选中的那根竖带。不再有第二强调色：`--accent-2` 只用于头像渐变，界面元素一律不用。
3. **方向**：涨跌（`--up` / `--down`，跟着「红涨绿跌 / 绿涨红跌」走）。凡是买 / 卖、多 / 空、挂买 / 挂卖都用它。
4. **提醒**：橙（`--alert-line`），只用于提醒线与提醒徽章。

**分类色**只用于区分「谁」，不表达方向或好坏，例如交易所、现货 / 永续 / 币本位 / 交割、关键价位日 / 周。
- 一套 6 色，**同明度、同饱和度**（OKLCH），所以放在一起不打架。
- 浅色 `oklch(0.60 0.12 h)`，深色 `oklch(0.76 0.10 h)`。
- 色相 h：币安 88（金）、Coinbase 255（蓝）、Bybit 45（橙）、Hyperliquid 330（品红）、OKX 中性（`--text-3`）、备用 190（青）。
- 品类：现货 190、U 本位永续 280、币本位 88、交割 330。
- 关键价位：日 280、周 190。
- **分类色只出现在小记号上**：圆点、2–3 px 细条、图例。不许大面积填色。

### 订单流（图上大单带、抽屉、盘口）

- 图上大单带**按方向着色**：挂买用 `--up`，挂卖用 `--down`。
  - 填充透明度：浅色 0.10，深色 0.16。悬停 / 选中：浅色 0.22，深色 0.30。
  - 带左缘一道 2 px 实色细条，用品类的分类色，告诉你是现货还是永续。
  - 带上的金额字用 `--up-text` / `--down-text`。
- 原来那套「品类四色 + 买卖差 ±12° 色相」作废：买卖方向是交易员第一眼要看的，不该靠细微色相差分辨。
- 挂单墙 `--of-wall` = 强调色（不再单独一个紫）。
- 抽屉条形：买卖用方向色，「淡 → 实」渐变保留。交易所拆分条用分类色。
- 深度热力：单色相渐变，从透明到强调色，最浓处混一点 `--alert-line`，不再青紫橙乱跳。

## 3. 层级：一眼先看哪里

| 级 | 内容 | 画法 |
|---|---|---|
| 一级 | 品种、最新价、周期 | 品种 16 / 650 + 币标；周期是一条分段控件，选中项实底（强调软底 + 强调字 600） |
| 二级 | 指标（带字）、画线栏、提醒 | 图标 + 字，`--text-1`；画线栏图标 28 |
| 三级 | 对比、记一笔、热力、模板 | 图标 + 字，`--text-2`。窄屏先收字，和一、二级之间有一道分隔线 |
| 四级 | 撤销 / 重做、布局、截图、全屏、设置 | 纯图标靠右，`--text-2`，悬停变 `--text-1` |

框架上的图标静止就是 `--text-1`（TradingView 也是满对比度），不再用 `--text-2` 加 30% 衬底的淡灰。

### 左画线栏（照 TradingView 实测）

- 宽 52；每格 52 × 38 的点按区，图标 28。
- 右缘有一条 11 × 34 的展开条，箭头 4 × 7。
- 组之间分隔间距约 13。
- 展开菜单宽约 285，行高 40，14 号字，图标 28；组标题 11 号、大写、字间距 0.4。
- 选中：强调软底 + 强调色图标。粘住（连续画）在格子右下角加一个强调色圆点。

### 右侧栏

- 宽 48，图标 24，格 40 × 40。
- 选中：强调软底，左缘一道 3 px 强调色竖条贴着内容层。

## 4. 尺寸与密度（TradingView 实测，1024 × 768 · dpr 1）

| 项 | 值 |
|---|---|
| 顶栏高 | 48 |
| 图表工具条高 | 38；按钮高 32 |
| 控件高阶梯 | 24 / 28 / 32 / 40（`--h-xs/sm/md/lg`） |
| 圆角阶梯 | 4 / 6 / 8 / 12；卡片 8，对话框 12，药丸 = 高 / 2 |
| 间距 | 4 的倍数（`--s1…s12` = 4…48） |
| 图例行 | 24 高；悬浮按钮 28 × 24，图标 18 |
| 指标弹窗 | 标题 20 / 600；搜索框 40 高；左栏宽 clamp(168, 22%, 220)，行 40；列表行 40 |
| 最小点按面积 | 24 × 24（图例行内）；其余 ≥ 28 × 28 |

所有宽度都随窗口收：工具条按容器宽度逐级收字（1120 → 920 → 880）。画线栏在窗口高度不够时整条可滚，展开菜单超出时翻到上方。

## 5. 字

- 字号阶梯：11（辅助、轴）/ 12（次要）/ 13（正文、表格）/ 14（按钮、菜单）/ 16（品种、卡片标题）/ 20（对话框标题、最新价）。
- 字重只用 400 / 500 / 600；650 只给品牌与品种名。
- 数字一律等宽数字（`tnum`）。

## 5b. 数据可读性（关键数字一眼看清）

- **数据分三级**：
  - 关键数据：最新价、净额、合计金额、当前选中值。用 `--text-1` 或方向色文字，字重 600，比周围大一阶。
  - 普通数据：表格里的金额、价位。用 `--text-1`，字重 500。
  - 标签与单位：「本根」「1 小时」「M」「USDT」。用 `--text-3`，字重 400，比数字小一阶。
- **数字不靠颜色单独区分**：正负同时写「+ / −」号；方向色只加强，不承担唯一信息。
- **方向色文字**（`--up-text` / `--down-text`）在 `--surface`、`--surface-2`、悬停行、选中行上都 ≥ 4.5:1，关键数据处 ≥ 5.5:1。
  - 浅色：涨 #067A66、跌 #CC2E3D。
  - 深色：涨 #34C5A4、跌 #FF6874。
- **字不压彩色底**：条形里写数字时，条形填充 ≤ 30% 透明度、字用 `--text-1`；实色条（≥ 60%）上不写字，数字放在条外。
- **表格**：行高 28（密）/ 32（常规）；数字右对齐、等宽；隔行不加斑马纹，悬停整行 `--surface-3`。
- **图表上的标签**（订单流金额、气泡数字、价格轴标签）：
  - 字 11–12 / 600。
  - 底色与字的对比 ≥ 4.5:1。
  - 半透明底下面要垫一层 70% 的 `--surface`，防止蜡烛从字后面透出来。

## 6. 图标

- **界面图标**（24 格，显示 20 / 18 / 16）：
  - 实心为主。双调衬底从 30% 提到 45%，并且只在大于 18 px 的尺寸用；16 px 及以下单色实心。
  - 描边 2.0，端点圆头。
  - 外形对齐像素格：主轮廓落在整数或 .5 上，不糊边。
- **画线工具图标**（28 格，显示 28；菜单里 28；收藏条 20）：
  - 画的是线，所以「线」用 1.5 描边，线端与锚点用 2.5 半径实心圆点。
  - 面状的部分（矩形、区间、成交量分布）用 18% 填充 + 1.5 描边。
  - 同一组内母题一致：斐波那契系都带三条等比横线，江恩系都带格子，形态系都带锚点折线。
  - 一个工具一个键（键名 = `DrawingType`），换图只换 `icons.ts` 里的路径。
- 颜色只用 `currentColor`，选中态由按钮把它染成强调色；图标里不写死颜色（品牌记号除外）。

## 7. 状态

| 状态 | 框架层上 | 内容层上 |
|---|---|---|
| 静止 | `--text-1` 图标 / 字 | 同左 |
| 悬停 | `--frame-hover` 底 | `--surface-3` 底 |
| 按下 / 选中 | `--accent-soft` 底 + `--accent-text` | 同左 |
| 焦点 | 2 px 强调色外框，外扩 2 | 同左 |
| 禁用 | `--text-3`，不响应悬停 | 同左 |

动效：颜色 / 底 120 ms，弹层 160 ms `cubic-bezier(.2,.8,.2,1)`；`prefers-reduced-motion` 一律关。
