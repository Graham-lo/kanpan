# 图上大单与爆仓气泡 · 三端规格（2026-10-08 二稿，待用户定版）

设计源：`docs/prototypes/web-bigtrade-bubbles-2026-10-08.html` 的 `one()`（「统一透明泡」画法，默认），线上 `https://kanpan.43-160-232-253.sslip.io/ui/web-bigtrade-bubbles-2026-10-08.html`。

用户 2026-10-08 两轮意见：先定「大单和爆仓统一用气泡、只分红绿、不要三角」；看过一稿（大单实心 / 爆仓空心、三档）后又说**「大单和爆仓能不能统一一个透明气泡」「气泡太多了其实都分不清而且占用空间」**。二稿照此改：一种样子、一根最多上下各一枚、数量压到一屏几枚。三端（电脑网页、手机网页、iOS）同一套。

## 1. 数据：每根只剩两个数

- 向上的钱 `U = 大买 + 空单爆仓`，向下的钱 `D = 大卖 + 多单爆仓`（空爆是被动买、多爆是被动卖，和主动大单同向，合起来就是这根的买压 / 卖压）。
- 大买 / 大卖沿用现有 BigBarCache / BigTradeBarsCache；爆仓按本图 K 线开盘时间把 `/v1/market/orderflow/liq` 的分钟行（`longUsd` → 多爆、`shortUsd` → 空爆）并成根。现货（Coinbase X-USD）与宏观品种（DXY）没有爆仓项，U / D 就是大买 / 大卖。
- 图上不再区分「这枚是大单还是爆仓」；拆分只在悬停 / 点开的卡里给（见 §4）。
- 开关仍是 Prefs.bigTradeSigns 一个（大单与爆仓同开同关）。

## 2. 门槛：两级，不是三档

- 样本：最近 300 根（TIER_BARS）里每根 `max(U, D)` 的非零值，垫同一个绝对下限（门槛 ÷ 5，`unitFor` 不变）；只在数据版本变时重算（现有 TierCache 机制）。
- **点线 `tD = P90`、泡线 `tB = P97`**（原型「少」档，默认）。备选「中」= P85 / P95（即现在签的一二档线）。
- `v < tD` 不画；`tD ≤ v < tB` 画小圆点；`v ≥ tB` 画带字的泡。
- **一屏带字的泡最多 6 枚**：可见根里所有 `≥ tB` 的候选按金额降序取前 6，其余退成点。候选 = 每根的 U（上侧）和 D（下侧）各算一枚，所以一根最多上下各一枚。
- 一根宽 `bw < 4 px` 时全部只画点。

## 3. 几何（px / pt，`bw` = 一根 K 线宽）

- 锚点：上侧（U）挂最高点之上 anchor = y(high)，下侧（D）挂最低点之下 anchor = y(low)；X = 根中心。
- 点：`r = clamp(bw × 0.4, 1.5, 2.8)`，柄 2（不画柄线，只是留的间距），无字。
- 泡：字号 11（现有大单签字体：半粗、等宽数字），`r = max(11 + 6 × min(1, (v − tB) / (tB × 2)), 字宽 / 2 + 4)`，柄 4。字 = 金额短写去掉 `M`（`1.2M` → `1.2`，`860K` 保留 K）。
- 圆心 `cy = anchor ∓ (柄 + r)`。
- 错层：同侧已摆的（点和泡都算）若 `hypot(px − X, py − cy) < p.r + r + 2`，往外推：`cy = p.y ∓ (p.r + r + 2)`，最多 6 次。
- 退化：泡推完出了窗格（上 `cy − r < top + 4`，下 `cy + r > bottom − 4`）→ 退成点（r = 点半径、无字、柄 2、cy 重算），不占 6 枚配额。
- 摆放顺序：候选按金额降序，大的先占位。
- 继续躲现有禁区：图例那一带、画线文字框、主图上下沿（现有 avoid 逻辑，对象换成圆）。

## 4. 画法与交互

- 颜色只分红绿：上侧 = 涨色，下侧 = 跌色（跟皮肤涨跌色，默认绿涨红跌）。
- 泡：填充方向色 **16%**（深色皮肤 22%）+ 描边方向色 1.4；字方向色、居中。没有光晕、没有高光、没有实心 / 空心之分。
- 点：方向色 85% 不透明实心小圆。
- 柄：只有泡才画，从 anchor 到泡近边（上 cy + r，下 cy − r），1.2 宽、.6 透明、方向色。柄全部先画，再画点与泡。
- 电脑网页：悬停泡 → 泡填充升到 32%、放大 1.1、那根铺淡色竖带、弹读数卡（沿用现有大单读数卡，顶上加两行「向上 U：大买 x · 空爆 y」「向下 D：大卖 x · 多爆 y」）；点 → 选中那根、抽屉滚到它。点（小圆）不响应悬停 / 点击。
- 手机网页 / iOS：轻点泡 → 弹这根的「大单与爆仓」卡（现有 onTap / onBigTradeTap，44×44 命中取最近）；点中放大 1.3× / 120 ms、新大单光环外扩 8 pt / 600 ms（减少动效时 150 ms 闪）照旧，对象换成圆。小圆点不响应、不进读屏按钮列表。
- 手机网页 / iOS 点击互斥（2026-10-09）：挂单墙的金额标签按避让后的实际框命中，优先于附近气泡的扩展热区和底下的 K 线，只出所属整堵墙的挂单详情；点成交 / 爆仓气泡只开「大单与爆仓」页并清除旧挂单选择。气泡及大单页「每根」的程序十字线定位不触发挂单悬停卡，行情更新后也不恢复该卡；用户重新手动移动十字线后恢复正常挂单检查。
- 手机大单页排版（2026-10-09）：整页使用项目现有 `TypeScale` / `--t-*` 令牌。页标题与本根主金额 17 semibold；卡片标题 / 动作 13 semibold；最大单笔金额 15 medium；次级金额、说明、品种 12 regular / medium；图轴与紧凑挂单墙 11 regular / medium。取消正文的 bold、20 / 22 / 14 等局部字号与负字距，数字保持等宽，iOS 继续跟随 Dynamic Type。行情页最新价字号不受影响。
- 读屏：泡读「{时间} 向上 / 向下 {金额}」，用词只加在 `KanpanCore/Sources/KanpanCore/Terms/terms.json`。
