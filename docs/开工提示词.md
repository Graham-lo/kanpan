# 开工提示词（整段复制给新窗口 / 新模型）

---

你要实现「看盘」——一个原生 iOS（Swift 6、iOS 17+）实时看盘 app，只做 品种 / 周期 / K 线 / 指标，数据源币安 USDT 本位永续合约，手感对标 AICoin 手机端。

全部规格在这个仓库里。先读根目录 `README.md`，再读 `docs/实施任务书.md` 开头的「开工须知」，然后按任务书 §15 的开工顺序做。

不要重新设计、不要询问已经定死的事：

- 图表只有蜡烛一种；11 款风格（默认 墩）、靛配色浅深两版，几何常数照 `prototype/src/styles.js`。
- 周期 14 档默认 1h，**日线以上只给周、月、年**（1m 3m 5m 15m 30m 1h 2h 4h 6h 12h 1d 1w 1M 1y，没有 3d；币安没有 1y，年线自己聚合）。切周期保持 K 线像素宽度不变。副图默认 MACD + RSI，主图默认 MA。
- 持仓量 OI 有完整历史，走 data.binance.vision 归档站（和 K 线归档同一个站），不要按「只有 30 天」来做，见任务书 §4.5。
- 图表引擎自绘（UIKit + CoreGraphics），零第三方依赖；算法一比一移植 `prototype/src/chart.js`。
- K 线行情不永久落盘：内存 LRU + 一份 ≤ 60 KB 启动快照，其它一律不写磁盘；但体验优先，该用的内存就用。
- 右侧可以拖出大片空白，这是正常行为。

硬规则：

- 代码写在本仓库根目录下（`KanpanCore/`、`Kanpan/`）。`prototype/` 与 `docs/` 是已定版的规格，只读，不要改。
- 装 Xcode 和 `xcode-select` 需要用户密码，把命令交给用户自己跑，你不要索要或输入密码。
- 每个里程碑交付前，按任务书 §12 写 `docs/acceptance/M<n>.md` 证据，再让用户按 §13 的表逐条验收；没有证据不算完成。
- 先做 M0（`KanpanCore` 空包 `swift test` 通过），再往下。

现在从 M0 开始。第一步：在仓库根目录建 `KanpanCore` SwiftPM 包并让 `swift test` 通过；接着报告 `xcodebuild -version` 的结果，没有 Xcode.app 就把安装命令交给仓库主人自己跑。
