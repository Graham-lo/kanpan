## 口径

- 板块涨跌幅默认取**成员中位数**，备选均值与成交额加权。中位数抗单只暴涨暴跌。
- 气泡面积 ∝ |涨跌幅|，即半径 ∝ sqrt(|涨跌幅|)。
- 一只标的允许跨段（高通同时在算力芯片与端侧 AI），每段各自算中位数。
- 加密里归为 `NONE` 的 48 个币落回币安自带标签兜底，在界面上要弱化显示。
- 美股 182 个币安股票标的 100% 有归宿：84 只进 AI 板块、39 只结构性排除
  （杠杆/反向 ETP、宽基与行业 ETF）、56 只判为非 AI、3 只重复挂牌合并。

## 查证方式

代号一律用 `/fapi/v1/constituents?symbol=<SYM>USDT` 反查背后的真实交易所代码，
不按字面猜。币安会给撞名的股票改代号（希捷 STX→STXX、Quantinuum QNT→QNTX），
韩股是 `KK_RFR_A<六位代码>KRW_USD`、港股是 `<四位>HK`。
加密同理：`LIT` 是 Lighter 不是 Litentry，`XAI` 是链游不是 AI，
`NEWT` 币安自带标签写的 Meme 是错的（实际是 AI 自动化层）。
