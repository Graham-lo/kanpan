# Hkline 使用手册

写于 2026-09-21，对照当时工作树里的源码逐项核过。这是给**用的人**看的说明书，不是开发文档；
实现细节、色值来源、验收记录在 `README.md`、`.project-memory/PROJECT.md` 和 `docs/` 的其他文件里。

Hkline 是一个 iOS 行情 app：看币安 USDT 永续的 K 线、管自选、画线、按线提醒、把每一次判断记下来复盘。
**它不提供下单交易**，只看不买。

---

## 0. 一分钟上手

装好第一次打开，没有账号也能直接用。app 会先给你种上 BTC / ETH / SOL 加上当天成交额前 5 的币当自选
（删掉就不会再回来），然后停在自选页。

屏幕最下面是五格常驻标签栏，整个 app 就这五个去处：

| 格子 | 是什么 |
| --- | --- |
| **画线** | 不是一个页面，是一个**动作**：点它，当前这张图横过来变成画线工作台，画完自动转回竖屏 |
| **图表** | 行情页——K 线、价格、指标、复盘入口都在这儿 |
| **自选** | 你的自选列表与分类 |
| **板块分类** | 按板块看谁在涨，点进去是该板块的品种列表 |
| **设置** | 外观、配色、提醒、行情线路、账号 |

## 1. 行情页（底栏「图表」）

### 顶栏

从左到右：品种徽章（一个品种一个记号）· 品种名 · 复盘按钮（有待办时带角标）· 放大镜。

- **品种名只是个标签**，点它什么都不会弹。换品种只有两条路：点放大镜搜，或者去自选页 / 板块页点一只。
- **复盘**按钮进复盘本，角标上的数字是到期待判定的记录条数。

### 价格区（这里有个手势）

22pt 的最新价 + 涨跌幅药丸，下面一行是成交额和振幅小字。

> **连续扫图**：从自选分类或板块品种列表点进来的时候，那份名单会被冻住。在**价格区左右横滑**就能
> 切上一只 / 下一只，一路扫完整个分类。画布和周期条上不接这个手势——在图上横滑永远是平移 K 线。

再往下是六格统计，两列三行：**仓 / 额**、**市值 / 费率**、**结算 / 振幅**。
「结算」是资金费率的下一次结算倒计时，不足一分钟写「即将结算」，拿不到时刻就留空。
数额统一用 K / M / B / T，市值是总市值（总供应量 × 现价）。

### 周期条

一行六档，出厂是 `5m 30m 1h 4h 1d 1w`，等宽平分铺满整行。没选中的档是纯文字，
当前档是一颗贴着字的琥珀胶囊；当前档没被你钉住时那颗胶囊画虚线边。

- 点「**更多 ˅**」展开全部 14 档（1m 到 1y），在那儿**钉住 / 取消钉住**要常用的档。
  钉几档、钉哪几档你自己定，剩下的档永远在「更多」里能找到。
- 行尾还有「**图表**」（开图表设置面板）和一颗会来会走的动作按钮：
  拖远了显示「**最新**」（跳回右缘），从小周期「看细节」回来显示「**返回刚才**」（只活一分钟）。

### 图表上的手势

| 想干什么 | 怎么做 |
| --- | --- |
| 平移 | 单指横拖 |
| 缩放 | 双指捏合（以两指中点为焦点，不是永远缩右边） |
| 调价格轴 | 在右侧价格轴上竖拖；双击价格轴上下颠倒（要在图表设置里开「主轴允许翻转」） |
| 十字线 | 长按图面 |
| 回到末根 | 点周期条行尾的「最新」 |

越界有阻尼，末根始终贴着右缘留白。主图与副图指标同时落在一屏里，不用滚。

### 十字线那一行

长按出十字线之后，头部会出现一行动作：**‹ 上一根 / 下一根 ›** · **按此价画线** · **看细节**。

- 「按此价画线」直接在十字线那个价位落一条水平线。
- 「**看细节**」：进下一档更小的周期，并把视野正好铺成刚才选中那一根 K 线覆盖的区间。
  切回大周期时会恢复你原来的视野。

### 图表设置（周期条行尾的「图表」）

一张面板，四块：

- **K 线**：画法（蜡烛 / 收盘价 / 平均 K 线）、阳线实心或空心、平均 K 线是否用平滑价格。
- **显示**：网格、实时价格线、本根倒计时、显示画线、指标区域自适应、简化指标数值、
  十字线读数（选中价 / 至今涨幅）。
- **价格轴**：线性 / 对数 / 百分比，主轴与副轴是否允许双击翻转。
- **指标**：主图 MA / EMA / BOLL，副图成交量 / MACD / RSI / KDJ / StochRSI / ATR / 持仓量。
  **副图同时最多三个**。每个指标的周期参数都能手输（没有加减按钮，直接填数字）。
  出厂是主图 MA(10/30/120/256)、副图**成交量 + 持仓量 + MACD**。
- **这张图**：**分享图片**（离屏渲染当前这张图，画线、指标、皮肤底色都带着，走系统分享面板）、
  **记一笔**（存进复盘本，自动附同一张截图）。

面板选完即收起，不用手动关。

## 2. 画线（底栏「画线」）

点底栏「画线」，当前这张图**横过来**变成画线工作台。工具栏在图外，画布上不浮任何控件。
画完点「完成」或转回竖屏，图自动回到竖屏。横屏画线时主图副图的指标全部不画，只留原始 K 线。

### 工具

一共 **41 把**，按 TradingView 手机版的清单与形态做的，分九组：
**线条 · 通道 · 几何 · 区间 · 斐波那契 · 江恩 · 形态 · 测量 · 标注**。

- 线条：水平线、水平射线、趋势线、射线、直线、垂直线、十字线、箭头
- 通道：平行通道、回归通道、安德鲁斯分叉、斐波那契通道
- 几何：矩形、椭圆、三角形、曲线
- 区间：价格区间、日期区间、日期价格区间
- 斐波那契：回撤、扩展、时区、扇形
- 江恩：江恩箱、江恩扇形
- 形态：XABCD、ABCD、头肩、艾略特推动浪 / 调整浪
- 测量：价时测量、多空持仓框、VWAP、区间成交量分布、锚定成交量分布
- 标注：文字标注、气泡标注、价格标签、旗标、向上 / 向下箭头

常用的可以**收藏**，收藏过之后工具面板第一格就是「收藏」。上次用的哪把、停在哪个分类都记着。

### 画线的操作

- 落点：按住拖，端点能逐个拖（形态类最多八个锚点）。
- **吸附**：工具栏上的「吸附」开关，开着就贴到 K 线的高低收开。
- **样式**：颜色、粗细、虚实；比例类工具（回撤 / 扩展）可以改比例数列。
- **撤销**：工具栏上的撤销；撤销栈按品种存，切页、进出横屏之后仍然能撤。
- **管理**：「画线管理」列出当前品种的全部线，可以逐条显示 / 隐藏 / 锁定 / 删除，也能一次清空
  （清空之后还能撤销）。
- 手指按着一个端点的那两秒里，**两根轴被钉住**——新 K 线到货、行情走出新高都不会让你的线跟着跑。

画完一条线，头部价格行那一行会**就地**变成一张小确认卡：「要在这条趋势线上提醒你吗？」
六秒不理等于「只画线」。图不会因此矮一行又弹回来。

## 3. 提醒

提醒是一个独立模块，不是画线的附属属性。

### 加一条

画完一条线 → 那张小确认卡 → 「**加入提醒**」。选两种判定之一：

- **等它碰到**：价格触到这条线就提醒。
- **等它收盘穿过**：要 1 分钟 K 线收在线的另一侧才算。

还可以开「**再次提醒**」（触发后不停用，下次再穿还提醒）。
加过提醒的线，右端会画一枚小铃铛。

### 管起来

**设置 → 提醒**，列出全部提醒：待触发的、已暂停的、已触发的。可以暂停、删除、点进去看是哪条线。

### 触发之后

- app 在前台时用当前行情流本地判定，立刻响应。
- app 不在前台时由服务端判定（服务端订阅 1 分钟 K 线跑评估），触发状态会随同步落回你这台机器，
  你下次打开就看到那条已经触发了。
- **横幅推送目前不会响**：还没开 Apple 开发者会员、没有 APNs 密钥，工程里也没加推送能力。
  判定、状态回写、列表里标「已触发」全都正常，少的只是最后那一下锁屏横幅。密钥一到位就能接上。
- 复盘待办到期会发**本地通知**，这个不依赖 APNs，现在就有。

自选页的排序里有一档「**离提醒线最近**」，按当前价距离最近那条提醒线的远近排。

## 4. 自选（底栏「自选」）

衬线标题旁一枚数量印章，下面一条涨跌比例条，再下面是列表。每行：品种徽章 · 名字 · 价格 · 涨跌药丸。

- **加自选**：在搜索页或板块品种列表的那一行上点星。顶栏没有星——同一个动作只留一个入口。
- **分类**：顶上一条胶囊分类。「…」菜单里新建 / 重命名 / 删除分类；长按某一行的菜单里「移到分类」。
- **排序**：排序弹层，按价格 / 涨跌幅 / 涨跌额 / 成交额 / 自选顺序 / 离提醒线最近。
  手指按在表上的时候排序会冻住（只冻顺序，价格照刷），手一松再重排。
- **长按一行**：弹出只读预览卡，旁边菜单有「打开 / 调整顺序 / 移到分类 / 取消自选」。
  点「调整顺序」进批量编辑，在那儿长按拖动排序。
- **删除**：左滑单条，或者进编辑批量选删；删完给一次「撤销」。
- **迷你走势图**默认关着，在「…」里打开。
- 回到自选页会滚回你刚才看的那一行。

## 5. 板块分类（底栏「板块分类」）

一屏气泡，一颗气泡是一个板块，大小与颜色按板块表现走。顶上是**加密 / 美股**硬切换。

- 板块有：公链 Layer-1、ETH 生态、Solana 生态、BTC 生态、Layer-2、DeFi 蓝筹 / 其他、AI 代币、
  DePIN、RWA、NFT 与社交、Meme、存储、隐私、PoW 挖矿、DeSci、元宇宙…… 美股那侧是云厂商、
  光通信、云与电力这类。
- 点一颗气泡**进这个板块的品种列表**（视觉和自选页的列表一样），在那儿点星加自选、点行进图表。
  没有第二层气泡，也没有粗细粒度切换。
- 每个板块下面标着成交额、20 日表现、多少个成员跑赢。
- 美股那侧只用币安自己有的标的，所以分类比加密那侧粗。

## 6. 复盘（行情页顶栏那颗按钮）

复盘本是「把每一次判断写下来，到期让市场给答案」。**需要登录**——运算在后端。

### 记一笔

在行情页框出一段区间（或者从「图表设置 → 这张图 → 记一笔」），写下：

- **方向**（看多 / 看空 / 观望）、**把握**百分比
- **这次判断**：一句话现在怎么看
- **判断处**的参考价与范围、**到期**时间

保存时自动附一张当前图的截图。没写完可以存草稿，下次「继续未完成的记录」。

### 到期之后

到期的记录进「**待办**」，顶栏按钮上的角标就是它的条数。点进去做**判定**：

- 「**当时那张图**」和「**市场的答案**」并排看
- 回答：当时的判断哪些成立、同样的局面再来改哪儿、下次怎么做
- 写完这条进**战绩**统计

如果结果在你写完复盘之后又变了，那条会标「这条的结果在你写完复盘之后变过，再看一眼」。

### 其他

- **在图上重温**：逐根往前 / 往后播放当时那段行情，可以暂停、按方向重置。
- **找相似**：框选至少 16 根 K 线，在历史里找形态接近的区间（比对进度会实时显示）。
- **作废记录**：保留内容但退出战绩统计。
- 记录固定所属行情源，不会因为你换了线路就对不上。

## 7. 设置（底栏「设置」）

| 行 | 做什么 |
| --- | --- |
| 账号 | 没登录显示「登录」，登录后显示用户名与同步状态 |
| 外观 | 皮肤三套：**青苔·冷**（默认）、**陶土·暖**、**经典**（AICoin 白底）；深浅跟随系统或手动指定 |
| 自动护眼配色 | 随屏幕明暗切换 |
| 涨跌配色 | 绿涨红跌 / 红涨绿跌 |
| 开盘时间 | 交易所时间 / 本地 |
| 时区 | 图表时间轴的时区 |
| 十字线磁吸 | 十字线是否贴到 K 线 |
| 提醒 | 进提醒列表 |
| 盯盘时不锁屏 | 开着的时候屏幕不自动熄 |
| 启动快照 | 冷启动先画上次那张图，不等网络 |
| 行情线路 | **直连 / 网关**两档，见下 |
| 清缓存 | 清掉本地 K 线缓存 |
| 恢复默认 | 重置所有偏好设置 |

### 行情线路

只有两档，**出厂默认「直连」，两条之间没有自动切换、不混源**：

- **直连**：只走币安自己的域名。探不通就照实提示「点此重试」，绝不偷偷切到别处。
- **网关**：只走两台 VPS 网关取 OKX 行情，两台之间自己竞速。

在国内网络下币安域名可能连不上，那就切网关。这个选择**只记在这台设备上**，不随账号同步——
不同设备的网络环境本来就不一样。

## 8. 账号与同步

**用户名 + 密码**注册，没有邮箱、没有验证码。

- 登录后这些东西跟着人走：设置偏好、画线偏好、**画线**、**自选**、**分类**、**提醒**。
- **不登录也能用**。同步只是通道，不是门槛：自选、画线、设置、提醒离线全都正常，
  服务器宕了 app 照常看盘。只有**复盘**真的需要登录（运算在后端，那是权限验证）。
- 账号页能看同步状态（已同步 / 待同步 N 项 / 上次同步多久前）、**立即同步**、
  **登录设备**管理、**修改密码**、**退出登录**、**注销账号**。
- 同一类设备同时只允许一台在线：手机一类、平板一类、电脑一类，同类第二台登录会把前一台踢下线。
- 本机永远留一份带账号标识的完整缓存。两份都在时谁新用谁；真冲突的时候问你「用云端那份 / 用我这份」。

## 9. 不在 app 里的那些入口

- **桌面长按图标**：最近看过的 3 个品种 + 直接进搜索。
- **剪贴板识别**：复制了 `SOLUSDT`、`$SOL` 或者中文币名再打开 app，会提示一次要不要跳过去。
- **搜索**：放大镜进搜索页。可以打代号、中文名、拼音全拼或首字母（「以太」「yitai」「yt」都行）。
  结果先按最匹配排，同档之间按 24 小时成交额降序。输入框锁英文键盘。
- **深链**：`hkline://symbol/BTCUSDT?interval=1h`、`hkline://alerts`、`hkline://review/<id>`、
  `hkline://search` 等；分享出去的链接是 `https://kanpan.107-174-172-10.sslip.io/s/<id>`。

## 10. 现在还没有的

- **推送横幅**：没有 APNs 密钥，提醒触发不会弹锁屏横幅（判定与状态回写都正常）。见上面第 3 节。
- **交易**：不做，也不打算做。
- **复盘的几件**：框选贴边自动滚动、精确时间编辑、痕迹点进详情、保存案例管理界面、
  规则版本查看、截图补录、旧资料归属导入。
- **OKX 的持仓量副图**还没接（直连币安那条路的 OI 是有的）。
- **iPad** 只做到「不破」：能用、不错位，但没有专门的宽屏分栏布局。
- 最低系统 **iOS 18.0**。
