## 底栏与「我的」

底栏常驻四格「**图表 · 自选 · 板块分类 · 我的**」，每格一整页，切到哪一页它都在；底栏没有自己的底，页面的材料从它身后穿过去。

「我的」收拢六块：**账号**（未登录是「登录 / 注册」，登录后是用户名 + 同步状态 + 「立即同步」）、**复盘本**（观点 N 条 · 待判定 N）、**全部预警**（生效中 N）、**朋友与收件箱**（未读 N）、**交易所账户**（只读 API 接入，用于自动复盘）、**设置**。复盘待判定的角标挂在底栏「我的」记号右上。

## 行情页

### 头部

左侧品种徽章 · 品种名（从自选行或板块品种列表进来时最左还多一颗**返回**键，点底栏任一格即清掉）；右上三颗圆片「**提醒铃 · ⋯ · 搜索**」：
铃上的角标是当前品种还没触发的提醒数，点开「提醒」表（见「提醒」）；「⋯」是系统菜单「**添加对比 · 记一笔 · 分享**」（对比满 3 只时「添加对比」置灰）；放大镜进搜索页。
品种名只是标签，点不动——**换品种只有放大镜和自选 / 板块两条路**。

左侧是最新价，紧贴下方一行涨跌额 + 涨跌幅小字，无底色、无箭头。右侧始终为**六格统计**，两列三行：

| | |
| --- | --- |
| **仓**（持仓量） | **额**（24h 成交额） |
| **市值** | **费率**（资金费率） |
| **结算** | **振幅** |

- 「**结算**」是费率的下一次结算**倒计时**，写成「4时31分」或「31分」，不足一分钟写「<1分」，缺数据统一写「—」。
- 价格与涨跌额按报价步长显示位数，闪迪 / 美光两位、比特币一位、1000SATS八位；均线、十字线与列表一致。头部动态字体封顶 `.large`。
- **市值是总市值**（总供应量 × 现价），不是流通市值。
- 数额统一 K / M / B / T。
- 不显示 24h 高低——那两个数占地方又不常用。
- 一格都给不出的品种（美元指数）整块不摆；Coinbase 现货没有的格写「—」。
- 行情停住（断线、休市）时价格变灰，不另加状态字。

### 连续扫图（藏在价格区的手势）

从自选分类或板块品种列表进图表时，**那份名单会被冻住**。在**价格区**（最新价 + 涨跌小字 +
右侧六格那一整块）左右横滑就切上一只 / 下一只，一路扫完整个分类。周期条和画布上没有这个
手势——图上横滑永远是平移。

### 周期条

常用行**六档等宽铺满**，出厂 `5m 30m 1h 4h 1d 1w`。

- 行尾「**更多 ˅**」里是全部 **14 档**（1m 到 1y，不含 3d），常用行放哪六档由你在那儿**钉**。
- 常用行**不会横向滚动**——能滚就意味着有钉住的档藏在屏幕外，所以永远只有六档、永远铺满。
- 没选中的档是纯文字，当前档是一颗贴着字的琥珀胶囊；**当前档没被钉住时那颗胶囊画虚线边**。
- 行尾还有一颗会来会走的动作：拖远了出现「**最新**」（跳回右缘）。不在场时它是零宽的。
- 行尾常驻三件：「**更多 ˅**」、「**分析**」（开「分析」面板，见下）、图表设置记号。
- 十字线在时，这一行换成十字线读数（开高低收、量、持仓量等，放不下先去开高低再去时间）。

### 「分析」面板

一张面板四节「**画线 · 主力订单流 · 指标 · 对比**」，出厂就是这个顺序；2026-10-08 起**按你的使用频率排位**——用过的节按次数前移，面板打开那一刻定一次顺序、开着期间不重排。

- **画线**：「开始画线」把当前这张图横过来变成画线工作台，画完自动转回竖屏；下一行「**隐藏画线**」开关只藏线不删线，挂在线上的提醒照旧（见「提醒」）。
- **主力订单流**：显示开关、图上大单签（现在是「大单与爆仓」气泡，见下）、「大单与爆仓」弹层入口（行上带实时副文字）、门槛。
- **指标**：主图叠加与副图开关、参数与颜色、副图高度、拖副图换序；「恢复默认指标」永远在最后。
- **对比**：添加 / 移除 / 清除对比品种，和顶栏「⋯ › 添加对比」开的是同一张对比模式搜索页。

### 图上的操作

- 双指捏合以**两指中点**为焦点缩放，不是永远缩右边；纵向张开量明显大于横向且在主图里时这一捏只缩价格轴，一捏之内不换轴。
- 右侧价格轴上竖拖 = 手动调纵向范围；双击价格轴上下颠倒。
- 价格轴**按内容定宽**：这一屏最宽那条刻度 + 两边 4pt。量宽时数字先换成 `0`，
  所以最新价每跳一下轴都不动，只有真的多一位才走一个字符的台阶。
- 越界有阻尼，末根始终贴右缘留白，主图与副图同时落在一屏里、不用滚。
- 横屏画线台自己记一份缩放，和竖屏互不影响。

### 大单与爆仓（图上气泡）

每根 K 线最多一枚透明气泡：向上 = 大买 + 空单爆仓，向下 = 大卖 + 多单爆仓，门槛按最近 300 根的分布自动定，一屏带字泡最多 6 枚、其余退成小圆点。点泡十字线落到那根并开「大单与爆仓」弹层：本根 / 爆仓 / 每根对撞柱 / 价位 / 24 小时爆仓 96 格 + 今日最大一笔 / 门槛。现货与美元指数不拉爆仓。开关在「分析 › 主力订单流」。

### 十字线那一行

点图面出十字线，周期条那一行换成一颗带铃铛的「**创建提醒**」药丸。点它：十字线收起，
弹出「创建提醒」页，价格已经填成十字线停在的那口价（见下面「提醒」）。
十字线停在副图上时不出这颗。

## 图表设置（周期条行尾记号）

一张面板，选完即收起。2026-09-28 收设置项后只剩四节，凡不是必须由人定的都收成定值或自动规则。

- **这张图**：**分享图片**（离屏渲染当前这张图，画线、指标、皮肤底色都带着，走系统分享面板）、**记一笔**（存进复盘本，自动用同一套截一张附在记录上）。
- **K 线**：画法三种（蜡烛 / 平均 K 线 / 收盘价）、阳线实心或空心。平均 K 线只换蜡烛的开高低收，
  读数、最新价、指标仍是真实价；收盘价只画一条收盘价折线加最新价胶囊。
  **K 线造型只有 AICoin 那一套**，没有风格选择。
- **显示**：只剩**盘口**开关（默认关闭，打开后在图区右侧显示上卖五、下买五的固定十行盘口梯）。网格、实时价格线、至今涨幅等都成了定值。
- **价格轴**：线性 / 对数。

### 指标（在「分析」面板里）

- 主图 **MA**（出厂 10/30/120/256）、**EMA**、**BOLL**、**VWAP**、**超级趋势**、**抛物线**、**主力订单流**
- 副图 **成交量 · 累计量差 · MACD · RSI · KDJ · 动向指标 · 持仓量 · 多空比 · 买卖比 · 基差**
- **副图同时最多三个**，出厂是成交量 + 持仓量 + MACD
- 周期参数**手输**，没有加减按钮；指标名与出厂参数三端只有一份（`indicators.json`）
- 多空比为全市场多空账户数比，买卖比为主动买量除以主动卖量，基差显示基差率百分数。基差只提供近 30 天；持仓量、多空比、买卖比支持归档历史。这几种只有币安 U 本位、直连线路才有，网关线路保留所选副图并显示中文空态；现货与美元指数不画它们。

### 对比

把别的品种叠到当前这张图上比强弱。两处入口：「分析」面板「对比」一节，以及顶栏「⋯ › 添加对比」，开的都是**对比模式的搜索页**——上方「正在对比」条最多三枚胶囊各带 ×，每行行尾＋点加、再点去，满三只提示「最多对比 3 个品种」，主品种置灰。

- **画法**：一加上主图就换成**百分比坐标**——0% 是**当前可视区最左那根 K 线的开盘价**，
  拖图、缩放时跟着重定基点。主品种照常画蜡烛，对比品种各画一条收盘价折线，颜色按加入顺序
  固定取皮肤的指标色，不给选。右轴写 `+1.25%`，图例一行写每只的代号和当前涨跌幅，
  十字线在时图例和右轴都读十字线那一根。
- **对比期间**：主图均线 / 指数均线 / 布林带不画（百分比轴上没意义）；副图照常算主品种；
  画线全部藏起、「开始画线」置灰。转横屏画线、打开「记一笔」、看朋友发来的线时
  暂时退出对比，回来自动恢复——集合本身不动。
- **扫图**：横滑换主品种时集合保留；扫到的那只本身在集合里，这张图上就先不画它。
- **跟着人走**：集合随账号同步；没登录也照常可用。

## 画线

「分析 › 画线 › 开始画线」，当前这张图横过来变成画线工作台，画完自动转回竖屏。
横屏画线台里副图不画，主图指标默认照画、顶行右端「主图˅」开只摆主图指标的侧栏、眼睛胶囊一点收掉；画布上不浮任何控件，工具都在图外。

### 面板 12 把，契约 41 种

「绘图」面板只摆 **12 把**常用工具（2026-09-22 用户砍的，见[不做清单](不做清单.md)），一屏摆得下，没有分类标签、搜索框和收藏星：
水平线、趋势线、垂直线、平行通道、斐波那契回撤、斐波那契扩展、测量、文字标注、锚定 VWAP、区间成交量分布、锚定成交量分布、多空持仓框（`Drawing.Kind.palette`）。
另有十一把**并进别的工具**：射线 / 水平射线 / 直线 / 箭头 / 十字线画完之后在样式表的「换一种画法」里换；价格区间 / 日期区间 / 日期价格区间并进「测量」；气泡标注 / 价格标签 / 旗标 / 上下箭头并进「标注」。
江恩、艾略特、XABCD、矩形、椭圆、三角形等在手机上不做。存档与同步契约仍认全部 **41 种**（老线与电脑网页画的都能显示），电脑网页的工具栏按 TradingView 九组摆全 41 种。

### 细节

- **笔色跟皮肤**：没选色的线用皮肤强调色（青苔墨绿、陶土赤陶），色板五支全从皮肤派生；没在编辑的线 70%，选中与正在画的 100%。
- **吸附**：工具栏上的开关，开着就贴到 K 线的高开低收。
- **样式**：颜色、粗细；回撤 / 扩展这类能改比例数列（逗号分隔）。新线一律实线、带填充的工具一律填充；**锁定**在图上长按那条线 400ms（再按解锁）。
- 形态类**最多八个锚点**，每个端点都能单独拖。
- **画线时两根轴被钉住**：手指按着端点的那两秒里，新 K 线到货、行情走出新高都不会让线跟着跑。
- **撤销栈按品种存**，切页、进出横屏之后撤销仍然有效。
- **画线管理**：列出当前品种全部线（每行带「周期 · 距现价 ±x.xx% · 价」），逐条显示 / 隐藏 / 锁定 / 删除，也能一次清空——
  **清空之后还能撤销**。
- **上次用的画法记着**：每把工具记上次的样式。

## 提醒

独立模块，不是画线的属性。**画线和提醒互不牵连**：藏线、删线都不动提醒；线看不见时图上按提醒自己的几何画一条琥珀虚线 + 右缘铃铛，点中开「提醒」表。

提醒有几种，都随账号同步：

- **画线提醒**：选中一条线，选中栏左边那颗「跌到 / 涨到 X 叫我」胶囊一点就开、再点就关；
  画完线什么都不问。加过提醒的线，右端画一枚小铃铛。判定一律**价格达到**。
- **价格提醒**（从图上加）：点图出十字线 → 周期条那一行「创建提醒」→「创建提醒」页。整页是几张分组卡片：
  - **品种卡**：图上那只，只读（名称、交易所 · 产品、现价与涨跌幅），这里不能换品种。
  - **价格**：预填十字线那口价，直接改成你要的那个数；下面一行「现价 84,535.5 · 高于现价 0.15%」。
    整行都点得着，输入井带一枚铅笔记号、聚焦时描一圈主题色；键盘上方有「完成」。价格非法时主按钮直接变灰，不弹提示。
    **条件**：价格达到 / 收盘穿过。方向按现价自动判定（高于现价就是「涨到」）。
  - **网络回调**：只一个地址框（http/https），填了就发；有字才露「发一条测试」。
    提醒响的时候 POST 一份定好的 JSON（`User-Agent: Hkline-Alerts/1`，8 秒超时，失败 3 秒后重试一次）：
    本机判响的本机发，服务端判响的服务端发，不会发两遍。
  - 「创建提醒」按钮：表收起，图上浮一句「已加提醒 · BTC 涨到 84,662.2」。创建页第一次露面时问一次通知权限。
  - **当前提醒 N**：按钮下面只列这只品种**还没触发**的价格提醒与画线提醒，按新旧排；
    点价格提醒那一行进「编辑提醒」页（按钮换成「保存」）；每行右边一枚垃圾桶。
- **条件提醒**（只在登录且币安 U 本位时出现）：费率、1 小时持仓量变化、均线穿越、大单墙；服务端与前台同一口径判，谁先判到谁响、只响一次。
- **复盘到点**：记一笔时填了「到点再看」，到点就响，点它直接打开那条复盘记录；响过的在总表里留一天后自动清掉。
- **自选五分钟波动**：我的 › 设置 › 通知 →「自选波动提醒」开关（默认关）；幅度按每只最近一天的 1 分钟波动自动定，不手填。
  同品种同方向同一个五分钟窗口只响一次，退回阈值以内才重新上膛。响时浮一条「BTC 五分钟涨 2.00% · 查看」，点了跳到该品种。
- **品种上新与停牌下架**：设置 › 通知里一个开关。

**只响一次，响完就删**（通知 / 回调发出去之后这条提醒就从列表里没了，也随同步从别的设备上删掉）；**没响的一直留着**，不因为数量多或画线没了被清。

**管：** 顶栏**铃**开「提醒」表，分段「**列表 | 日志**」：列表把当前品种置顶，底部「创建提醒」开创建页（品种锁死、价格预填现价）；日志是全部品种最近 30 天的触发记录，按天分组，「清空」要确认，未登录写「登录后可查看」。
总表「**全部预警**」在「我的」里（点通知、`hkline://alerts` 链接也直接开它），分段「价格提醒 N」「画线提醒 N」（有复盘到点再多一段），段内按品种分组，行尾只有垃圾桶；点一行表收起、跳到那只品种（画线提醒直接到那条线上）。空态「还没有提醒 + 一句怎么建 + 去创建」。

**判定在哪跑：** app 在前台时本机算，立刻响应——`AlertEngine` 把行情流里一口一口的成交价
折成 1 分钟桶（和服务端订的那条 1m K 线对齐，不是你图上正在看的那个周期），
价格达到／穿过就当场震一下、页面上浮一条「BTC 触到你画的趋势线 · 查看」，点得动，点了就去那条线上，
通知中心里同时留一条。挂着提醒的品种会被钉进行情订阅里，所以它不在自选里、你也没在看它，照样算。
app 不在前台时由服务端订阅 1 分钟 K 线算（回调由服务端发），触发状态随同步落回你这台机器，
下次打开 app 补一条本地通知，随即把这条提醒删掉。美元指数的画线 / 价格提醒由服务端读自己的库判。

**锁屏横幅现在不会弹。** 没开 Apple 开发者会员、没有 APNs 密钥，工程里也没有推送能力。
所以**只有 app 开着的时候提醒才会当场响**；app 在后台或关着的那一段，服务端照样判、状态照样回写，
但它敲不动你的锁屏屏幕，你得下次打开 app 才看到（那一下会补一条本地通知）。密钥一到位就接上。
**复盘待办到期的本地通知不依赖这个，现在就有。**

**还有两种情况会漏：**本机是按看到的成交价折桶的，两次采样之间插进来的一根针可能没量到（宁可漏，
不误响）；「等它收盘穿过」要连着两根 1 分钟 K 线，中间切过后台或断过线的那一根不判。

### 提醒铃声

我的 › 设置 › 通知 → **提醒铃声**。四档为「默认」「清脆」「电子」「玻璃」，点一行立即选中并试听，返回或重启后仍保留。

这是所有价格提醒共用的选择，登录后随账号同步。本地提醒与服务端推送使用同一档；复盘到期通知仍用系统声。

试听尊重静音状态。默认档由系统通知播放，需要已允许 Hkline 的通知；三段自备音可直接试听。

## 复盘

**唯一一个真需要登录的功能**——运算在后端。其余（自选、画线、设置、提醒）离线照常，
服务器宕了 app 照样看盘，同步只是通道不是门槛。

入口在「**我的 › 复盘本**」（底栏「我的」记号右上的角标是到期待判定的条数）；记一笔从顶栏「**⋯ › 记一笔**」或图表设置「这张图 › 记一笔」起手。

**记一笔：** 取景区间就是**图上看得见的那一段**——拖图、捏图就是在圈，卡上只读一行「x 根 · 起 – 止」；填方向（看多 / 看空 / 观望）、一句话「现在怎么看」、参考价与范围；到期按周期给默认（分钟级 1 天、小时级 1 周、日线 1 个月…），图上拖到期线是唯一的改法。保存时自动附一张当前图的截图。
**没写完能存草稿**，下次「继续未完成的记录」。

**判定：** 到期进待办。判定时「**当时那张图**」和「**市场的答案**」并排看，回答：当时的判断
哪些成立、同样的局面再来改哪儿、下次怎么做。写完进**战绩**统计。

**其他：**

- 结果在你写完复盘之后又变过的，那条会标出来让你再看一眼。
- 「**作废记录**」保留内容但退出战绩统计，不是删除。
- 「**在图上重温**」逐根播放当时那段行情，能暂停、按方向重置。
- **交易回放**：接了只读交易所 API 后，复盘本「交易」里已平的一笔，详情页图上点一下就回到行情图，从开仓前 20 根一路自动播到
  平仓后 5 根；开仓、平仓各停一下轻震，头部显示持仓浮盈，写过「当时怎么想」的会在开仓时浮出那句话。
  倍速在 1× / 2× / 4× 里自动挑让这一趟落在 40 秒内，回放条上的倍速键只管这一趟。
- 两种回放都**没有「前一根 / 后一根」**：按住播放条中间那根进度线拖，游标跟着手指走，
  越过开仓 / 平仓（或判断那一刻）的刻度轻震一下，松手停在那儿，原来在播接着播。
- 「**找相似**」在历史里找形态接近的区间，**至少要框 16 根** K 线；比对进度实时显示。
- 记录固定所属行情源，换线路不会让旧记录对不上。
- 观点一条没有而交易有时直接开在交易面；观点空态「还没有观点 · 在图上记一笔」。

  提醒列表本身不在设置里，见「提醒」→「管」。
- **行情线路**：见下。
- **关于**：版本号、构建号、隐私政策与服务条款（正文由服务端 `/privacy`、`/terms` 提供）。
- **恢复默认**（重置所有偏好）。
- 收掉的：时区（全 app 上海时间，日线边界仍 UTC 0）、盯盘时不锁屏（图表页在前台常亮）、十字线磁吸（常开）、清缓存（按上限自清）、按屏幕亮度切换深浅、涨跌幅起点（按品种类型自动）。

### 行情线路：没有自动切换

两档，**出厂「网关」**（2026-10-08 起，和网页版一致）：经我们新加坡那台服务器转一道，不开代理也能用——iOS 的 K 线 / 报价 / 推送在这档由 **OKX** 供数（服务端替身），所以直连才有的外部统计副图（持仓量、多空比、买卖比、基差）显示中文空态、盘口为空。
「**直连**」只走币安自己的域名，探不通就提示「点此重试」，**绝不偷偷切到别处**；国内要开代理，网络本来就连得上交易所时更快。老档里的直连升级时迁成网关一次，之后自己切回直连就留住。

这个选择**只记在这台设备上**，不随账号同步——不同设备的网络环境本来就不一样。在「图表设置 › 线路」或「我的 › 设置」都能切。
