# Hkline 功能与细节

写于2026-09-21，2026-09-22按现行源码及P0返工更新。工作安排仅见[交接书](待办交接-Codex-2026-09-22.md)，本文不是待办清单。

最低系统 iOS 26.0（2026-09-21 起；iOS 27 也在支持范围内，26 以下不再维护）。

按功能写，每一项连着它的关键细节和不明显的地方。「点哪格去哪儿、拖图平移捏合缩放、
点星加自选」这类看一眼就会的不写。

## 行情页

### 头部

品种徽章 · 品种名 · 复盘（带待办角标）· 放大镜。品种名只是标签，点不动——**换品种只有
放大镜和自选两条路**。

左侧是最新价，紧贴下方一行涨跌额 + 涨跌幅小字，无底色、无箭头。右侧始终为**六格统计**，两列三行：

| | |
| --- | --- |
| **仓**（持仓量） | **额**（24h 成交额） |
| **市值** | **费率**（资金费率） |
| **结算** | **振幅** |

- 「**结算**」是费率的下一次结算**倒计时**，写成「4时31分」或「31分」，不足一分钟写「<1分」，缺数据统一写「—」。
- 价格与涨跌额按报价步长显示位数，闪迪 / 美光两位、比特币一位、1000SATS八位；均线、十字线与列表一致。头部动态字体封顶 `.large`。
- **市值是总市值**（总供应量 × 现价），不是流通市值。
- 数额统一 K / M / B / T。
- 不显示 24h 高低——那两个数占地方又不常用。

### 连续扫图（藏在价格区的手势）

从自选分类或板块品种列表进图表时，**那份名单会被冻住**。在**价格区**（最新价 + 涨跌小字 +
右侧六格那一整块）左右横滑就切上一只 / 下一只，一路扫完整个分类。周期条和画布上没有这个
手势——图上横滑永远是平移。

### 周期条

常用行**六档等宽铺满**，出厂 `5m 30m 1h 4h 1d 1w`。

- 行尾「**更多 ˅**」里是全部 **14 档**（1m 到 1y，不含 3d），常用行放哪六档由你在那儿**钉**。
- 常用行**不会横向滚动**——能滚就意味着有钉住的档藏在屏幕外，所以永远只有六档、永远铺满。
- 没选中的档是纯文字，当前档是一颗贴着字的琥珀胶囊；**当前档没被钉住时那颗胶囊画虚线边**。
- 行尾还有一颗会来会走的动作：拖远了出现「**最新**」（跳回右缘）。不在场时它是零宽的。
- 行尾常驻三件：「**更多 ˅**」、「**指标**」（直接开指标页，左上角那颗关面板）、图表设置记号。

### 图上的操作

- 双指捏合以**两指中点**为焦点缩放，不是永远缩右边。
- 右侧价格轴上竖拖 = 手动调纵向范围；**双击价格轴上下颠倒**要先在图表设置里开
  「主轴允许翻转」（副图同理是「副轴允许翻转」）。
- 价格轴**按内容定宽**：这一屏最宽那条刻度 + 两边 4pt。量宽时数字先换成 `0`，
  所以最新价每跳一下轴都不动，只有真的多一位才走一个字符的台阶。
- 越界有阻尼，末根始终贴右缘留白，主图与副图同时落在一屏里、不用滚。

### 十字线那一行

长按图面出十字线，头部换成「**‹ 上一根 / 下一根 ›** · **按此价画线** · **看细节**」。

- 「按此价画线」直接在十字线那个价位落一条水平线。
- 「**看细节**」进下一档更小的周期，并把视野正好铺成刚才选中那一根 K 线覆盖的区间；
  切回大周期时恢复你原来的视野（视野栈按品种存）。
- 十字线读数显示「选中价」还是「至今涨幅」在图表设置里选。

## 图表设置（周期条行尾「图表」）

一张面板，选完即收起。

- **K 线**：画法三种（蜡烛 / 平均 K 线 / 收盘价）、阳线实心或空心。平均 K 线只换蜡烛的开高低收，
  读数、最新价、指标仍是真实价；收盘价只画一条收盘价折线加最新价胶囊，价格轴按收盘价自适应，
  指标照常画，横屏画线时也保持这种画法。
  **K 线造型只有 AICoin 那一套**，没有风格选择。
- **显示**：网格、实时价格线、本根倒计时、显示画线、指标区域自适应、
  十字线读数（量、均量、持仓量一律 K / M / B / T，价格与均线原样按品种小数位）、盘口（默认关闭，打开后在图区右侧显示上卖五、下买五的固定十行盘口梯）。
- **价格轴**：线性 / 对数 / 百分比；主轴、副轴是否允许双击翻转。
- **指标**：
  - 主图 **均线**（出厂 10/30/120/256）、**指数均线**、**布林带**
  - 副图 **成交量 · 持仓量 · 平滑异同 · 相对强弱 · 随机指标 · 随机强弱 · 真实波幅 · 多空比 · 主动买卖比 · 基差**
  - **副图同时最多三个**，出厂是成交量 + 持仓量 + 平滑异同
  - 周期参数**手输**，没有加减按钮
  - 多空比为全市场多空账户数比，主动买卖比为主动买量除以主动卖量，基差显示基差率百分数。基差只提供近30天；持仓量、多空比、主动买卖比支持归档历史。网关线路保留所选副图并显示中文空态，盘口为空
- **这张图**：
  - **分享图片** — 离屏渲染当前这张图，画线、指标、皮肤底色都带着，走系统分享面板
  - **记一笔** — 存进复盘本，自动用同一套截一张附在记录上

### 对比（面板里「对比」一节）

把别的品种叠到当前这张图上比强弱。入口只有这一个，图上、顶栏都不放按钮。

- **加**：「添加对比品种」打开品种搜索，点一行就加上；**最多 3 只**，满了「添加」置灰。
  当前主品种和已经加过的不会重复进来。已加的每只一行，行尾「移除」；最下面「清除对比」。
- **画法**：一加上主图就换成**百分比坐标**——0% 是**当前可视区最左那根 K 线的开盘价**，
  拖图、缩放时跟着重定基点。主品种照常画蜡烛，对比品种各画一条收盘价折线，颜色按加入顺序
  固定取皮肤的指标色，不给选。右轴写 `+1.25%`，图例一行写每只的代号和当前涨跌幅，
  十字线在时图例和右轴都读十字线那一根。
- **对比期间**：主图均线 / 指数均线 / 布林带不画（百分比轴上没意义）；副图照常算主品种；
  画线全部藏起、底栏「画线」置灰。转横屏画线、打开复盘「记一笔」、看朋友发来的线时
  暂时退出对比，回来自动恢复——集合本身不动。
- **扫图**：顶栏横滑换主品种时集合保留；扫到的那只本身在集合里，这张图上就先不画它，
  其余几条颜色不变，扫走后它又回来。
- **跟着人走**：集合随账号同步，换一台手机登录后原样回来；没登录也照常可用。

## 画线

点底栏「画线」，当前这张图横过来变成画线工作台，画完自动转回竖屏。
**横屏画线时主图副图的指标全部不画**，只留原始 K 线；画布上不浮任何控件，工具都在图外。

| 组 | 有什么 |

| 线条 | 水平线 · 水平射线 · 趋势线 · 射线 · 直线 · 垂直线 · 十字线 · 箭头 |
| 通道 | 平行通道 · 回归通道 · 安德鲁斯分叉 · 斐波那契通道 |
| 几何 | 矩形 · 椭圆 · 三角形 · 曲线 |
| 区间 | 价格区间 · 日期区间 · 日期价格区间 |
| 斐波那契 | 回撤 · 扩展 · 时区 · 扇形 |
| 江恩 | 江恩箱 · 江恩扇形 |
| 形态 | XABCD · ABCD · 头肩 · 艾略特推动浪 · 艾略特调整浪 |
| 测量 | 价时测量 · 多空持仓框 · VWAP · 区间成交量分布 · 锚定成交量分布 |
| 标注 | 文字标注 · 气泡标注 · 价格标签 · 旗标 · 向上 / 向下箭头 |

清单与形态按 TradingView 手机版对齐。**常用的可以收藏**，收藏过之后工具面板第一格就是
「收藏」；上次用哪把、停在哪个分类都记着。

### 细节

- **吸附**：工具栏上的开关，开着就贴到 K 线的高开低收。
- **样式**：颜色、粗细、虚实；回撤 / 扩展这类能改比例数列（逗号分隔）。
- 形态类**最多八个锚点**，每个端点都能单独拖。
- **画线时两根轴被钉住**：手指按着端点的那两秒里，新 K 线到货、行情走出新高都不会让线跟着跑。
- **撤销栈按品种存**，切页、进出横屏之后撤销仍然有效。
- **画线管理**：列出当前品种全部线，逐条显示 / 隐藏 / 锁定 / 删除，也能一次清空——
  **清空之后还能撤销**。

## 提醒

独立模块，不是画线的属性。

提醒有四种，都进同一张提醒总表（设置 → 提醒），都随账号同步：

- **画线提醒**：画完一条线，**头部价格行那一行就地变成一张小确认卡**问「要在这条趋势线上提醒你吗？」——
  六秒不理等于只画线。加过提醒的线，右端画一枚小铃铛。两种判定：**等它碰到**（价格触到这条线）、
  **等它收盘穿过**（要 1 分钟 K 线收在线的另一侧才算）；还能开「**再次提醒**」：触发后不停用，下次再穿还提醒。
- **价格提醒**：提醒总表右上角「新建」，选品种（默认当前品种）、手输一个价格，高于还是低于按现价自动判定，
  价格穿过就响。
- **复盘到点**：记一笔时填了「到点再看」，到点就响，点它直接打开那条复盘记录；响过的在总表里留一天后自动清掉。
- **自选五分钟波动**：提醒总表顶上的「自选波动提醒」开关（默认关）和「五分钟涨跌超过 [1.5] %」（手输，0.1–50）。
  五分钟涨跌 = 现价 ÷ 五分钟前那根 1 分钟 K 线的收盘价 − 1；同品种同方向同一个五分钟窗口只响一次，
  退回阈值以内才重新上膛；有缺口的那一口不判。响时浮一条「BTC 五分钟涨 2.00% · 查看」，点了跳到该品种。

**管：** 设置 → 提醒，列出待触发 / 已暂停 / 已触发，可暂停、删除、看是哪条线。

**判定在哪跑：** app 在前台时本机算，立刻响应——`AlertEngine` 把行情流里一口一口的成交价
折成 1 分钟桶（和服务端订的那条 1m K 线对齐，不是你图上正在看的那个周期），
碰到／穿过就当场震一下、页面上浮一条「BTC 触到你画的趋势线 · 查看」，点得动，点了就去那条线上，
通知中心里同时留一条。挂着提醒的品种会被钉进行情订阅里，所以它不在自选里、你也没在看它，照样算。
app 不在前台时由服务端订阅 1 分钟 K 线算，触发状态随同步落回你这台机器，下次打开就看到。

**锁屏横幅现在不会弹。** 没开 Apple 开发者会员、没有 APNs 密钥，工程里也没有推送能力。
所以**只有 app 开着的时候提醒才会当场响**；app 在后台或关着的那一段，服务端照样判、状态照样回写，
但它敲不动你的锁屏屏幕，你得下次打开 app 才看到（那一下会补一条本地通知）。密钥一到位就接上。
**复盘待办到期的本地通知不依赖这个，现在就有。**

**还有两种情况会漏：**本机是按看到的成交价折桶的，两次采样之间插进来的一根针可能没量到（宁可漏，
不误响）；「等它收盘穿过」要连着两根 1 分钟 K 线，中间切过后台或断过线的那一根不判。

自选页排序里那档「**离提醒线最近**」，就是按当前价距最近一条提醒线的远近排。

### 提醒铃声

设置 → 提醒 → **提醒铃声**。四档为「默认」「清脆」「电子」「玻璃」，点一行立即选中并试听，返回或重启后仍保留。

这是所有价格提醒共用的选择，登录后随账号同步。本地提醒与服务端推送使用同一档；复盘到期通知仍用系统声。

试听尊重静音状态。默认档由系统通知播放，需要已允许 Hkline 的通知；三段自备音可直接试听。铃声选择不改变上面说明的通知权限与锁屏推送条件。

## 复盘

**唯一一个真需要登录的功能**——运算在后端。其余（自选、画线、设置、提醒）离线照常，
服务器宕了 app 照样看盘，同步只是通道不是门槛。

入口在行情页顶栏那颗按钮，**角标上的数字是到期待判定的条数**。

**记一笔：** 框一段区间（或图表设置 → 这张图 → 记一笔），填方向（看多 / 看空 / 观望）、
把握百分比、一句话「现在怎么看」、参考价与范围、到期时间。保存时自动附一张当前图的截图。
**没写完能存草稿**，下次「继续未完成的记录」。

**判定：** 到期进待办。判定时「**当时那张图**」和「**市场的答案**」并排看，回答：当时的判断
哪些成立、同样的局面再来改哪儿、下次怎么做。写完进**战绩**统计。

**其他：**

- 结果在你写完复盘之后又变过的，那条会标出来让你再看一眼。
- 「**作废记录**」保留内容但退出战绩统计，不是删除。
- 「**在图上重温**」逐根播放当时那段行情，能暂停、按方向重置。
- 「**找相似**」在历史里找形态接近的区间，**至少要框 16 根** K 线；比对进度实时显示。
- 记录固定所属行情源，换线路不会让旧记录对不上。

## 自选

- **加自选只在品种行的星上做**（搜索页、板块品种列表），顶栏没有星。
- **分类**：顶上一条胶囊。「…」菜单里新建 / 重命名 / 删除分类，长按某行的菜单里「移到分类」。
- **排序**：价格 / 涨跌幅 / 涨跌额 / 成交额 / 自选顺序 / **离提醒线最近**。
  **手指按在表上时排序冻住**（只冻顺序，价格照刷），手一松再重排。
- **长按一行出只读预览卡**，动作在旁边菜单：打开 / **调整顺序** / 移到分类 / 取消自选。
  原来「长按整行直接拖」起不来了（同一个手势不能干两件事），拖动排序退到卡上那条
  「调整顺序」里——点进去是批量编辑，**在那儿长按才是拖动**。
- **删除给撤销**：左滑单条或批量删完，都有一次「撤销」。
- **迷你走势图默认关着**，在「…」里开。
- 回到自选页会滚回你刚才看的那一行。
- 第一次装、没账号没自选时种上 BTC / ETH / SOL + 当天成交额前 5；**删掉就不再回来**。

## 板块分类

一屏气泡，一颗气泡 = 一个板块，大小与颜色按表现走。顶上**加密 / 美股**硬切换。

- 点一颗气泡**进这个板块的品种列表**（视觉和自选页一样），在那儿点星加自选、点行进图表。
  **没有第二层气泡**，也没有粗细粒度切换。
- 每个板块标着成交额、20 日表现、多少成员跑赢。
- 加密那侧：公链 Layer-1 · ETH 生态 · Solana 生态 · BTC 生态 · Layer-2 · DeFi 蓝筹 / 其他 ·
  AI 代币 · DePIN · RWA · NFT 与社交 · Meme · 存储 · 隐私 · PoW 挖矿 · DeSci · 元宇宙 ……
- **美股那侧分类更粗**（云厂商 · 光通信 · 云与电力 …）——只用币安自己有的标的，数量有限。

## 设置

- **外观**：皮肤三套 **青苔·冷**（默认）/ **陶土·暖** / **经典**（AICoin 白底），
  各有浅深，跟随系统或手动指定；「自动护眼配色」随屏幕明暗切换。
- **涨跌配色**：绿涨红跌 / 红涨绿跌。
- **开盘时间**：交易所时间 / 本地。**时区**：图表时间轴用哪个时区。
- **十字线磁吸**：在这里，不在图表设置里。
- **提醒**：进提醒列表。
- **盯盘时不锁屏**、**启动快照**（冷启动先画上次那张图，不等网络）。
- **行情线路**：见下。
- **清缓存**、**恢复默认**（重置所有偏好）。

### 行情线路：没有自动切换

两档，**出厂「直连」**：只走币安自己的域名，探不通就提示「点此重试」，**绝不偷偷切到别处**。
国内网络连不上币安就手动切「**网关**」（走两台 VPS 取 OKX 行情，两台之间自己竞速）。

这个选择**只记在这台设备上**，不随账号同步——不同设备的网络环境本来就不一样。

## 账号与同步

**用户名 + 密码**，没有邮箱、没有验证码。

- 跟着账号走的：设置偏好、画线偏好、**画线**、**自选**、**分类**、**提醒**。
- **不登录也能用**，见上面复盘那节。
- 账号页：同步状态（已同步 / 待同步 N 项 / 上次同步多久前）、立即同步、**登录设备**管理、
  改密码、退出、注销。
