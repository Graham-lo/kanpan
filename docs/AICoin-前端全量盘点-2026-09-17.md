## 6. 建议落地顺序（只列大块，具体先给方案再做）

1. **顶栏改造 + 搜索**（2.1 #1/#3、2.6 #1–#6）：正在等用户决定网格内容、返回目标、是否删半屏层、是否显示历史。
2. **只改解析就能做的**（第 3 节倒数第 4/5 行）：解析 `volume/count/priceChange/openPrice`、`takerBuyQuoteAssetVolume`、`onboardDate/status`，解锁 头部量格、近期上新、新增 / 待定 / 下线标签、涨跌分布。
3. **放开 `@markPrice@1s` 的解码**（`DTO.swift:183` 补 `r`/`T`/`i`/`P` 四个字段，零新增请求）+ **取 `openInterestHist` 末行当当前持仓量**：解锁 头部 仓 / FR 两格、费率倒计时、基差率、指数价。再往后才是 全市场 `premiumIndex` 与 `fundingRate` 两个客户端方法（费率榜 / 7 日累加），以及给自家网关加 OKX 的 open-interest / funding-rate 两条路由。
4. **供应量表进后端**（Rust 侧每天拉一次 apex 列表 + get-products，缺的用 CoinGecko 补，存成 `base → 流通量 / 总量 / 排名`）：解锁 头部市值格、市值榜、发行总量、板块总市值、近期上新的流通市值列，以及法币汇率（同一处的 currency 接口）。走后端是因为这两条是币安官网自用的非文档接口，哪天变了要能服务端改掉，不靠发版。
5. **分析 Tab 三张表**（MA / 枢轴 / 技术指标）：纯本地算，先抓一张仪表盘真机图。
6. **价格预警本地闭环**（2.9 #1–#10）→ WidgetKit（2.10 #1–#3）→ Rust 推送 → Live Activity。
7. **报价簿 / 逐笔**（depth / aggTrades）→ 盘口 / 成交 Tab、委比。
8. **市场页**（2.5 列表壳 + 涨跌分布 + 榜单三块）—— 看盘目前没有全市场列表，这是新面，做之前先问用户要不要。
