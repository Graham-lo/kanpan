## 0. 决定（不再摆给用户选）

| 事项 | 决定 | 依据 |
|---|---|---|
| 归到哪 | 三把都是**画线工具**（`Drawing.Kind`），不是指标 | TV 就放在绘图面板；要锚点，指标没有锚点这个概念；横屏画线台里指标全关、画线照显示 |
| 分类 | 「测量」组（和「价时测量」「多空持仓框」同组） | 对应 TV 的「预测和测量」 |
| VWAP 价源 | `hlc3 = (H+L+C)/3` | TV 默认 |
| VWAP 标准差带 | **不画**，只有一条线 + 右端读数 | TV 画线版默认关；手机屏窄，三条线糊成一团；不给开关 |
| 成交量分布行数 | **固定 24 行**，按区间内 `[min low, max high]` 等分 | TV 默认 Number of Rows = 24；不做「每行多少 tick」 |
| 分布模式 | **涨/跌拆开**（每行 = 涨量段 + 跌量段横向拼接） | TV 默认 up/down；颜色直接复用图表涨跌色 `DrawTint.up/.down` |
| 涨跌口径 | 与蜡烛同一口径：`close >= open` 为涨（`ChartRenderer.swift:661`） | 柱子颜色要和它底下的蜡烛一致 |
| 价值区 | 70%，从 POC 起向两侧扩，每步比较上方两行之和与下方两行之和、并入大的一侧 | TV / CBOT 标准算法 |
| 画出来的线 | POC 一条实线 + VAH/VAL 两条虚线（横贯区间宽度）；只给 POC 一枚读数胶囊 | VAH/VAL 不写字——屏窄 |
| 柱子根在哪 | 区间**左边界**，向右生长；最长一行宽度 `W = clamp(0.30 × 区间像素宽, 24pt, 0.5 × plotW)` | TV 默认 Placement=Left、Width=30%；下限保证区间很窄时也读得出形状 |
| 左边界滚出屏幕 | 柱根钉到 `max(区间左 x, 图区左沿)`，柱子跟着留在屏内 | 锚定分布的锚常在很远的左边，不钉住就永远看不见 |
| 数据口径 | 就用当前周期的 K 线，不像 TV 那样下钻到更小周期 | 数据层没有跨周期下钻；量级对 3 位用户够用 |
| 锚点早于已加载历史 | 从已加载的第一根算起；往回滚加载了更早的根，结果随之更新 | TV 同样行为 |
| 落点后的「加提醒」小确认 | 这三把**不弹** | 它们不是一条价位线；提醒模块以后要做 VWAP 穿越再单独接 |

## 2. 算法（新文件 `KanpanCore/Sources/KanpanCore/Drawing/DrawVolume.swift`）

全部纯函数、`Sendable`、不碰 UIKit，单测直接打。

### 2.1 锚定 VWAP

```swift
public struct VWAPTrail: Sendable, Equatable {
  /// 从这一根开始（`series` 下标）。
  public var start: Int
  /// 每根一个值，与 `start...` 对齐；Σv == 0 的前缀是 NaN。
  public var values: [Double]
}
extension Drawing {
  /// 从第一根 `time >= anchorT` 的 K 线起累计 Σ(hlc3·v) / Σv 到末根。锚点在末根之后 → nil。
  public static func vwapTrail(anchorT: Double, series: BarSeries) -> VWAPTrail?
}
```

- 起点下标：二分找第一根 `series.time(at: i) >= anchorT`（`openTime` 单调）；找不到 → nil。
- 逐根：`pv += (h+l+c)/3 * v; vv += v; value = vv > 0 ? pv/vv : .nan`。非有限值的根跳过、不推进累计。
- 末根随行情推送变化：`replaceLast` 只动末根，重算是 O(n) 但 n 就是区间根数，不做增量缓存（见 §9 性能验收）。

### 2.2 成交量分布

```swift
public struct VolumeProfile: Sendable, Equatable {
  public static let rows = 24
  public static let valueArea = 0.70
  public var lo: Double, hi: Double          // 区间内 min(low) / max(high)
  public var rowHeight: Double               // (hi - lo) / rows；hi == lo 时取 1 行、高度 0 → 见下
  public var up: [Double], down: [Double]    // 每行涨量 / 跌量，count == rows
  public var poc: Int                        // 总量最大的行
  public var vaLow: Int, vaHigh: Int         // 价值区首末行（含）
  public var first: Int, last: Int           // 参与计算的 K 线下标范围
  public func rowLow(_ r: Int) -> Double; public func rowHigh(_ r: Int) -> Double
  public var total: Double
}
extension Drawing {
  /// `[fromT, toT]` 圈住的 K 线（含两端那根）。`toT == nil` 表示到末根（锚定分布）。
  /// 圈不到任何一根 → nil。
  public static func volumeProfile(fromT: Double, toT: Double?, series: BarSeries) -> VolumeProfile?
}
```

- 分桶：每根把 `volume` **按价格重叠比例**摊到它 `[low, high]` 覆盖到的行上（`overlap / (high - low)`）；
  `high == low` 的根全部落到它所在那一行。`close >= open` 记入 `up`，否则 `down`。
- `hi == lo`（区间内全是一字线）：退化为 1 行，`rowHeight = 0`，几何层给它一个固定 6pt 的行高画出来。
- POC：`up[r] + down[r]` 最大的行；并列取更靠近区间中价的那一行。
- 价值区：`acc = total[poc]`，`lo = hi = poc`；循环：`above = total[hi+1] + total[hi+2]`、`below = total[lo-1] + total[lo-2]`
  （越界记 0），并入大的一侧（相等先并上方），直到 `acc >= 0.70 × total` 或两侧都到头。
- 用当前周期 K 线，**不跨周期下钻**（§0）。

## 3. 几何（`DrawGeometry.swift`）

`drawingGeometry` 增加一个参数：

```swift
public func drawingGeometry(_ d: Drawing, bounds r: DrawBounds,
                            xOf: (Double) -> Double, yOf: (Double) -> Double,
                            decimals: Int? = nil, series: BarSeries? = nil) -> DrawGeometry
```

- 非计算型工具完全不看 `series`，行为一个像素都不变。
- 计算型工具 `series == nil` 时只出手柄（`Drawing.swift:321` 的 `hitDraw` 老入口就是这样，它只在 Core 单测里用）。
- 真正的命中入口是 `ChartView+Drawing.swift:444 drawGeometry(_:axes:)`，改成传 `state.series`；
  `paintDrawing(…)`（`:1021`）同样加 `series:` 参数，`drawDrawings`（`ChartRenderer+Sub.swift:385`）、
  选中覆盖层（`:895` 附近）、落点预览（`:907`）三处调用全部传 `s.series`。

`DrawFill` 加一个字段：

```swift
public var opacity: Double? = nil   // nil → 老的 0.12；柱子要 0.45 / 0.22
```

`paintDrawing` 里 `ctx.setAlpha(fill.opacity ?? 0.12)`。别的工具不传，还是 0.12。

### 3.1 锚定 VWAP 的几何

- `segments`：相邻两根之间一段，只收 x 落在 `[r.left - 2, r.right + 2]` 的根（屏外不出段，命中也不用算屏外）。
  `tint = .line`。
- `labels`：一枚 `.chip`，文字 = 末根 VWAP 价（按 `decimals`），锚在末根 `(x, y)`，`centered: false`（和测量读数同一画法）。
- `handles`：`[xOf(a.t), yOf(a.p)]`。
- 命中：走现成的 `inkDistance`（段距）；没有 fill。

### 3.2 成交量分布的几何（两把共用一个函数，区别只在 `toT`）

记 `xL = xOf(区间左 t)`、`xR = 固定：xOf(区间右 t)；锚定：xOf(末根 t)`，两者都夹进 `[r.left, r.right]`。
`root = max(xL, r.left)`，`W = clamp(0.30 × (xR - xL), 24, 0.5 × (r.right - r.left))`，`maxTotal = max(up[r] + down[r])`。

- 每行两块 `DrawFill`（四点矩形）：涨段 `[root, root + W × up/maxTotal]`、跌段紧随其后，`tint = .up / .down`；
  行高 `yOf(rowLow) - yOf(rowHigh)` 再各留 1pt 缝；`opacity`：价值区内 0.45，区外 0.22。
- `segments`：
  - POC：`(xL, yPOC) → (xR, yPOC)`，`tint = .line`（走用户在样式里挑的颜色与粗细）。
  - VAH / VAL：同样横贯，`tint = .line`；几何里没有虚实之分，`paintDrawing` 收到 `segment.dashed == true`
    时临时改线型——给 `DrawSegment` 加 `public var dashed = false`，别的工具不传。
  - 区间边界：固定分布画两条竖线 `xL` / `xR`（`dashed`），锚定分布只画 `xL`。
- `labels`：一枚 `.chip`，POC 价，锚在 `(xR, yPOC)`。
- `handles`：锚点原样 `(xOf(t), yOf(p))`。
- 命中：柱子是 fill → `hitsFill` 点到任一行就是 `.body`；POC/VAH/VAL 走 `inkDistance`。

## 8. 测试

### 8.1 Core 单测（`DrawVolumeTests.swift`）
- VWAP：三根手造 K 线，手算 Σ(hlc3·v)/Σv 逐根对上；锚在两根之间取后一根起；锚在末根之后 → nil；`volume == 0` 的前缀是 NaN。
- 分布：两根 K 线各覆盖不同价带，24 行摊量对得上（总量守恒到 1e-9）；`high == low` 全落一行；涨跌拆分正确；
  一个手造的三峰分布，POC 与 70% 价值区落在预期行；`toT == nil` 用到末根。
- 几何：VWAP 出 `n-1` 段 + 1 枚 chip + 1 手柄；分布出 `≤ 48` 块 fill + 3 条横线（+2/+1 竖线）+ 1 chip；
  点在任一柱子上 `hit` 返回 `.body`；`series == nil` 只剩手柄。
- 老工具回归：随便挑 3 把现有工具，传 `series` 与不传的几何逐字节相等。

### 8.2 Chart 测试（`ChartDrawingTests.swift`）
- 三把各画一次到离屏 `CGContext` 不崩、有墨；两点工具的预览（`aim` 当第二点）能画出柱子。
