# 账号与同步：现行规格

更新：2026-09-22。文件名保留便于检索，正文描述已实现行为。唯一工作清单是 [交接书](待办交接-Codex-2026-09-22.md)，不从本文件生成工作项。

## 账号与会话

- 账号为用户名 + 密码，不使用邮箱注册或验证码。用户名为3～32个ASCII字母、数字或下划线，服务端规范化；密码以服务端哈希保存，凭证保存在客户端Keychain。
- 设置页提供注册 / 登录、同步状态、立即同步、设备管理、修改密码、退出与注销。图表、行情及本地个人资料可在访客状态使用；需要服务端的复盘操作按登录门处理。
- 手机、平板、电脑各允许一台活会话。同类第二台登录撤销前一台；被替换的客户端显示重新登录入口，保留本地个人资料，不把会话失效当成删除用户内容。
- 全进程同一凭证槽共享刷新协调器。刷新请求有稳定请求ID和重放恢复，登录 / 退出推进代际，旧响应不能覆盖新身份。
- 本地退出先停止旧身份的使用、卸载个人视图，再载入访客资料；服务器会话撤销在后台重试，离线不能阻塞安全退出。
- 注销需要身份确认并执行服务端硬删除。冷静期撤销、回收站、额外认证与个人资料扩展不做，见 [不做清单](不做清单.md)。

## 本地资料与同步

- 个人资料位于各账号独立目录，访客另有目录。草稿、未确认送达的操作与用户亲手修改不可因缓存清理或切号丢弃。
- 设置、自选、分类、画线、提醒等通过持久操作队列同步；复盘使用独立记录 / 修订接口与待发队列。不同账号的请求结果和ACK只能提交到原所属目录。
- 本地修改先可靠落盘，再发送。删除与撤销按依赖顺序提交；失败重试复用操作身份，永久协议拒绝保留本地意图并隔离，不能堵住后续正常项。
- 字段冲突自动按服务端版本规则以较新的一份为准，不弹云端 / 本地二选一。复盘文字保留修订，结果判定与复盘对应版本分开记录。
- 偏好母表为 `Kanpan/Kanpan/Settings/Model/PrefsFieldPlan.swift`。`synced`跟账号，`deviceOnly`留本机，`derivedLocal`为本机统计；`make sync-contract`生成契约，服务端白名单和值域同时核对。
- 行情线路选择只在本机保存，不被另一设备的偏好覆盖。网关自动切换不做，见不做清单。
- K线为有界缓存与启动快照，不作为永久个人资料。复盘缓存按容量及最近使用淘汰，待发内容和草稿不进入可淘汰区。

## 服务端与接口

实现位于 `Backend/kanpan-api`，客户端位于 `KanpanAccount`、app 的 `Account/` 与 `KanpanReview`。

| 入口 | 当前用途 |
| --- | --- |
| `POST /v1/auth/register`、`POST /v1/auth/login` | 注册与登录 |
| `POST /v1/auth/refresh` | 轮换 / 恢复会话 |
| `POST /v1/auth/logout`、`POST /v1/auth/session/revoke` | 退出与会话级幂等撤销 |
| `GET /v1/auth/me` | 当前账号 |
| `POST /v1/auth/password/change` | 改密 |
| `GET /v1/auth/devices`、`DELETE /v1/auth/devices/{id}` | 设备列表与撤销 |
| `DELETE /v1/auth/account` | 注销 |
| `/v1/sync/*` | 个人对象同步 |
| `/v1/native-review/*` | 复盘记录、判定、修订及截图 |

生产运行角色为非表属主、无BYPASSRLS，个人表启用强制RLS；事务设置所属用户后访问。客户端相同隔离边界包括账号目录、刷新代际与视图激活代际。

API / worker部署与数据库备份按 [后端说明](../Backend/kanpan-api/README.md) 和 [离机备份说明](../Backend/kanpan-api/ops/OFFSITE.md)。恢复需要数据库与原密钥配套，不能生成新密钥冒充恢复成功。
