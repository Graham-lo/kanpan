# 电脑网页版 UI / 交互审查（2026-10-10，全屏 2560×1440）

审查方式：线上 `https://kanpan.43-160-232-253.sslip.io/web/` 最新部署（`1a4a6829`），本机 Chrome 无头 2560×1440 @1x 截全屏图，并用脚本量计算样式（字号、控件高、对比度）。截图在 `docs/acceptance/网页版-UI审查-2026-10-10/`。
视角：视觉设计 + 交易员真实用（看自选 → 开图 → 看订单流 → 多图 → 板块 → 建提醒 / 记一笔）。
对照：`docs/design/电脑网页UI规范-2026-10-08.md`。

## 总评

材料两层、框架一色、图标一套，整体已经不「割裂」，深色尤其整。问题集中在三处：**大屏上空间没用起来**（右栏、面板、板块页大片空白）；**多图布局的 chrome 太重**；**浅色下几处文字对比度不够、控件偏小**。功能排列上最大的缺口是电脑端没有「首页 / 榜单」入口。

## B. 层级、字号、可读性

| # | 位置 | 现状 | 建议 |
|---|---|---|---|
| B1 | 全站字号 | 正文 13、自选 14、详情卡标签 12 / 值 13、轴 13、底栏 12；1440×900 下刚好，2560×1440 @1x 偏小（没随屏放大） | 加一档「大屏密度」：≥2200 宽时正文 13→14、轴 13→14、详情卡值 13→15、行高同步 |
| B2 | 图例均线值 | 用线色当字色：MA10 黄 #F6C309 对 `--surface` 1.6:1，MA30 橙 2.1:1，MACD DEA 青 1.3:1，浅色下读不清（01a-topleft） | 线色不动（AICoin），文字另取同色相压暗到 ≥4.5:1 的「文字版」；深色无此问题 |
| B3 | 工具条控件 | 周期按钮 24 高、指标 / 提醒等 28 高、工具条 40；规范定按钮 32 / 工具条 38 | 统一 28（和右侧图标块一致）或按规范 32 |
| B4 | 详情卡 | 板块标签「比特币生态 …」被省略号截掉；卡只 320×330 | 结合 A1 扩卡；标签换行或只留一个 |
| B5 | 左画线栏顶部 | 「十字光标」是整屏最重的一块绿（比品牌还抢眼），而它只是光标模式（01f-leftbar） | 降成普通块，选中态用强调软底 |

## 做得对的（不动）

周期「更多」弹层分组 + 星标钉住；右键菜单（创建提醒 / 画水平线 / 记一笔 / 复制价格 / 重置视图 / 对数 / 隐藏画线 / 设置）齐全；搜索弹窗键盘提示；大单抽屉四块卡（汇总 / 逐根 / 价位 / 爆仓）信息密度好；深色整体；框架层一色、卡片无描边；1440×900 笔记本尺寸下整体刚好。

## 建议的整改顺序

1. A1 + A6 + A5（右栏、首页榜单入口、板块页）——功能排列
2. A3 + A4（多图 chrome 与轴标签）——重点审查对象「十六图」
3. B2 + B1 + B3（对比度、大屏密度、控件高）
4. A2 / C3 + C4 + C5（面板弹层化、提示位置、重复入口）
5. C1 + C2 + B5 + B4 + C6
