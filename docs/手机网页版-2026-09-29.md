# 手机网页版（iOS 复刻替代版）· 交接说明 2026-09-29

## 定位（用户 2026-09-29 定）

三端各司其职：**iOS app** 功能最全的正主；**PC 网页版**（`/web/`）大屏用、是独立的一套设计；
**手机网页版**（本文，`/web/m/`）是装不了 app 时的临时替代，目标是**完全按 iOS app 复刻、尽量还原**，
验收标准是「加到主屏幕后日常用下来和 app 没有区别」。

不复刻的只有浏览器做不到的系统能力：灵动岛 / 实时活动、APNs 推送、震动、代码锁定横屏、桌面小组件。
已接受的三点差异：不能强制横屏（用户自己转手机）、没有震动、切后台要重连并恢复现场。
其余一切（视觉、交互、功能）都以 iOS 现有定稿为准，**不另起设计、不借 PC 网页版的视觉**。

## 地址与入口

- 路由走 hash：`#chart` `#favorites` `#sectors` `#me`，与底栏四格一一对应。

## 代码结构（`Web/src/m/`）

```
Web/m/index.html           手机入口 HTML（首帧前套皮肤，viewport-fit=cover, user-scalable=no）
Web/src/m/main.ts          入口
Web/src/m/app/             store（localStorage「hkline-m-v1」）、shell（底栏、路由、恢复现场）、prefs 同步字段
Web/src/m/styles/          tokens.css（三套皮肤 × 浅深，令牌名照 Palette.swift）、各页 css
Web/src/m/chart/           从 KanpanChart 逐文件移植的引擎（renderer / sub / orderflow / state / paint / gesture / drawing）
Web/src/m/indicator/       从 KanpanCore/Indicator 移植的指标引擎
Web/src/m/pages/           chart（MainScreen）、favorites、sectors、me、alerts、search、drawingBench（横屏画线台）
Web/src/m/ui/              手机端小控件：左滑删除、拖动排序、弹层、问号解释弹窗、胶囊
```

**共用**（直接 import，不复制）：`Web/src/market/`（币安 REST / WS / 品种表 / 供应量）、`Web/src/account/`、`Web/src/sync/`、`Web/src/util/format.ts`、`Web/src/data/sectors.json`、`Web/src/review/api.ts`、`Web/src/notes/`。
**不共用**：`Web/src/chart/`（PC 引擎）、`Web/src/styles/`、`Web/src/pages/`、`Web/src/ui/`（PC 的图标与浮层）。

共用模块需要参数化的地方（改时不能让 PC 版回归红：`node scripts/regress.mjs`）：
- `account/client.ts`：`ACCOUNT_KEY` / `DEVICE_KEY` / `Device.kind` 现在写死 `'desktop'`。加 `configureAccount({ keyPrefix, kind })`，手机入口在任何 import 副作用前调用，kind 用服务端认的「手机」那一类（去 `Backend/kanpan-api/src/auth.rs` 查设备类别的枚举值，手机网页在「一类设备一台在线」里算手机）。
- `app/store.ts` 是 PC 的状态，手机不用它；手机自己的 `m/app/store.ts` 字段照 iOS `Prefs`（`Kanpan/Kanpan/Settings/Model/Prefs.swift`）来，同步字段白名单与 `Backend/kanpan-api/src/sync.rs` 的 `valid_field` 对账（两份清单必须一致，服务端对含未知字段的操作是整条拒绝）。

## 手机浏览器的硬约束（写代码时就要照办）

- `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover, user-scalable=no">`；图表画布 `touch-action: none`；全局禁双击缩放与长按选中（`-webkit-user-select: none; -webkit-touch-callout: none`）。
- 安全区用 `env(safe-area-inset-*)`；`apple-mobile-web-app-status-bar-style` 跟皮肤深浅走。
- 切后台 WS 会断：`visibilitychange` 回前台立刻重连补订；当前品种 / 周期 / 页 / 滚动位置随时落 localStorage，冷启动恢复到原地。
- Canvas 按 `devicePixelRatio` 画，线宽 1 物理像素对齐（和 iOS 一样清晰）。
- 长按十字线、双指缩放、单指平移、惯性，全部用 Pointer Events 自己写，不依赖库；`Web/package.json` 不加运行时依赖。
- 竖屏 / 横屏用 `matchMedia('(orientation: landscape)')` 监听；画线台在横屏时才展开。
