日期：2026-09-15。本文按用户最新要求定案，覆盖此前文档中冲突的入口、存储与实施顺序；原型和 Claude 原文保留。

## 1. 先定用户体验

**打开就能看，操作立即响应；登录后数据以云端为主，每个人只看到自己的内容。**

| 用户在做什么 | 最终行为 |
| --- | --- |
| 第一次打开 | 直接看盘。画线、改指标、改色、自选、本地记一笔可以直接用 |
| 登录 | 登录后回到原来的图和位置；后台接续数据，只提示一次「已登录」 |
| 画线、改色 | 当场生效；可靠写入本机后后台上传，不等接口返回才画出来 |
| 记一笔 | 先保存，允许马上离开；未上传标「待同步」，服务端受理后进入「等答案」 |
| 离线回来 | 自动补传、恢复加载；草稿和待发操作不会被云端旧版本覆盖 |
| 换设备 | 常用设置和自选先到；复盘与画线按当前需要加载，首页不等待全库下载 |
| 查看旧复盘 | 分页加载，点详情才取完整内容，重温才加载对应行情 |
| 切换账号 | 立即切换个人内容，清理前一个账号的内存和正在展示的页面；公开行情可以继续用 |
| 退出账号 | 立即退出，待发内容保留在原账号的受保护目录，其他账号不能继承 |

后台实现不进入普通使用流程：没有服务地址、Token、合并报告、技术说明段落。确实需要用户处理时，在对应位置给一句原因和一个操作。

### 页面与入口

- 底栏固定 **指标 · 自选 · 复盘 · 设置**，四格等宽。
- 「图表」在周期行右侧；K 线风格合入其中，只展示经典、圆角、空心、轮廓四种。老版本已选风格保留，主动改选后才替换。
- 手机跟随系统自动旋转，尊重系统旋转锁定；不再添加横屏按钮。
- 图右下保留「记」；进入框选后才显示相关把手与记录卡，平时不遮挡 K 线。
- 「设置」顶部放账号入口与同步状态；复盘使用同一账号。
- 「复盘」内是待办、记录、战绩。没有第二套复盘主页或连接账号表单。

### 手机交互与文案

- 单指平移、长按十字线保持原习惯。点「记」显式进入框选，点「画线」进入画线，两者互斥。
- 把手和按钮至少提供 44pt 触摸区域；重叠时选最近把手，拖动读数避开手指；不依赖悬停、右键或键盘。
- 点选一条线后直接显示「样式、锁定、复制、删除」。删一条立即生效且能撤销；清空才确认。锁定后也能从管理列表解锁。
- 编辑价格能直接输入；键盘不遮住保存；返回或收起保留未完成记录，重新打开继续。
- 常规设置立即生效；需要多项一起编辑的参数、颜色保留「取消 / 保存」，不把两种规则混在一个编辑页里。
- 删除解释实现的长段落与重复提示；保留短名称、单位、当前状态、数据确实不可用的原因和必要的操作后果。
- 错误色、复盘琥珀色与市场涨跌色分开，互换红绿不会改变错误或对错的语义。

## 2. 登录后云端为主，本机只留必要内容

后端保存完整个人资料和历史。本机保留轻量缓存与可靠的待发区，避免弱网让每一步都转圈。**缓存可淘汰；未上传的用户内容不可淘汰。**

| 数据 | 云端 | 登录后的本机策略 |
| --- | --- | --- |
| 指标参数、颜色、常用周期、外观 | 完整保存 | 保留完整轻量副本，启动和改设置立即响应 |
| 自选与分组 | 完整保存 | 保留轻量列表，报价按可见品种订阅 |
| 画线及工具偏好 | 按账号、市场、品种、对象保存 | 工具偏好常驻；当前及近期品种的画线缓存，其他品种按需拉取 |
| 复盘记录、规则、复盘文字、判定证据 | 完整保存 | 首屏摘要与最近打开内容缓存；旧详情分页取 |
| 战绩 | 服务端计算，带统计版本 | 只缓存返回结果，不下载所有记录重算 |
| 保存的相似案例 | 保存来源、时间范围、特征版本等定位信息 | 打开才加载；不复制整段行情常驻 |
| 截图附件 | 私有对象存储，按账号授权 | 缩略图和最近查看内容有限缓存 |
| 草稿、尚未确认送达的操作 | 已提交的业务内容由服务器接收 | 本机持久保存；未点「记下」的草稿不上传 |
| 行情、回放数据 | 公开行情由网关提供；后端临时取数 | 视野所需内容与有上限缓存，退出回放释放额外内存 |

缓存先采用一个全设备预算：个人历史与附件缓存总计 50 MiB、清单页最多保留最近 200 条摘要；按最近使用淘汰。它是缓存预算，不是记录总量限制。设置、自选、游客未上传内容、草稿和待发队列不计入可淘汰区；容量异常时如实报保存失败，不能假报成功。预算后续用真机实测调整。

已同步完整历史不长期复制到手机；未活跃账号的可重建缓存优先释放。服务器搜索、统计和判定不占手机后台持续运算。前台合并短时间修改、滚动停稳再拉详情，不用持续高频轮询。

### 本机账户目录

```text
Application Support/kanpan/accounts/local/       游客资料与草稿
Application Support/kanpan/accounts/u-<id>/      小型偏好副本、草稿、待发日志、同步元数据
Library/Caches/kanpan/accounts/u-<id>/           可重建的个人历史与附件缓存
Library/Caches/kanpan/market/                    公共行情缓存，不含个人内容
Keychain: kanpan.account                        按账号与会话区分的刷新凭证
```

- 原有分散文件一次性迁移到以上结构；校验写入成功再切换，迁移可重试，旧文件不能先删。
- 游客数据用批次 ID 认领，每批只能归属一个账号。首次登录自动认领未归属批次；服务端确认与本机认领标记可靠落盘后，再清理游客重复副本。退出后开始新的游客批次，不能让 B 再认领 A 已接收过的资料。
- 不因为登录成功就清除未送达内容。被认领但尚未送达的批次继续留在原账号待发区。
- 切账号先取消任务、解除旧订阅，再切存储；所有异步返回检查账号 ID 和本次会话代号，旧账号结果不能写进新账号。
- 未登录不能打开已退出账号的缓存。清缓存只清可重建内容，不清草稿、队列、凭证或游客记录。
- 单纯把文件放到服务端不等于安全：本机使用 iOS 文件保护，服务端使用受限身份、加密磁盘与备份；后台仍需读取数据进行判定，不声称端到端加密。

## 3. 多人隔离是一条端到端规则

采用一个 PostgreSQL 服务承载多个账号，个人业务行带不可变 `user_id`，配合数据库行级安全策略隔离。**不为每个人起一套数据库或服务器，也不只靠前端筛选。**

- 用户身份只来自验证后的会话；URL 中的记录 ID、请求体中的 ID 均不能替代授权。读取、修改、删除、搜索、统计、附件、后台任务都检查归属。
- 对他人记录与不存在记录返回一致的不可访问结果，不能靠连续猜 ID 获取他人数据。
- 应用数据库角色不是表所有者、没有 `BYPASSRLS`；个人表启用并强制 RLS。在连接池事务内设置当前账号，用事务级上下文避免下一个请求继承身份。[PostgreSQL RLS 文档](https://www.postgresql.org/docs/17/ddl-rowsecurity.html)
- 关系引用同时约束账号与对象 ID，不能出现 A 的复盘引用 B 的截图或规则。后台作业也携带并验证账号，不绕过隔离。
- 附件为私有桶；鉴权后发短期访问地址。日志不记录密码、验证码、Token、完整原话或附件正文。
- 公共行情和仅来自公开 OHLC 的相似索引共享；个人画线、原话、截图、私库向量与搜索结果不进入公共索引。
- 缓存键、任务去重键、导入键与幂等键都含账号作用域。限流按账号并结合 IP；一个用户不能耗尽所有人的搜索和判定资源。
- 服务器使用最小权限、异地加密备份并做恢复演练。覆盖前 30 天快照属于内部保障，不增加用户误删找回页面。
- 不接交易所账户、交易密钥、资金或仓位采集接口。用户主动填写的原话、上传的截图按私有内容处理。

## 4. 账号流程：简单页面，后端负责完整性

邮箱 + 密码，不做手机号或第三方登录。本轮直接补齐注册、登录、找回、改密、设备退出和注销，避免做出只有登录没有找回的半套账号。

| 场景 | 定案 |
| --- | --- |
| 注册 | 邮箱、密码 → 邮箱验证码 → 自动登录。新增邮箱验证，防止邮箱输错或被抢占 |
| 登录 | 邮箱、密码；成功返回原页面，不跳转账号首页 |
| 找回 | 邮箱 → 验证码、新密码 → 自动登录；旧设备会话全部撤销 |
| 改密 | 当前密码、新密码；当前设备继续使用，其他设备退出 |
| 退出 | 本机立即退出；联网撤销服务端当前会话。离线时不声称已完成服务器撤销 |
| 设备 | 标明「本机」，其他设备单独退出；服务器撤销后，该设备后续请求失效 |
| 注销 | 密码确认，关闭账号并撤销会话，停止作业，删除云端个人数据；不弹假成功 |

- 密码采用原要求的至少 8 位且含字母数字，最大长度明确且不静默截断；Argon2id 配合版本化服务端 pepper，参数按部署机器实测。
- 验证码 6 位、10 分钟、最多错 3 次、60 秒后可重发；重发废除旧码。注册码和找回码分用途、分挑战，校验和消费为原子操作；不存明文码。
- 密码连续错误 5 次锁 60 秒；账号限制与 IP 速率限制分别实现，IP 阈值可调，避免几个人共用网络就连坐锁定全部账号。
- 发码对有效格式邮箱统一返回 202；登录失败统一 401 和短提示；正文、耗时与冷却行为都要避免暴露邮箱是否注册。
- 找回自动登录保留原型的短流程，但须在同一事务中消费验证码、改密码、撤销旧会话并建立新会话；客户端只接收最后的新会话。OWASP 更推荐重设后常规登录，本项目采用自动登录须单独覆盖这条事务与重放测试。[OWASP 找回密码指引](https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html)
- access 最长 15 分钟、只在内存；refresh 存 Keychain `AfterFirstUnlockThisDeviceOnly`，使用轮换和重放检测。刷新单飞；断线重试用同一请求 ID 和设备绑定，仅允许短时重取同一结果，不把任意旧 Token 重用当正常刷新。[RFC 9700](https://www.rfc-editor.org/rfc/rfc9700.html)
- 注销后备份中的数据按明确保留期到期清除；恢复备份必须重放账号删除清单。原本已在本机的内容不被静默删除，转为受本机解锁保护的离线存档，不归入游客区、不自动上传给其他账号；云端未缓存的历史不会为了注销而下载。
- 原生表单使用邮箱键盘、密码自动填充、验证码粘贴/自动填充；验证码用一个真实输入框承接六格视觉，不强迫用户逐格输入。

## 5. 自动同步：不打扰，也不丢资料

### 同步边界

- 上传白名单：指标与图表配置、常用周期、主题与涨跌色、画线和工具偏好、自选分组，以及用户正式提交的复盘内容。
- 不上传：行情缓存、当前周期与视野、十字线、回放游标、最近访问、当前选中的自选分类、网络域名与路由、设备息屏/启动快照开关。草稿和队列作为容器不上传，队列中的已提交业务操作需要传输。
- 正式判定、统计和样本资格由服务器产生，客户端只接收；不是可双向覆盖的用户偏好。
- 每个账号在每台设备的「自动同步」开关独立保存。关闭后停止自动上传和拉取，保留待发内容；「立即同步」执行一次，开关仍关闭。已经受理的服务器判定继续运行。
- 主动点查找或打开云端详情属于当次请求，不受自动同步开关拦截；界面显示真正结果。同步状态保留最后成功时间，不能把「已暂停」塞到「上次同步」时间字段里。

### 合并协议

采用对象变更与游标协议，不用整份 `draws.json` 或整个 `Prefs` PUT 覆盖云端：

1. 每个修改带 `operation_id`、对象 ID、字段路径、基础版本和设备逻辑时间；服务端分配提交序号。ACK 与本机待发状态原子写入，超时用同一操作重试。
2. 只合并确实修改的字段。颜色分到指标/输出；画线锚点作为一个整体、RSI 上下限作为一组、存在依赖的参数一起验证，防止合出不合法对象。
3. 已知先后按版本处理；真正并发用服务端校准的设备时间加逻辑计数与稳定 ID 决胜，限制异常未来时间。不能直接信任手机 `updated_at`，也不能保证离线设备有绝对准确的先后。
4. 首次导入没有字段历史的旧文件以低优先级填充云端缺项；未修改的安装默认值不参与竞争。覆盖前保存 30 天版本快照。
5. 删除留下墓碑；并发普通编辑不复活已删除对象。用户明确撤销删除产生新的恢复操作。墓碑保留到设备确认或设备被退休；30 天快照期限不是墓碑期限。过旧游标要求重新同步并重新检查待发操作。
6. 同步按订阅范围返回当前对象变更，离屏历史只使缓存失效，不把整库推到手机。旧版客户端不认识的数据保持原样，不能解码失败后用空集合覆盖。
7. 自选成员按市场身份去重；分组删除保留品种并归到未分组。排序合并保留另一端新加的成员。
8. 画线合并不得截取最后 50 条。现有 `DrawArchive.capped` 在读入和赋值都会裁剪，接云同步前必须改掉；存储保留全部，绘制按视野筛选并分页管理。设备性能上限不转化为用户数据删除。
9. 用户正在拖线或改参数时，相关远端更新等手势/编辑提交后处理，不在手指下跳变；退出账号即终止这个缓冲区的应用。

复盘正式规则、结果与复盘修订采用版本和事件记录：已受理规则冻结；后续修改形成新版本；并发复盘文字两个版本均保留，正常展示当前版本。复盘针对哪个结果写的必须记录，结果修订后不能把针对旧结果的复盘假标成已处理当前结果。

## 6. 复盘补全：一个独立模块，复用同一张图

保留 `KanpanReview` 的 Domain / Data / UI 分层，App 的 `ReviewIntegration` 只适配图表。账号、存储与请求能力经接口注入，复盘模块不自己保管第二套凭证。

### 记录

- 框选至少 3 根已收盘 K 线；左右端点吸附、贴边滚动和补历史，支持精确起止输入。
- 目标、失效、到期可拖也可输入；用户动过的值不再被默认值覆盖。行情区间和真正做判断的时间/参考价分开。
- 方向可改；从图上录入默认「图在先」，把握默认未填。原话改为可选：原生记录已有精确范围和明确规则，后端不能因旧版必填字段逼用户凑一句话；旧截图契约单独兼容。
- 默认「收盘确认」，可选「触价确认」。触价依据先触目标还是先触失效；同根同时跨越而无逐笔证据时保持待核验，不能猜。
- 到期是 UTC 绝对时间，周期按交易所日历解释；月线/年线不能用固定分钟数凑。只在实际已支持的市场和周期上开放正式判定。
- 离线补记保留实际写入时间与服务端受理时间；不把已经走完的行情伪装成提前预测。正式战绩按冻结的样本资格入选。

### 痕迹、待办与战绩

- 痕迹用琥珀与中性灰：范围、目标/失效、到期和结果。点痕迹打开对应记录，详情回到真图。
- 待办分「等答案 / 待判定 / 待复盘」，角标只计需要用户行动的数量，正常等待不制造红点压力。
- 历史按需分页、服务端筛选与搜索；空态给「记一笔」，错误态给「重试」，不展示数据库或任务术语。
- 战绩复用既有样本资格与代表样本规则，拆开图在先/想法在先。当前草稿的 5 天分组占位必须移除；样本资格、结果版本与统计版本可追溯。

### 重温

- 复用现有 K 线引擎，逐根前后、播放与 1×/2×/4×，可跳到判断时刻。
- 回放游标同时限制 K 线、指标、OHLC、价格轴范围、报价、痕迹和当时可知信息，避免提前看到未来结果。缺失的 OI 显示缺失，不画替代数据。
- 记录只保存白名单 `ChartSnapshot`（指标、颜色、画线快照等）；禁止序列化整个 `Prefs`。当前草稿直接 `encode(prefs)` 会夹带本机网络配置，接后端前必须替换。
- 退出重温恢复进入前的品种、周期和位置，不把回放设置写回日常看盘偏好。

### 找相似：列入本次完整交付

- 从框选区间或记录发起。直接用真实 OHLC 构建与索引同版本特征，不再用像素近似还原看盘内已有数据。
- 范围为「市场历史 / 我的记录」。公开历史可提供受限匿名查询；我的记录必须登录且只搜本人。公共索引不能混入用户私库。
- 发起时固定截止时间、特征版本和市场范围；重绘、分页、重试不刷新截止时间。排除自身重叠区间，历史查询不越过当时截止点。
- 复用已有公开检索的 0.60 结构相似度门槛，经 OHLC 查询一致性验证后沿用；结果写「相似度」，不解释成胜率或预测概率。保留分页顺序，可看过的页能返回。
- 查询可取消、异步分页，点结果在真图上对比；点「保存」才成为个人案例。数据不足时如实显示范围不足，不伪造匹配。
- 公开索引使用有来源与版本的特征；不永久保存完整原始 K 线。索引构建与正式判定运行在服务端 worker，Mac 关机不影响线上功能。
- 截图补录保留在「更多」中，沿用定位后的真实图表；未知股票/黄金不能强行映射成同名永续。币安 TradFi 永续与现货市场身份分开。

## 7. 服务端与模块边界

```text
iOS App
  Account：账号、会话、账号切换
  Sync：轻量副本、待发日志、订阅变更、缓存淘汰
  KanpanReview：记录、痕迹、重温、找相似、战绩
             ↓ 同一会话
kanpan-api（axum + sqlx）
  账号 / 个人同步 / 复盘 / 检索
             ↓
PostgreSQL + pgvector       私有附件存储
             ↑
kanpan-worker：判定、索引、清理、统计

既有行情网关：继续匿名公开行情转发，不携带个人凭证
```

- 在看盘仓库新增 `Backend/kanpan-api/`，API 与 worker 分进程部署，共用契约、业务模块与数据库；搜索和判定分别限并发，避免搜索排队拖慢登录和保存。
- 复用 `scorebook-core` 已验证的判定、样本资格与检索计算；固定依赖版本，核对实际依赖，不把它假设成只有 serde 的轻量包。部署不引用 Mac 的绝对路径。
- v1 判定保持版本兼容；原生目标/失效规则以受测试约束的 v2 实现。整个系统只有一份权威记录、规则版本、结果与复盘事件，不另养一套会漂移的「原生正式结果」。
- 现有 scorebook-backend 中的 `native_review` 与 0057 迁移是本地未部署草稿，作为代码素材审查移植；不能一边部署旧草稿，一边另写一套正式 API。
- pgvector 保存公共 OHLC 特征与隔离的个人特征；仅迁移来源明确、版本一致的旧公共索引。旧个人复盘按核实的账号映射导入，不按邮箱猜归属、不复制给所有新用户。
- 既有 Scorebook 服务与前端本轮不改动、不重启。上线需要的发信域名、服务配置、数据库与存储备份在部署阶段接入，密钥不进仓库或普通设置页。

### 契约清单

以下是待实现的最终接口范围，完整 DTO、版本与错误码由 OpenAPI 冻结；不沿用「等四个」的省略描述。

| 接口组 | 必须覆盖 |
| --- | --- |
| `/v1/auth/register`、`/register/verify`、`/code/resend` | 注册挑战、验证、重发 |
| `/v1/auth/login`、`/refresh`、`/logout`、`/me` | 会话与当前身份 |
| `/v1/auth/password/code`、`/reset`、`/change` | 找回、改密 |
| `GET /v1/auth/devices`、`DELETE /v1/auth/devices/{id}` | 列表、单设备撤销 |
| `DELETE /v1/auth/account` | 注销事务、异步清理状态与可重试结果 |
| `/v1/sync/bootstrap`、`/changes`、`/operations` | 轻量初始状态、按范围增量、幂等提交；不返回整库历史 |
| `/v1/native-review/records`、`/{id}` | 创建、分页、详情、条件与资格状态 |
| `/{id}/revisions`、`/{id}/reflections`、`/{id}/void` | 新规则版本、复盘修订、作废 |
| `/v1/native-review/statistics` | 权威统计、样本口径与版本 |
| `/v1/native-review/searches`、`/{id}`、`/{id}/results` | 发起、状态/取消、稳定分页；公共匿名任务仅临时会话可访问 |
| `/v1/native-review/saved-matches` | 保存、分页、移除个人相似案例 |
| `/v1/native-review/attachments` 与定位状态 | 私有上传、定位、截图补录 |
| `/v1/capabilities` | 实际支持市场、周期、检索覆盖、截图能力 |

所有写接口使用幂等键；所有可变对象使用明确版本。服务端确认保存才标「已同步」，成功登录不能顺带冒充数据已送达。

## 8. 实施顺序与交付标准

| 阶段 | 完成内容 |
| --- | --- |
| 1. 冻结契约与归属 | 用户模型、存储迁移、字段白名单、版本/删除/队列协议，正式复盘 v2 口径 |
| 2. 完整账号 | kanpan-api、隔离与会话、注册验证/登录/找回/改密/设备/注销；原生表单与账号切换 |
| 3. 轻量云同步 | 偏好、自选、按品种画线；去掉 50 条裁剪；离线补传、取消同步、容量控制 |
| 4. 完成复盘闭环 | 接正式接口、服务端判定、文字修订与战绩；移除服务地址和凭证表单；补完手机框选与回放 |
| 5. 接完整检索 | 公共 OHLC 检索、个人检索、保存案例、旧数据有归属导入、截图补录 |
| 6. 统一验收 | 真机完整链路、弱网与跨账号/跨设备、缓存占用与流畅度；通过后再单独展开机型兼容 |

各阶段做必要编译和协议/隔离测试，新增功能完成后统一进行用户流程和真机验收，符合用户要求的测试顺序。

必须通过的场景：

- A/B 两个账号同时使用，改 ID 也读不到对方记录、图片、向量、作业结果或统计；退出、切换过程中旧请求不能串数据。
- 两台设备分别改均线颜色、同一条线、不同字段；断网删除后旧设备上线，线不复活；超过 50 条不丢；未来系统时间不永久压过所有修改。
- 杀进程发生在保存、服务端 ACK、刷新令牌、游客认领期间，恢复后不丢记录、不重发成重复记录、不串号。
- 验证码第 3 次错误后即使输入正确旧码也失败；并发重放、改密撤销、设备撤销真实生效。
- 离线先记、晚到服务端、同根触及上下界、缺行情、到期、结果修订都如实归类，不污染战绩。
- 重温任何一根时不暴露未来指标、价格尺度或结果；相似搜索不越界，不将相似度显示为胜率。
- 用户有大量复盘和附件时，登录仍只请求轻量首屏；缓存稳定在预算附近，清缓存不损害未上传记录。
- 手机单手框选、拖线、删线撤销、改色保存/取消、键盘遮挡、自动横竖屏、后台恢复完整走通。
