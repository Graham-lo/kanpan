## 画线交互

- **⇧ 拖端点 / ⇧ 画**：线吸到 0° / 45° / 90°。
- **方向键**：选中的画线移动 1 px，⇧ 加方向键移动 10 px。一次按键（按住不放的自动重复也算一次）记一步撤销。只要选中了画线，方向键就只移动画线，不再平移图表或换品种；画线锁住时方向键什么也不做。
- **复制**：⌘ 拖一条画线会复制一条拖走，原来那条不动。⌘C / ⌘V 只能贴回同一只品种，每贴一次往右下错开 12 px。
- **选中后的快捷条**（贴在格子上沿，网页自己的样式；画线挨着上沿时让到下面）：
  - 内容：当前颜色（点开是 14 色调色板），最近用过的 2 种颜色，粗细 1–4 px，线型（实线 / 虚线 / 点线），画线提醒，锁这一条，删除。
  - 拖动画线时快捷条淡出。
  - 多空持仓只有锁和删（颜色固定为红绿）。固定区间成交量分布只能改颜色。斐波那契没有线型。
- **样式记忆**：同一族工具（线族 = 趋势线 / 射线 / 水平线 / 垂直线）记住上次改的颜色、粗细、线型，新画的直接用。
- **批量删除**（工具栏最下面的垃圾桶）：
  - 三个选项：全部画线 / 全部指标 / 全部，每个选项都实时显示数量。
  - 删完弹提示，⌘Z 可以撤销（指标也会一起恢复）。
  - 范围是当前格子的品种。指标本来就对全部格子生效。
- **磁吸**：保留原来的开关，按住 ⌘ 时临时反过来；不分强弱两档。
- **复盘回放**：回放图上会显示这只品种保存的画线，但只能看：不能选中、不能拖、不能新画，快捷键也不起作用。
- **上限**：每只品种最多 500 条、2 MB。到了上限就不再新建，并提示「<品种> 的画线到上限了」。

## 快捷键（`?` 打开，能搜）

新增的快捷键：

| 快捷键 | 作用 |
|---|---|
| Alt J | 射线 |
| Alt N | 记一笔 |
| ⌘ Y | 重做（⌘ ⇧ Z 也行） |
| ⌘ C / ⌘ V | 复制 / 粘贴画线 |
| ⌘ ⌥ H | 隐藏 / 显示全部画线（macOS 可能吞掉这个组合，⌃ ⌥ H 也行） |
| Alt ⇧ W | 开关侧栏，再开时回到上一次那一栏 |
| ⇧ T | 打开布局菜单 |

- 搜索框可以搜功能名（例如「射线」），也可以搜按键：「alt j」「⌥J」「option j」都能搜到 Alt J，cmd / ⌘、shift / ⇧、ctrl / ⌃ 同理。输入的内容和分组名匹配时，返回整组。
- 不支持改键。
- 修了一处：原来按 `?` 打开快捷键表时，焦点落在搜索框上，那个「?」会被打进搜索框，整张表被滤成一行。现在这次按键会被吞掉。
- 「⇧ 点『添加指标』加到全部格子」：网页的指标 `st.ind` 本来就对全部格子生效，所以没有另外做界面。

## 同步字段的改动与对账

| 项 | 改动 |
|---|---|
| 种类映射（`Web/src/sync/codec.ts`） | `avwap ↔ anchoredVWAP`（1 个锚点）、`fvp ↔ fixedVolumeProfile`（2 个）、`position ↔ position`（3 个：入场、目标、止损），照手机的 `Drawing.Kind` rawValue |
| body 字段 | 网页开始写 `dash`（solid / dashed / dotted），读的时候也认。网页写的键：`anchors color dash filled hidden kind levels lineWidth locked market symbol venue` |
| 服务端 | **不用改**。`Backend/kanpan-api/src/sync.rs` 的 `DRAWING_FIELDS` 本来就有 `dash`；`sync_validation.rs` 本来就认 `anchoredVWAP` / `fixedVolumeProfile` / `position` 以及它们的锚点数 |
| 只存本机、不进同步的新字段 | `drawStyles`（每族记住的样式）、`recentColors`、`toolLast`（每组上次用的工具）、`lastPanel`。它们是本机的操作习惯，不算账号数据，也不参与同步指纹 |

对账结果：

- `Web/tests/sync-codec.test.ts` 用 `contract/drawing-fields.json` 做对账：`ANCHORS` 必须等于契约的 `anchorCounts`，`WEB_BODY_KEYS` 必须是契约 `syncFields` 的子集。结果通过。
- `make backend-test`（`cargo test --lib`）：501 通过，0 失败，3 忽略。
- `make sync-contract` 没跑：这次 iOS 那边的编码没有变，而且它要起一次很重的 iOS 构建。契约一致性由上面两项覆盖。

## 同步自检（P2-5 第 12 条）

- 登录状态下，本机画线存档读坏（解析失败、形状不对）时会打一个「可疑」标记。标记期间记账**只推新增和修改，不推删除**，并先把账本里云端那一份并回来，所以不会拿一份空表去清掉云端的画线。
- 拉取页的形状不对时，当成拉取失败抛出，不当成「云端是空的」。
- 没推出去的账本按账号存。只有同一个账号重新登录时才接着推；换了账号，云端的那一份整体覆盖本机。
- 单测用 `Web/tests/sync-fake.ts` 模拟服务端，放在 `Web/tests/draw.test.ts`。
