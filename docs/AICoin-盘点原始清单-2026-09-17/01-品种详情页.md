资源根目录：`/Users/mdd/zhk/kanpan/refs/aicoin/res-full/`（layout / layout-land / values / values-zh-rCN / values-night）。
本文只读资源、未改任何项目代码。所有 dp/sp/颜色/文案均直接取自布局 XML 与 `values*/` 资源文件；标注「（未读）」的 include 未展开。

分类口径：
- **A** 资源齐、看盘现在的数据（ticker24h / klines / openInterestHist）就够；
- **B** 资源齐，但看盘缺数据（写明缺什么、Binance/OKX 公开接口能否补）；
- **C** 资源不齐（自绘 View / WebView / 未展开 include），需真机镜像；
- **D** 不复刻（广告、资讯、社区、下单、VIP、AI、直播、KOL、分享海报），一行带过。

通用尺寸/颜色（后文引用）：
- `sh_base_title_block_height`=44dp，`sh_base_title_text_size`=17sp；`font_size_small/normal/large`=12/14/18sp。
- 文本色：primary `#292d33`/夜 `#c3c7d9`；secondary `#525a66`/`#7a8899`；tertiary `#7a8899`/`#667180`；highlight `#1478fa`/`#1060c8`；view bg `#ffffff`/`#0d111c`；页面 bg 夜 `#090c14`。
- `ui_ticker_detail_kline_block_height`=420dp，`ui_ticker_detail_tab_content_height`=320dp。
- 样式：`ui_ticker.PriceBoard.ContentText.Title` 11sp `#b7bfc8`（夜 `#7a8899`）/ `.Value` 13sp primary；`ui_ticker.PriceBoard.ItemTitle` 12sp / `.ItemValue` 13sp；`ui_ticker.Technical.DataText` 13sp（min 9sp）`#333333`/`#858a99`，`.DataTitle` 12sp，`.DataTipText` 11sp。
