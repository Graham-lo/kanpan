# kanpan-web-uses-tradingview-chart-27in-2k

**项目约定**：看盘 web 端是一套全新 UI，K 线用 TradingView 那一套而不是手机的 AICoin 那一套；先按用户的 27 寸 2K（2560×1440）屏设计，其它屏幕以后再兼容；UI 必须符合设计规范

2026-09-29 用户要推进看盘（Hkline）的 web 端，原话：「我需要你设计一版全新 web 版的 ui 设计，
k 线不再用手机那一套，用 tv 那一套，因为屏幕很大，目前的电脑是 27 寸 2k，先按照这个来设计，
后续再做其它屏幕的兼容，注意 ui 设计要符合规范」。前一天他也说过 web 的 UI 不能和手机一样，
交互不能按手机的触屏点击来做。

所以在 web 端：

- **K 线图表照 TradingView 桌面版的那一套**（多窗格与分隔、右侧价格轴上的最新价标签与收线倒计时、
  虚线十字线与轴上标签、左上角图例、主图底部叠加成交量、底部时间范围条、左侧画线工具栏）。
  手机端的记忆 kanpan-kline-colors-are-aicoin-only、kanpan-single-aicoin-candle-style、
  kanpan-chart-base-is-not-a-design-target 只管手机，不约束 web 的图表。
- **界面是全新设计**，不是把手机的底栏、圆片、面板搬过来，也不是把 09-22 那版 Mac 桌面原型直接拿来用。
  功能与产品规矩（提醒只响一次、中文标签、K/M/B/T、上海时区、最少设置等）照旧有效。
- **设计基准屏是 27 寸 2560×1440**，先把这台做好；别的分辨率、窄窗口以后再做兼容，不要一开始就
  为了照顾小屏把信息密度压下来。
- **「符合规范」**指有成体系的栅格、字号阶梯、圆角与控件高度，对比度要过 WCAG AA，焦点态可见、
  键盘可达、目标尺寸够大——交付原型时要把这套规范本身也摆出来让他看。
