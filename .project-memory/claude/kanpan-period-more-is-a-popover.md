# kanpan-period-more-is-a-popover

**项目约定**：看盘行情页周期条的「更多」点开后是一块独立弹层（照 AICoin：从周期条下沿展开、盖在图上、带遮罩），不许再做成内联展开把 K 线压扁

2026-09-23 体验审查里我指出：周期条右侧「更多 ▾」点开后，面板是内联展开的，K 线图被压扁了一半，
下滑也关不掉。用户看完贴了一张 AICoin 手机端的截图，说：「点击周期更多时我建议做成**单独的弹层**，
而不是压扁，你看 aicoin 这种做法就比较好」。

AICoin 的做法是：面板从周期条下沿往下展开，盖在图表上方，图表本身的高度不变，面板以外的区域
压一层半透明遮罩；面板里是 5 列的周期网格，当前周期高亮；点遮罩或者再点一次「更多」就收起。

所以在看盘里：

- 「更多」周期面板一律做成**临时弹层**，绝不能占用布局高度、挤压 K 线图。以后重构周期条或者
  调整图表布局时，也不许把它改回内联展开。
- 这块弹层是点开才出现、点外面就收起的临时面板，不违反「K 线画布上不浮常驻控件」
  （kanpan-no-floating-controls-over-chart）那条规矩。
- 周期条本身的规矩不变：按用户钉住的周期排列，钉得少时自动铺满（kanpan-period-bar-pins-and-autofill）。
