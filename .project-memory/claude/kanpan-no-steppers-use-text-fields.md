# kanpan-no-steppers-use-text-fields

**项目约定**：看盘里数值参数（均线周期等）一律用手动输入框，不用加减步进器；非必要的 +/- 控件一律不出现

2026-09-20 用户在看盘（Hkline / Kanpan）里看到指标参数（均线周期）用的是加减步进器之后说：
「ma 参数一律改成手动输入框，不再搞那种加减，那个都没用，非必要这种加减的一律不要出现，
非常影响体验」。

所以这是一条全局规则，不只针对均线：

- **数值参数一律是可直接打字的输入框**（数字键盘，点进去就能改），不用 `Stepper`、不用一对
  「−」「+」按钮。原因很简单：把 10 改成 144 要点一百多下，加减对这种输入毫无用处。
- **非必要的加减控件一律不出现。** 只有那种取值范围极小、一次只可能动一格的场合（用户没举例，
  我也想不出看盘里有这样的地方）才允许，默认就当作不允许。
- 输入框的体验要按「改一个数只需要改数字」来做：点进去原值全选、直接输入新值、按保存时正在编辑
  的最后一格先提交再关面板、按取消一个参数都不变、输入过程中不按中间值重算图表。

这条和 kanpan-ui-restrained-element-scale、kanpan-ui-no-lecturing 同属「界面别给用户添麻烦」
一类；以后审查任何面板，看到 `Stepper` 或 +/- 就直接判为要改。
