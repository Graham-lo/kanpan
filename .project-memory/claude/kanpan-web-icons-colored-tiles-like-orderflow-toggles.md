# kanpan-web-icons-colored-tiles-like-orderflow-toggles

**工作习惯 / 用户纠正**：电脑网页图标要高级质感：单一皮肤色系的层级单色（SF Symbols 式）+ 毛玻璃小方块，不许黑白铅笔线描，也不许按类别上各种颜色（用户 2026-10-08 说「像卡通」）

用户 2026-10-08 对电脑网页图标前后提了三轮意见：
- 第一轮：左右栏的图标都是黑白线描，像铅笔画的，不好看。
- 第二轮：点名说「主力订单流」面板四个开关的质感好看。
- 第三轮：看了按类别分色相的方案后说「像卡通一样的各种颜色」，要高级感和质感，不要炫酷的多色土设计，整体要搭配。最终方案交给我定。

**Why:** 用户要的「好看」是材质和层次，不是颜色多。单色细线显得廉价，彩虹分类色显得土，两头都不对。

**How to apply:**
- 字形用填充的圆角形状，单色分透明度层级（1 / .55 / .25），颜色取 text-1。
- 每个图标最多一处用皮肤强调色。
- 静止时是一块很淡的中性毛玻璃小方块：细内描边、顶部高光、轻阴影。
- 选中时方块变成强调色玻璃，字形变白。
- 不按类别分色，涨跌箭头也走单色。

规范见 `kanpan-web-visual-spec-two-layers-soft-light`，偏好来源见 `kanpan-redesign-boldly-not-by-subtraction`（大胆指的是材质，不是颜色数量）。
