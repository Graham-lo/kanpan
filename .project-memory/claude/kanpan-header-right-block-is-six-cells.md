# kanpan-header-right-block-is-six-cells

**项目约定**：看盘行情页头部右侧的统计块是用户定的两列六格：仓/额、市值/费率、结算(倒计时)/估值；「振幅」2026-09-25 被去掉，同日第六格换成估值（币 OI/MC，美股 Fwd PE、预期亏损的给 P/S，其它类别不摆），估值格用英文缩写是用户点名要的；倒计时独占一格

2026-09-20 做费率结算倒计时时，实现代理把倒计时接在费率值后面同一格（「费率 +0.0074% · 42分」），
用户看了说：「我看费率和倒计时都重叠了，不如上部分右边留出 6 格的区域」。

所以看盘行情页头部的定稿结构是：

- **左侧**：最新价 + 涨跌幅药丸（kanpan-header-price-and-change 仍然有效：不放 24h 高/低）。
- **右侧**：六格，两列三行，每格「标签 + 值」——
  第一行「仓 ｜ 额」，第二行「市值 ｜ 费率」，第三行「结算 ｜ 振幅」。
  「结算」格的值是资金费率结算倒计时（3时53分 / 42分 / 即将结算），「振幅」是 24h 振幅百分比。
- **一格只放一个数。** 倒计时、费率各占一格，不用「·」把两个数拼进一格；一格里塞两个数在
  手机上就会挤、看起来像重叠。
- 头部因此比原来的两行高一行，这是用户接受的：他同时定了「上部空间不够可以向图表借高度」
  （见 kanpan-header-may-borrow-height-from-chart）。
- 六格字号不按屏宽缩放、不截断；窄屏（iPhone SE）也是同一套六格，只允许略微收紧格间距。

## 2026-09-25：「振幅」格去掉，六格变五格

用户在改自选页时先说「把振幅也去掉 / 品种中的振幅去掉」，我只删了自选行副文案里的振幅；
装到手机上后他又说「把振幅去掉啊」——那时 app 里唯一还在的振幅就是顶栏这一格。所以顶栏
现在是**五格**：左列仓 / 市值 / 结算三行，右列额 / 费率两行，（同日稍后用户又要把第六格补成估值，见下一节）。
`HeaderStats.amplitudeText` 连同它的单测已删。以后任何地方都不要再摆 24h 振幅。

## 2026-09-25（同日稍后）：第六格补成「估值」

去掉振幅后用户又说：「我想添加一个指标展示凑满 6 格，换成持仓量/市值，名字最好用英文简写
或者首字母展示……但这只限于加密。美股你看看能不能展示 forward pe，或者 ps 等要符合股票的特性」。
所以右列第三格现在是按品种类别给的估值比率（规则在 `HeaderStats.valuationCell`）：

- **币**：`OI/MC` = 持仓量 ÷ 总市值（就是左边「仓」「市值」两格相除，百分比）。
- **美股 / 港股 / 韩股**：`Fwd PE` = 市值 ÷ 一致预期未来十二个月净利润；预期亏损、没有远期利润的
  给 `P/S` = 市值 ÷ 过去十二个月营收。底数来自 kanpan-api `/v1/market/meta` 的
  `forwardEarnings` / `revenue`（从抓市值的同一张 stockanalysis 页读，折成美元），比率在手机上用
  正在显示的那口价现除。
- 金属、指数、未上市、分类未知：不摆这一格，回到五格。

这一格的名字用英文缩写是用户明确要的，是 kanpan-ui-labels-are-chinese 的例外；
别的格子仍然是中文单字/双字标签。
