# kanpan-max-three-sub-indicators

**项目约定**：看盘的副图指标同时最多三个，不是两个；指标面板、提示文案和验收都按三个来

2026-09-17 我交完交互定板原型后，用户第一条纠正就是「副图指标最多三个」。我在原型里把
指标面板写成「副图 · 同时最多两个」，还配了一条「副图最多两个，已换下 MACD」的 toast，
这是我自己定的数，不是产品规则。

看盘（Kanpan）的规则是：**副图（VOL / MACD / KDJ / RSI / 持仓量这一类）同时最多开三个**。
打开第四个时才需要顶掉最早开的那个并提示，打开第三个不算超限。原型、实施说明、验收用例
里凡是写副图上限的地方都按三个来，和「主图与副图指标要同时落在一屏可视区域内」那条一起
考虑：三个副图也必须和主图同屏放得下，不能靠滚动。
