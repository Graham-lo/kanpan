# kanpan-kline-colors-are-aicoin-only

**项目约定**：看盘的 K 线颜色只有 AICoin 手机端那一套：浅色下所有皮肤的蜡烛、均线、副图线都用它，不再另起一套 K 线配色；2026-09-24 起图外「文字」上的涨跌色（顶栏价格、涨跌小字、列表涨跌）在浅色皮肤下用加深版以过对比度，K 线本身不动

2026-09-17 我先给「经典」皮肤换上了 AICoin iPhone 端实测的 K 线色（蜡烛 `#36B257` / `#E64552`，
MA10/30/120/256 黄 / 紫 / 绿 / 珊瑚，副图槽位 `#2FD2B2 #FFB400 #E849B9 #1478C8 …`），青苔与陶土
仍各自带一套自家的涨跌与均线色。用户看到真机后说：「浅色所有模式下的 k 线颜色都统一成 aicoin 那种
k 线颜色」，紧接着又补了一句「以后不再另起一套」。

所以在看盘（Kanpan / 产品名 Hkline）里：

- **K 线的颜色只有一套，就是 AICoin 手机 App 上的那套。** 蜡烛涨跌、主图均线、副图指标线（MAVOL、
  DIF / DEA、RSI、持仓量）浅色模式下青苔、陶土、经典三套皮肤全部一样，
  皮肤只管图外的底、面、文字、强调色。
- **不要再为任何皮肤（包括将来的新皮肤）设计自己的涨跌色或均线色。** 之前「青苔的涨色和强调色同色系」
  这种把 K 线色融进皮肤的做法已经被用户否掉了；皮肤要「融」的是图外，不是图。
- 色值以 iPhone 上 AICoin 的截图逐像素实测为准，逆向出来的安卓常量只做旁证。深色版 AICoin 没在真机上
  量过，用户这次只点名了浅色；深色要动之前先量真机。

## 2026-09-24 的补充：图外「文字」上的涨跌色可以加深，K 线不动

UI 对照 HIG 审查时量出：AICoin 涨色 `#36B257` 对三套浅色页面底的对比度只有 2.5–2.7 : 1，
22pt 的最新价连大字要求的 3 : 1 都不到，13pt 涨跌小字更不够。我给了三个选项，推荐
「只加深文字上的涨跌色，蜡烛、均线、副图一点不动」，用户回：「可以的，k 线那块不需要动」。

所以现在的口径是两支色：
- **图内**（蜡烛、均线、副图线、图上的价格标签）：AICoin 原色，永远不动。
- **图外文字**（顶栏最新价、涨跌小字、费率值、自选 / 板块 / 搜索列表里的涨跌数字）：浅色皮肤下用
  加深版——涨 `#1E8040`、跌 `#C9303E`（对三套浅底都 ≥ 4.5 : 1）；深色皮肤基本沿用原色，
  只有经典深的跌色文字提亮到 `#E0524F`。落点在 `PanelTheme.up / down`（图区以外的主题），
  K 线取的是 `ChartColors`，两边互不牵连。
- 理由：图上的绿是面积色，大片浅绿舒服；文字是细线，要深一档才看得清。AICoin 手机端自己图上和
  文字上的涨色也不是同一个值。
