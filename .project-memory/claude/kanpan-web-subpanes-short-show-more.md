# kanpan-web-subpanes-short-show-more

**项目约定**：看盘网页版的副图指标默认不要占那么高（用户 2026-09-29 看第一版说「过高了，没必要」）；大屏上要用省下来的高度多展示信息，而不是把少量内容拉大

2026-09-29 我交出网页版第一版原型（2560×1440，副图 MACD / RSI 各占约 200 px），用户看完说：
「默认副图指标有点过高了，没必要那么高，web 版本其实可以多展示一些信息」。

所以网页版上的规矩是：

- **副图默认矮**：每个副图保持在能看清形态的最小高度（大约 110–140 px 一档，TradingView 桌面版
  的默认比例），主图拿大头。副图再多也只是加档数，不是把每档拉高。
- **大屏省下来的空间用来多摆信息**，比如更多副图、更多侧栏内容、更密的表格，而不是把少量内容
  放大铺满。这和手机端「元素尺寸要克制」（kanpan-ui-restrained-element-scale）是同一个思路：
  屏幕大了，密度可以上去，尺寸不能跟着涨。
- 副图高度仍然可以拖分隔线调，但默认值要矮。
