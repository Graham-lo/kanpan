# kanpan-one-device-per-class-online

**项目约定**：看盘账号同时只允许每一类设备各一台在线——手机一类、平板一类、电脑一类；同类第二台登录就把前一台踢下线

2026-09-19 做完账号安全整改后，用户补了一条账号规则：
「同时只能一台设备在线，不允许多台，这里的一台指的是手机算一类，平板算一类，电脑等」。

含义：

- **按设备类别限一台在线**：手机（iPhone）、平板（iPad）、电脑（Mac 等）各算一类，
  一个账号同一时刻每类最多一台设备有活跃会话。一部手机 + 一台 iPad + 一台电脑同时在线是允许的；
  两部手机同时在线不允许。
- **后登录的顶掉先登录的**：同类第二台设备登录（或注册后登录）时，服务端撤销该用户同类别的
  其他会话；被顶掉的那台下一次刷新令牌就 401，客户端走「登录已过期 / 重新登录」那条路，
  本地资料照常可用（见 kanpan-cloud-outage-must-not-break-the-app）。
- 这是服务端强制的规则，不是客户端提示：会话表要带设备类别，登录路径按类别撤销；
  客户端在设备信息里如实上报类别（`UIDevice.userInterfaceIdiom`：phone / pad，Mac Catalyst
  或 Designed for iPad 算电脑）。
- 设备管理页里的列表也按这条口径理解：每类最多一台是活的。
