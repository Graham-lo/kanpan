# kanpan-landscape-workbench-shows-indicators-with-switch-entry

**项目约定**：看盘横屏画线工作台默认展示主图指标、给一颗可关的开关，并且要有一个就地切换主图指标的入口；横屏的双指缩放要顺手，用户 2026-10-05 两次提到

2026-10-05 用户先说「展示在主图的指标现在横屏自动画线也要默认展示，并且给可关闭的按钮」，
实现之后又补了两条：

1. 「既然现在画线也展示指标，那么就增加一个入口，方便主图切换指标。」——横屏画线工作台
   不只是「看得见指标」，还要能**不退出横屏、不回竖屏**就换主图指标（开关均线 / 布林 /
   锚定 VWAP 这类，改参数不是重点）。入口放在工作台自己的 chrome 上（和「主图指标」开关
   挨着），打开的是和竖屏同一份指标数据（指标布局整份跟人走，见
   kanpan-indicator-layout-is-one-per-person-all-devices），不是另起一套横屏专用配置。
2. 「横屏的放大缩小逻辑能不能优化一下，现在用起来感觉不太顺。」——横屏下的双指缩放是一个
   被用户点名的体验项，验收标准是「用起来顺」（见 kanpan-invisible-means-fixed 的精神：
   以手感为准），不是参数上「能缩能放」。

背景：横屏工作台里主图指标参与量程与否由 `overlaysAffectPriceRange` 控制（工作台里关掉，
价格区间只按蜡烛算），指标开关是 `Prefs.drawingOverlaysShown`（同步字段）。
