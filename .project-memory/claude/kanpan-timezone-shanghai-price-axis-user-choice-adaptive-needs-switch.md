# 看盘：时区固定上海、价格轴交给用户、个性化学习必须有开关

2026-09-28 我按 kanpan-minimal-settings-surface 列出可收掉的设置清单后，用户回了三条修正：
「**时区统一成上海 8 点也就是国际 0 点，坐标是对数还是常规交给用户，其实最好加一个功能，
类似于大数据那种，能长期根据用户的数据来调整体验，但是这个功能需要给出开关**」。

- **时区不做成设置，统一用上海时间（UTC+8）**。K 线时间轴、十字线读数、提醒与复盘里的时间
  一律按上海显示；日线的切换点就是交易所的 UTC 0 点，也就是上海早上 8 点，不要改成本地零点。
  这推翻了我「跟本机时区」的建议——用户和他的朋友都在国内，固定一个时区比跟机器走更稳。
- **价格轴对数 / 线性是用户自己的看图习惯，保留给他选**，不要按价格跨度自动切。
  这是「只有用户自己知道答案」那一类，属于该留的设置。
- **个性化学习可以做，但必须有开关**。用户想要的是「像大数据那样，长期根据这个人的使用数据
  自动调整体验」——把他反复做的选择变成默认。但它不能是暗箱：在「我的 › 设置」里给一个
  总开关，关掉后一律回到出厂默认、不再收集；开着时学到的东西要能在同一处看到并一键清除。
  这和 kanpan-period-bar-pins-and-autofill 里「周期钉住不要用停留时长自动学习」不冲突：
  钉住是用户明确摆好的，不归学习管；学习只动那些用户没有明确定义过的默认值。
