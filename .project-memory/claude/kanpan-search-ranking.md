# kanpan-search-ranking

**项目约定**：看盘的品种搜索结果先按「最匹配」排，同档之间按 24h 成交额降序，让没打全的词也能第一眼看到最热门的品种

2026-09-18 我把搜索页接进看盘之后，排序只做到「base 前缀优先、同档保持交易所原表顺序」。
用户看了说：「搜索做的有点问题，首先选最匹配的，然后如果出现多个应该按照成交额来排序，
这样用户如果不是输入全匹配的品种就可以第一时间搜到最热门的品种。」

所以看盘任何一处搜品种的排序都按两层来，顺序不能颠倒：

1. **先最匹配。** 输入和 base 或和整个 symbol 完全相等的那条排最前——搜 `ETH` 出 `ETHUSDT`，
   不能被 `ETHFIUSDT` 挤下去；搜 `ETHUSDT` 也一样。完全相等之后才轮到 base 前缀、
   symbol 前缀、base 含、symbol 含这些次一级的档。
2. **同一档之间按 24h 成交额降序。** 交易所原表的顺序不是热度顺序，照它排会让用户
   打半个词时先撞上冷门合约。成交额相同或都没有行情时才回落到原表顺序，保证排序稳定。

这条规矩的用意是「没打全也能第一时间搜到最热门的那个」，所以凡是以后再动搜索、
补模糊匹配或换数据源，这两层都要留着，不能退回纯字面排序。
