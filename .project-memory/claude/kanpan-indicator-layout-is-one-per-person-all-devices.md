# kanpan-indicator-layout-is-one-per-person-all-devices

**项目约定**：看盘 2026-10-03 起指标布局整份跟人走、不再按周期分组记（推翻 09-27 的「周期分组指标」）：开了哪些指标、参数、顺序、副图高度、K 线缩放在任何周期都一样；同一账号的 iOS、手机网页、电脑、iPad 之间改了也要互相生效；手机网页默认副图要矮、K 线区要大

# 指标布局只有一份，跟人走，跨周期、跨设备都生效

2026-09-27 我做过「周期分组指标」：分钟、小时、日线三组各记一份指标布局，某一组被改过就单独
留一份（继承直到分叉）。2026-10-03 用户在手机网页版上碰到后果：没登录，在 1 小时调了副图高度
和顺序，切到 30 分又「被改回去了」。我先只把高度和顺序改成跟人走，开关与参数仍按组记，用户
随即把话说死：

> 应该是通用的啊，不管什么周期，不然别人以为没改，比如换了一个指标，切换四小时发现不是自己要的
> 指标这样就很怪
> 现在是任意周期缩小放大 k 线，调整指标顺序，指标区域大小等是否切换任意周期都生效
> 移动版也要做成和人走，统一起来，这样体验才好，并且云端是接起来的……同一台手机或者同一个账号，
> 不同设备类型也应该如此，电脑，ipad 等

所以规矩是：

- **指标布局没有周期维度**。开了哪些主图、副图指标，参数，副图顺序与高度，K 线缩放（根宽），
  在任何周期都是同一份。不要再按周期、按品种分组记任何「人调出来的」图表状态。用户的判据是
  「别人以为没改」——在一个周期改了、另一个周期看不到，就会被当成 bug。
- **跨端一致**。同一账号下，iOS app、手机网页版、电脑网页版、iPad 改了的体验设置要经云端互相
  生效；未登录时同一台设备上的各个入口也要一致。电脑网页版视觉独立，但能对应上的设置（指标开关、
  参数、顺序等）仍要走同一份同步字段，不另起一套。
- **手机网页版的默认值要适合看盘**：副图默认矮一点，把高度让给 K 线区；用户拖过之后就记住，
  切周期、刷新、换设备都不能跳回去。

为什么：这类「改过的东西在某条路径上悄悄变回去」的问题不报错，用户说不清是哪一步，只会觉得
app 怪（同 kanpan-preferences-follow-the-person-instantly）。
