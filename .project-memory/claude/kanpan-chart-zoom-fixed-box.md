# 双指缩放：框是固定的，K 线不许上下跳

用户在真机上对比 AICoin 之后给的判定，原话是：**「我找到原因了，aicoin 展示 k 线的框是
固定大小，双指缩放都在这个框内，所以目前你实现的是缩放 k 线会自动上下跳」**。

## 规矩

双指缩放的时候，主图那个框（价格区间映射到的那块矩形）必须是**定住的**。缩放只在这个
框里发生，蜡烛跟着手指横向展开或收拢，**纵向不许整体平移或重新缩放**。

我原来的实现是每一帧都按「当前可见那几根的最高/最低」重新自动贴合价格区间。捏合过程中
可见的根数一直在变，只要有一根新的极值进出视野，整张图就会瞬间上下挪一截——用户看到的
「自动上下跳」就是这个。自动贴合本身没错，错在**它不该在手势进行中生效**。

## 更一般的一条

手感类的问题，用户的基准是 AICoin。做完要按 AICoin 的实际表现验，不是按我觉得
「图表一般都这么做」来推。
