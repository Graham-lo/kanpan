# kanpan-scan-swipe-lives-on-header-quote

**项目约定**：看盘「连续扫图」的横滑手势只挂在行情页顶栏价格区（最新价+涨跌幅胶囊+右侧六格整块），左滑下一只、右滑上一只；周期条与 K 线画布不参与，图上横滑永远是平移。用户 2026-09-21 看过 AICoin 逆向证据后确认，这个落点不要再改

2026-09-21 做「连续扫图」（一屏一只往下翻品种）时，横滑翻品种的落点定在顶栏价格区
（`market.quote`：左边最新价 + 涨跌幅胶囊、右边六格统计整块）。用户起初以为应该像 AICoin
那样在图区横滑翻品种；kanpan-73 窗口查了仓库里的逆向素材（refs/aicoin：详情页整页装在
GestureViewPager 里，但 K 线自绘 view 用 requestDisallowInterceptTouchEvent 把横向手势抢走，
只有竖直滑动才交还父容器），证明 AICoin 在图上横滑同样是平移、翻品种靠图以外的区域和顶栏箭头。
用户看过证据后说「可以」。

所以在看盘里：

- **横滑翻品种只挂在顶栏价格区。** 左滑下一只、右滑上一只。
- **周期条和 K 线画布不参与翻品种**，图上横滑永远是平移 K 线。
- 这个落点是用户确认过的，之后改头部（价格行让位给十字线动作、提醒确认条等）时，
  不能把这块区域的横滑手势弄丢或改到别处。
