# kanpan-web-orderbook-redesigned-for-desktop-ref-openmarket

**项目约定**：看盘网页版的订单簿 / 主力订单流展示要为大屏重新设计，不许照搬手机端那套（那是专为手机适配的）；网页版参照对象加一个 openmarket.xyz，要去它官网与推特把优秀的功能与设计吸收过来；用户 2026-09-29 明说

2026-09-29 网页版正式开工当天，用户补了两条：

> 「订单簿这里就需要重新设计了，因为 PC 屏幕大，不要用手机那一套，手机那一套是专门为了手机而适配，
> 所以展示方式你要有所变化。另外你看看 https://openmarket.xyz ，这也是 K 线图表，你可以访问官网
> 或者推特把它优秀的功能和设计拿过来。」

所以：

- **订单簿 / 主力订单流在网页版要按大屏重做展示形态**。手机端那套（大单垫在蜡烛下面、细线加签、
  点开一张详情卡）是为小屏挤出来的；27 寸 2K 屏有地方，可以把盘口深度、大单墙、成交流等**并排常驻**
  地展示（比如图表右侧或下方常驻的深度梯子 / 热力图 / 成交带），信息密度和布局都要重新设计，
  不是把手机的画法放大。数据口径不变（三家聚合、门槛过滤、只展示不判定）。
- **openmarket.xyz 是网页版的参照之一**：设计或加功能前先去看它的官网与推特（X）上展示的功能，
  把它做得好的功能与设计吸收进来。仍按 kanpan-references-are-for-absorbing-not-cloning 的规矩，
  吸收优点、不整块复刻。
- 更一般地：网页版凡是从手机端「搬」过来的展示方式都要过一遍「这是不是为手机屏挤出来的」，
  是的话就按大屏重新设计。
