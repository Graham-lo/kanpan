# kanpan-skip-device-install-when-phone-unavailable

**项目约定**：看盘里手机不在身边或无法解锁时，装真机包这步直接跳过，不开重试或轮询等它；做完任务的窗口立刻结束回合，不空等耗 token

2026-09-20 用户通过另一个 Claude 窗口（kanpan-d8）转达了一条指令：手机不在身边、无法解锁时，
「装真机包这步一律直接跳过，不要开重试循环或后台轮询等它解锁；已经完成任务的窗口不准空等
消耗 token，做完就结束回合」。

这是对 kanpan-dont-ask-just-ship 里「push 完顺手 `make install-release` 装到真机」那一步的例外：

- **真机装不上（设备锁着、不在线、没连 Mac）就跳过这一步**，在汇报里说一句「真机包未装，
  设备不可用」即可。不要重试、不要开后台任务轮询设备状态、不要安排唤醒等它解锁。
- **任务做完就结束回合。** 不要为了等设备、等另一个窗口、等用户回复而挂着一个循环，
  这样只会烧 token。用户在意的是 token 开销，不是「装包这步有没有最终完成」。
- 用户回来后如果要装，他会说；到时再装即可。
