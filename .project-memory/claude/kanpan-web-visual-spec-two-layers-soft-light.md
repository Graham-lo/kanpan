# kanpan-web-visual-spec-two-layers-soft-light

**工作习惯 / 用户纠正**：电脑网页 2026-10-08 起按 docs/design/电脑网页UI规范-2026-10-08.md 重订深浅两套视觉：TV 尺寸 + 自家材料，浅色不刺眼、关键数据要清楚、色相收敛

2026-10-08，用户对电脑网页版的整体视觉提了一组意见：
- 深浅色下都觉得割裂、不协调。
- 左右两条栏「像虚幻的」。
- 主要功能没有层级。
- 深色下的订单流颜色和整页不搭。
- 图标（尤其画线）要更精美。
- 浅色稍微刺眼，重要数据对比起来看不清、难受。
- 要求：深浅两套重新规范，凡是和视觉相关的都要管。

规范在 docs/design/电脑网页UI规范-2026-10-08.md（草案，等原型 /ui/web-visual-2026-10-08.html 确认后定版）。

**Why:** 上一版的问题有三类：
- 图表画布是 TV 中性白 / 黑，外框是皮肤色，三种底色撞在一起。
- 七八个互不相干的色相：品类四色、交易所五色、挂单墙紫等。
- 框架图标用 text-2 加 30% 双调，看着发虚；浅色下大面积纯白，加上饱和的缝。

**How to apply:**
- 网页视觉照规范走：
  - 材料只两层：框架 / 内容，K 线画布 = 卡片底。
  - 浅色不用纯白大面积铺底，纯白只给浮层。
  - 颜色只有四类语义，外加同明度的分类色，分类色只上小记号。
  - 订单流带按方向着色。
  - 数据分三级可读性。
- 尺寸密度仍照 TV 实测（见 `kanpan-web-uses-tradingview-chart-27in-2k`）。
- 网页视觉独立于 iOS（`kanpan-web-is-its-own-design-not-ios`）。
