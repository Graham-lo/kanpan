# kanpan-minimal-settings-surface

**项目约定**：看盘尽量不让用户设置东西——只有必须由用户自己定义的（自选、提醒条件、账号、皮肤这类个人选择）才做成设置，其余一律由我定好默认、自动适应；用户 2026-09-28 明说多余的设置让人觉得麻烦、调好要花大量时间

# 看盘：设置项越少越好，只留必须由用户自己定义的

2026-09-28 用户说：「**这个产品除了必须要用户自己去做的事自己去定义的设置之外，尽量减少让
用户自己去设置很多东西，因为很多多余的设置会让用户感觉到麻烦，调整好自己需要的要花费大量
的时间**」。这是产品级原则，适用于「我的」、图表设置、指标参数、提醒、复盘等所有设置面。

判断一个设置该不该存在，只问一句：**这件事是不是只有用户自己才知道答案？**

- **该留的**：自选与分类、提醒的品种与条件、账号与交易所接入、皮肤、周期钉住、要不要开某个指标
  ——这些是个人选择，系统猜不出来。
- **不该留的**：算法口径、阈值、步长、节奏、缓存大小、同步策略、回放倍速这类「系统可以自己定
  一个好的、或者按情境自动适应」的东西。这些由我定默认值并自动调，不摆给用户。
  已有的例子：板块页不给统计口径选项（kanpan-sector-page-no-basis-picker）、行情线路只有两档、
  提醒不给重复频率。
- **必须暴露的参数也要「零配置可用」**：默认值就是大多数人要的，用户不碰也完全正常；
  参数放在用到它的那个位置（比如指标参数在指标面板里），不集中堆在设置页里。
- 新功能落地前把它带来的每一个设置项列出来过一遍这条规矩；能删的删，能自动的自动。
  审查现有设置面时也按这条来，多余的直接收掉（有默认值可继承的收掉后行为不变）。

## 2026-09-28 用户圈定的「必须保留自定义」名单

我按这条原则列出整份可收清单后，用户逐项圈了要保留的：「**价格轴，指标颜色，副图高度，
提醒铃声，找相似都保留自定义，其他按照你的建议**」。所以下面这几项是用户点名要留的个人选择，
以后收设置项时不要再把它们列进候选：

- 价格轴 对数 / 线性
- 指标线颜色自定义
- 副图高度（拖分隔线并记住）
- 提醒铃声
- 复盘「找相似」的搜索范围

其余（深浅的亮度切换、时区、涨跌幅起点、不锁屏、清理存储、十字线吸附与读数、K 线数据位置、
实心空心、网格、实时价格线 / 倒计时 / 至今涨幅开关、图表纵横位置、翻转许可、指标区域自适应、
隐藏指标输出、RSI 上下轨、订单流四个显示开关、Webhook 开关、波动阈值、画线样式表的线型 /
填充 / 逐点坐标 / 锁定开关、自选四个死字段、板块排序、账号同步开关、取景卡日期与把握度、
回放倍速记忆）都按「收掉、由代码定默认或自动适应」处理。
