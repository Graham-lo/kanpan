# kanpan-single-aicoin-candle-style

**项目约定**：看盘只保留 AICoin 那一套 K 线风格，不要再做多套风格供用户挑选

看盘（Kanpan）项目里原来有十二套蜡烛造型：AICoin 一套，加上从原型带过来的十一款
（墩／靛／辉／阔／砖／针／芯／纸／描／骨／密），「图表」面板顶上还摆着一张四选一的风格卡。
2026-09-15 用户一句话定了调：「k 线风格直接默认 aicoin 那套就行了，不用搞那么多套」。

所以这个项目里 **K 线的视觉只有 AICoin 这一套**，不需要风格选择入口，也不要再以
「给用户更多选择」为由把风格表加回来。理由是这套看盘视觉本来就是照着手机 AICoin 抄的
（默认风格的 id 就叫 `aicoin`），多出来的十一款没人在用，却让每一次渲染改动都要横着
验十二遍——调成交量颜色那次就是十二套一起量的，成本全花在没人看的分支上。

这条同时约束后续的取舍：面板上凡是「跟随风格」这类只有在多套风格时才有意义的档位，
一并撤掉（比如阳线实体就只留「实心 / 空心」两档）；旧存档里残留的风格 id 解码时
一律落回 AICoin，不要为了兼容把老风格再养回来。注意它并不和「合并入口不能丢功能」
冲突——那条讲的是功能还得有路能走到，而这里是用户明确不要这个功能了。
