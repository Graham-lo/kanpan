# kanpan-web-16-chart-layout-is-a-key-review-target

**工作习惯 / 用户纠正**：看盘网页版的十六图布局是重点审查对象：交互体验、切换、性能每轮都要单独过一遍，并与画线交叉

看盘网页版的多图布局（最多十六格）是用户点名的重点审查对象。用户 2026-10-07 原话：「16 个布局你要放到重点审查里面，交互的体验，切换，性能等」。

**Why:** 十六图是网页版区别于手机端的核心场景，格子切换、活动格、逐格换品种周期、拖分隔线、满副图时的帧率都容易在别的改动里退化。

**How to apply:**
- 每轮验收单列「十六图」一节：交互体验（活动格切换、逐格换品种 / 周期、十字线联动、拖分隔线、全屏某格）、布局切换（1 ↔ 2×2 ↔ 16 来回、保存恢复）、性能（满副图 + 画线时每帧 p50 / p95、长任务、内存）。
- 与画线交叉（见 `kanpan-drawing-is-core-cross-verify-everything`）；相关 `kanpan-web-chart-page-resizable-regions-up-to-16-charts`。
