# kanpan-sector-symbol-list-copies-favorites

**项目约定**：看盘板块气泡页点进去的那层品种列表，视觉要照抄自选页的列表，不要做成浮在气泡场上的胶囊卡片

2026-09-18 我拿四个板块气泡图原型给用户看，其中「琉璃」版把第二层
（点一个板块气泡之后的品种列表）做成了一张浮在气泡场上方的圆角胶囊卡片，
卡片只占上半屏，下面还露着没退场的气泡。用户当场否掉：

> 「你这个点击气泡进入列表页面做的太丑了啊，你要和风格融合起来，
> 不要搞这种不好看的悬浮胶囊，其实你可以参考自选页面那么做啊，
> 只是展示的东西不同而已」

所以板块气泡页的第二层不要另起一套列表视觉：**直接用自选页那一套**。
自选页是用户自己定稿的「琉璃」版（见 `kanpan-favorites-page-is-users-own-design`），
它的行、间距、材质、头部排版都已经过他的眼，板块内的品种列表和它显示的字段
几乎一样（品种名 / 最新价 / 涨跌幅 / 成交额），没有任何理由重新设计一遍。
换句话说这一层是「同一张自选列表，换了一批品种」，不是一个新页面。

具体落到做法上：列表要**整页铺开**、和上下文是同一块连续的材料
（见 `kanpan-no-seams-one-continuous-surface`），不要做成悬浮卡片、
不要让它只盖住半屏而在下面露出上一层的残影。这跟项目里
`kanpan-prototype-reuses-implemented-ui`（皮肤、底栏、徽章这些视觉已经定型，
原型默认照抄真机视觉，只有用户点名要某一页「极致好看」时才重设计那一页）
是同一条：气泡层是被点名要重新设计的那一页，它下面的品种列表不是。
