# kanpan-symbol-name-is-not-a-picker

**项目约定**：看盘行情页左上角的品种名一律不再是按钮，换品种只走顶栏搜索和底栏自选两条路；横屏画线工作台是唯一例外

2026-09-18 搜索页接进来之后，用户说：「现在行情页点击坐上角品种一律不再弹出选择框，
把那个功能去掉，现在有了所搜不需要这个功能」。

所以看盘（Kanpan）行情页左上角那块「BTCUSDT 永续」只是一个**标签**，不是按钮：
没有 chevron，点上去不该有任何反应，也不再有半屏快速切换弹层
（`FavoritesQuickPicker` 已删除）。换品种只剩两条路——顶栏放大镜进搜索页，
底栏「自选」进带加密／美股分类的那张完整自选页。用户用了「一律」，这是长期口径，
以后不要以「顺手方便」为由把它变回可点的入口。

**唯一的例外是横屏画线工作台。** 同一天稍晚，用户提出「进入画线里面如果我想继续画
别的品种就必须退出然后重新从别的入口进入，中间不是展示了该画线的品种吗，点击该品种」，
要求那一行品种名可点、点开一个只列品种名（不带价格涨跌等任何其它信息）的搜索层，
没输入时列常看的品种、输入时列匹配结果，选中后立刻收起并把画线目标换成它。
理由是画线是连续作业，退出再从别的入口进来会把工作流打断——这跟竖屏行情页
「有了搜索就不需要这个入口」的情形不是一回事。所以这条例外只在画线工作台里成立，
不要据此把竖屏行情页的品种名也改回按钮。
