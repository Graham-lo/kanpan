# 面板和下拉：选完就收起，点别处也收起

用户在真机上试了主界面之后提的一条交互要求，原话是：**「我手机上点击风格选择后没有
自动收起，或者点击 k 线和其他地方也没有收起自动跳到 k 线看盘的地方，这是交互问题，
其他的下拉或者选择应该也要这么做，体验更好」**。

## 规矩

1. **单选的面板，选完那一下就收起。** 风格、周期这类「选一个」的面板，点中之后立刻关
   掉，让用户直接看到换过的图。指标和设置这种一次要调好几项的不在此列——那两个是
   配置页，连着关会很难用。
2. **手指落到面板以外的任何地方，面板收起。** 点 K 线图、点顶栏的品种/搜索/自选星、
   点周期条的档位、点底栏的画线或横屏，全都先把面板关掉再做自己的事。
3. 这条是**通则**，不限于当时那个风格面板。以后新加的面板、下拉、选择器一律照办，
   不用再问。

## 在这个工程里怎么落的

面板走的是 SwiftUI 的 `.sheet` 加 `presentationBackgroundInteraction(.enabled)`，
所以背后的图仍然收得到手势（任务书 §10.6 要求「面板打开时图仍可单指拖」），代价是
SwiftUI 自己不提供「点遮罩关闭」。解法是不铺遮罩，改成让图把轻点报上来——
`ChartView.onTapped` 接到主界面的 `dismissPanel()`。这样拖图和点击关闭两件事都成立。
