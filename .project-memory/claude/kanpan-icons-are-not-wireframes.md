# kanpan-icons-are-not-wireframes

**项目约定**：看盘的图标不能是单色细线线框（那是工程风/后台风），要实心圆润、有色彩材质的「精致唯美」画法；被否两次就别再调参数了

2026-09-18 我重做看盘底栏（画线·图表·自选·设置）的四个图标，画的是单色细线线框：
两个圆点连一根斜线当「画线」、方块加引线当「蜡烛」、六边形螺母当「设置」，
颜色是灰色描边、选中时换成主色描边。用户连着否了两次——先是
「这看起来太工程太后台风了」，接着是「一点都不精致好看唯美」。

所以在这个项目里：

**线框 = 工程风。** 单色细描边、示意图式的几何（节点连线、螺母、齿轮、方框加引线）
在用户眼里就是后台管理系统的味道，无论描边调到多粗、图标放到多大都救不回来。
要的是实心/双色填充、圆润有性格的造型，带渐变、柔光、材质感的配色，
图形本身也要挑有美感的隐喻（笔尖而不是节点连线，花瓣状的圆齿而不是六角螺母）。

**同一处视觉被否第二次时，停止调参数。** 我前两版都是在原方向上加大尺寸、加粗描边、
提高不透明度，这不是用户要的答案——他否的是整个视觉语汇，不是某个数值。
第二次被否就该换做法：按 `kanpan-put-the-knob-in-the-prototype` 和
`kanpan-prototype-delivery`，做几套差异明显的方案原型让用户挑，别再自己猜下一版。
