# kanpan-one-entry-per-action

**项目约定**：看盘里同一个动作只留一个入口——加自选统一在品种行的星上做，顶栏不放星，自选页的编辑只留在设置菜单里

2026-09-18 用户连着点了三处重复入口，方向是一致的：**同一个动作在界面上只留一个地方。**

- 「行情页右边的收藏不用再加了，因为现在都统一放到搜索那边做收藏了」——行情页顶栏
  右上角的自选星撤掉，右上角只剩放大镜。加自选统一在**品种行**上那颗星做：搜索页
  （`SymbolSearchView`）和自选页的行都有，看得见一整列、挑着加；顶栏那一颗既和它们
  重复，又紧贴品种名最容易误触。
- 「自选页面那个编辑自选和右边三个点里面的重复了，现在统一放到右边三个点里，外面不再展示」
  ——自选页导航栏常态下的铅笔去掉，「编辑自选」只留在那个菜单里。编辑**中**的「完成」
  留着，因为一个模式总得有看得见的出口。
- 「三个点换成设置的icon」——那个菜单装的是编辑自选、新建/重命名/删除分类、迷你走势
  开关，本质是这一页的设置。（**这一条后来被推翻了**：同日晚些定稿的自选页头部把它换回了
  省略号，现行代码是 `circleButton("ellipsis", label: "自选菜单", id: "favorites.more")`，
  见 `kanpan-favorites-header-layout`。这里保留只为记住「一个动作一个入口」这条本身——
  重复的入口要合并，合并到哪颗图标上是另一回事。）

同时定下的另一条是**入口要在需要它的那一页上**：「自选列表页面应该也加上搜索才对，
不然得先跳到行情页面才能添加」。所以自选页自己开搜索页，不用先退回行情页。

但「在这一页上」不等于「在这一页上放两颗」。同一天稍晚用户又收了一次：「自选列表页面
还是去掉搜索吧，都已经有 ➕ 号这个功能了」。自选页的放大镜因此撤掉，**加号是这一页
唯一的加自选入口**（它和空态的「添加品种」开的都是 `SymbolSearchView`）。行情页顶栏的
放大镜不受影响，那是换品种的路。这条对我的提醒是：给某一页补入口时，先看这页上现有的
按钮是不是已经干了这件事，两颗按钮点开同一张页面就是重复入口，哪怕图标不一样。

收敛入口的时候仍然受 `kanpan-finish-features-completely` 约束：砍掉一个按钮之前先确认
那个功能还有别的路走得到（编辑自选还在菜单里、浏览全部合约还在搜索页的「查看全部」后面）。
