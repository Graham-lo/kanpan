# kanpan-web-is-its-own-design-not-ios

**项目约定**：看盘网页版是独立的一套视觉设计，不和 iOS 端混在一起（不搬手机的皮肤、配色、线条规格），但代码仍放在同一个仓库；用户 2026-09-29 明说

2026-09-29 我把网页版原型的第二版交出去时，顺手把 iOS 端的三套皮肤（青苔 / 陶土 / 经典）
原样搬到了网页上。用户看完的回话是：「默认线条的粗细和大小整体你要设计的更好看更适合视觉美感
一些，直接开始动工，**不要和 iOS 混合到一起，但还是同一个仓库**」。

所以网页版的规矩：

- **视觉独立**：网页版有自己的一套配色、线条粗细、字号与尺寸体系，按 27 寸 2K 大屏单独设计，
  不从 iOS 端搬皮肤、色板或规格过来「保持一致」。手机端那套是给手机的，大屏另起。
- **仓库不分**：代码仍留在 `kanpan` 仓库里（原型在 `prototype/web-…/`），不另开仓库；
  只是不共用视觉资产，也不把网页的东西塞进 iOS 工程。
- **线条与尺寸是设计对象**：K 线、均线、副图线、网格、十字线、画线工具的默认粗细，以及
  图标、控件、字号这些尺寸，都要按视觉美感专门定过，不能沿用引擎默认值或手机端的值。
- 这条和 kanpan-web-uses-tradingview-chart-27in-2k（K 线用 TradingView 那一套、先按 2K 屏做）
  是一组：网页版整体是「全新的一套 UI」。
