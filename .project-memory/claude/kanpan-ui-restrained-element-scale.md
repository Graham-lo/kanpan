# kanpan-ui-restrained-element-scale

**项目约定**：看盘的界面元素尺寸要克制——价格字号、全页字号、徽章都不要往大里做；但「克制」不等于把图标做小，底栏图标用户点名要求过更大更有分量

看盘（Kanpan）的界面元素尺寸整体要克制。用户看过几版之后定下的判断是：价格字号、
全页字号、品种徽章往大里做会被判「廉价」，字体要选精致的。所以正文、数字、徽章
这些**文字与信息密度相关**的元素，默认往小里、往精致里调。

但这条不适用于图标，尤其不适用于底栏那五格。2026-09-18 我按「克制」的思路把底栏
图标只从 18pt 抬到 20pt、配色也只加了一层很淡的强调色底，用户的回复是
「底栏的 icon 是不是有点小啊，还是太素了，我想更好看一点」——这已经是他第二次说
「太素」。所以：**图标的尺寸、描边粗细、选中态的色彩强度要做足**，宁可一次推到
明显，再往回收，也不要连着两版都偏保守。这和
`kanpan-redesign-boldly-not-by-subtraction`（说「更好看」时要的是更大胆的色彩与材质）
是同一件事的两面。


2026-09-18 收尾时用户又补了一句：「大小你自己决断就好，整体协调，利用好空间，底栏稍微
大一点点有辨识性和层次」。所以具体数值不用回头问他——**尺寸是我的决断**，他要的是结果
上的三件事：整条栏读起来协调、空间被用满、底栏比系统默认的再高出一点点，好让它有辨识度
和层次。拿不准时按这个方向自己定，然后用截图证明协调，而不是把一串数字摆出来让他选。
