# kanpan-app-icon-need-not-depict-markets

**项目约定**：看盘的 app icon 不需要画 K 线、曲线、表盘这类行情意象，可以和行情完全无关

2026-09-18 我给看盘重做 app icon，一口气提了四个方向：一根蜡烛、一条行情曲线、一枚表盘、
一排 K 线做成的山峦——全都在画「这是个看行情的 app」。用户挑方向时回的是「可以和行情无关」。

所以看盘的 app icon 不承担「说明这个 app 是干什么的」这个任务。图标好不好看是唯一标准，
题材可以是月、釉、山水、器物、光，任何东西，不必出现蜡烛、曲线、涨跌、图表这些行情符号。
这和项目里既有的两条视觉要求叠在一起看：图标要实心圆润、有色彩材质，不能是单色细线线框；
配色只从青苔 / 陶土 / 经典三套皮肤的色板里取，不自创色板。
