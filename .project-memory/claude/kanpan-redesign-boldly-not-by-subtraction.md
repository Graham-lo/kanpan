# kanpan-redesign-boldly-not-by-subtraction

**项目约定**：看盘说「更好看」时要的是更大胆的色彩与材质，不是做减法；背景、底色、涨跌色这些既有元素全都可以动

在看盘（Kanpan）里，用户说某个界面「不够好看、差点什么」时，他要的**不是**把元素删干净的
安静版本。我曾经按「减法」的思路重做自选分类页——拿掉涨跌色块、拿掉行尾箭头、只留价格当主角，
结果他的回复是「你这个设计更丑了，我需要极致好看的那种，**重新设计元素色彩搭配**，
要极致的好看和视觉体验」。也就是说，精致感要靠**加**：层次、材质、光泽、颜色之间的关系，
而不是靠留白和克制。

紧接着他又补了一句「自选列表的背景颜色也可以设计啊，你可以**完全大胆**的设计出来，
**所有的元素都可以动**」。所以在做视觉方案时不要把现有的令牌当成禁区：页面底色、卡片材质、
涨跌用什么红什么绿、徽章周围的光、分组条的形态，全都可以重新提案。

这一条**收窄**了早先那条「配色定为陶土·暖与青苔·冷两套，不要再自创色板」：
两套皮肤仍然是身份和出厂设定（青苔冷是默认），但「在这两套底子上怎么配元素的颜色」
是开放的设计题，可以大胆改，不需要每次回到原型里那几个十六进制值。

实践上这意味着：给方案时优先拿出**明显不同的几种质感**（例如底色渗品种品牌色、纯层次无彩、
深色发光、极光渐变背景）让他挑，而不是同一套配色的几种信息密度变体——密度差异他看不出好看与否。

## 2026-09-18 补：不要拿实现成本当筛子，也不要替他把候选集砍小

做板块气泡页的球体材质时，我用一张材质实验页并排画了六种材质（琉璃、水珠、玉髓、珐琅、
琥珀、拉丝金属），然后**按我自己的判断把它砍成两种**再推给用户二选一。他的回应是
「有没有更好看的设计啊」，紧接着一句 **「极致好看精美，特效拉满这次」**。

两条教训：

**候选集不是我该收的。** 上面那条「优先拿出明显不同的几种质感让他挑」说的是要多给，
我却在给之前先用自己的审美裁掉了四种。在这个项目里审美的裁判是用户，我的活儿是把场铺开，
不是先替他决出决赛圈。要淘汰一个候选，只能因为它硬性不成立（比如最小半径下糊成一团、
球面上压不住字），不能因为「我觉得另一个更好」。

**成本和性能不是自我设限的理由。** 我在材质表里给每种材质标了 `cost:'中'/'高'` 的渲染
开销，并让它参与了取舍。用户「特效拉满」这句话把这条掐掉了：视觉题上先做到极致好看，
性能是之后用缓存、预渲染、降采样去解决的工程问题，不是提案阶段的减分项。
（这与 `kanpan-device-resource-budget` 一致——他宁可花手机的资源换体验。）
