# 看盘：板块页不再有气泡，一律用页面（列表）

2026-09-24 我正在派子代理整改深度审查里的板块气泡问题（描边颜色与数字颜色打架、
球上短名与表头对不上、气泡场 120Hz 重绘）时，用户直接说：

> 「另外现在不再展示气泡，一律用页面即可，ui 也不用改，去掉气泡，至于怎么交互你来设计。」

所以从这天起：

- **板块分类页是一张普通列表页**，不再有气泡场。之前定稿的「一层气泡、点进去是品种列表」
  （kanpan-sector-bubble-page-structure）和「气泡本体要单独打磨」
  （kanpan-bubble-body-is-its-own-design-object）这两条都作废，气泡相关代码
  （`SectorBubbleField` / `SectorBubbleRenderer` / `SectorLayout` / 强弱分色 `SectorSelection` /
  短名映射 / 对应测试与 UI 用例）一律删，不留开关。
- **「UI 也不用改」的意思是沿用现有视觉**：板块列表照抄自选页列表的样子（这一点和
  kanpan-sector-symbol-list-copies-favorites 一致），不为它另做一套视觉；「今日 / 5 日」这类
  窗口切换和钻进去的品种列表照旧。
- **交互由我设计**，不必回头问他：我的定稿是「板块列表 →（点一行）该板块的品种列表」两层，
  列表按窗口内涨跌幅排序，行上放板块名、涨跌幅、品种数与领涨品种。

原因：气泡华而不实、维护成本高（每帧重绘、颜色语义打架、短名对不上），用户要的是
能快速扫一眼哪个板块在动的页面，列表就够了。
