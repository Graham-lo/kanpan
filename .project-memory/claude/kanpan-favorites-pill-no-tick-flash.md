# kanpan-favorites-pill-no-tick-flash

**工作习惯 / 用户纠正**：看盘自选行的涨跌药丸不做跳价闪动，也不做闪动开关；用户 2026-10-08 加上当天就拿掉

自选行的涨跌药丸在价格跳动时不闪（iOS、手机网页都不闪），也不留「闪烁」开关。2026-10-08 那批先加了 150 ms 药丸闪，用户同日先问开关在哪、说加关闭按钮，随即改口「还是不加闪动了 / 去掉闪动」。

**Why:** 用户不想要列表里的跳价闪动，宁可直接没有，也不要一个开关来关它（和 `kanpan-minimal-settings-surface` 一致）。

**How to apply:** 以后对齐 iOS 批次、给自选 / 板块列表加动效时别把药丸闪加回来。图上最新价胶囊的闪不受影响。电脑网页自选侧栏价格文字的闪色用户没点名，没动；若用户再提「闪」，先确认是不是也要拿掉它。相关：`kanpan-favorites-sparkline-default-on-with-global-switch`（走势线开关在「我的 › 设置 › 通用」）。
