# kanpan-landscape-is-for-drawing

**项目约定**：看盘里横屏不是一个独立入口，它是画线的工作台——点「画线」直接横屏，画完自动转回，且横屏画线时主图副图的指标全部不画，只留原始 K 线

用户明确否掉了「底栏／工具栏上留一个独立的横屏按钮」这个做法：「横屏完全没必要搞，
干脆做成点击画线直接横屏不是更好吗，本来画线就要在更大的空间里」。所以在看盘
（Kanpan）里，横屏不是用户会主动想去的一个地方，而是画线这件事需要的工作空间。

由此定下来的交互：点周期行上的「画线」就直接转成横屏，退出画线（点「完成」）自己转
回竖屏；横屏工具栏上的「竖屏」只退横屏、不退画线，方便用户横着画完转回来接着看。
底栏不为横屏留格子。

关于横屏画线时显示什么，用户先说「然后画线的时候横屏不要展示指标，这样更有利于画线」，
后来又把范围讲清楚了：「是这样的因为 ma 本身会影响 k 线的高度和展示，所以需要原始 k 线
展示用来画图」。所以要隐藏的**不只是成交量、MACD 这类副图**，主图上叠加的均线（MA／
EMA／BOLL 之类）同样要收掉——理由是价格轴的取值范围会把均线也算进去，均线一在，K 线
被压扁、位置也挪了，画在上面的线条和真正的价格结构对不上。横屏画线要的是一张没有任何
指标参与定标的原始 K 线图。

注意这只影响画线横屏时画出来的那一帧，不要去动用户开着的指标偏好；退出画线回到竖屏，
副图和均线都要原样回来。

以后再讨论横屏相关的布局时，默认按这套来，别再提议把横屏做成一个单独的入口。
