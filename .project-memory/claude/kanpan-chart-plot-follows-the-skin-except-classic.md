# kanpan-chart-plot-follows-the-skin-except-classic

**项目约定**：看盘只有「经典」皮肤的 K 线图区照抄 AICoin 的白／深蓝；青苔与陶土的图区跟着自己皮肤的底色走

看盘（Kanpan）的 K 线绘图区（主图 + 副图 + 坐标轴）曾经一律固定成 AICoin 那套白 / 深蓝，
不跟皮肤走，理由是染过底的画布会让蜡烛和均线压在一层带色的面上。

**2026-09-18 用户推翻了这条。** 他的话是：「既然现在有了经典这个风格复刻了 aicoin，那么
青苔冷和陶土暖的 k 线指标展示区域也不再用 aicoin 那种白色的颜色。会显得特别割接这是最大的
原因之一，也改掉」，接着又确认「还是用之前那两种风格的背景颜色即可」「这样整体就搭配了」。

所以现行规则是：

- **「经典」是那份 AICoin 复刻**，图区的底、网格、分隔线、轴文字一个像素不差地照抄
  （`Palette.dayCanvas` / `nightCanvas`）。想看原汁原味的 AICoin 就切这一套。
- **青苔与陶土是两套自己的皮肤**，图区跟着种子的底色走，线与字也换成皮肤自己的那几支——
  AICoin 的分隔线 `#F2F4F7` 落在青苔的 `#F3F7F4` 上等于没画，蓝灰的轴文字压在带绿的底上
  也不是一家人。轻重次序照搬 AICoin：网格比结构分隔线重。

这条服从的是更上位的那条——整屏要读成一块连续的材料
（`kanpan-no-seams-one-continuous-surface`）。图区的四条边曾经是全 app 最明显的拼缝，
用户点名说那是「割接」最大的原因之一。

**蜡烛、涨跌、均线、副图线仍然只有 AICoin 那一套**
（`kanpan-kline-colors-are-aicoin-only`），这次改的只有图区的底与线字，不是 K 线本身的颜色。
