# kanpan-share-lines-on-friends-own-layout

**项目约定**：看盘「发给朋友」分享的只是画线：线落在朋友自己的图表布局上（他的皮肤、指标、参数一概不动），不把分享者的布局整套盖过去；走账号内朋友 + 收件箱，不走链接

# 看盘：分享给朋友的是「线」，不是「图」

2026-09-22 设计「朋友间共享图表」时，我先后给过两版：第一版按旧方案第 8 节走链接
（通用链接 / `hkline://share/<id>` / 剪贴板识别）；第二版改成账号内直达——加朋友、
发给朋友、朋友回前台时收件箱里出现一张卡。用户对第二版说「这个想法可以，先保留」。

但我在这两版里都写了「进影子态时把分享者的指标、参数、视野整套覆盖到朋友的图上」。
用户明确否掉了这一点：

> 「画线应该用的是朋友自己的 K 线图表布局，这样不会感觉到别扭，只是我们将画线展示上去。」

所以这个功能的定义是：

- **分享的载荷只有画线**（外加品种、周期提示、分享者当时的视野时间段，用来把朋友带到
  线所在的那一段）。指标、参数、皮肤、副图、价格轴模式一律不带、不覆盖——那些是
  朋友自己的东西，换掉就「别扭」。
- 线是时间 + 价格坐标，在朋友任何布局上都落在对的位置，所以本来也不需要带布局。
- 「退出恢复他自己的布局」因此不是一段还原逻辑：朋友的偏好从头到尾没被写过。
- 朋友可以「留下」这些线，留下之后它们就是他自己的普通画线——可编辑、可删、可以
  按现有的画线提醒机制加提醒（用户点名要的用法）。
- 传递方式走账号内朋友 + 收件箱（服务器上大家都有账号），不走链接：没有付费开发者
  账号做不了通用链接，微信也拦自定义 scheme。

这条和 kanpan-preferences-follow-the-person-instantly（体验类设置跟着人走）是同一
个道理：布局是人的属性，线才是这次要传的东西。
