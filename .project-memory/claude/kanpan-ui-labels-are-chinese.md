# kanpan-ui-labels-are-chinese

**项目约定**：看盘界面上的标签和文案一律用中文，不要出现 FR、OI、Vol 这类英文缩写；K/M/B/T 数额单位是用户点名要的，不在此列

2026-09-18 我按 AICoin 的顶栏复刻，把资金费率那一格的标签写成了 AICoin 原样的 `FR`。
用户先说「fr 改成费率」，我照改之后他又补了一句「不用英文」——也就是说这不是单独一个
标签的修正，而是一条通用要求：看盘界面上的标签、栏目名、按钮文案一律用中文，
不要出现 `FR`、`OI`、`Vol`、`MC` 这类英文缩写，哪怕参照的 AICoin 自己就是这么写的。
复刻 AICoin 是复刻它的布局和信息密度，不是连它的英文缩写一起搬。

有一处例外，而且是用户自己定的：数额单位用 K / M / B / T 这套金融单位，
不用万／亿（见 `kanpan-number-units-and-marketcap-basis`）。所以「不用英文」
管的是标签与文案，不管数字后面的单位后缀，也不管品种代号本身（BTCUSDT 这类）。

## 第二处例外：指标与工具的专名（MACD / RSI / KDJ / VWAP）

2026-09-20 给锚定 VWAP 画线工具起名时，我拿不准「VWAP」这个缩写犯不犯这条规矩，
给了「锚定 VWAP」和「锚定均价」两个选项。用户回的是「直接叫 vwap 就行」。
所以这条规矩管的是**栏目标签和说明文案**（资金费率、持仓量、成交量这类本来就有中文词的），
不管**技术指标与工具的专名**——MACD、RSI、KDJ、BOLL、VWAP 这类在交易圈里就是以缩写为名，
翻成中文反而没人认得。碰到这类专名直接用缩写，不要再来问。

## 例外：顶栏估值格（2026-09-25）

行情页顶栏第六格的名字用户点名要「英文简写或者首字母」，所以那一格写 `OI/MC`（币）、
`Fwd PE` / `P/S`（股票）。这是用户明示的单点例外，不是放开英文缩写的口子——别的地方
（包括同一块里的仓、额、市值、费率、结算）仍一律中文。

## 2026-10-08：均线 / 指数均线也改叫 MA / EMA

用户说「均线现在改名为 ma，指数均线改为 ema」，并要三端名称一致。于是指标专名统一为
MA、EMA、BOLL、MACD、RSI、KDJ（iOS 原来的「平滑异同 / 相对强弱 / 随机指标 / 布林带」一并改掉）；
成交量、持仓量、多空比这类数据栏目仍是中文。名称只存一处，见 `kanpan-indicator-names-params-single-source`。
