# kanpan-badge-colors-match-the-skin

**项目约定**：看盘的品种徽章要整体融进 UI：配色按皮肤特调，线条粗细也要统一，不能各画各的

用户在品种徽章这件事上除了「一个品种一个记号」之外，还给了第二条要求，原话是
「注意图标 icon 的设计要搭配整个 ui 的配色等其他的设计，要自然不要显得很突兀」。

背景是徽章当时按各家品牌的原色画——苹果的灰、Coinbase 的蓝、AMD 的绿、Costco 的红，
一屏扫下去像贴了一排别人家的贴纸，和「青苔·冷」「陶土·暖」这两套皮肤完全不是一家。

所以徽章的渐变不是自由色。**记号（画什么）按品种走，颜色（怎么上色）要按皮肤走**：
色相可以保留品种自己的身份好让人分得开，但饱和度、明度要收进当前皮肤的那个band里，
必要时整体往皮肤的主色偏一点，让它们看起来是同一套界面里长出来的东西。
换皮肤（sage / terra）和明暗模式时，徽章也要跟着变，而不是一套固定的十六进制常量。

后来用户又把这条推到线条上：「注意一下所有的品种的设计都要兼容 ui 配色，颜色需要特调，
线条什么的都需要特调，这样整体才好看，风格才统一」。所以徽章是一套**图标家族**，不是
一百多枚各自为政的小图：笔画粗细、圆角端头、记号在方块里占多大，都要收进同一套规格，
让它们并排放在一屏里像一个人画的。新加一枚记号时按家族的规格画，不要凭手感另起一套。
