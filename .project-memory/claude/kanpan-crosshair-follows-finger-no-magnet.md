# kanpan-crosshair-follows-finger-no-magnet

**项目约定**：看盘十字线的横线（价格线）必须跟着手指高度走、一路跟手不跳——2026-10-03 起十字线一律不吸附收盘价（推翻 09-28 收设置项时定的「吸附常开」），iOS 与手机网页同一套

# 十字线跟手、不吸附

2026-10-03 用户报：「手指点击空白处，会出现价格线，但我想将价格线移动到我想要的位置非常费力，
价格线不跟手，会出现跳动」。复现下来根因是 2026-09-28 收设置项时把「十字线吸附到 K 线」定成了
常开：横线只认手指底下那根 K 线的收盘价，手指上下拖它不动，横着走一根跳一个收盘价。

用户要的是能把价格线放到自己想要的价位，所以看盘的十字线规矩是：

- **不吸附**：横线跟着手指高度走（iOS `ChartSession`、手机网页 `m/chart/index.ts` 都是 `magnet: false`）。
  以后收设置项、对齐 AICoin 时不要再把十字线吸附打开。画线工具栏上的「吸附」是另一件事，不受影响。
- **跟手**：拎起已有的十字线时按手指位移走（保持按下时交叉点与手指的距离），不往手指底下跳；
  微调几个点不能被当成轻点收掉；按在横线上竖拖就挪价格线，横拖照旧拖图。
- 验证脚本：`Web/scripts/m-crosshair-e2e.mjs`（量「手指位移 vs 横线位移」）；iOS 用例
  `ChartGestureTests.crosshairFollowsFinger`。
