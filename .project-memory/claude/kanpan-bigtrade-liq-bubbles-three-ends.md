# kanpan-bigtrade-liq-bubbles-three-ends

**项目约定**：看盘图上大单与爆仓 2026-10-08 起三端统一是「一枚透明气泡」（已实现上线，b05d943f / b67c871d）：每根只有向上（大买+空爆）/ 向下（大卖+多爆）两个数、一种样子、一屏最多 6 枚带字泡、两级门槛；泡字三端同一口径；规格 docs/design/大单爆仓气泡-三端规格-2026-10-08.md，PROJECT.md §67

2026-10-08 用户两轮定方向：先说大单与爆仓三端统一用气泡、只分红绿、不要三角（三角「反而引起人误会」）；看过一稿（大单实心 / 爆仓空心、三档）后又说「大单和爆仓能不能统一一个透明气泡」「气泡太多了其实都分不清而且占用空间」，然后「这个可以直接开始实现」。

二稿当晚三端实现并上线（电脑网页 / 手机网页 / iOS，PROJECT.md §67）：每根只剩向上 U = 大买 + 空爆、向下 D = 大卖 + 多爆；一种样子（方向色 16% 填充 + 1.4 描边 + 方向色字），没有实心 / 空心、光晕、三档；门槛两级：过 P90 只点一个小点、过 P97 才成泡写字；一屏带字的泡最多 6 枚，其余退成点；大单 / 爆仓拆分只在悬停卡 / 弹层卡里给。泡字三端同一口径（不足 100 一位小数、≥ 100 取整、进位升档、去 M）——上线后曾出现电脑「974」手机「974.1」的差别，已统一。

**Why:** 签比根宽、三角像方向、一稿泡太多且实 / 空心看不出区别，用户要的是少而清楚、不占空间。
**How to apply:** 别再往图上加第二种标记样式、更多档位或更多泡；改气泡的任何规则三端一起改（PC `Web/src/orderflow/bigTags.ts`、手机 `Web/src/m/chart/bigTradeSigns.ts`、iOS `KanpanChart/.../BigTradeSigns.swift`），金额写法走各端的 amt / amtShort 不另起。见 `kanpan-bigtrade-page-takes-all-venues-no-descriptions`、`kanpan-no-liquidation-feature`。
