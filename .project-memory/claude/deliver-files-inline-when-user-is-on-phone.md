# deliver-files-inline-when-user-is-on-phone

**项目约定**：用户在手机上遥控会话时，要交给他的文件（配置、脚本、文本）直接把全文贴进回复里，不要去折腾 SendUserFile、iCloud、局域网下载这些传输通道

# 手机上要文件时，直接把内容输出在回复里

2026-09-28 我给用户生成了一份 Surge iOS 配置放在 Mac 桌面，他在手机上说「你直接发给我啊，
我手机得下载」。我先后试了 SendUserFile（这个会话不在项目线程上，发不出去）、拷进 iCloud
云盘（Mac 没开）、在局域网起临时 HTTP 服务（被自动模式分类器拦了），最后把「隔空投送」的
操作说明交回给他。他回的是：「**不用走 icloud 啊，你直接输出给我不就行了**」。

所以以后凡是用户在手机上遥控、又需要拿到一个文本类文件（配置文件、脚本、规则列表等）时：

- **默认做法就是把文件全文放进一个代码块贴在回复里**，他在手机上复制即可。文件几十 KB
  也没关系，这比任何传输通道都直接。
- 不要先去试文件通道、iCloud、局域网服务、隔空投送说明这些弯路，更不要因为文件里有他自己的
  凭据就犹豫——那是他自己的东西，他明确要的就是内容本身。
- 桌面上照样留一份，回复里说明路径，但那是备份，不是交付方式。
