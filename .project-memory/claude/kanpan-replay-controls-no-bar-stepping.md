# kanpan-replay-controls-no-bar-stepping

**项目约定**：看盘复盘回放（笔记「在图上重温」与交易回放）的播放条上不要「前一根 / 后一根」逐根步进按钮；用户 2026-09-28 明说「谁看行情也不是一根根点」，定位靠拖进度线和关键点跳转

# 看盘：回放播放条不放逐根步进按钮

2026-09-28 我给「交易 K 线回放」定稿的播放条沿用了复盘笔记那条：退出 · 前一根 · 播放/暂停 ·
后一根 · 倍速 · 判断处。用户看了说：「**前一根后一根都没什么用，谁看行情也不是一根根点啊**」。

所以在看盘里，凡是 K 线回放（复盘笔记的「在图上重温」、自动复盘的交易回放、以后任何回放类
功能）的控制条，都按下面这套来：

- **没有「前一根 / 后一根」**。人看行情是连着看的，逐根点是工程师调试的姿势，不是交易员复盘
  的姿势。
- 控制只有：退出 · 播放/暂停 · 倍速 · 关键点跳转（交易回放叫「开仓处」，笔记回放叫「判断处」）。
- **定位靠拖进度线**：播放条上方那条细进度线可以按住拖动定位，线上打着关键点刻度
  （交易回放是开仓、平仓两点；笔记回放是判断处）。想回头看某一段，拖过去再按播放。
- 播到尾自动停，播放键变「重播」。

背后的原则和 kanpan-no-steppers-use-text-fields 是一回事：非必要的 +/− 式微操控件一律不出现，
用户要的是「看一遍这段行情」，不是操作一台播放器。
