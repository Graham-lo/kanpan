# 看盘：能做的做到极致，少点击，细节完美，守 UI 规范

2026-09-28 我在解释交易回放「还原不了盘口、新闻、当时的状态」这些边界时，用户回了一句：
「**这个不用管，做到能做的极致和交互体验，尽量让用户少去点击，把细节做完美，注意 ui 规范**」。
这句话是对整个看盘项目的标准，不只针对回放：

- **不要在汇报里花篇幅讲「做不到什么」**。边界一句话带过甚至不提，把能做的那部分做到头。
- **少点击是硬指标**。每个功能落地前数一遍：用户从起点到目的要点几下？能自动做的（进页面就开始、
  播完自动停、退出自动回原处、该聚焦的输入框自动聚焦）一律自动做；不加确认弹窗、不加中间页、
  不加需要人再点一下才生效的开关。这是 kanpan-ui-no-lecturing 与 kanpan-one-entry-per-action
  的延伸。
- **细节要完美**：记号不压住 K 线与价格轴、标签不重叠、动画时长与缓动统一、触感克制、
  数字等宽、加载不闪、失败一句提示并自动回退，读屏标签齐全。「大体能用」不算完成。
- **UI 规范**指苹果 HIG（见 kanpan-ui-follows-hig-type-and-spacing-scales）：44pt 命中区、
  字号成阶梯、边距成体系（20 / 16 / 8）、圆角成套、跟随动态字体与安全区。
