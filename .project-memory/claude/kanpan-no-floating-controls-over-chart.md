# kanpan-no-floating-controls-over-chart

**项目约定**：看盘的 K 线画布上不要浮任何控件，工具一律放到图外面的周期条／底栏／横屏工具栏上

看盘（Kanpan）里「记一笔」原来是一颗浮在主图上、可以拖着到处摆的圆钮，位置还落盘保存。
用户看到之后直接否掉了这个做法：「这个记能不能移动到最右边的不影响主图副图区域的地方，
或者透明化现在有点影响视觉了」，紧接着问「你看看有没有更好的设计」。

所以这个项目的规矩是：**K 线画布（主图 + 副图）上不浮控件**。浮在图上的按钮必然挡图——
它停在哪儿就糊掉哪一块 K 线、均线或价格标签；而且在一张全靠手势操作的图上，它还是一块
点不动的死区（画线时尤其碍事）。「让它半透明」「让用户自己拖开」都只是把问题挪个位置，
不是解法。

正确做法是把工具挪到图**外面**已经有的那几条：竖屏放周期条右端（和「画线」「图表」作伴）
或底栏，横屏放右侧的 `ToolRail`。两个方向摆成同一套，用户不用换一套肌肉记忆。「记」就是
这么收掉的——顺带连可拖动、位置持久化那一整套机制也一起删了，功能一点没少。

以后再想给图上加快捷按钮，先想清楚它能不能放进图外的工具条；放不进去再谈别的，不要
默认往画布上浮。

同一条规矩也管「装饰性的把手」。副图高度原来在每格底边画了一根短粗的横线当拖动把手，
用户一眼就挑了出来：「为什么副图还有几根短粗的横线，这是什么，有点影响视觉了」，
听完解释直接说「把这个去掉，按住区域的那根细线应该也能缩小或者放大区域啊，
为什么要设计这个」。也就是说：**能拖的边界本身就是把手，不要再为它单独画一个可见控件。**
热区（那条十几个点高的透明带）该留就留，可见的那根线撤掉——用户靠已有的分隔线就知道
该按哪儿，多画一根只是往图上又加了一处视觉噪音。
