# kanpan-top-bar-three-discs-more-menu

**工作习惯 / 用户纠正**：看盘行情页顶栏右上 2026-10-08 起只有三颗「提醒铃 · ⋯ · 搜索」；记一笔、分享、添加对比收进「⋯」二级菜单（用户：分享和记一笔用得极少）；「分析」面板里的对比一节照旧保留

2026-10-08 我指出顶栏右上五颗圆片（对比＋ · 铃 · 记一笔 · 分享 · 搜索）太多、没有主次，
16 Pro 带返回键时品种块只剩 122pt 徽章被挤掉。用户回：「**分享和记一笔用的极少，我觉得可以放到二级菜单里**」。

定稿：
- 顶栏右上只剩**三颗**：提醒铃（带未触发条数角标）· 「⋯」更多 · 搜索。三颗步距 12，簇宽 120pt。
- 「⋯」点开二级菜单，项为「添加对比 · 记一笔 · 分享」；id 仍是 `top.compare` / `top.note` / `top.share`，圆片是 `top.more`。
- 「添加对比」在「分析」面板里的那一节不动（见 `kanpan-keep-compare-in-analysis-and-keep-valid-alerts`）。
- 对比集合非空时顶栏不再亮强调色，图上图例已写明在对比哪几只。
- 手机网页版照 iOS 复刻同样的三颗（`kanpan-mobile-web-is-an-ios-replica-fallback`）。

**Why:** 用户按真实使用频率定的：换品种与看提醒是常做的，记一笔、分享、对比是偶尔才做的，不值得各占一颗常驻圆片。
这条**覆盖** `kanpan-chart-page-note-share-icons-and-sector-header` 里「记一笔 / 分享必须是顶栏上一眼可见的图标、不再藏两层」
那一句：当时反对的是藏在「图表设置」面板里，现在是顶栏自己的「⋯」菜单，一步可达，用户认可。

**How to apply:** 以后再有「这张图」上的动作要加入口，往「⋯」菜单里放，不往顶栏再加第四颗；
周期条行尾也仍是三件（`kanpan-interval-bar-indicators-entry-no-return-back`）。
