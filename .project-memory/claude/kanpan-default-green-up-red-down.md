# kanpan-default-green-up-red-down

**项目约定**：看盘 2026-10-03 起所有端一律默认绿涨红跌（iOS、小组件、灵动岛、PC 网页、手机网页），老用户也一次性迁过去；涨跌色开关保留，用户可自己再切回红涨

# 看盘：一律默认绿涨红跌

2026-10-03 用户说：「现在一律默认绿涨红跌」。

这推翻了早先「国内看盘习惯红涨绿跌，出厂就给红涨」的默认值（`Prefs.redUp = true`、
网页 `data-updown="red-up"` 那一套）。「一律」的意思是：

- **所有端的出厂默认都是绿涨红跌**：iOS app、小组件、灵动岛 / 实时活动、PC 网页版、手机网页版。
  新写的任何涨跌配色、占位图、首帧脚本、兜底颜色也按绿涨红跌来。
- **老用户也要迁过去一次**：本地存档、首帧镜像、以及云端同步里存着的「红涨」都要一次性改成绿涨，
  否则同步会把旧值盖回来。迁移只做一次，之后用户自己在设置里切回红涨要尊重，不能再被改掉。
- **涨跌色开关保留**，不是把红涨这一档删掉。

以后再碰涨跌色的默认值、或者写新的涨跌配色时，以这条为准。
