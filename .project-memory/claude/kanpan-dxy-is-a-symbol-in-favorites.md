# kanpan-dxy-is-a-symbol-in-favorites

**项目约定**：看盘的美元指数（DXY）要作为一只普通品种接入（搜得到、能加自选、能开图、能建价格提醒），不是行情页上的一块附加数据；用户 2026-10-05 明说

2026-10-05 用户先问「行情能不能加入美元一些比较重要的数据」，我给的第一版方案把美元指数、
收益率、日历事件当成行情页上附加展示的数据块。用户随后把范围收成「我想要的是美元的实时行情，
事件这些不需要」，开工后又补了一句：「**我其实希望美元 DXY 是作为一个品种来接入的，可以添加自选**」。

所以在看盘里美元指数的定位是**一只品种**，和一只币、一只美股同级：

- 走多交易所那套「品种身份 / 行情提供者 / 线路」正交架构，新 venue `macro`、市场 `index`、
  键 `macro/index/DXY`，展示名「美元指数」。
- 搜索里搜得到（美元 / 美指 / DXY / USD），品种行上有星可以加进自选，自选页里有自己的分类
  「指数」；点进去就是一张完整的行情页（K 线、周期、主图指标、画线、价格提醒都能用）。
- 不是「在 BTC 行情页上加一行美元数据」，也不是只能对比不能单独看。
- 头部六格里它给不出的（持仓、费率、结算、估值）留「—」，主力订单流与条件提醒对它不做。
- 本轮只接 DXY 这一只，不加美债收益率等别的宏观品种；经济日历 / 事件不做。
