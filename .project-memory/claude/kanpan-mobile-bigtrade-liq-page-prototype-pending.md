原型里定下的结构（实现时照此，除非用户改）：
- 不加新标签页、不占常驻面积；K 线上每根一枚大单签（点 / 三角 / 金额胶囊三档，按近 300 根的 P85 / P95 / max(P99, 3×P95) 自动升降）。
- 「大单与爆仓」一开就是整页（一档 780，iOS `.large`），所有卡一次摆全、往下滚看；没有半屏、没有「展开」、不用二次上拉。往下拉过 110 或快速下甩关。2026-10-08 用户试用后改：「做成两次上拉体验不好，直接全部展示即可」。原先的 440/780 两档作废，别再做回去。
- 页内顺序：本根对撞条 → 爆仓（现货不显示）→ 每根走势条 → 价位阶梯 → 24 小时爆仓时间线 → 门槛。
- 只新增一个开关「图上大单签」（放在分析面板主力订单流一节），其余默认开、自动适应。
- 状态齐全：首次打开骨架、服务端未跟踪品种提示、断网重连 toast、今天没爆仓空态、数据停了灰化。

**Why:** 用户 2026-10-08 明确要手机端独立设计，不复制网页版的四块抽屉。
