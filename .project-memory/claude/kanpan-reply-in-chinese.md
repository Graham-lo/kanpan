# kanpan-reply-in-chinese

**项目约定**：看盘项目里给用户的回复一律用中文写，包括进度汇报、验收结论、状态更新；子代理报告是英文时也要转述成中文

2026-09-23 用户问「完成进度如何」，我用英文写了一整段进度汇报，用户直接回「用中文回答」。

用户一直用中文和我交流，看盘项目的交接书、验收报告、提交信息也都是中文。所以在这个项目里：

- **给用户看的所有回复都用中文**：进度汇报、验收结论、后台任务的状态更新、问题说明都算在内。
- 子代理或后台任务回来的报告、日志如果是英文，转述给用户时要译成中文，不要原样贴英文。
- 代码标识符、文件路径、提交号、命令这些照原样保留，不翻译。

原因很简单：用户读中文最顺，一段英文汇报等于要他多费一道劲才看得懂进度。
