# kanpan-favorites-entry-is-the-category-page

**项目约定**：看盘底栏的「自选」必须进带加密／美股分类的那张完整自选页，不是顶栏品种名开的半屏弹层

在把换品种的多个入口收敛成一个的时候，我一度把底栏的「自选」去掉，用户直接指出
「你怎么把自选的入口弄没了」；补回来之后我又让它开顶栏那个半屏快速弹层，用户再次
纠正：「点击自选应该进入自选的那个页面啊」「那个页面不是有加密美股分类吗」
「点击自选跳到分类页面」。

所以看盘（Kanpan）里底栏的「自选」是「去管我的表」，进的是带加密 / 美股分类、分组、
排序、历史的那张完整自选页（`FavoritesView`）。做入口收敛时可以合并搜索这类路径，
但**不要**把底栏自选这一格删掉，也不要把它降级成弹层。

补记（2026-09-18）：当时那个「顶栏品种名开的半屏快速弹层」后来也被用户点名去掉了，
换品种改走顶栏搜索，详见 `kanpan-symbol-name-is-not-a-picker`。
