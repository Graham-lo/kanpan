# 看盘的提醒只响一次，不做重复提醒

2026-09-25 我在做「从图上加提醒」功能时，照 AICoin 的「预警频率」给新建提醒页加了
「仅一次 / 每次（每分钟最多一次）」的频率选择，并准备在客户端与服务端各实现一套
重复触发与去重。用户看到方案后说：「**默认就是触发一次就删除啊，不要搞重复提醒**」。

所以在看盘里：

- 价格提醒的语义就是**触发一次**：碰到（或收盘穿过）目标价响一下，之后这条提醒就完成了
  （现有机制是置成 `fired`，用户要的效果是它不再响）。不需要「每次」「每 N 分钟」这类频率选项，
  界面上不出「频率」行，`Alert.once` 字段保持永远为 true、不实现 false 分支。
- 用户的理由是这就是他心里提醒的默认样子；重复提醒对他是多余的复杂度，不是功能缺口。
  以后参照 AICoin / TradingView 做提醒相关功能时，「预警频率」这一块直接跳过，不要再提。
- 这条和 kanpan-no-flashy-rarely-used-features（华而不实的功能宁可不做）同源：
  参照别家 app 时只搬他真的会用的那几样。
