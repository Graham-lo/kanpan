# kanpan-price-axis-column-narrow

**项目约定**：看盘行情页 K 线图右侧的价格刻度列要窄，宽度按最宽的刻度文字贴着算，不留多余空白；用户 2026-09-20 看真机截图点名说它「不需要这么宽」

2026-09-20 用户拿着真机截图指着行情页 K 线图右边那一列价格刻度（80821.64、79221.26 这些
数字所在的竖条，主图和副图共用）说：「行情页右边的价格区域，也就是图表下方的区域其实可以
稍微缩小一点，不需要这么宽」。当时这一列大约 66pt 宽，刻度文字左右两边都留着明显空白。

所以在看盘里：

- **价格刻度列的宽度按内容算，不是一个宽裕的固定值。** 用当前可见刻度里最宽的那个字串
  （含最新价那个色块标签）的实际宽度加很小的内边距（左右各 3–4pt 量级）来定，品种价位
  小数位多就宽一点、少就窄一点，把横向空间尽量留给 K 线本身。
- **不要为了「以后可能出现更长的数字」预留空白**；宽度是动态的，长数字来了自己会撑开。
- 这条和 kanpan-ui-restrained-element-scale（元素尺寸克制）同向，也和
  kanpan-chart-base-is-not-a-design-target 不冲突——刻度列的宽度是布局，不是 AICoin
  还原的视觉本体。
