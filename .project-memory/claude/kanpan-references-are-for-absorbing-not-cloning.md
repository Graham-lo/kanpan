# kanpan-references-are-for-absorbing-not-cloning

**项目约定**：看盘里拿 TradingView / AICoin 当参照时，吸收的是它布局上的优点，不是把整块界面复刻过来

2026-09-18 我在照 TradingView 手机版重做看盘（Kanpan）的画线工具面板时，用户补了一句：
「注意参考的是 tv 布局，不要全部复刻进来，吸收的是它的优点」。

所以在这个项目里，「参照某个 app」永远是**取它某一处的做法好在哪里**，不是把那一屏
整个搬过来。具体到那一轮：从 TV 取的是「工具入口收成一个笔形图标」「面板自带搜索框」
「横向分类标签 + 三列图标格」「横屏工具条摆在底部」这几条，理由都能说清楚（工具有 38 把，
竖栏摆不下、翻起来慢；横屏高度紧、宽度富余；两个拇指都停在下沿）。没有跟着搬的是 TV
底部那排指标 / 闹钟 / 图层 / 回放图标，也没有把我们自己那几个天天要点的东西
（吸附、连续、撤销、重做、隐藏、管理、完成、收藏的工具）换掉——它们本来就好用。

判断标准是能不能讲出「这一条解决了我们的什么问题」。讲不出来的，就是复刻，不要做。
同理见 `kanpan-aicoin-reference-is-the-phone-app` 与
`kanpan-drawing-tools-align-with-tradingview`。
