# kanpan-drawing-bar-shows-few-frequent-tools

**项目约定**：看盘底部的画线工具条只摆少量常用工具，按用户的使用频率智能排，不许把全部工具一字铺满；用户 2026-10-05 明说铺满了体验不好、把别的功能都遮住了

2026-10-05 用户看了画线工作台之后说：「底下的画线工具只展示少量常用的，根据用户的使用频率
智能展示即可，不然全部撑满了，体验不好，把其它功能都遮盖了。」

所以看盘里画线工具条（横屏工作台底部那一条，以及任何把工具一字排开的地方）的规矩是：

- **只露少量常用工具**，不是把 TradingView 对齐来的整套工具全部铺在条上。条上保持短、
  有留白，别压到图表和别的控件。
- **哪几把露出来由使用频率决定**：按这个用户实际用过的次数（近期加权）排序，常用的在前；
  没有使用记录时用一组默认常用（趋势线、水平线、斐波那契回撤这一类）。这是「智能展示」，
  不是让用户自己去配置哪几把常驻（见 kanpan-minimal-settings-surface）。
- **其余工具收进一个「更多 / 全部」入口**，功能一把都不能少（见 kanpan-finish-features-completely），
  只是不常驻。
- 使用频率这类数据按 kanpan-preferences-follow-the-person-instantly 跟人走、落盘并同步。
