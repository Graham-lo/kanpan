# kanpan-chart-page-note-share-icons-and-sector-header

**项目约定**：（顶栏那半截已被 2026-10-08 的 kanpan-top-bar-three-discs-more-menu 覆盖：记一笔 / 分享现在在顶栏「⋯」二级菜单里）看盘行情页的「记一笔」「分享」不该藏在图表设置里——用户 2026-09-28 定为顶栏上的图标；板块页头部那行只留「跑赢大盘」，品种数与成交额去掉

2026-09-28 我评估看盘的用户体验时指出，「记一笔」和「分享」两个高频动作藏在周期条行尾
「图表设置」面板的「这张图」一节里，想记观点的人不会去点那个滑杆图标。用户认可并给了方向：

> 「分享其实可以放一个 icon 到右上角，记一笔我记得之前左上角有一个书面的标志。你重新布局排列一下看看。」

所以在看盘行情页上：

- **分享是顶栏右上的一枚图标**，和放大镜并列，不再放在面板里。
- **记一笔用早先那种书本 / 笔记本记号**，位置按用户的记忆在顶栏左上（早期版本顶栏左上有过
  `top.review` 复盘入口，2026-09-27 收底栏时被撤到「我的」）。具体排布由我重新布局后给他看，
  但两个动作都必须是图外顶栏上一眼可见的图标，不再藏两层。
- 「图表设置」面板的「这张图」一节随之不再需要这两行。
- 顶栏仍然遵守 kanpan-symbol-name-is-not-a-picker（品种名不是按钮）、
  kanpan-one-entry-per-action（一个动作一个入口）——挪上去之后面板里的那份要删掉。

同一轮还定了**板块页头部**：原来品种列表页头部一行是「43 个品种 · 24/43 跑赢大盘 ·
成交额 967.28M」，在 16 Pro 上换行后数字孤悬。用户说「只需要跑赢大盘这个即可，其它也不需要」，
所以那一行只保留「N/M 跑赢大盘」，品种数与成交额都不再显示。


**2026-10-08 更新：** 用户说「分享和记一笔用的极少，我觉得可以放到二级菜单里」，顶栏收成三颗「铃 · ⋯ · 搜索」，
记一笔 / 分享 / 添加对比进「⋯」菜单。上面「必须一眼可见、不再藏两层」那句不再适用，见 `kanpan-top-bar-three-discs-more-menu`。板块页头部那条仍有效。
