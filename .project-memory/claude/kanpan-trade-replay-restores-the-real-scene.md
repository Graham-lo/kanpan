# kanpan-trade-replay-restores-the-real-scene

**项目约定**：看盘自动复盘里「交易回放」的目标是把交易所开单历史尽量还原成当时的真实场景（当时的 K 线怎么走、找回当时的感觉），不是做一个 K 线动画播放器；设计取舍都以「更像当时」为准

# 看盘：交易回放的价值在「还原当时的真实场景」

2026-09-28 用户在定交易 K 线回放的设计时说：「**最有价值的我觉得是把交易所的开单历史记录
尽量还原成真实场景，当时的 k 线怎么走，找回当时的感觉**」。这是这个功能的目标函数，
以后所有细节取舍都按它来判断，而不是按「播放器功能全不全」。

具体含义：

- **看的是用户自己当时会看的那张图**：周期优先取他自己常用 / 上次在这只品种上用的周期
  （只要整笔交易在这个周期下落得进合理根数），其次才是服务端为截图挑的周期；主图指标、皮肤
  都是他自己的一套。不是「系统认为合适的图」。
- **不泄露未来**：开仓前只能看到开仓前的 K 线，成交记号要等游标走到那一刻才出现；
  在开仓那根停一下，让人重新体会「那一刻为什么下手」。
- **感觉靠持仓期的浮盈浮亏**：持仓期间按当根收盘算的浮盈浮亏胶囊，是让人重新经历一遍
  当时的煎熬或从容的关键，不能省。
- **和「当时怎么想」那条笔记是一体的**：开仓停顿时把他写过的「当时怎么想」以一行字幕带出来；
  没写过的，回放看完退回详情时把那一格顺手放到眼前，看完当场补一句。
- 播放条越少越好（见 kanpan-replay-controls-no-bar-stepping）：控件多了就成了播放器，
  不是在重看那笔交易。
