# kanpan-chart-base-is-not-a-design-target

**项目约定**：看盘的 K 线图表底座与指标是「还原 AICoin」的成果，不是设计对象；要设计的是图表以外的一切

用户在看盘（Kanpan / 产品名 Hkline）项目里连续两次划定了同一条范围线：K 线图表本体
——图表底座、指标、K 线的绘制与手感——**不参与交互审查，也不参与体验设计**。
理由是这一块的目标是还原手机版 AICoin，是复刻而不是发挥，已经定稿够用了。
他的原话是「k线图表底座指标等不要设计，这是还原 aicoin 的」。

所以在这个项目里收到「审查交互」「设计体验」「让产品更好用」这类请求时，默认范围是
**图表以外的全部**：周期选择条、各主页面的排版与布局、页面之间的过渡与动画、
自选与换品种、复盘、账号与设置、反馈与状态语言、视觉系统。用户点名的例子就是
「周期选择、UI、各个主页面的排版布局、UI 动画过渡、各个主页面的细节体验」。

两侧的自由度完全不同，不要混着用：图表那边要克制、以参照物为准；图表以外的地方
用户明确鼓励**脱离现有功能给全新思路**，因为功能可以后续再加，目的是让程序有
「为用户考虑」的感觉。所以在授权区里提保守的小修小补反而不符合他的要求。
