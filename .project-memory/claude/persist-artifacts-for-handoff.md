# 中间产物要落盘到仓库，因为会有别人接手

用户在看盘项目里明确要求过：**「反编译出来的实现也保存起来，目前额度不够了，后面我
需要交给 codex 来接手」**。

背景是我把 AICoin 安卓包反编译后，源码、资源、实测截图、分析报告全都堆在会话的
scratchpad 临时目录里，只把结论写进了文档。用户指出这不够——他会在额度用完后把这个
项目交给另一个 agent（Codex）继续做，那个 agent 看不到我的会话上下文，也进不了我的
临时目录。

## 因此

- **凡是花了成本产出的素材都要落进仓库**：反编译源码的相关子集、真机实测截图、
  分析报告，而不是只留结论文档。临时目录会被清掉，等于白做。
- **落盘时要附一份来源说明**（README），写清每个目录是什么、从哪来、证据等级怎么排、
  以及「结论已经整理在哪份文档里，不用重读源码」。接手的人应该能零上下文启动。
- 体积要挑过：整包几百 MB 不要全塞进去，只留和当前任务相关的包与资源（我那次筛到
  7.7 MB / 643 个文件）。

这条和 `integrate-findings-not-todo-lists` 配套：那条要求结论直接落地成代码，这条要求
支撑结论的原始素材落地成仓库里的文件。
