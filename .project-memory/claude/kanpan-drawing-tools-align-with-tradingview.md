# kanpan-drawing-tools-align-with-tradingview

**项目约定**：看盘画线的工具清单、工具选择面板、以及每把工具画在图上的形态，都以 TradingView 手机版为基准

2026-09-18 我按「第一批 6 个」的节奏给看盘（Kanpan）的画线加高级工具，用户中途打断说：
「你还是直接把所有工具接入进来吧，工具和 tv 那套对齐，不过手机版有些不用的你不需要加进来」。

所以看盘画线工具的**基准清单是 TradingView 的画线工具全集**，不是我自己挑的一小撮，
也不是分批慢慢加。做法是照 TV 的分类逐项过一遍，默认全都接进来；只有在手机上真的
不好用或没价值的才剔掉，并且要说明理由——典型的是需要自由手绘、点数不定的那几种
（多边线、路径、画笔、荧光笔）。点数固定的工具（XABCD、ABCD、头肩、艾略特波浪等）
都属于「应该接进来」的一类，它们只是点多，不是不可控。

**工具选择面板同样照 TV。** 我一度按 AICoin 做成「右侧竖排分类图标 + 向左弹出的分类
浮层」，用户看过之后说「好像 tv 这种布局更好，点击那个笔画 icon，就弹出这些」，并给了
TV 手机版的截图：底部弹层，标题「绘图」，第一行是搜索框，下面一条横向滚动的分类标签
（形态 / 预测和测量 / 几何形状 / 注释 / 视觉效果…），再下面是三列的图标格子，每格一个
图形缩略图加完整中文名。入口只有一个笔形图标，不是一列分类图标。这一套横竖屏共用。

**每把工具画在图上长什么样，同样照 TV，不要自己改造。** 2026-09-18 我曾把「测量」从一个
矩形改成只连起落两点的一根对角线，理由写在代码注释里：框既不是结构也不是区间，填上底
会把底下的 K 线盖住。用户看到之后直接否掉：「这个测量不对吧，不需要显示这根线啊，测量
可以做成和 tv 那种，是用颜色框起来吧好像」。TV 的量尺就是一个框——框住被量的那段横竖
范围，按涨跌染成绿或红。那根对角线其实什么都不表达，它的斜率只取决于当前缩放。
教训是：工具的画法是这类软件里约定俗成的语言，我觉得「更干净」的改造多半是把用户认得的
形状改没了；要改先问，别在代码注释里给自己立论。

AICoin 仍然是看盘别处**布局与交互**的参照（见 `kanpan-aicoin-reference-is-the-phone-app`），
但画线的工具清单、工具面板、以及工具本身的画法这几件事看 TV。
