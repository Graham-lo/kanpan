# kanpan-chart-and-indicators-one-viewport

**项目约定**：看盘主图与副图指标要同时落在一屏可视区域内，不要靠压缩副图或滚动来腾地方

# 看盘：K 线和指标要在同一个可看区域里

用户明确说过「本来就是要 k 线和指标展示在一个可看区域内」。这是看盘主界面的设计
意图，不是可以商量的排版细节：主图和打开的副图指标（成交量、MACD、RSI 等）必须
**同时**落在竖屏那一屏的可视范围内，用户不需要滚动、也不需要切换才能看到两者。

因此不要提这类「优化」：把主图比例调到 55–60% 再让副图挤在下面、默认只留成交量而
把其它指标关掉、或者让副图区变成可滚动的一条。我曾把这些当成布局改进提出来，用户
直接否掉了——副图少了或者要滚，正是看盘这个场景要避免的事。

真要处理密度问题，方向是在「同屏都看得见」的前提下调，比如缩紧轴与留白、副图自身
的高度分配，而不是把某一块挪出视野。

同屏之外还有一条高度分配上的偏好，用户后来补的：「初始的副图指标上下区域不需要
这么大啊，除了成交量」。也就是说出厂默认里成交量保持满格（它是靠柱子之间的高度差
读的，压扁就读不出长短），MACD / 持仓量 / KDJ 这类读方向和零轴的副图矮一截，省下来
的高度全给主图。用户手动调过高度的副图当然以用户调的为准，这只是没调过时的缺省。
