# kanpan-header-price-and-change

**项目约定**：看盘行情页头部左侧只放最新价和涨跌：价格一行，涨跌额+涨跌幅一行小字紧贴其下（照 AICoin，不用药丸、不横排），24h 高/低不展示，成交额振幅只能是一行小字

在看盘（Kanpan）的行情页里，顶部那一块代表「这个品种现在怎么样」，用户要求它显示的
始终是**最新价和涨跌幅**。一次改版把 24h 高/低/额挪到了行首、把价格压到右边的小字，
用户立刻反馈「我要的是品种的展示价格和涨跌幅怎么变成高低值了」——他一屏扫过去
首先要看到的就是「现在多少钱、今天涨没涨」。

2026-09-17 的改版验收里用户进一步收紧：**24H 高和 24H 低根本不必展示**
（「高低其实没必要展示」）。剩下的成交额、振幅属于背景信息，而且**不要装进方框卡片**
——用户当时看到四张等宽圆角小卡的评价是「方框有点太方了」。正确的做法是一行不带底色的
小字，用「·」隔开。

## 涨跌放在价格正下方，不横排、不做药丸（2026-09-22 定稿）

之前的落地是「22pt 价格 + 一颗填色涨跌幅药丸横排在同一行」。这个横排在闪迪、美光
这类品种上把右侧六格挤到了价格下面。我先按「装不下时才竖排」写了修法，用户看到后
拿 AICoin 的头部截图说：「**涨跌幅度不需要搞这么大浪费空间，直接放到价格下面就行了啊**」。

所以头部左侧的定稿结构是（照 AICoin）：

- 第一行：最新价，22pt medium 等宽数字，这是唯一的大字。
- 第二行：紧贴其下的一行小字 `+6.72  +0.64%`——涨跌额 + 涨跌幅，涨跌色的**文字**，
  没有药丸底色、没有圆角矩形、没有箭头图标。
- **永远这一种布局**，不做「宽屏横排、窄屏竖排」的分档；价格块窄了，右侧六格（仓/市值/结算 ·
  额/费率/振幅）永远在价格右边，头部高度由六格的三行决定，不会长高。
- 自选表里那一列的涨跌幅药丸不受影响，这条只管行情页头部。

字号原则不变：用户早先说过「行情页面左上角价格也太大太粗糙了」，**主角地位靠对比而不是
靠加字号**，22pt 等宽数字就够抢眼，不要再往大里加，也不要给它配更重的字重。
